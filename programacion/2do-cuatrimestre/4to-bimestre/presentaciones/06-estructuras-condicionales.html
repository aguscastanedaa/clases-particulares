02 El Problema: Un Programa Que Siempre Hace Lo Mismo

Hasta ahora nuestros programas ejecutaban todas las instrucciones, en orden, siempre. Esto se llama flujo secuencial. Pero en la vida real decidimos:

☔ "Si llueve..."

...llevo paraguas; si no, no.

🎟️ "Si sos mayor de 18..."

...podés entrar; si no, no.

📝 "Si la nota es..."

Mayor o igual a 9, excelente; si no, si es mayor o igual a 6, aprobado; si no, desaprobado.

Definición

Una estructura condicional permite que el programa elija qué instrucciones ejecutar según el resultado de una condición (True o False). El flujo deja de ser una línea recta y pasa a tener caminos.

03 Los Tipos de Estructuras Condicionales

Comparación con C

En C: if (...) {}, else if (...) {}, else {}. En Python se abrevia else if como elif, se eliminan los paréntesis obligatorios y las llaves, y se agregan dos puntos : más la indentación.

CC
if (nota >= 6) { printf("Aprobado"); } else { printf("Desaprobado"); }
PythonPython
if nota >= 6: print("Aprobado") else: print("Desaprobado")

06 Diagrama de Flujo del if

Cómo leerlo

  • El rombo es la pregunta (condición).
  • Si la respuesta es Sí (True), se ejecuta la caja del bloque.
  • Si es No (False), el programa se salta el bloque.
  • En ambos casos el programa continúa con la instrucción que sigue.
flujo_if.pyCódigo del diagrama
if edad >= 18: print("Mayor") print("Continúa")

13 Ejemplo del Apunte: Clasificar una Nota

clasificar_nota.pyPython
nota = 8 if nota >= 9: print("Excelente") elif nota >= 6: print("Aprobado") else: print("Desaprobado")
Salida en consola● ● ●
Aprobado
1
Python pregunta primero nota >= 9 → 8 >= 9 → False. Saltea ese bloque.
2
Pregunta nota >= 6 → 8 >= 6 → True. Ejecuta ese bloque: muestra Aprobado.
3
Como ya encontró una condición verdadera, no evalúa nada más (ni siquiera el else). Sigue con lo que viene después de toda la estructura.

Regla de oro

Python evalúa de arriba hacia abajo y ejecuta solo el PRIMER bloque cuya condición sea True. Los demás se ignoran, aunque también fueran verdaderos.

21 Condicionales Anidados

Definición

Un condicional anidado es un if dentro del bloque de otro if. La decisión interna solo se evalúa si se cumplió la externa. Cada nivel agrega 4 espacios más de sangría.

anidado.pyPython
edad = 20 tiene_entrada = True if edad >= 18: if tiene_entrada: print("Puede ingresar") else: print("Necesita comprar entrada") else: print("Es menor de edad")
Salida en consola● ● ●
Puede ingresar
1
El if edad >= 18 externo decide si es mayor.
2
Solo si lo es, entra al bloque y evalúa el if tiene_entrada interno.
3
El else del nivel interno y el del nivel externo se distinguen por la sangría: pertenecen al if que tiene su mismo nivel.

Con and (una sola decisión)

Anidado (decisiones separadas)

Más de dos o tres niveles de anidamiento vuelven el código ilegible. Si te pasa, probá combinar condiciones con and/or o usar elif.

33 Buenas Prácticas con Condicionales

Hacé

  • 4 espacios por nivel de sangría.
  • Validá los datos primero.
  • Ordená los elif de lo más específico a lo más general.
  • Usá nombres booleanos claros: if es_mayor:.
  • Probá todos los caminos y los valores de borde.
  • Dejá un comentario si la condición no es obvia.

Evitá

  • Anidar más de 2 o 3 niveles.
  • Repetir el mismo bloque en varias ramas.
  • Escribir condiciones imposibles (x < 5 and x > 10).
  • Comparar con == True.
  • Usar varios if cuando las opciones son excluyentes.

Pedí los tres lados de un triángulo. Primero verificá que sea válido (cada lado menor que la suma de los otros dos). Si lo es, indicá si es equilátero (3 lados iguales), isósceles (2 iguales) o escaleno (todos distintos).

👁️ Ver solución
ejercicio4.pyPython
a = float(input("Lado a: ")) b = float(input("Lado b: ")) c = float(input("Lado c: ")) if a < b + c and b < a + c and c < a + b: if a == b == c: print("Equilátero") elif a == b or b == c or a == c: print("Isósceles") else: print("Escaleno") else: print("No forma un triángulo")
Salida en consola● ● ●
Lado a: 5 Lado b: 5 Lado c: 8 Isósceles

38 Resumen de la Unidad 06

Ideas clave

  • if condicion: ejecuta su bloque solo si es True.
  • else: es el camino cuando no se cumple.
  • elif permite más de dos caminos; se ejecuta solo el primer bloque verdadero.
  • Se puede anidar (cada nivel, 4 espacios más).
  • Dos puntos + indentación reemplazan a ( ) y { } de C.
  • Probá siempre los bordes y todos los caminos.

Checklist de autoevaluación

✓ ¿Sé qué bloque se ejecuta con cada valor?
✓ ¿Entiendo por qué el orden de los elif importa?
✓ ¿Distingo varios if de un if-elif?
✓ ¿Puedo seguir un condicional anidado con una tabla?
✓ ¿Recuerdo los : y la indentación?
