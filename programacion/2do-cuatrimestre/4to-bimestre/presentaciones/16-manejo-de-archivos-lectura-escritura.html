01 Hoja de Ruta: De fopen a open

Lo que ya conocemos de C

  • Trabajar con archivos requería un puntero FILE *.
  • Se abría con fopen("datos.txt", "w") y se cerraba con fclose.
  • Se escribía con fprintf y se leía con fscanf o fgets.
  • Los modos eran "r", "w", "a".

Lo que vamos a aprender en Python

  • Por qué necesitamos archivos (persistencia).
  • open() y sus modos.
  • Escribir: write(); leer: read(), readline(), recorrer con for.
  • close() y la forma segura: with open().
  • Rutas, codificación y errores frecuentes.

🎯 Meta: que puedas guardar información en un archivo y recuperarla en otra ejecución, sin perder datos ni dejar archivos abiertos.

02 El Problema: Los Datos Se Pierden al Terminar

Hasta ahora...

Todos los datos que usamos (variables, listas, matrices) viven en la memoria RAM mientras el programa se ejecuta. Cuando el programa termina, desaparecen.

sin_persistencia.pyPython
notas = [] for i in range(3): notas.append(int(input(f"Nota {i + 1}: "))) print("Guardadas:", notas)
Salida en consola● ● ●
Nota 1: 8 Nota 2: 6 Nota 3: 9 Guardadas: [8, 6, 9]

Al ejecutar de nuevo

Hay que volver a escribir todas las notas: el programa no recuerda nada de la ejecución anterior.

La solución: archivos

Un archivo guarda información en el disco, donde permanece aunque el programa termine (¡o se apague la computadora!).

Ejemplos reales

  • Guardar nombres de alumnos y notas.
  • Registrar un historial de compras.
  • Guardar la configuración o el progreso de un juego.

04 El Ciclo de Vida de un Archivo: Abrir, Usar, Cerrar

🚪 Analogía: una puerta

Para entrar a una habitación hay que abrir la puerta, hacer lo que necesitás y cerrarla al salir. Si la dejás abierta, gastás recursos y puede haber problemas.

Siempre los tres pasos

Olvidar cerrar un archivo puede hacer que los datos no se guarden realmente en el disco. Python tiene una forma que cierra solo: with (la vemos en breve).

Es exactamente el mismo ciclo: fopen → fprintf/fgets → fclose. Cambian los nombres y la sintaxis.

Qué pasó

Comparación con C

En C, fprintf(archivo, "%d\n", edad) formateaba el número. En Python se arma el texto primero (f-string) y recién ahí se escribe.

10 ¿Por Qué Hay Que Cerrar el Archivo? close()

Qué hace close()

  • Guarda de verdad los datos pendientes (Python los acumula en un búfer y los envía al disco en bloques).
  • Libera el archivo para que otros programas puedan usarlo.
  • Libera los recursos del sistema.

Si no se cierra

  • Puede que los datos no se guarden completos.
  • El archivo queda bloqueado (en Windows, no podés borrarlo ni abrirlo desde otro programa).
  • Un programa que abre muchos archivos sin cerrarlos puede agotar los recursos.
escribir_cerrado.pyCon error
archivo = open("prueba.txt", "w") archivo.write("dato") archivo.close() archivo.write("otro")
Salida en consola● ● ●
Traceback (most recent call last): File "ejemplo.py", line 4, in <module> archivo.write("otro") ~~~~~~~~~~~~~^^^^^^^^ ValueError: I/O operation on closed file.

Después de close()

Ya no se puede usar el archivo: ValueError: I/O operation on closed file. Para volver a trabajar con él hay que abrirlo de nuevo.

11 El Modo "w" Sobrescribe

sobrescribir.pyPython
archivo = open("saludo.txt", "w") archivo.write("Primera version\n") archivo.close() archivo = open("saludo.txt", "w") archivo.write("Segunda version\n") archivo.close()
📄 saludo.txtArchivo de texto
Segunda version

Qué pasó

La segunda apertura con "w" borró Primera version y dejó solo Segunda version. El modo "w" siempre parte de un archivo vacío.

Entonces...

Usá "w" cuando querés reemplazar todo el contenido (guardar el estado actual). Usá "a" cuando querés conservar lo anterior y sumar datos.

14 El Archivo como una Cinta: la Posición de Lectura

Idea

Al abrir un archivo, Python mantiene una posición actual (un "cursor"). Cada lectura avanza esa posición. Cuando llega al final, no hay más para leer.

posicion.pyPython
archivo = open("datos.txt", "r") primera = archivo.read() segunda = archivo.read() print(repr(primera)) print(repr(segunda)) archivo.seek(0) print(repr(archivo.read())) archivo.close()
Salida en consola● ● ●
'Hola mundo\n' '' 'Hola mundo\n'

La segunda lectura devuelve ""

La primera read() consumió todo: el cursor quedó al final. La segunda no encuentra nada y devuelve un string vacío.

Volver al principio

archivo.seek(0) reposiciona el cursor al inicio. (repr muestra el texto con comillas y \n visibles.)

Cómo funciona

readline() lee una línea (hasta el \n inclusive) y avanza el cursor. La siguiente llamada lee la línea que sigue.

Al terminar el archivo

Cuando no quedan líneas, readline() devuelve "" (string vacío). Con una línea en blanco del archivo devuelve "\n" (no vacío).

17 Recorrer un Archivo Línea por Línea con for

for_archivo.pyPython
archivo = open("alumnos.txt", "r") for linea in archivo: print(linea) archivo.close()
Salida en consola● ● ●
Ana Luis Marta

La forma recomendada

Un archivo abierto se puede recorrer directamente con for: Python entrega una línea por vuelta, sin cargar todo en memoria. Es la forma más eficiente y legible.

¿Por qué sale una línea en blanco de más?

Cada linea ya trae su \n y print agrega otro salto: queda doble espacio. Se soluciona con .strip() (siguiente diapositiva).

18 Limpiar el Salto de Línea: strip() y rstrip()

strip_lineas.pyPython
archivo = open("alumnos.txt", "r") for linea in archivo: nombre = linea.strip() print(f"Alumno: {nombre}") archivo.close()
Salida en consola● ● ●
Alumno: Ana Alumno: Luis Alumno: Marta

linea.strip()

Elimina espacios y saltos de línea del principio y del final de la línea (unidad 12). Es el paso habitual al leer.

linea.rstrip("\n")

Quita solo el salto de línea del final (conserva espacios iniciales, por si importan).

Alternativa

print(linea, end="") también evita el doble salto, pero conviene limpiar el dato para poder usarlo (comparar, convertir).

28 Codificación de Texto: encoding="utf-8"

El problema

Un archivo de texto guarda bytes; la codificación define cómo se traducen a letras. Si escribís y leés con codificaciones distintas, las tildes y la ñ se ven mal (Ã¡ en lugar de á).

utf8.pyPython
with open("saludo.txt", "w", encoding="utf-8") as archivo: archivo.write("Canción: ¡Hola, niño!\n") with open("saludo.txt", "r", encoding="utf-8") as archivo: print(archivo.read())
Salida en consola● ● ●
Canción: ¡Hola, niño!

Recomendación

Siempre agregá encoding="utf-8" al abrir archivos con texto en español: funciona igual en todos los sistemas.

Por qué importa

En Windows, el valor por defecto puede ser otro (por ejemplo cp1252). Con utf-8 explícito evitás sorpresas al compartir archivos.

29 Error Frecuente #1: El Archivo No Existe (FileNotFoundError)

no_existe.pyCon error

Salida en consola● ● ●

Qué pasó

El modo "r" necesita que el archivo ya exista. Si no está en la carpeta actual, Python lanza FileNotFoundError.

Cómo evitarlo

  • Verificar el nombre y la ruta (¡las mayúsculas y la extensión cuentan!).
  • Comprobar antes con os.path.exists.
  • Atrapar el error con try/except (unidad 17).

Comparación con C

En C, fopen devolvía NULL y había que comprobarlo. Python detiene el programa con una excepción si no se maneja.

33 Buenas Prácticas con Archivos

Hacé

  • Usá siempre with open(...).
  • Agregá encoding="utf-8" si hay tildes.
  • Elegí el modo correcto (r, w, a).
  • Limpiá las líneas con strip() antes de usarlas.
  • Convertí los datos al tipo correcto (int, float).
  • Usá nombres de archivo claros (notas_2024.txt).

Evitá

  • Dejar archivos abiertos.
  • Usar "w" sobre un archivo que querés conservar.
  • Cargar todo con read() si el archivo es enorme.

38 Resumen de la Unidad 16

Ideas clave

  • Los archivos guardan datos en el disco (persistencia).
  • Ciclo: abrir (open) → usar → cerrar (close o with).
  • Modos: r lee, w escribe (borra), a agrega, x crea.
  • write() solo texto y sin \n automático; read(), readline(), readlines(), for linea in f.
  • with open(...) as f: cierra solo: usalo siempre.
  • Limpiá con strip(), convertí con int/float y usá encoding="utf-8".
