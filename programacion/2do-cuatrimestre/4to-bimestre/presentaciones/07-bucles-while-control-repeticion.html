02 El Problema: Repetir a Mano

Queremos mostrar los números del 1 al 5. Con lo que sabemos hasta ahora:

a_mano.pyPython
print(1) print(2) print(3) print(4) print(5)
Salida en consola● ● ●
1 2 3 4 5

Problemas

  • ¿Y si fueran 1000 números?
  • ¿Y si la cantidad la elige el usuario?
  • Hay que copiar y pegar código: cualquier cambio obliga a modificar muchas líneas.

La solución

Escribir las instrucciones una sola vez y decirle a Python cuántas veces (o hasta cuándo) repetirlas. Eso es un bucle.

03 ¿Qué Es un Bucle?

Definición

Un bucle (también llamado ciclo o loop) es una estructura que repite un bloque de instrucciones mientras se cumpla una condición. Cada repetición se llama iteración.

🏃 Analogía

Dar vueltas a una pista mientras no completes 5 vueltas. En cada vuelta preguntás: "¿ya completé las 5?".

🔁 Iteración

Una pasada por el bloque. Si el bucle repite 5 veces, tiene 5 iteraciones.

❓ Condición

La pregunta que se evalúa antes de cada iteración para decidir si sigue o termina.

Dos tipos en Python

  • while (hoy): se repite mientras una condición sea verdadera. Ideal cuando no sabemos cuántas veces.
  • for (próxima unidad): recorre una secuencia o repite una cantidad conocida de veces.

05 Ejemplo del Apunte: Contar del 1 al 5

contar.pyPython
i = 1 while i <= 5: print(i) i += 1
Salida en consola● ● ●
1 2 3 4 5

Qué hace cada línea

  • i = 1: inicialización de la variable de control.
  • while i <= 5:: condición, se evalúa antes de cada vuelta.
  • print(i): muestra el valor actual.
  • i += 1: actualización; sin ella el bucle sería infinito.

07 Las Tres Partes de un while Correcto

1. Inicialización

Darle un valor inicial a la variable de control antes del bucle: i = 1.

2. Condición

La pregunta que decide si se repite: while i <= 5:.

3. Actualización

Cambiar la variable de control dentro del cuerpo para acercarse al final: i += 1.

tres_partes.pyPlantilla mental
i = 1 # 1. Inicialización while i <= 5: # 2. Condición print(i) i += 1 # 3. Actualización

Si falta alguna de las tres

  • Sin inicialización → NameError (la variable no existe).
  • Sin actualización → bucle infinito (la condición nunca cambia).
  • Condición mal armada → se repite de más o de menos.

08 Cuando la Condición Es Falsa desde el Principio

cero_iteraciones.pyPython
i = 10 while i <= 5: print(i) i += 1 print("Terminó. i vale", i)
Salida en consola● ● ●
Terminó. i vale 10

Se evalúa ANTES

El while primero pregunta, después ejecuta. Si la condición es falsa desde el inicio, el cuerpo se ejecuta 0 veces.

Comparación con C

Igual que el while de C. (El do-while de C, que ejecuta al menos una vez, no existe en Python: lo veremos más adelante.)

12 Contador: ¿Cuántos Cumplen una Condición?

Un if dentro del while

15 Bucles Infinitos: El Error Más Temido

Definición

Un bucle infinito es un bucle cuya condición nunca se vuelve falsa. El programa se queda repitiendo para siempre (y la pantalla se llena de mensajes o el programa "se cuelga").

❌ Se olvida la actualización
infinito.pyNunca termina
i = 1 while i <= 5: print(i) # ¡falta i += 1!

i siempre vale 1, así que 1 <= 5 es siempre True.

Salida (infinita)● ● ●
1 1 1 1 1 1 1 ... (no termina nunca)

¿Cómo lo detengo?

Presioná Ctrl + C en la terminal: Python interrumpe el programa y muestra KeyboardInterrupt. En un editor, usá el botón de Stop/Detener.

Actualizar en la dirección equivocadawhile i <= 5: con i -= 1Usar i += 1

Chequeo rápido

Antes de ejecutar un while, preguntate: "¿qué línea del cuerpo hace que la condición se vuelva falsa algún día?" Si no encontrás ninguna, hay un bucle infinito.

17 Bucle Infinito Intencional: while True

Idea

A veces queremos un bucle que no tenga una condición natural de fin (un menú, un juego, un servidor). Se escribe while True: y se sale con break cuando corresponde.

while_true.pyPython
contador = 0 while True: contador += 1 print("Vuelta", contador) if contador == 3: break print("Fin")
Salida en consola● ● ●
Vuelta 1 Vuelta 2 Vuelta 3 Fin

Importante

while True sin un break alcanzable es un bucle infinito de verdad. Siempre verificá que alguna condición dentro del bucle lleve al break.

19 continue: Saltear una Iteración

Definición

continue saltea el resto del cuerpo en la iteración actual y vuelve a evaluar la condición para pasar a la siguiente vuelta. El bucle no termina.

continue.pyPython
i = 0 while i < 5: i += 1 if i == 3: continue print(i)
Salida en consola● ● ●
1 2 4 5

Cuidado: la actualización va ANTES del continue

continue_infinito.pySe cuelga en i = 3
i = 0 while i < 5: if i == 3: continue # ¡salta el i += 1! print(i) i += 1

Si continue se ejecuta antes de i += 1, i se queda valiendo 3 para siempre. Por eso en el ejemplo anterior el i += 1 está primero.

Resultado

Ventaja

23 Centinela: Leer Datos Hasta un Valor Especial

Idea

Un centinela es un valor especial (por ejemplo 0) que avisa que se terminó la carga de datos. No se cuenta como un dato más.

centinela.pyPython
suma = 0 cantidad = 0 numero = int(input("Número (0 para terminar): ")) while numero != 0: suma += numero cantidad += 1 numero = int(input("Número (0 para terminar): ")) print(f"Ingresaste {cantidad} números. Suma: {suma}")
Salida en consola● ● ●
Número (0 para terminar): 10 Número (0 para terminar): 25 Número (0 para terminar): 5 Número (0 para terminar): 0 Ingresaste 3 números. Suma: 40

Patrón

Leer antes del bucle → procesar → leer de nuevo al final del cuerpo. El valor centinela corta el ciclo sin ser procesado.

Idea

Cada término es la suma de los dos anteriores: 0, 1, 1, 2, 3, 5, 8.... Necesitamos dos variables que "avancen" juntas.

29 Error Frecuente #1: Off-by-One (Una Vuelta de Más o de Menos)

❌ Empezar en 0 con <= (queríamos 3 saludos)
cuatro_veces.pyCuenta mal
i = 0 while i <= 3: print("Hola") i += 1
Salida en consola● ● ●
Hola Hola Hola Hola
✅ Condición correcta
tres_veces.py3 veces
i = 0 while i < 3: print("Hola") i += 1
Salida en consola● ● ●
Hola Hola Hola
1
Para repetir N veces: empezá en 0 y usá < N; o empezá en 1 y usá <= N.
2
Las dos formas son correctas; el error aparece al mezclarlas (empezar en 0 con <= N da N+1 vueltas).

En el primer ejemplo

Con i = 0 y i <= 3 el contador toma los valores 0, 1, 2 y 3: ¡4 vueltas! Verificá siempre contando a mano las vueltas.

33 Buenas Prácticas con while

Hacé

  • Pensá siempre en las tres partes: inicializar, condición, actualizar.
  • Usá nombres claros: intentos, suma, contador.
  • Probá a mano las primeras y las últimas vueltas con una tabla.
  • Usá while True + break solo cuando no hay una condición natural.
  • Agregá un límite (por ejemplo, máximo de intentos) si hay riesgo de bucle infinito.

Evitá

  • Condiciones imposibles de cumplir.
  • Modificar la variable de control en muchos lugares.
  • Bucles anidados profundos si se puede evitar.
  • Usar continue sin asegurar antes la actualización.
  • Dejar un print de depuración olvidado dentro del bucle.

Ideas clave

  • while condicion: repite el bloque mientras la condición sea True.
  • Tres partes: inicializar, condición, actualizar.
  • La condición se evalúa antes de cada iteración (puede haber 0).
  • Bucle infinito = la condición nunca se vuelve falsa (Ctrl + C para cortar).
  • break sale; continue saltea la iteración.
  • while True + break reemplaza al do-while de C.
