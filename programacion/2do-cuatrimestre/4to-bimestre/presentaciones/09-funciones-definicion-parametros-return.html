01 Hoja de Ruta: De las Funciones de C a las de Python

Lo que ya conocemos de C

  • Una función es un bloque con nombre que hace una tarea (unidad 12 del 1er bimestre).
  • En C se declara el tipo de retorno y el tipo de cada parámetro: int sumar(int a, int b).
  • Necesita prototipos y llaves { }.
  • Se retorna con return.

Lo que vamos a aprender

  • Qué es una función y por qué usarlas.
  • Cómo definirla (def) y cómo llamarla.
  • Parámetros y argumentos.
  • return y la diferencia con print().
  • Funciones que devuelven booleanos.
  • Funciones que llaman a otras funciones.

🎯 Meta: que puedas dividir un problema en funciones pequeñas y entender exactamente qué pasa con los datos cuando se llama a una función y cuando esta devuelve un resultado.

02 El Problema: Código Repetido

Imaginá que un programa necesita mostrar este mismo cartel de bienvenida en tres lugares distintos:

repetido.pyPython
print("====================") print(" Bienvenido al curso") print("====================") print("Primera parte del programa...") print("====================") print(" Bienvenido al curso") print("====================") print("Segunda parte del programa...") print("====================") print(" Bienvenido al curso") print("====================")
Salida en consola● ● ●
==================== Bienvenido al curso ==================== Primera parte del programa... ==================== Bienvenido al curso ==================== Segunda parte del programa... ==================== Bienvenido al curso ====================

Problemas

  • Mismo código copiado varias veces.
  • Si hay que cambiar el cartel, hay que editar todas las copias (y es fácil olvidar una).
  • El programa se vuelve largo y difícil de leer.

La solución

Escribir esas instrucciones una sola vez, ponerles un nombre y llamarlas cada vez que haga falta. Eso es una función.

03 ¿Qué Es una Función?

Definición

Una función es un bloque de código con nombre que realiza una tarea específica. Se define una vez y se puede usar (llamar) todas las veces que se quiera. Puede recibir datos y puede devolver un resultado.

Entrada
Los datos que recibe (parámetros)
→
Proceso
Las instrucciones del cuerpo de la función
→
Salida
El resultado que devuelve (return)

🏭 Analogía: una máquina

Una licuadora: ponés frutas (entrada), la máquina trabaja (proceso) y obtenés jugo (salida). No hace falta saber cómo funciona por dentro para usarla.

Para qué sirven

  • Reutilizar código.
  • Organizar el programa en partes.
  • Evitar repeticiones.
  • Probar cada parte por separado.

06 Definir una Función No la Ejecuta

solo_definir.pyPython
def saludar(): print("Hola mundo") print("Fin del programa")
Salida en consola● ● ●
Fin del programa

Qué pasó

Python leyó def saludar() y recordó que existe esa función, pero no ejecutó su cuerpo. Solo se ejecutó el último print.

Analogía

Definir una función es escribir una receta en el libro. No cocinás nada hasta que decidís prepararla.

Idea clave

Definir (con def) y llamar (con nombre()) son dos pasos distintos. Sin el segundo, el cuerpo nunca se ejecuta.

11 Funciones con Parámetros: Recibir Datos

Definición

Un parámetro es una variable escrita entre los paréntesis del def que recibe un dato cuando se llama a la función. Permite que la misma función trabaje con datos distintos cada vez.

parametro.pyPython

Salida en consola● ● ●

Sin parámetros

cartel() siempre hace lo mismo.

Con parámetros

saludar("Lucía") hace lo mismo para distintos valores: la función se adapta a lo que recibe.

16 Funciones Que Muestran vs. Funciones Que Devuelven

Hasta ahora nuestras funciones mostraban el resultado con print(). Pero muchas veces necesitamos recibir ese resultado para seguir usándolo en otra parte del programa.

Con print() dentro

muestra.pySolo muestra
def sumar(a, b): print(a + b) sumar(5, 3) # muestra 8

El resultado sale por pantalla y se pierde: el programa no puede usarlo.

Con return

devuelve.pyDevuelve
def sumar(a, b): return a + b r = sumar(5, 3) # r vale 8

El resultado vuelve al código que llamó y puede guardarse, calcularse o mostrarse.

Idea

Una función que calcula algo casi siempre debería devolver el resultado (return) y dejar que quien la llama decida si lo muestra o no.

17 return: Devolver un Resultado

return valor_o_expresion
return_basico.pyPython
def doble(numero): return numero * 2 resultado = doble(5) print(resultado)
Salida en consola● ● ●
10
1
doble(5): el parámetro numero recibe 5.
2
return numero * 2: Python calcula 5 * 2 = 10 y termina la función devolviendo ese valor.
3
La llamada completa doble(5) se reemplaza por el valor devuelto (10).
4
resultado = 10: ese valor se guarda en la variable resultado.

Imaginalo así

Cuando una función devuelve algo, la llamada "se convierte" en ese valor: resultado = doble(5) es como escribir resultado = 10.

19 Usar el Valor Devuelto de Distintas Formas

usos_return.pyPython
def doble(n): return n * 2 x = doble(4) # 1) guardarlo print(x) print(doble(10)) # 2) mostrarlo directamente y = doble(3) + doble(5) # 3) usarlo en una cuenta print(y) print(doble(doble(3))) # 4) usarlo como argumento de otra llamada if doble(6) > 10: # 5) usarlo en una condición print("Mayor que 10")
Salida en consola● ● ●
8 20 16 12 Mayor que 10

Idea

Como la llamada se convierte en un valor, puede aparecer en cualquier lugar donde iría un valor: en una asignación, un print, una cuenta, una condición o dentro de otra llamada. Por eso doble(doble(3)) da 12: primero doble(3) → 6, y luego doble(6) → 12.

21 Qué Devuelve una Función Sin return: None

sin_return.pyPython
def saludar(nombre): print("Hola,", nombre) resultado = saludar("Ana") print(resultado) print(type(resultado))
Salida en consola● ● ●
Hola, Ana None <class 'NoneType'>

None

Toda función que termina sin ejecutar un return con valor devuelve automáticamente None: el valor especial que significa "ningún valor".

Error típico

Intentar usar ese None en una cuenta: resultado + 1 → TypeError. Pasa cuando la función mostraba el valor (con print) en lugar de devolverlo.

22 return Termina la Función Inmediatamente

return_termina.pyPython
def probar(): print("Antes del return") return 10 print("Esto NUNCA se ejecuta") valor = probar() print("Recibido:", valor)
Salida en consola● ● ●
Antes del return Recibido: 10

Regla

En cuanto Python ejecuta un return, sale de la función y vuelve a quien la llamó. Las líneas que están después (en ese camino) no se ejecutan.

Equivale a break

Es parecido a break en un bucle, pero sale de toda la función, no solo del bucle.

Varios return posibles

Una función puede tener varios return en distintos caminos (por ejemplo, dentro de un if y un else). Se ejecuta solo uno: el primero que se alcance.

23 Varios return en Caminos Distintos

varios_return.pyPython
def clasificar(nota): if nota >= 9: return "Excelente" elif nota >= 6: return "Aprobado" return "Desaprobado" print(clasificar(10)) print(clasificar(7)) print(clasificar(3))
Salida en consola● ● ●
Excelente Aprobado Desaprobado
LlamadaCaminoDevuelve
clasificar(10)nota >= 9 es True → primer return"Excelente"
clasificar(7)False; nota >= 6 es True → segundo return"Aprobado"

Ventaja

Como return ya sale de la función, no hace falta else para el último caso: si llegó ahí, es porque no se cumplió ninguna de las condiciones anteriores.

24 Funciones Que Devuelven Booleanos

Idea

Una función puede devolver True o False. Es muy útil para darle nombre a una pregunta y usarla después en un if o un while.

funcion_booleana.pyPython
def es_par(numero): return numero % 2 == 0 print(es_par(10)) print(es_par(7)) if es_par(10): print("Es par")
Salida en consola● ● ●
True False Es par

Cómo funciona

numero % 2 == 0 ya es un True/False: la función lo devuelve directamente. No hace falta escribir if ...: return True else: return False.

Se lee como una frase

if es_par(10): → "si es par el 10". Los nombres como es_..., tiene_... o puede_... dejan claro que devuelve un booleano.

Dividir y conquistar

Un problema grande se descompone en funciones pequeñas, cada una con una sola tarea, que se combinan entre sí. Es la base de un programa ordenado.

Observá

  • mayor_de_dos(mayor_de_dos(4, 9), 6) reutiliza la función para comparar tres valores.

28 Ejemplo: ¿Es Primo? (Función con Bucle y Booleano)

es_primo.pyPython
def es_primo(n): if n < 2: return False for divisor in range(2, n): if n % divisor == 0: return False return True for numero in [1, 2, 9, 13, 20, 29]: print(numero, "->", es_primo(numero))
Salida en consola● ● ●
1 -> False 2 -> True 9 -> False 13 -> True 20 -> False 29 -> True
1
Los menores que 2 no son primos: se devuelve False enseguida.
2
Se prueban todos los divisores desde 2 hasta n - 1. Si alguno divide a n, se devuelve False y la función termina (el return actúa como un break).
3
Si el bucle termina sin encontrar divisores, el último return True indica que es primo.

33 Error Frecuente #3: return Mal Ubicado

❌ return dentro del bucle

Salida en consola● ● ●

✅ return al final, fuera del bucle
return_afuera.pyOK
def sumar_hasta(n): total = 0 for i in range(1, n + 1): total += i return total print(sumar_hasta(4))
Salida en consola● ● ●
10

Qué pasó

El return dentro del for termina la función en la primera vuelta y devuelve 1. Para devolver el total, el return debe estar después del bucle (a la sangría de la función).

35 Buenas Prácticas con Funciones

Hacé

  • Una función = una tarea.
  • Nombres con verbos en snake_case: calcular_total, es_primo.
  • Que las funciones de cálculo devuelvan (return) en lugar de imprimir.
  • Mostrá resultados fuera de la función (en quien la llama).
  • Agregá un docstring a las funciones importantes.
  • Definí todas las funciones antes de usarlas.

Evitá

  • Funciones enormes que hacen de todo.
  • Repetir el mismo bloque en vez de crear una función.
  • Mezclar cálculo, entrada y salida en la misma función.
  • Nombres vagos: funcion1, hacer(), proceso().
  • Olvidar el return y esperar un valor.

40 Resumen de la Unidad 09

Ideas clave

  • Una función es un bloque con nombre que se define (def) una vez y se llama muchas.
  • Definir no ejecuta: hay que llamar con nombre().
  • Parámetro = nombre en el def; argumento = valor en la llamada.
  • return devuelve un valor y termina la función.
  • Sin return, la función devuelve None.
  • print muestra; return entrega el resultado al programa.
