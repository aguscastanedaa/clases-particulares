02 ¿Qué Es un Operador? Anatomía de una Expresión

Definición

Un operador es un símbolo que le indica a Python que realice una operación con uno o más valores. Los valores sobre los que opera se llaman operandos. El conjunto se llama expresión y siempre produce un valor.

precio * cantidad

Operandos

precio y cantidad: los valores con los que se calcula.

Operador

*: indica qué operación hacer (multiplicar).

Resultado

La expresión se evalúa y se convierte en un valor, que podemos guardar o mostrar.

expresion.pyPython
precio = 250 cantidad = 4 total = precio * cantidad print(total)
Salida en consola● ● ●

06 División Real: el Operador /

Definición

El operador / realiza la división matemática normal, con parte decimal si hace falta. El resultado siempre es float.

division.pyPython
print(7 / 2) print(10 / 4) print(9 / 3) print(1 / 3)
Salida en consola● ● ●
3.5 2.5 3.0 0.3333333333333333

Diferencia fundamental con C

CC
/* C */ int r = 7 / 2; /* r vale 3 */

En C, dividir dos enteros da un entero (descarta decimales).

En Python

PythonPython
r = 7 / 2 # r vale 3.5

Dividir con / nunca descarta decimales. Para dividir "como en C" se usa //.

07 División Entera: el Operador //

Definición

El operador // calcula cuántas veces entra el divisor en el dividendo y descarta el resto. Es el cociente entero.

division_entera.pyPython
print(7 // 2) print(20 // 6) print(9 // 3) print(-7 // 2)
Salida en consola● ● ●
3 3 3 -4

Analogía

Repartís 7 caramelos entre 2 amigos: a cada uno le tocan 3 (7 // 2) y sobra 1 (7 % 2).

Números negativos

-7 // 2 da -4 y no -3: // redondea hacia abajo (hacia el menor entero). En C, -7 / 2 daría -3 (trunca). ¡No son equivalentes!

09 El Módulo (%): el Resto de una División

Definición

El operador % (módulo) devuelve el resto de la división entera: lo que sobra.

modulo.pyPython
print(15 % 7) print(10 % 5) print(7 % 2) print(3 % 10)
Salida en consola● ● ●
1 0 1 3
CuentaCociente (//)Resto (%)Comprobación
15 ÷ 7217 × 2 + 1 = 15
10 ÷ 5205 × 2 + 0 = 10

3 ÷ 100310 × 0 + 3 = 3

Fórmula

dividendo = divisor × cociente + resto. Cuando el dividendo es menor que el divisor, el cociente es 0 y el resto es el propio dividendo.

10 Aplicaciones del Módulo (1/2): Pares, Impares y Divisibilidad

¿Par o impar?

  • Un número es par si n % 2 == 0.
  • Es impar si n % 2 == 1.

¿Divisible por otro?

  • a es divisible por b si a % b == 0 (el resto es cero).
divisibilidad.pyPython
print(14 % 7 == 0) print(20 % 2 == 0) print(15 % 7 == 0) print(9 % 2 == 1)
Salida en consola● ● ●
True True False True

Cómo leer 14 % 7 == 0

Primero se calcula 14 % 7 → 0. Después se compara 0 == 0 → True. (La comparación == la estudiamos en la unidad siguiente.)

13 Potencia: el Operador

Definición

base ** exponente eleva la base al exponente: multiplica la base por sí misma tantas veces como indique el exponente.

potencia.pyPython
print(2 ** 3) print(5 ** 2) print(10 ** 0) print(9 ** 0.5) print(2 ** -1)
Salida en consola● ● ●
8 25 1 3.0 0.5

Casos útiles

  • x ** 2 → el cuadrado.
  • x ** 0.5 → la raíz cuadrada.
  • 2 ** -1 → 0.5 (exponente negativo = inversa).
❌ Error de C

2 ^ 3 no es potencia en Python: ^ es otro operador (XOR bit a bit) y devuelve 1.

14 Orden de las Operaciones (Precedencia)

Cuando una expresión tiene varios operadores, Python los resuelve en un orden fijo, igual que en matemática:

PrioridadOperadoresSe resuelve
1 (mayor)( ) paréntesisPrimero lo de adentro
2** potenciaAntes que multiplicar
3-x signo negativo
4* / // %De izquierda a derecha
5 (menor)+ -De izquierda a derecha
precedencia.pyPython
print(2 + 3 * 4) print((2 + 3) * 4) print(2 * 3 ** 2) print(-2 ** 2) print(10 - 4 - 3)
Salida en consola● ● ●
14 20 18 -4 3

Tres que sorprenden

  • 2 + 3 * 4 = 14 (primero 3 * 4).
  • -2 ** 2 = -4: primero la potencia (2 ** 2 = 4) y después el signo.
  • 10 - 4 - 3 = 3: de izquierda a derecha.

15 Paréntesis: Cuándo y Por Qué Usarlos

❌ Sin paréntesis (error lógico)
promedio_mal.pyResultado incorrecto
n1, n2, n3 = 6, 8, 10 print(n1 + n2 + n3 / 3)
Salida en consola● ● ●
17.333333333333332
✅ Con paréntesis
promedio_ok.pyCorrecto
n1, n2, n3 = 6, 8, 10 print((n1 + n2 + n3) / 3)
Salida en consola● ● ●
8.0

Qué pasó

Sin paréntesis, solo n3 se divide por 3 (10 / 3 = 3.33) y luego se suman los otros dos. Los paréntesis fuerzan a sumar primero.

Regla práctica

Ante la duda, usá paréntesis: no cuestan nada y vuelven la expresión más clara para quien la lea. (La línea n1, n2, n3 = 6, 8, 10 asigna tres variables a la vez.)

29 Buenas Prácticas con Operaciones

Hacé

  • Un espacio a cada lado del operador: a + b.
  • Paréntesis para aclarar el orden aunque no sean obligatorios.
  • Nombres con significado: total, descuento.
  • Guardá resultados intermedios en variables.
  • Probá con valores sencillos que puedas verificar a mano.

Evitá

  • Expresiones larguísimas en una sola línea.
  • Usar / cuando necesitás un entero (o // cuando necesitás decimales).
  • Escribir "números mágicos" sin nombre: usá IVA = 21.
  • Dividir sin verificar que el divisor no sea cero.

34 Resumen de la Unidad 04

Ideas clave

  • Operadores: + - * / // % **.
  • / siempre da float; // da el cociente entero.
  • % da el resto: sirve para pares, divisibilidad y dígitos.
  • Precedencia: ( ) → ** → * / // % → + -.
  • x += 1 reemplaza a x++ (que no existe).
  • ZeroDivisionError si el divisor es 0.
