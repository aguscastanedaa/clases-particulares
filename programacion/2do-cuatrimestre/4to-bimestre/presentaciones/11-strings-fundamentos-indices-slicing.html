01 Hoja de Ruta: Del char[] de C al str de Python

Lo que ya conocemos de C

  • El texto se guardaba en un arreglo de char: char nombre[20];.
  • Terminaba con el carácter nulo \0.
  • Había que usar strlen, strcpy, strcat, strcmp de string.h.
  • Los índices empezaban en 0.

Lo que vamos a aprender en Python

  • El tipo str: no hay \0, ni tamaño fijo.
  • Índices positivos y negativos.
  • len() y recorrer con for.
  • + y * con textos, y los operadores in / not in.
  • Slicing: cortar partes de un texto.
  • Por qué los strings son inmutables.

🎯 Meta: que puedas acceder a cualquier parte de un texto (un carácter o un fragmento) y que entiendas por qué no se puede modificar una letra directamente.

02 ¿Qué Es un String?

Definición

Un string (cadena de caracteres) es una secuencia ordenada de caracteres: letras, números, símbolos o espacios que representan texto. En Python su tipo se llama str.

que_es_string.pyPython
nombre = "Agustin" saludo = 'Hola, ¿cómo estás?' codigo = "A-104" numeros = "12345" vacio = "" print(nombre, type(nombre)) print(saludo) print(len(vacio))
Salida en consola● ● ●
Agustin <class 'str'> Hola, ¿cómo estás? 0

Es una secuencia

Cada carácter ocupa una posición y el orden importa: "roma" y "amor" tienen las mismas letras, pero son textos distintos.

Comparación con C

No hay char nombre[20], ni tamaño máximo, ni \0 final: Python se ocupa de la memoria. Un carácter suelto es también un str (de longitud 1).

08 Error: Índice Fuera de Rango (IndexError)

fuera_de_rango.pyCon error
palabra = "Hola" print(palabra[4])
Salida en consola● ● ●
Traceback (most recent call last): File "ejemplo.py", line 2, in <module> print(palabra[4]) ~~~~~~~^^^ IndexError: string index out of range

Qué pasó

"Hola" tiene 4 caracteres: índices 0, 1, 2, 3. El índice 4 no existe: Python avisa con IndexError: string index out of range.

Rangos válidos

Con n caracteres:

  • Positivos: de 0 a n − 1.
  • Negativos: de −1 a −n.

Comparación con C

En C, leer fuera del arreglo no daba error: leía memoria que no era tuya (comportamiento indefinido). Python se detiene y avisa: más seguro.

La forma más simple

Python entrega un carácter por vuelta, de izquierda a derecha, y termina solo. No necesitás índices. Usala cuando solo te importan los caracteres, no sus posiciones.

Comparación con C

En C: for (i = 0; texto[i] != '\0'; i++). En Python no hay que buscar el final.

20 Los Strings Son Inmutables

Definición

Inmutable significa que no se puede modificar una vez creado. No se puede cambiar un carácter de un string "en el lugar": hay que crear uno nuevo.

inmutable.pyCon error
palabra = "hola" palabra[0] = "H"
Salida en consola● ● ●
Traceback (most recent call last): File "ejemplo.py", line 2, in <module> palabra[0] = "H" ~~~~~~~^^^ TypeError: 'str' object does not support item assignment

Qué pasó

Intentamos asignar a una posición: TypeError: 'str' object does not support item assignment ("un str no admite asignación por índice").

Comparación con C

En C, palabra[0] = 'H'; sí funcionaba (el arreglo de char era modificable). En Python es distinto: no mezcles las reglas.

21 Cómo "Modificar" un Texto: Crear Uno Nuevo

crear_nuevo.pyPython
palabra = "hola" nueva = "H" + palabra[1:] print(nueva) print(palabra) palabra = "H" + palabra[1:] print(palabra) otra = palabra[:-1] + "!" print(otra)
Salida en consola● ● ●
Hola hola Hola Hol!
1
"H" + palabra[1:] arma un string nuevo: la H más el resto (ola) del original.
2
El original no cambió (palabra sigue siendo "hola"): así se ve que el texto no se modificó.
3
palabra = "H" + palabra[1:] reasigna la variable: ahora apunta al string nuevo.

Diferencia clave

Modificar un texto ≠ reasignar una variable. El texto "hola" sigue igual en memoria; la variable simplemente pasó a apuntar a otro texto.

22 Caracteres y Códigos: ord() y chr()

Idea

Cada carácter tiene un código numérico. ord(c) devuelve el código de un carácter y chr(n) devuelve el carácter de un código. (En C, un char era ese número.)

ord_chr.pyPython
print(ord("A"), ord("B"), ord("a"), ord("0")) print(chr(65), chr(97), chr(48)) print(chr(ord("A") + 2)) print("a" < "b", "Z" < "a")
Salida en consola● ● ●
65 66 97 48 A a 0 C True True

Para qué sirve

Para mover una letra "n posiciones" (cifrado César), comprobar si una letra está entre a y z, o entender por qué las mayúsculas se ordenan antes que las minúsculas.

Diferencia con C

En Python no se puede hacer "A" + 2. Hay que pasar por ord y chr: chr(ord("A") + 2) → "C".

26 Ejemplo: ¿Es un Palíndromo?

Definición

Un palíndromo es una palabra que se lee igual de izquierda a derecha que de derecha a izquierda (neuquen, reconocer).

palindromo.pyPython
def es_palindromo(palabra): return palabra == palabra[::-1] for p in ["neuquen", "reconocer", "python", "a", ""]: print(f"{p!r:12} -> {es_palindromo(p)}")
Salida en consola● ● ●
'neuquen' -> True 'reconocer' -> True 'python' -> False 'a' -> True '' -> True

Idea

Se compara el texto con su inverso ([::-1]). Combina slicing, comparación y una función booleana. {p!r} muestra el texto con comillas, útil para ver el vacío ('').

31 Buenas Prácticas con Strings

Hacé

  • Usá f-strings para armar mensajes.
  • Preferí for c in texto si no necesitás la posición.
  • Usá índices negativos ([-1]) para el final.
  • Usá slicing en lugar de bucles cuando sea posible ([::-1]).
  • Convertí a número (int/float) antes de calcular.
  • Recordá que todo + crea un string nuevo.

Evitá

  • Intentar modificar un carácter con texto[i] = ....
  • Concatenar dentro de bucles muy largos sin necesidad.
  • Comparar textos sin pensar en mayúsculas.
  • Adivinar índices: probá con len() y con ejemplos cortos.
  • Mezclar comillas del mismo tipo dentro del texto.

36 Resumen de la Unidad 11

Ideas clave

  • Un str es una secuencia ordenada de caracteres.
  • Índices: 0 a n − 1 (o −1 a −n). Fuera de rango → IndexError.
  • len(texto) da la cantidad de caracteres.
  • + une, * repite, in busca.
  • Slicing: texto[inicio:fin:paso], el fin no se incluye; [::-1] invierte.
  • Los strings son inmutables: se crean nuevos.
