02 ¿Qué Es Comparar? Preguntas con Respuesta Verdadero o Falso

Definición

Un operador de comparación relaciona dos valores y responde una pregunta de sí o no. El resultado siempre es un valor booleano: True (verdadero) o False (falso).

primera_comparacion.pyPython
edad = 20 print(edad >= 18) print(edad == 25) print(type(edad >= 18))
Salida en consola● ● ●
True False <class 'bool'>

La pregunta

edad >= 18 se lee: "¿la edad es mayor o igual que 18?"

La respuesta

Como 20 es mayor o igual que 18, la respuesta es True. Con edad == 25 la respuesta es False.

04 Asignación (=) vs. Comparación (==)

= se lee "se guarda en" y == se lee "es igual a".

05 Comparando Números: int y float

numeros.pyPython
print(5 == 5.0) print(7 > 3.5) print(10 / 4 == 2.5) print(3 != 3) print(0.1 + 0.2 == 0.3)
Salida en consola● ● ●
True True True False False

int y float se comparan bien

5 == 5.0 es True: Python compara el valor numérico, no el tipo.

Cuidado con los decimales

0.1 + 0.2 == 0.3 da False por el pequeño error de redondeo de los float (lo vimos en la unidad 02). Nunca confíes en == con resultados de cuentas decimales.

Solución habitual

Comparar si la diferencia es muy pequeña: abs((0.1 + 0.2) - 0.3) < 0.000001 → True. O trabajar con enteros (centavos).

16 Rangos de Valores: dentro y fuera

rangos.pyPython
nota = 7 print(nota >= 1 and nota <= 10) print(1 <= nota <= 10) nota = 15 print(nota < 1 or nota > 10) print(not (1 <= nota <= 10))
Salida en consola● ● ●
True True True True

Dentro del rango → and

Debe cumplir las dos condiciones a la vez: nota >= 1 and nota <= 10.

Fuera del rango → or

Alcanza con que una falle: nota < 1 or nota > 10.

Error clásico

"Fuera de rango" con and (nota < 1 and nota > 10) nunca es verdadero: ningún número es menor que 1 y mayor que 10 a la vez.

17 El Gran Error de Principiantes: x == 2 or 7

Queremos preguntar "¿la categoría es 2 o es 7?". Mucha gente lo escribe como se dice en español:

error_or.pyError lógico
categoria = 5 if categoria == 2 or 7: print("Categoría especial") else: print("Categoría común")
Salida en consola● ● ●
Categoría especial

Por qué sale "especial" con 5

Python lee (categoria == 2) or 7. Como categoria == 2 es False, mira 7, y 7 cuenta como verdadero (cualquier número distinto de cero lo es). Entonces la condición siempre es verdadera.

✅ Forma correcta
correcto.pyOK
categoria == 2 or categoria == 7 # o más corto: categoria in (2, 7)

Cada lado del or debe ser una pregunta completa.

21 Cortocircuito: Python No Evalúa lo Innecesario

Idea

Python evalúa de izquierda a derecha y se detiene apenas conoce el resultado. Si en un and el primer valor es False, el total ya es False; si en un or el primero es True, el total ya es True.

cortocircuito.pyPython
a = 10 b = 0 print(b != 0 and a / b > 2) print(b == 0 or a / b > 2)
Salida en consola● ● ●
False True

Qué pasó

En ambas líneas, a / b nunca se ejecutó: si se hubiera ejecutado, daría ZeroDivisionError. La primera parte ya decidió el resultado.

Para qué sirve

Ordenar las condiciones para proteger operaciones peligrosas: primero la verificación y después la cuenta. En C pasa exactamente lo mismo con && y ||.

29 Buenas Prácticas con Condiciones

Hacé

  • Usá nombres booleanos descriptivos: es_mayor, tiene_entrada.
  • Descomponé condiciones largas en variables intermedias.
  • Usá paréntesis al mezclar and con or.
  • Preferí 1 <= x <= 10 o x in (...).
  • Probá cada condición con valores en el borde (por ejemplo 17, 18 y 19).

  • Comparar con == True o == False.
  • x == 2 or 7 (cada lado debe ser una pregunta completa).

34 Resumen de la Unidad 05

Ideas clave

  • Comparar produce True o False (tipo bool).
  • == pregunta; = guarda.
  • and: todas verdaderas. or: al menos una. not: invierte.
  • Precedencia: comparación → not → and → or.
  • 1 < x < 10 funciona en Python.
  • Cada lado de and/or debe ser una condición completa.
