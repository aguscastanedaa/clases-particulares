02 Repaso: ¿Qué Es Programar?

Antes de ver Python, recordemos la idea central que ya conocemos de C:

Un programa es una receta

Una receta de cocina es una lista de pasos ordenados: "romper dos huevos", "batirlos", "agregar sal". Si cambiás el orden o salteás un paso, el resultado cambia.

Un programa es lo mismo: una lista de instrucciones que la computadora ejecuta una por una, de arriba hacia abajo.

Un lenguaje es la forma de escribir la receta

La computadora no entiende el español. Necesitamos un lenguaje de programación: un conjunto de palabras y reglas para escribir instrucciones.

  • C es un lenguaje.
  • Python es otro lenguaje.

Cambian las palabras y las reglas, pero la forma de pensar (secuencia, decisiones, repeticiones) es la misma.

💡 Todo lo que aprendiste pensando en C te sirve en Python: cambia la escritura, no la lógica.

03 ¿Qué Es Python?

Definición:

Python es un lenguaje de programación de alto nivel, de propósito general e interpretado, creado por Guido van Rossum y publicado por primera vez en 1991. Su filosofía es que el código sea fácil de leer y de escribir.

¿Alto nivel?

Se parece más al lenguaje humano que al lenguaje de la máquina. Nos ocupamos del problema, no de los detalles internos del procesador.

¿Propósito general?

Sirve para casi todo: no está limitado a un solo tipo de programa.

¿Interpretado?

Un programa llamado intérprete lee tu código y lo va ejecutando. Lo vemos en detalle enseguida.

04 ¿Para Qué Se Usa Python en el Mundo Real?

Python es hoy uno de los lenguajes más usados del mundo, precisamente por ser tan versátil:

🌐 Desarrollo web

Sitios y servicios que funcionan "detrás" de las páginas.

📊 Ciencia de datos

Analizar y graficar grandes cantidades de información.

🤖 Inteligencia artificial

Gran parte de las herramientas de IA y aprendizaje automático se programan en Python.

⚙️ Automatización

Scripts que renombran archivos, envían mails o procesan planillas por vos.

🎮 Juegos y simulaciones

Prototipos de juegos, simulaciones científicas y robótica.

🎓 Educación

Es muy elegido para aprender a programar porque su sintaxis es limpia.

Y como C y Python son lenguajes distintos, un buen programador usa cada uno donde mejor rinde: C cerca del hardware, Python para resolver rápido.

07 Compilado (C) vs. Interpretado (Python)

La computadora solo entiende código máquina. Alguien tiene que traducir lo que escribimos. Hay dos estrategias:

Lenguaje compilado — C

Escribís programa.c
→
El compilador traduce TODO el programa
→
Se genera un ejecutable (.exe)
→
Ejecutás el .exe

Analogía: traducir un libro completo antes de publicarlo. Si hay un error, el compilador avisa antes de ejecutar nada.

Lenguaje interpretado — Python

Escribís programa.py
→
El intérprete (python) lee tu código
→
Va ejecutando instrucción por instrucción
→
Ves el resultado al instante

Analogía: un intérprete en vivo que traduce frase por frase mientras la persona habla. No hay un ".exe" intermedio que tengas que generar vos.

08 ¿Qué Implica Ser Interpretado?

Ventajas

  • Probás cambios al instante: editás y ejecutás.
  • No hay paso de compilación separado.
  • Ideal para experimentar y aprender.
  • Existe un modo interactivo para probar una línea sola.

Cosas para tener en cuenta

  • Un programa interpretado suele ser más lento que uno en C.
  • Algunos errores recién aparecen cuando esa línea se ejecuta, no antes.
  • Para correr el programa hace falta tener Python instalado.

Una precisión técnica

Por dentro, Python primero traduce tu archivo a un formato intermedio llamado bytecode y después lo ejecuta. Para nosotros no cambia nada: vos escribís .py y ejecutás con python, sin pasos intermedios visibles.

09 El Mismo Programa en C y en Python

Mostrar "Hola mundo" por pantalla. Comparemos:

hola.cC
#include <stdio.h> int main() { printf("Hola mundo\n"); return 0; }
hola.pyPython
print("Hola mundo")

En C necesitamos...

  • Incluir la biblioteca stdio.h.
  • Escribir la función main.
  • Llaves, ;, \n y return 0.

En Python alcanza con...

  • Una sola línea.
  • print() ya está disponible: no hay que incluir nada.
  • Sin main, sin llaves, sin ;.

18 Los Comentarios (#)

Definición

Un comentario es un texto que escribimos dentro del código para explicarlo a las personas. Python lo ignora por completo: no se ejecuta. Empieza con el símbolo # y llega hasta el final de la línea.

comentarios.pyPython
# Calculamos el área de un rectángulo base = 5 # base en centímetros altura = 3 # altura en centímetros # print(base) <- línea "apagada" print(base * altura)
Salida en consola● ● ●
15

Para qué sirven

  • Explicar por qué se hace algo.
  • "Apagar" una línea temporalmente para probar.
  • Dejar el código claro para vos del futuro y para otros.

Buena práctica

Comentá lo que no es obvio. Un comentario como # suma 1 al lado de x += 1 no ayuda. Mejor: # paso al siguiente alumno.

19 Los Tres Tipos de Errores

Cuando programamos, cometer errores es normal y forma parte del aprendizaje. Se clasifican en:

1) Error de sintaxis

Escribimos algo que rompe las reglas del lenguaje (falta un paréntesis o una comilla). Python no ejecuta nada y avisa.

2) Error de ejecución

La sintaxis es correcta, pero al ejecutar una línea ocurre un problema (usar una variable que no existe, dividir por cero). El programa se detiene en esa línea.

3) Error lógico

El programa funciona sin avisos pero hace algo distinto de lo que queríamos. Python no puede detectarlo: lo detectás probando.

El más difícil de encontrar es el lógico: el programa corre, pero el resultado es incorrecto.

22 Errores Frecuentes #2: Python Distingue Mayúsculas de Minúsculas

Para Python, print y Print son nombres distintos. Solo existe print en minúscula:

error3.pyCon error
Print("Hola mundo")
Salida en consola● ● ●
Traceback (most recent call last): File "ejemplo.py", line 1, in <module> Print("Hola mundo") ^^^^^ NameError: name 'Print' is not defined. Did you mean: 'print'?

Qué pasó

NameError: name 'Print' is not defined significa: "no conozco ningún nombre llamado Print". El intérprete no encontró esa función porque la escribimos con mayúscula.

Cómo se soluciona

Escribir print todo en minúscula. Lo mismo pasa con cualquier nombre: Edad, edad y EDAD son tres cosas distintas.

23 La Indentación: La Regla de Oro de Python

Definición

La indentación (o sangría) es dejar espacios al comienzo de una línea. En Python sirve para indicar que esa instrucción pertenece a un bloque de código (por ejemplo, el interior de un if).

En C: llaves

CC
if (edad >= 18) { printf("Mayor"); }

Las llaves marcan el bloque. Los espacios son solo estética.

En Python: indentación

PythonPython
if edad >= 18: print("Mayor")

No hay llaves. El espacio al comienzo de la línea marca el bloque.

⚠️ En Python la indentación es obligatoria: no es estética, es parte de la sintaxis.

24 Indentación en Acción

Este código decide si mostrar un mensaje. (Los condicionales los estudiamos a fondo en la Unidad 06; hoy solo mirá cómo se usa la sangría):

indentacion.pyPython
edad = 20 if edad >= 18: print("Es mayor de edad") print("Puede votar") print("Fin del programa")
Salida en consola● ● ●
Es mayor de edad Puede votar Fin del programa
1
if edad >= 18: termina con dos puntos :. Eso anuncia "viene un bloque".
2
Las dos líneas con 4 espacios pertenecen al if: se ejecutan solo si la condición es verdadera.
3
print("Fin del programa") está sin sangría: ya no pertenece al if, se ejecuta siempre.

26 Reglas de la Indentación

1
Después de una línea que termina en :, la siguiente línea debe tener más sangría.
2
Todas las líneas del mismo bloque deben tener exactamente la misma cantidad de espacios.
3
La convención (PEP 8) es usar 4 espacios por nivel. En la mayoría de los editores la tecla Tab inserta esos espacios.
4
No mezcles tabulaciones con espacios en un mismo archivo: provoca errores difíciles de ver.
5
Para "salir" del bloque, volvés a escribir la línea con menos sangría.

Truco

Si te aparece un IndentationError, revisá que las líneas del bloque estén alineadas verticalmente y que la línea anterior termine en :.
