01 Hoja de Ruta: De los Vectores de C a las Listas de Python

Lo que ya conocemos de C (2.º bimestre)

  • Para cambiar el tamaño había que usar malloc / realloc.
  • Recorrer, buscar y ordenar exigían escribir bucles a mano.

Lo que vamos a aprender

  • La lista de Python: qué es y cómo se crea.
  • Índices y slicing (igual que en strings).
  • Que las listas se pueden modificar (mutables).
  • Agregar, insertar y eliminar elementos.
  • Buscar, contar y ordenar.

03 ¿Qué Es una Lista?

Definición

Una lista es una colección ordenada de elementos guardados bajo un mismo nombre. Cada elemento ocupa una posición (índice, desde 0) y la lista puede crecer, achicarse y modificarse durante el programa.

0
16
1
18
2
20
3
15
4
17

edades = [16, 18, 20, 15, 17] → una lista de 5 elementos con índices 0 a 4

Ordenada

Los elementos conservan el orden en que se agregaron.

Mutable

Se pueden cambiar, agregar y quitar elementos (a diferencia de los strings).

Flexible

Tamaño dinámico y tipos mezclados en una misma lista.

Comparación con C

Una lista es como un vector, pero sin tamaño fijo (no hay malloc) y sin obligación de que todos los elementos sean del mismo tipo.

23 ¿Qué Pasa al Asignar una Lista a Otra Variable?

referencia.pyPython
a = [1, 2, 3] b = a b.append(4) print("a:", a) print("b:", b) print(a is b)
Salida en consola● ● ●
a: [1, 2, 3, 4] b: [1, 2, 3, 4] True

¡Sorpresa!

b = a no copia la lista: hace que b y a sean dos nombres de la MISMA lista. Si modificás una, se modifica "la otra" porque es la misma.

Con números era distinto

Con int: b = a copiaba el valor y luego eran independientes (unidad 02). Los int son inmutables; las listas son mutables.

Analogía

Es como darle a un amigo el link de un documento compartido (no una fotocopia): lo que uno edite, lo ve el otro.

Tres formas de copiar

  • lista.copy()

  • list(lista)

Las tres crean una lista nueva e independiente.

Para qué sirve

Cuando querés modificar sin perder el original: por ejemplo, ordenar una copia y conservar el orden inicial.

Dato

25 Listas y Funciones: La Función Puede Modificar la Original

lista_en_funcion.pyPython
def agregar_ceros(lista): lista.append(0) lista.append(0) def duplicar(numero): numero = numero * 2 mi_lista = [1, 2] agregar_ceros(mi_lista) print(mi_lista) n = 5 duplicar(n) print(n)
Salida en consola● ● ●
[1, 2, 0, 0] 5

Con una lista

El parámetro lista y mi_lista son la misma lista. append la modifica y el cambio se ve afuera. (No hace falta return.)

Con un número

numero recibe una copia del valor y es local: n sigue valiendo 5. (Es lo que vimos en la unidad 10.)

Regla práctica

Una función que recibe una lista puede modificarla. Si no querés que lo haga, trabajá sobre una copia (lista.copy()).

26 Reasignar vs. Modificar dentro de una Función

reasignar_vs_modificar.pyPython
def con_append(lista): lista.append(99) def con_reasignacion(lista): lista = lista + [99] a = [1, 2] con_append(a) print(a) b = [1, 2] con_reasignacion(b) print(b)
Salida en consola● ● ●
[1, 2, 99] [1, 2]

La diferencia

  • append modifica la lista compartida → el cambio se ve afuera.
  • lista = lista + [99] crea una lista nueva y la asigna a la variable local lista; la lista original no cambia.

Por eso

Modificar y reasignar no son lo mismo. Para que el resultado de una reasignación llegue afuera hay que devolverlo con return.

30 Error Frecuente #2: Modificar una Lista Mientras la Recorrés

Queremos eliminar todos los elementos de [2, 4, 6, 8] recorriéndola:

Qué pasó

Al eliminar un elemento, los que siguen se corren una posición, pero el for sigue avanzando de índice en índice: se saltea el elemento que ocupó el lugar. Por eso quedaron 4 y 8.

Recorrer una copia (for n in pares.copy():) o construir una lista nueva con los elementos que sí querés conservar.

38 Resumen de la Unidad 13

Ideas clave

  • Una lista guarda varios elementos: [ ], ordenada, mutable, de tamaño dinámico.
  • Índices 0..n-1 y -1..-n; slicing igual que en strings.
  • Se modifica con lista[i] = x, append, insert, extend, remove, pop, del.
  • in, index, count buscan; sort/sorted, reverse ordenan.
  • b = a no copia: usá .copy(), [:] o list().
  • Los métodos que modifican devuelven None.
