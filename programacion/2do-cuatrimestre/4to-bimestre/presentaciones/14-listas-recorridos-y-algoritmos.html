04 Contador: ¿Cuántos Cumplen una Condición?

contar.pyPython
notas = [8, 4, 9, 5, 10, 6, 3] aprobados = 0 for nota in notas: if nota >= 6: aprobados += 1 print(f"Aprobados: {aprobados} de {len(notas)}")
Salida en consola● ● ●
Aprobados: 4 de 7

Estructura

Un if dentro del for: el contador solo aumenta cuando se cumple la condición.

Variante con count

notas.count(10) cuenta un valor exacto. Para condiciones como >= 6 hace falta el bucle.

Podés combinar

Cambiando la condición contás pares (x % 2 == 0), positivos (x > 0), textos largos (len(x) > 5), etc.

06 Máximo: El Algoritmo Clásico

Idea

Se supone que el primer elemento es el mayor (el "candidato") y se compara con cada uno de los demás: si aparece uno mayor, pasa a ser el nuevo candidato.

numeros = [14, 7, 32, 5, 21] mayor = numeros[0] for n in numeros: if n > mayor: mayor = n print("El mayor es", mayor)

Por qué no empezar en 0

Si mayor = 0 y todos los números son negativos ([-5, -2, -9]), el resultado sería 0, que ni siquiera está en la lista. Por eso se parte del primer elemento.

07 Mínimo y Posición del Mayor

minimo_posicion.pyPython
numeros = [14, 7, 32, 5, 21] menor = numeros[0] pos_mayor = 0 for i in range(len(numeros)): if numeros[i] < menor: menor = numeros[i] if numeros[i] > numeros[pos_mayor]: pos_mayor = i print("Menor:", menor) print("El mayor está en la posición", pos_mayor)
Salida en consola● ● ●
Menor: 5 El mayor está en la posición 2

Cuándo guardar la posición

Si necesitás saber dónde está el máximo (no solo su valor), guardá el índice en lugar del valor. Con el índice se obtiene el valor: numeros[pos_mayor]. Se recorre con range(len(...)) porque necesitamos i.

Atajo

numeros.index(max(numeros)) devuelve la posición del primer mayor.

08 Búsqueda Lineal: ¿Está el Elemento?

buscar_bandera.pyPython
numeros = [14, 7, 32, 5, 21] buscado = 5 encontrado = False for n in numeros: if n == buscado: encontrado = True break print("¿Está el", buscado, "?", encontrado)
Salida en consola● ● ●
¿Está el 5 ? True

La "bandera"

Una variable booleana que empieza en False y pasa a True cuando se encuentra lo buscado. El break evita seguir recorriendo de más.

El atajo

buscado in numeros hace exactamente lo mismo por dentro. Conviene entender el algoritmo porque sirve para condiciones más complejas.

09 Función de Búsqueda: Devolver la Posición

funcion_buscar.pyPython
def buscar(lista, valor): for i in range(len(lista)): if lista[i] == valor: return i return -1 nombres = ["Ana", "Luis", "Marta", "Luis"] print(buscar(nombres, "Marta")) print(buscar(nombres, "Luis")) print(buscar(nombres, "Pedro"))
Salida en consola● ● ●
2 1 -1
1
Se recorre con índices. Al encontrar el valor, return i corta la función y devuelve la posición.
2
Si el bucle termina sin encontrar, se llega al return -1 (convención: "no encontrado").
3
Devuelve la primera aparición: "Luis" está en 1 y en 3, pero devuelve 1.

Comparación con C

Es el mismo algoritmo de búsqueda secuencial que hicimos con vectores en el 2.º bimestre, con la misma convención de -1.

12 Listas por Comprensión (List Comprehension)

Una lista por comprensión crea una lista en una sola línea, describiendo qué elementos incluir y cómo transformarlos.

Con bucle

Con comprensión

numeros = [1, 2, 3, 4, 5, 6] pares = [] for n in numeros: if n % 2 == 0: pares.append(n * 10) otra = [n * 10 for n in numeros if n % 2 == 0] print(pares, otra, pares == otra)

Cuándo conviene cada una

  • Bucle: cuando hay varias instrucciones, break, o la lógica es compleja (se vuelve ilegible en una línea).

14 Modificar los Elementos en el Lugar

modificar_en_lugar.pyPython
numeros = [1, 2, 3, 4] for n in numeros: n = n * 2 print("Con for directo:", numeros) for i in range(len(numeros)): numeros[i] = numeros[i] * 2 print("Con índices:", numeros)
Salida en consola● ● ●
Con for directo: [1, 2, 3, 4] Con índices: [2, 4, 6, 8]

Por qué no cambió la primera vez

En for n in numeros, n es una variable aparte que recibe cada valor. Hacer n = n * 2 reasigna n, no el elemento de la lista.

Para modificar la lista

Hay que asignar a la posición: numeros[i] = .... Por eso se recorre con range(len(numeros)).

Regla

Para leer → for x in lista. Para modificar los elementos → for i in range(len(lista)).

15 Recorrer Dos Listas a la Vez: zip()

zip.pyPython
nombres = ["Ana", "Luis", "Marta"] notas = [8, 6, 9.5] for i in range(len(nombres)): print(nombres[i], "->", notas[i]) print("---") for nombre, nota in zip(nombres, notas): print(f"{nombre}: {nota}")
Salida en consola● ● ●
Ana -> 8 Luis -> 6 Marta -> 9.5 --- Ana: 8 Luis: 6 Marta: 9.5

zip(a, b)

Empareja los elementos de igual posición: (a[0], b[0]), (a[1], b[1])... Se desempaquetan en el for (nombre, nota). Se detiene cuando la lista más corta termina.

Listas paralelas

Cuando la información de una persona se reparte en varias listas del mismo largo (nombres[i] ↔ notas[i]), zip permite recorrerlas juntas sin manejar índices.

19 Ordenar a Mano: Método de la Burbuja

Idea

Se recorre la lista comparando pares de vecinos: si están en mal orden, se intercambian. Después de cada pasada, el mayor "sube" al final como una burbuja.

burbuja.pyPython
a = [5, 3, 8, 1] n = len(a) for pasada in range(n - 1): for j in range(n - 1 - pasada): if a[j] > a[j + 1]: a[j], a[j + 1] = a[j + 1], a[j] print(a)
Salida en consola● ● ●
[1, 3, 5, 8]

El intercambio

a[j], a[j+1] = a[j+1], a[j] usa la asignación múltiple (unidad 02): no hace falta variable auxiliar, como sí hacía en C.

Los límites

En cada pasada hay un elemento más ya ubicado, por eso el bucle interno es range(n - 1 - pasada).

Entender la burbuja sirve para aprender cómo se ordena. Para trabajar, usá sort() / sorted(): es mucho más rápido y no tiene errores.

Es el mismo algoritmo del 2.º bimestre. Cambia la sintaxis: sin { }, sin variable auxiliar para intercambiar.

21 Búsqueda Binaria (Sobre una Lista Ordenada)

Idea

Si la lista está ordenada, no hace falta mirar todo: se mira el elemento del medio y se descarta la mitad donde seguro no está. Se repite hasta encontrarlo o quedarse sin elementos.

busqueda_binaria.pyPython
def binaria(lista, valor): izq = 0 der = len(lista) - 1 while izq <= der: medio = (izq + der) // 2 if lista[medio] == valor: return medio elif lista[medio] < valor: izq = medio + 1 else: der = medio - 1 return -1 datos = [2, 5, 8, 12, 16, 23, 38, 56] print(binaria(datos, 23), binaria(datos, 7))
Salida en consola● ● ●
5 -1

Ventaja

Con 1000 elementos: la lineal puede hacer 1000 comparaciones; la binaria, 10 como mucho. Pero exige lista ordenada.

30 Buenas Prácticas al Resolver Problemas con Listas

Hacé

  • Planificá primero: ¿qué recorro? ¿qué acumulo? ¿qué devuelvo?
  • Probá con listas pequeñas que puedas resolver a mano.
  • Pensá siempre en los casos borde: lista vacía, un solo elemento, todos iguales.
  • Usá for x in lista salvo que necesites índices.
  • Usá comprensiones para casos simples.
  • Usá las funciones incorporadas (sum, max, sorted) en el código real.

Evitá

  • Inicializar el máximo en 0 o el mínimo en un número "grande" arbitrario.
  • Calcular len() y sum() dentro del bucle si no cambian.
  • Comprensiones largas o anidadas difíciles de leer.
  • Olvidar el return -1 (o equivalente) cuando no se encuentra.
  • Confiar en que la lista no está vacía.

  • mayor(lista) → el mayor (devolver None si está vacía).
  • contar(lista, valor) → cuántas veces aparece.
  • positivos(lista) → nueva lista con solo los números mayores que cero.

def suma(lista): total = 0 for x in lista: total += x return total def mayor(lista): if len(lista) == 0: return None m = lista[0] for x in lista: if x > m: m = x return m def contar(lista, valor): c = 0 for x in lista: if x == valor: c += 1 return c def positivos(lista): return [x for x in lista if x > 0] datos = [3, -1, 7, 3, 0] print(suma(datos), mayor(datos), mayor([]), contar(datos, 3), positivos(datos))

numeros = [5, 12, 8] mayor = 0 for n in numeros: if n < mayor: mayor = n total = 0 for i in range(1, len(numeros)): total += numeros[i] print(total / len(numeros)) pares = [] for n in numeros: if n % 2 == 0: pares = pares.append(n) print(numeros[len(numeros)])
👁️ Ver errores y solución
  • mayor debería partir de numeros[0] y comparar con > (acá usa < y parte de 0).
  • range(1, len(numeros)) se saltea el índice 0: el total omite el primer elemento (error lógico).
  • pares = pares.append(n) deja pares en None → solo pares.append(n).
  • numeros[len(numeros)] es IndexError: el último índice es len - 1 (o -1).

Con temps = [18.5, 21, 25.2, 19.8, 30.1, 22, 17.4], calculá y mostrá: el promedio, la máxima y en qué posición está, cuántos días superaron el promedio, y la lista de los días (posiciones) con temperatura menor a 20.
