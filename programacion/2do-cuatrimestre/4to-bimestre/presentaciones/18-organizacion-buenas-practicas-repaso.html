02 No Alcanza con Que Funcione

Idea

A medida que los programas crecen, el código se lee muchas más veces de las que se escribe (por vos en el futuro, por tus compañeros, por tu docente). Un programa correcto pero ilegible es difícil de corregir y de ampliar.

Comparación con C

En C, main era obligatoria y el sistema la ejecutaba solo. En Python no hace falta, pero es una convención muy extendida: ordena el programa igual que en C.

10 if _name_ == "_main_": Ejecutar o Importar

programa.pyPython
def main(): print("Ejecutando el programa") if __name__ == "__main__": main()
Salida en consola● ● ●
Ejecutando el programa
1
Cada archivo .py tiene una variable especial __name__.
2
Si ejecutás el archivo directamente (python programa.py), __name__ vale "__main__" y se llama a main().
3
Si otro archivo lo importa (import programa), __name__ vale "programa" y no se ejecuta main().

Para qué sirve

Permite que un mismo archivo sirva como programa (se ejecuta solo) y como módulo (otro programa usa sus funciones sin que se ejecute todo). Es la forma estándar de cerrar un programa Python.

16 Resolver un Problema Paso a Paso: Las 7 Etapas

Del apunte

Cuando nos enfrentamos a un ejercicio, no debemos comenzar escribiendo código sin antes entender qué nos están pidiendo.

1
Comprender el problema: ¿qué tenemos que resolver?
2
Identificar los datos de entrada: ¿qué información necesitamos?
3
Identificar el resultado: ¿qué debemos obtener?
4
Pensar el procedimiento: ¿qué operaciones o decisiones necesitamos?
5
Dividir el problema: ¿podemos resolverlo mediante funciones?
6
Escribir el código: traducir la solución al lenguaje Python.
7
Probar el programa: verificar que funcione con distintos valores.

Lo más importante

La programación no consiste solamente en conocer las instrucciones de un lenguaje. Lo central es aprender a pensar cómo resolver un problema y después traducir esa solución a código.

17 Las 7 Etapas en un Ejemplo (1/2): Planificar

Enunciado

"Un local de ropa aplica 15 % de descuento a las compras de más de 5000 pesos. Pedir el total de la compra y mostrar cuánto se paga."

EtapaAplicada al problema
1. ComprenderHay que calcular el precio final; el descuento es condicional.
2. Datos de entradaEl total de la compra (número decimal).
3. ResultadoEl monto a pagar (y, si corresponde, el descuento).

25 Repaso Integrador: Biblioteca Personal (1/3) — Datos en Archivo

Proyecto

Un programa con menú, funciones, lista de listas de libros [título, autor, año], validación con try/except, persistencia en archivo y búsqueda.

biblioteca.pyParte 1: cargar y guardar
def cargar(nombre): libros = [] try: with open(nombre, "r", encoding="utf-8") as f: for linea in f: titulo, autor, anio = linea.strip().split(";") libros.append([titulo, autor, int(anio)]) except FileNotFoundError: pass return libros def guardar(nombre, libros): with open(nombre, "w", encoding="utf-8") as f: for titulo, autor, anio in libros: f.write(f"{titulo};{autor};{anio}\n")

Qué se reutiliza

cargar / guardar (unidad 17): try/except, split, conversión, with y la lista de listas (unidad 15).

27 Repaso Integrador: Biblioteca Personal (3/3) — El Menú

biblioteca.pyParte 3: menú y main()
def main(): libros = cargar("libros.txt") opcion = "" while opcion != "4": print("1) Agregar 2) Buscar 3) Listar 4) Salir") opcion = input("Opción: ") if opcion == "1": libros.append([input("Título: "), input("Autor: "), pedir_anio()]) guardar("libros.txt", libros) elif opcion == "2": for l in buscar(libros, input("Buscar: ")): print(f"- {l[0]} ({l[1]}, {l[2]})") elif opcion == "3": for l in sorted(libros, key=lambda x: x[2]): print(f"{l[2]}: {l[0]}") if __name__ == "__main__": main()

Para analizar en clase

Consigna

Creá un módulo estadistica.py con las funciones promedio(lista), maximo(lista), minimo(lista) y mediana(lista) (la mediana es el valor del medio de la lista ordenada; si hay cantidad par, el promedio de los dos centrales). Incluí if __name__ == "__main__": con pruebas assert. Luego creá otro archivo que lea números desde un archivo y use tu módulo.

👁️ Ver el módulo
estadistica.pyPython
def promedio(lista): return sum(lista) / len(lista) def maximo(lista): mayor = lista[0] for x in lista: if x > mayor: mayor = x return mayor def minimo(lista): menor = lista[0] for x in lista: if x < menor: menor = x return menor def mediana(lista): orden = sorted(lista) n = len(orden) medio = n // 2 if n % 2 == 1: return orden[medio] return (orden[medio - 1] + orden[medio]) / 2 if __name__ == "__main__": assert promedio([2, 4, 6]) == 4 assert mediana([3, 1, 2]) == 2 assert mediana([4, 1, 3, 2]) == 2.5 print("Pruebas OK")
