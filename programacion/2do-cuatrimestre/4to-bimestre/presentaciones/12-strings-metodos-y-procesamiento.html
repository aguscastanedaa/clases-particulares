01 Hoja de Ruta: Herramientas Listas para Usar

Lo que ya sabemos

  • Un str es una secuencia de caracteres con índices.
  • len(), +, *, in y el slicing.
  • Los strings son inmutables.
  • En C usábamos string.h: strlen, strcpy, strcat, strcmp, toupper...

Lo que vamos a aprender

  • Qué es un método y cómo se llama.
  • Convertir mayúsculas/minúsculas, limpiar espacios, reemplazar.
  • Buscar y contar fragmentos.

🎯 Meta: que sepas qué método usar para cada tarea con texto, y que recuerdes que todos devuelven un string nuevo sin modificar el original.

02 ¿Qué Es un Método?

Definición

Un método es una función que "pertenece" a un tipo de dato y trabaja sobre un valor concreto de ese tipo. Se llama con un punto después del valor: valor.metodo(argumentos).

texto.metodo(argumentos)

Comparación con C

En C: toupper(c) o strlen(s) (funciones sueltas de ctype.h/string.h). En Python las herramientas vienen con el propio string: no hace falta #include ni import.

06 Limpiar Espacios: strip(), lstrip(), rstrip()

strip.pyPython
dato = " Ana Perez " print("[" + dato + "]") print("[" + dato.strip() + "]") print("[" + dato.lstrip() + "]") print("[" + dato.rstrip() + "]") print("xxholaxx".strip("x"))
Salida en consola● ● ●
[ Ana Perez ] [Ana Perez] [Ana Perez ] [ Ana Perez] hola

Qué eliminan

  • strip(): espacios (y saltos de línea, tabulaciones) del principio y del final.
  • lstrip(): solo a la izquierda.
  • rstrip(): solo a la derecha.

Importante

No tocan los espacios del medio. Con un argumento (strip("x")) eliminan esos caracteres en los extremos. Es clave para limpiar datos escritos por el usuario o leídos de archivos.

13 Dividir un Texto: split()

Definición

texto.split(separador) divide el texto en pedazos cada vez que encuentra el separador y devuelve una lista con los pedazos. Sin argumento, separa por espacios en blanco.

split.pyPython
frase = "Aprender Python es divertido" print(frase.split()) fecha = "25/12/2024" print(fecha.split("/")) datos = "Ana,17,Rosario" nombre, edad, ciudad = datos.split(",") print(nombre, edad, ciudad)
Salida en consola● ● ●
['Aprender', 'Python', 'es', 'divertido'] ['25', '12', '2024'] Ana 17 Rosario

Qué es esa lista

Una lista es una colección de varios valores entre [ ] (la estudiamos a fondo en la unidad 13). Se puede recorrer con for y desempaquetar en variables como vimos con las tuplas.

Detalle

Los pedazos son siempre textos: edad es "17", no el número 17. Si hace falta, convertilo con int(edad).

14 Unir Textos: join()

Definición

separador.join(lista) une todos los textos de una lista poniendo el separador entre ellos. Es la operación inversa de split. El separador va antes del punto.

join.pyPython
palabras = ["Python", "es", "genial"] print(" ".join(palabras)) print("-".join(palabras)) print("".join(palabras)) print(", ".join(["rojo", "verde", "azul"]))
Salida en consola● ● ●
Python es genial Python-es-genial Pythonesgenial rojo, verde, azul

Solo con strings

Todos los elementos de la lista deben ser str. "-".join([1, 2, 3]) da TypeError: primero hay que convertirlos con str().

Ventaja sobre +

Armar un texto con join es más corto y más rápido que concatenar con + dentro de un bucle.

22 Ejemplo: Validar una Contraseña

Reglas

Una contraseña es válida si tiene al menos 8 caracteres, al menos un dígito y al menos una mayúscula.

validar_clave.pyPython
def es_valida(clave): digito = False mayus = False for c in clave: if c.isdigit(): digito = True if c.isupper(): mayus = True return len(clave) >= 8 and digito and mayus for c in ["python", "Python2024", "PYTHONES"]: print(f"{c:12} -> {es_valida(c)}")
Salida en consola● ● ●
python -> False Python2024 -> True PYTHONES -> False

Patrón

Se recorren los caracteres una sola vez con banderas (digito...) que pasan a True cuando se encuentra lo buscado. Al final se combinan con and.

24 Ejemplo: Cifrado César

Idea

Se desplaza cada letra n posiciones en el alfabeto (con n = 3, a → d). Usamos ord() y chr() (unidad 11) y % para "dar la vuelta" al final del alfabeto.

cesar.pyPython
def cesar(texto, desplazamiento): resultado = "" for letra in texto.lower(): if letra.isalpha(): posicion = ord(letra) - ord("a") nueva = (posicion + desplazamiento) % 26 resultado += chr(ord("a") + nueva) else: resultado += letra return resultado secreto = cesar("hola mundo", 3) print(secreto) print(cesar(secreto, -3))
Salida en consola● ● ●
krod pxqgr hola mundo

Observá

(posicion + n) % 26 hace que x + 3 vuelva a a. Se conservan espacios y signos con el else. Para descifrar, se usa el desplazamiento opuesto.

32 Buenas Prácticas al Procesar Texto

Hacé

  • Guardá siempre el resultado de un método.
  • Limpiá (strip) y normalizá (lower) los datos del usuario al recibirlos.
  • Usá in para preguntar si está; find solo si necesitás la posición.
  • Preferí split/join a bucles que concatenan.
  • Usá isdigit() para validar antes de convertir.
  • Encadená pocos métodos y comentá pasos no obvios.

Evitá

  • Pensar que texto.upper() cambia texto.
  • Escribir tus propias versiones de lo que ya existe.
  • Comparar textos sin pensar en mayúsculas/espacios.
  • Confiar en que isdigit() acepta negativos o decimales.

def limpiar(texto): return texto.strip().capitalize() def contar_palabra(texto, palabra): return texto.lower().split().count(palabra.lower()) def es_email(texto): return texto.count("@") == 1 and texto.endswith(".com") def iniciales(nombre_completo): resultado = "" for parte in nombre_completo.split(): resultado += parte[0].upper() + "." return resultado print(limpiar(" hOLA ")) print(contar_palabra("Si si SI no", "si")) print(es_email("ana@mail.com"), es_email("ana@@mail.com")) print(iniciales("juan carlos perez"))

ejercicio3.pyCon errores
nombre = " ana perez " nombre.strip() nombre.title print(nombre) edad = "25" if edad.isdigit: print(edad + 1) print("a,b,c".split(","))[0] print("-".join([1, 2, 3])) print("hola".push("!"))
👁️ Ver errores y solución
  • nombre.strip() y nombre.title no se guardan (y falta el paréntesis de title).
  • edad.isdigit sin (): la condición siempre es verdadera (es un método, no una llamada).
  • edad + 1: "25" + 1 → TypeError; convertir con int(edad) + 1.
  • print(...)[0]: el [0] se aplica al resultado de print (None). Debe ir dentro: print("a,b,c".split(",")[0]).
  • join con números → convertir a str.
  • push no existe en str (AttributeError); para agregar texto se concatena: "hola" + "!".

Ideas clave
