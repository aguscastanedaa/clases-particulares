01 Hoja de Ruta: Funciones Más Flexibles

Lo que ya sabemos

  • Definir con def, llamar con nombre().
  • Parámetros (en el def) y argumentos (en la llamada).
  • return devuelve un valor y termina la función.
  • print muestra; return entrega.

Lo que vamos a aprender

  • Argumentos con nombre: f(precio=100, iva=21).
  • Valores por defecto: parámetros opcionales.
  • Devolver varios valores a la vez.
  • Alcance: variables locales y globales.
  • Estructurar un programa completo con funciones.

02 Argumentos con Nombre (Keyword Arguments)

Hasta ahora los argumentos se asignaban por posición. Python también permite indicar el nombre del parámetro en la llamada:

argumentos_con_nombre.pyPython
def presentar(nombre, edad, ciudad): print(f"{nombre}, {edad} años, de {ciudad}") presentar("Ana", 17, "Rosario") presentar(nombre="Ana", edad=17, ciudad="Rosario") presentar(ciudad="Rosario", nombre="Ana", edad=17)
Salida en consola● ● ●
Ana, 17 años, de Rosario Ana, 17 años, de Rosario Ana, 17 años, de Rosario

Ventajas

  • La llamada se explica sola: edad=17 es más claro que un 17 suelto.
  • El orden deja de importar.
  • Útil con muchos parámetros.

Regla

Se pueden mezclar, pero los posicionales van primero: presentar("Ana", edad=17, ciudad="Rosario"). Después de un argumento con nombre no puede venir uno posicional.

05 Regla: Los Parámetros con Valor por Defecto Van al Final

❌ Opcional antes que obligatorio

✅ Obligatorios primero
orden_bien.pyOK

Salida en consola● ● ●
6 15

Por qué

Si a tuviera valor por defecto y b no, al llamar f(5) Python no sabría a cuál de los dos asignarle el 5. Por eso todos los obligatorios van primero y los opcionales después.

Comparación con C

En C no existen los parámetros opcionales: habría que escribir varias funciones o pasar siempre todos los datos.

06 Devolver Más de un Valor

Idea

Una función puede devolver varios valores a la vez separándolos con comas en el return. Python los empaqueta en una tupla (una secuencia de valores) y quien llama puede recibirlos en variables separadas.

retorno_multiple.pyPython
def dividir(a, b): cociente = a // b resto = a % b return cociente, resto c, r = dividir(17, 5) print("Cociente:", c) print("Resto:", r) todo = dividir(17, 5) print(todo)
Salida en consola● ● ●
Cociente: 3 Resto: 2 (3, 2)

Recibirlos

c, r = dividir(17, 5) reparte el primer valor en c y el segundo en r (desempaquetado). Importa el orden.

Comparación con C

En C una función devuelve un solo valor (para más había que usar punteros o struct). En Python alcanza con separar con comas.

08 Alcance de las Variables (Scope)

Definición

El alcance (o ámbito, scope) de una variable es la parte del programa donde esa variable existe y puede usarse. Depende de dónde se crea.

🏠 Variable local

Se crea dentro de una función. Solo existe dentro de ella y desaparece cuando la función termina.

🌍 Variable global

Se crea fuera de todas las funciones. Existe durante todo el programa y puede leerse desde cualquier función.

Analogía

Una habitación con la puerta cerrada: lo que hay adentro (variables locales) no se ve desde el pasillo. Pero desde la habitación sí se ve lo que hay en el pasillo (variables globales).

09 Variables Locales: Existen Solo Dentro de la Función

variable_local.pyCon error
def calcular(): resultado = 10 + 5 return resultado total = calcular() print(total) print(resultado)
Salida en consola● ● ●
15 Traceback (most recent call last): File "ejemplo.py", line 7, in <module> print(resultado) ^^^^^^^^^ NameError: name 'resultado' is not defined

Qué pasó

resultado nació dentro de calcular() y murió al terminar. Desde afuera Python no la conoce: NameError.

Cómo se obtiene su valor

Con return: la función devuelve el valor y afuera lo guardamos en otra variable (total). Los valores viajan; las variables no.

10 Ciclo de Vida de una Variable Local

ciclo_vida.pyPython
def contar_hasta(n): suma = 0 for i in range(1, n + 1): suma += i return suma print(contar_hasta(3)) print(contar_hasta(4))
Salida en consola● ● ●
6 10
1
Al llamar contar_hasta(3): se crean n, suma e i (las variables locales).
2
Al ejecutar el return: la función devuelve el valor 6 y todas sus variables locales se destruyen.
3
Al llamar de nuevo contar_hasta(4): se crean variables nuevas, que empiezan de cero (suma = 0). No recuerdan nada de la llamada anterior.

Consecuencia

Cada llamada es independiente. Por eso suma = 0 dentro de la función siempre arranca limpio.

11 Variables Globales: Leer Desde una Función

variable_global.pyPython
IVA = 21 def precio_con_iva(precio): return precio + precio * IVA / 100 print(precio_con_iva(1000)) print(precio_con_iva(200))
Salida en consola● ● ●
1210.0 242.0

Qué pasó

IVA está fuera de la función, pero la función puede leerla. Es una constante global: un valor que se usa en muchos lugares y no cambia.

Convención

Las constantes se escriben en MAYÚSCULAS. Son un uso legítimo y recomendado de las variables globales: un único lugar para cambiar el valor.

Lo desaconsejado

Usar globales que cambian para pasar datos entre funciones. Es más claro enviar datos con parámetros y recibirlos con return.

Qué pasó

En numero = 5 Python crea una variable local nueva que tapa a la global. La global no se tocó: siguió valiendo 100.

Para evitar confusiones

Evitá usar el mismo nombre en una función y en el programa principal: hace difícil saber de cuál se habla.

13 Modificar una Global: El Error UnboundLocalError

unbound.pyCon error
contador = 0 def sumar_uno(): contador = contador + 1 return contador print(sumar_uno())
Salida en consola● ● ●
Traceback (most recent call last): File "ejemplo.py", line 7, in <module> print(sumar_uno()) ~~~~~~~~~^^ File "ejemplo.py", line 4, in sumar_uno contador = contador + 1 ^^^^^^^^ UnboundLocalError: cannot access local variable 'contador' where it is not associated with a value

Qué pasó

Como la función asigna contador, Python decide que es local. Pero en contador + 1 se la lee antes de que tenga valor: error.

Solución recomendada

Pasar el valor como parámetro y devolver el nuevo: def sumar_uno(valor): return valor + 1 y luego contador = sumar_uno(contador).

14 La Palabra global (Existe, Pero Evitala)

con_global.pyPython
contador = 0 def sumar_uno(): global contador contador = contador + 1 sumar_uno() sumar_uno() print(contador)
Salida en consola● ● ●
2

Qué hace

global contador le dice a Python: "dentro de esta función, contador es la variable global, no una local nueva". Así sí se puede modificar.

Por qué desaconsejarla

La función depende de una variable externa y la modifica por detrás: es difícil de probar y de seguir. Preferí parámetros y return.

Comparación con C

En C las variables globales se modificaban sin avisos especiales. Python obliga a declarar la intención con global, justamente para que sea visible.

15 Los Parámetros También Son Variables Locales

parametro_local.pyPython
def duplicar(numero): numero = numero * 2 print("Dentro:", numero) return numero valor = 10 nuevo = duplicar(valor) print("Fuera:", valor, nuevo)
Salida en consola● ● ●
Dentro: 20 Fuera: 10 20

dentro: copia modificada

Idea

El parámetro numero recibe una copia del valor de valor. Cambiar numero no altera valor. Para "cambiar" el original hay que devolver el nuevo y reasignar: valor = duplicar(valor).

Comparación con C

Con números y textos se comporta como el paso por valor de C. (Con las listas que veremos en las unidades 13 y 14, la situación tiene un matiz importante.)

16 ¿Dónde Busca Python un Nombre? Local, Global, Incorporado

1
1.º — Local: si la variable existe dentro de la función, usa esa.
2
2.º — Global: si no, la busca en el programa principal.
3
3.º — Incorporado: si tampoco, busca entre las funciones que trae Python (print, len...).
4
Si no la encuentra en ninguno: NameError.

17 pass: Funciones Que Todavía No Escribiste

pass.pyPython
def calcular_promedio(): pass def mostrar_resultados(): pass print("El programa no falla")
Salida en consola● ● ●
El programa no falla

Qué es

pass es una instrucción que no hace nada. Python exige un cuerpo en un def (o if, for...); pass ocupa el lugar hasta que lo escribas.

Para qué sirve

Para esbozar la estructura de un programa: primero los nombres de las funciones y después sus cuerpos. Un def vacío da IndentationError.

18 Pedir Datos con una Función Reutilizable

pedir_numero.pyPython
def pedir_numero(mensaje, minimo, maximo): numero = int(input(mensaje)) while numero < minimo or numero > maximo: print(f"Debe estar entre {minimo} y {maximo}") numero = int(input(mensaje)) return numero edad = pedir_numero("Edad: ", 0, 120) nota = pedir_numero("Nota: ", 1, 10) print(f"Edad {edad}, nota {nota}")
Salida en consola● ● ●
Edad: 150 Debe estar entre 0 y 120 Edad: 25 Nota: 11 Debe estar entre 1 y 10 Nota: 8 Edad 25, nota 8

Qué ganamos

La validación (while) se escribe una vez y se reutiliza con distintos mensajes y rangos. Las funciones combinan parámetros, bucles, entrada y return.

19 Estructurar un Programa Completo con Funciones

Un buen programa separa tres tareas: pedir datos, calcular y mostrar. Cada una es una función:

programa_con_funciones.pyPython
def pedir_datos(): nombre = input("Nombre: ") nota1 = float(input("Nota 1: ")) nota2 = float(input("Nota 2: ")) return nombre, nota1, nota2 def calcular_promedio(a, b): return (a + b) / 2 def mostrar_resultado(nombre, promedio): estado = "aprobó" if promedio >= 6 else "desaprobó" print(f"{nombre} {estado} con {promedio:.2f}") nombre, n1, n2 = pedir_datos() prom = calcular_promedio(n1, n2) mostrar_resultado(nombre, prom)
Salida en consola● ● ●
Nombre: Julia Nota 1: 7 Nota 2: 8.5 Julia aprobó con 7.75

Flujo de datos

pedir_datos → devuelve tres valores → calcular_promedio → devuelve un número → mostrar_resultado lo imprime. Los datos viajan por parámetros y return, sin variables globales.

25 Buenas Prácticas: Funciones Flexibles y Bien Organizadas

Hacé

  • Usá parámetros con valor por defecto para los casos habituales.
  • Usá argumentos con nombre cuando la llamada no sea obvia.
  • Pasá los datos por parámetros y recibilos con return.
  • Declará constantes globales en MAYÚSCULAS al principio.
  • Separá entrada, cálculo y salida.
  • Devolvé una tupla solo cuando los valores van juntos.

Evitá

  • Modificar variables globales dentro de funciones (global).
  • Usar el mismo nombre para variables locales y globales.
  • Funciones con demasiados parámetros (más de 4 o 5).
  • Devolver muchos valores sin orden claro.
  • Tapar nombres de Python (len, max, sum...).

28 Ejercicio 3: Encontrá los Errores

ejercicio3.pyCon errores
def calcular(a=1, b): return a + b def doble(n): resultado = n * 2 print(doble(4) + 1) print(resultado) total = 0 def acumular(valor): total = total + valor acumular(5) def dos_valores(): return 1, 2, 3 x, y = dos_valores()
👁️ Ver errores y solución
  • a=1 antes de b: los parámetros por defecto van al final.
  • doble no devuelve nada: falta return; sin él, doble(4) + 1 es None + 1 (TypeError).

30 Resumen de la Unidad 10
