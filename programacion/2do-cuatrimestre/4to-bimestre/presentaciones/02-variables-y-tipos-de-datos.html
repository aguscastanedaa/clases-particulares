02 El Problema: ¿Cómo Recuerda Datos un Programa?

Imaginá que queremos calcular el precio de una compra con IVA. Sin variables, hay que repetir los números una y otra vez:

sin_variables.pyPython
print("Precio:", 1500) print("IVA:", 1500 * 0.21) print("Total:", 1500 + 1500 * 0.21)
Salida en consola● ● ●
Precio: 1500 IVA: 315.0 Total: 1815.0

Dos problemas

  • Si el precio cambia a 2000, hay que modificar tres lugares (y es fácil olvidarse de alguno).
  • El 1500 no explica qué significa: ¿es un precio, una cantidad, un año?

La solución

Guardar el dato una sola vez, con un nombre que lo explique, y reutilizarlo cuantas veces haga falta. Eso es una variable.

03 ¿Qué Es una Variable?

Definición

Una variable es un nombre que se refiere a un dato guardado en la memoria de la computadora. Nos permite almacenar información, usarla más adelante y cambiarla cuando haga falta.

Podemos imaginarla como una caja con etiqueta:

etiqueta: edad
edad int
16
etiqueta: nombre
nombre str
"Agustin"
etiqueta: altura
altura float
1.75
etiqueta: aprobado
aprobado bool
True

🏷️ Nombre

La etiqueta con la que nos referimos al dato: edad.

📦 Valor

El contenido guardado: 16.

⚙️ Tipo

La clase de dato que es: entero, decimal, texto o lógico.

04 ¿Para Qué Sirven las Variables?

1. Guardar datos

El programa "recuerda" información mientras se ejecuta: el nombre de un usuario, un puntaje, una temperatura.

2. Reutilizar

Usamos el mismo dato en muchos lugares escribiendo solo su nombre.

3. Modificar

El valor puede cambiar durante el programa (de ahí el nombre "variable").

con_variables.pyPython
precio = 1500 iva = precio * 0.21 total = precio + iva print("Precio:", precio) print("IVA:", iva) print("Total:", total)
Salida en consola● ● ●
Precio: 1500 IVA: 315.0 Total: 1815.0

Ahora, para cambiar el precio, solo modificamos una línea: el resto del programa se adapta solo.

05 Crear una Variable en Python

En Python no hay una instrucción especial de "declaración". La variable se crea en el momento en que le asignamos un valor por primera vez:

nombre_de_variable = valor
crear_variables.pyPython

Salida en consola● ● ●
Agustin 16 1.75 True

Comparación con C

CC
int edad = 16; float altura = 1.75f;

En Python no se escribe el tipo ni el ;. Python deduce el tipo mirando el valor.

06 Desglose de Sintaxis: edad = 16

edad = 16
1
edad → el nombre (identificador) de la variable. Lo elegimos nosotros.
2
= → el operador de asignación. No significa "es igual a" como en matemática: significa "guardá el valor de la derecha dentro de la variable de la izquierda".
3
16 → el valor que se guarda. Puede ser un número, un texto, un verdadero/falso... o incluso el resultado de una cuenta.
4
Python no muestra nada al ejecutar esta línea: solo guarda el dato. Para verlo hay que usar print(edad).

Dirección de lectura

Se lee de derecha a izquierda: "el valor 16 se guarda en edad". Imaginá una flecha: edad ← 16.

07 El Signo = Es una Orden, No una Igualdad

En matemática

Escribir x = x + 1 es imposible: ningún número es igual a sí mismo más uno. Es una ecuación sin solución.

En programación

Escribir x = x + 1 es normal y muy común: significa "tomá el valor actual de x, sumale 1 y guardá el resultado otra vez en x".

igual_orden.pyPython
x = 5 x = x + 1 print(x)
Salida en consola● ● ●
6

Por qué funciona

Python resuelve primero lo de la derecha (x + 1 → 5 + 1 → 6) y después guarda ese resultado en la variable de la izquierda.

2

13 Reglas para Nombrar Variables

✅ Nombres válidos
  • Comienzan con una letra o con guion bajo _.
  • Pueden contener letras, números y _.
  • Distinguen mayúsculas y minúsculas: edad, Edad y EDAD son tres variables distintas.
nombres_validos.pyOK
edad = 16 precio_total = 99.5 _contador = 0 nota1 = 8
❌ Nombres inválidos
  • No pueden empezar con número: 1nota.
  • No pueden tener espacios: precio total.
  • No pueden tener guion medio (es el signo menos): precio-total.
  • No pueden ser palabras reservadas: if, for, class...

15 Buenas Prácticas al Nombrar (PEP 8)

16 ¿Qué Es un Tipo de Dato?

Definición

El tipo de dato indica qué clase de información es un valor y qué operaciones se pueden hacer con él. Un número se puede sumar y multiplicar; un texto se puede poner en mayúsculas y concatenar.

¿Por qué existen los tipos?

Porque no es lo mismo 5 (cantidad) que "5" (un carácter que parece número). Con el primero podemos hacer cuentas; con el segundo, no.

Los cuatro tipos básicos de hoy

17 Tipo int: Números Enteros

Números sin parte decimal: positivos, negativos o cero.

enteros.pyPython
cantidad = 25 temperatura = -5 saldo = 0 grande = 2 ** 100 print(cantidad, temperatura, saldo) print(grande)
Salida en consola● ● ●
25 -5 0 1267650600228229401496703205376

Comparación con C

En C, un int ocupaba un tamaño fijo (por ejemplo 4 bytes) y tenía un máximo. En Python un int puede ser tan grande como la memoria permita: no hay desbordamiento.

Dónde se usan

Edades, cantidades, contadores, años, posiciones, puntajes...

18 Tipo float: Números Decimales

Números con parte decimal. El separador decimal es el punto ., nunca la coma.

decimales.pyPython
peso = 72.5 precio = 2500.99 cero_decimal = 5.0 print(peso, precio, cero_decimal) print(0.1 + 0.2)
Salida en consola● ● ●
72.5 2500.99 5.0 0.30000000000000004

Con coma es un error

Salida● ● ●
(1, 75)

Con coma Python no da error: crea una tupla (1, 75), que no es lo que queremos. Siempre usá punto.

¿Por qué 0.1 + 0.2 no da 0.3?

Los decimales se guardan en binario y algunos valores no se pueden representar exactamente (como 1/3 en decimal). Hay un pequeño error de redondeo: es normal y pasa en todos los lenguajes, también en C.

19 Tipo str: Cadenas de Texto

Una cadena (string) es una secuencia de caracteres encerrada entre comillas simples o dobles.

cadenas.pyPython
ciudad = "Buenos Aires" codigo = 'A-104' vacio = "" numero_como_texto = "123" print(ciudad, codigo) print(numero_como_texto + "4") print(123 + 4)
Salida en consola● ● ●
Buenos Aires A-104 1234 127

¡Atención!

"123" es texto (tres caracteres: 1, 2, 3); 123 es un número. Por eso "123" + "4" pega los textos (1234) y 123 + 4 suma (127).

Comparación con C

En C había char (un carácter) y arreglos de char para texto. En Python no existe char: un solo carácter también es un str de longitud 1.

21 Consultar el Tipo con type()

Como no declaramos el tipo, podemos preguntarle a Python qué tipo tiene un valor con la función type():

type.pyPython
edad = 18 precio = 1500.5 nombre = "Juan" activo = True print(type(edad)) print(type(precio)) print(type(nombre)) print(type(activo))
Salida en consola● ● ●
<class 'int'> <class 'float'> <class 'str'> <class 'bool'>

Cómo leer la salida

<class 'int'> significa "este valor pertenece a la clase int". En Python todos los valores pertenecen a una clase (el tipo). Solo nos interesa el nombre que aparece entre comillas.

22 Tipado Dinámico

Definición

En Python el tipo pertenece al valor, no a la variable. La variable es solo una etiqueta que puede apuntar a valores de distintos tipos a lo largo del programa. A esto se lo llama tipado dinámico.

tipado_dinamico.pyPython
dato = 100 print(dato, type(dato)) dato = "ahora soy texto" print(dato, type(dato)) dato = 99.99 print(dato, type(dato))
Salida en consola● ● ●
100 <class 'int'> ahora soy texto <class 'str'> 99.99 <class 'float'>

En C

Una variable int siempre es int. Intentar guardar texto es un error de compilación.

Buena práctica en Python

Aunque Python permite cambiar el tipo, mantené cada variable con un solo propósito: así el código es más fácil de entender.

23 Python No Mezcla Tipos Automáticamente

Aunque el tipado sea dinámico, Python no adivina qué querés hacer si mezclás un texto con un número:

mezcla_tipos.pyCon error
edad = 18 print("Tengo " + edad + " años")
Salida en consola● ● ●
Traceback (most recent call last): File "ejemplo.py", line 2, in <module> print("Tengo " + edad + " años") ~~~~~~~~~^~~~~~ TypeError: can only concatenate str (not "int") to str

Por qué falla

El operador + entre textos significa pegar; entre números, sumar. Con un texto y un número Python no sabe cuál de las dos cosas querés y lanza TypeError.

Tres soluciones

soluciones.pyOK
print("Tengo", edad, "años") print("Tengo " + str(edad) + " años") print(f"Tengo {edad} años")

24 Conversión de Tipos (Casting)

A veces necesitamos transformar un valor de un tipo a otro. Python tiene una función por cada tipo, con el mismo nombre:

int(x) → entero

int.pyPython
a = int("25") b = int(9.99) print(a, b)
Salida en consola● ● ●
25 9

float(x) → decimal

float.pyPython
c = float("18.5") d = float(10) print(c, d)
Salida en consola● ● ●
18.5 10.0

str(x) → texto

str.pyPython
e = str(100) f = str(True) print(e, f)
Salida en consola● ● ●
100 True

Importante

Convertir no modifica la variable original: devuelve un valor nuevo. Para conservarlo hay que guardarlo: numero = int(numero).

27 Ejemplo Práctico: Calculadora de Precio con Descuento

Los datos llegan como texto (por ejemplo, desde un archivo o desde el teclado) y hay que convertirlos antes de calcular:

precio_descuento.pyPython
precio_texto = "1500" cantidad_texto = "3" descuento_texto = "0.10" precio = float(precio_texto) cantidad = int(cantidad_texto) descuento = float(descuento_texto) subtotal = precio * cantidad monto_descuento = subtotal * descuento total = subtotal - monto_descuento print("Subtotal:", subtotal) print("Descuento:", monto_descuento) print("Total a pagar:", total) print(type(subtotal))
Salida en consola● ● ●
Subtotal: 4500.0 Descuento: 450.0 Total a pagar: 4050.0 <class 'float'>

Seguimiento

precio = 1500.0 → cantidad = 3 → subtotal = 4500.0 → monto_descuento = 450.0 → total = 4050.0. Como precio es float, el resultado también es float aunque parezca un entero.

32 Buenas Prácticas con Variables

Hacé

  • Elegí nombres que expliquen el dato.
  • Asigná un valor antes de usar la variable.
  • Usá snake_case y constantes en MAYUSCULAS.
  • Mantené el mismo tipo durante todo el programa.
  • Convertí los datos al tipo correcto apenas los recibís.

Evitá

  • Nombres de una letra sin sentido (salvo contadores simples como i).
  • Reutilizar la misma variable para cosas distintas.
  • Pisar nombres de funciones: print = 5, len = 3.
  • Confundir "5" con 5.
  • Dejar números "mágicos" sin nombre en medio del código.
