03 Símbolo 1: El Operador de Dirección &

Definición y Rol en C

El operador unario & se coloca delante del nombre de una variable para obtener su dirección física en la memoria RAM (imprimible con %p).

Los 2 Usos Fundamentales:

  • En scanf("%d", &x): le indica a la función en qué casillero de memoria debe depositar el número leído del teclado.
  • Paso por referencia: al llamar cambiar(&x) o aumentarSalario(&emp, 10) enviamos la dirección para modificar el original.
ejemplo_ampersand.c Operador &
#include <stdio.h> int main(void) { int edad = 19; // edad contiene el VALOR 19 printf("Valor: %d\n", edad); // &edad entrega la DIRECCIÓN de memoria printf("Ubicacion: %p\n", (void *)&edad); return 0; }

04 Símbolo 2: El Doble Rol del Asterisco *

El asterisco tiene dos significados totalmente distintos según dónde aparezca escrito:

1. En la Declaración: Molde de Puntero

int *p; // 'p' es una variable puntero a int int x = 10; p = &x; // Guardamos la direccion de x

Aquí el * forma parte del tipo (int *). Indica que la variable p almacenará una dirección de memoria, no un entero común.

2. En la Ejecución: Desreferenciación

printf("%d", *p); // Lee el valor: 10 *p = 20; // Modifica 'x' a traves de 'p'

Aquí el * es un operador que significa: "Entrar a la dirección guardada en p y acceder al valor real que hay en esa casilla".

05 Símbolo 3: Los Corchetes []

Arreglos y Vectores Homogéneos

Los corchetes [] representan una colección contigua de elementos del mismo tipo. Siempre se indexan en base cero: desde 0 hasta N - 1.

Equivalencia Puntero-Arreglo:

En C, v[i] es estrictamente idéntico a *(v + i). El nombre del vector v equivale a la dirección de su primer elemento: v == &v[0].

corchetes_demo.c Uso de []
#include <stdio.h> int main(void) { int notas[3] = {8, 9, 10}; // Acceso tradicional con corchetes notas[1] = 7; // Equivalencia con aritmetica de punteros *(notas + 2) = 6; printf("%d %d %d\n", notas[0], notas[1], notas[2]); return 0; }

06 Símbolos 4 y 5: Punto . vs Flecha ->

Esta es una de las distinciones más evaluadas en exámenes. Ambos acceden a campos de un struct, pero sobre tipos distintos:

Operador Punto . (Variable Directa)

struct Alumno alumno1; alumno1.edad = 18; alumno1.promedio = 8.5;

Se utiliza cuando tenemos la variable struct en nuestras manos (en el Stack de la función actual).

Operador Flecha -> (Puntero a Struct)

struct Alumno *ptr = &alumno1; ptr->edad = 19; ptr->promedio = 9.0;

Se utiliza cuando tenemos un puntero que apunta a la struct. Es el atajo seguro para escribir (*ptr).campo.

07 Símbolos 6 y 7: El Fin de Texto '\0' y return

El Centinela Nulo '\0'

En C no existe el tipo nativo String: usamos arreglos char[]. Para saber dónde termina el texto, se coloca el centinela '\0' (código ASCII 0).

char cad[5] = {'H', 'o', 'l', 'a', '\0'}; // strlen(cad) cuenta 4 caracteres (ignora '\0')

⚠️ Una cadena de N caracteres requiere un arreglo de al menos N + 1 bytes de espacio.

La Instrucción return

Finaliza la ejecución de la función actual y devuelve el control al llamador, opcionalmente transportando un valor de retorno.

int sumar(int a, int b) { return a + b; // Entrega el resultado }

💡 En funciones void se puede usar return; sin valor para salir anticipadamente.

08 Pares Confusos: La Regla de Oro de & y *

Para no dudar jamás entre dirección y contenido, recordá esta relación matemática y conceptual:

Expresión Tipo de Dato Qué contiene Analogía de la Casa (Apunte Pág. 23)
edad int 19 El habitante que vive adentro de la casa
&edad int * 0x7ffe... La dirección postal de la casa (calle y número)
p (si p = &edad) int * 0x7ffe... El papel donde anotaste la dirección de la casa
*p int 19 Ir con el papel a la casa y ver al habitante

🎯 Efecto espejo: *(&x) == x. El asterisco y el ampersand se cancelan mutuamente.

09 Pares Confusos: Tres Formas de Trabajar con Caracteres

1. Carácter Simple: char

char c = 'A';
  • Comillas simples.
  • Ocupa exactamente 1 byte.
  • Se imprime con %c.
  • No lleva '\0'.

2. Arreglo: char[]

char cad[] = "Hola";
  • Comillas dobles.
  • Modificable: cad[0]='h';
  • Se imprime con %s.
  • Ocupa 5 bytes (4 + '\0').

3. Puntero: char *

char *p = cad;
  • Apunta al primer char.
  • Puede reasignarse a otro texto.
  • Permite recorrer con p++.
  • Compara con strcmp().

10 Método de Descifrado: De Adentro hacia Afuera

Cuando veas una línea con muchos símbolos juntos, aplicá estos 3 pasos sistemáticos:

1
Identificá la variable raíz: ¿Es una variable simple, un vector, una struct o un puntero?
2
Seguí los operadores de mayor precedencia: Corchetes [], punto . y flecha -> se resuelven antes que el asterisco * y el ampersand &.
3
Verificá el tipo en cada nivel: Cada paso transforma el tipo hasta llegar al dato final (un entero, un float, un char o una dirección).

🔍 Ejemplo: En &clase[i].legajo: primero entramos al alumno clase[i], luego a su campo .legajo, y finalmente con & obtenemos la dirección de memoria de ese entero para el scanf.

11 Expresión 1: clase[i].promedio

Desglose Nivel por Nivel

  • clase: arreglo de structs de tipo struct Alumno.
  • clase[i]: elemento en la posición i (una struct completa).
  • .promedio: operador punto que accede al campo flotante.
  • Tipo final: float (un valor numérico real).

💡 Regla: Va corchete primero porque el arreglo es la colección de alumnos, no la nota: clase[i].promedio es correcto; clase.promedio[i] da error de compilación.

expresion1.c Arreglo de Structs
#include <stdio.h> struct Alumno { int legajo; float promedio; }; int main(void) { struct Alumno clase[2] = {{101, 8.5}, {102, 9.2}}; printf("Promedio: %.1f\n", clase[0].promedio); return 0; }

12 Expresión 2: emp->salario vs (*emp).salario

¿Por qué existe la flecha?

El operador punto . tiene mayor precedencia que el asterisco *. Si escribís *emp.salario, C intenta hacer *(emp.salario), lo cual falla porque emp es un puntero y no tiene campos directos.

Para resolverlo se requiere paréntesis: (*emp).salario. Como es engorroso, C inventó el operador flecha: emp->salario.

expresion2.c Puntero y Flecha
#include <stdio.h> struct Empleado { float salario; }; void aumentar(struct Empleado *e) { e->salario += 500.0; // Identico a (*e).salario } int main(void) { struct Empleado emp = {3000.0}; aumentar(&emp); printf("Nuevo salario: %.1f\n", emp.salario); return 0; }

13 Expresión 3: estudiante.notas[j]

Struct con Arreglo Interno

  • estudiante: variable directa de tipo struct Estudiante.
  • .notas: acceso al campo interno, que es un arreglo float[3].
  • [j]: índice para elegir una de las 3 calificaciones (0, 1 o 2).
  • Tipo final: float (la nota individual).
expresion3.c Arreglo Interno
#include <stdio.h> struct Estudiante { float notas[3]; }; int main(void) { struct Estudiante est = {{8.0, 7.5, 9.0}}; float suma = 0; for (int j = 0; j < 3; j++) { suma += est.notas[j]; } printf("Promedio: %.2f\n", suma / 3); return 0; }

14 Expresión 4: Modificación Directa en Arreglos

El Secreto del Apunte (Pág. 35)

Cuando enviamos un arreglo de structs a una función como actualizar(struct Vehiculo f[], int n), no se copia todo el arreglo: se envía la dirección base.

Por lo tanto, f[i].kilometraje += 1000; modifica directamente la memoria original en main sin necesitar operador flecha.

expresion4.c Modificacion en Arreglos
#include <stdio.h> struct Auto { int km; }; void sumarKm(struct Auto flota[], int n) { for (int i = 0; i < n; i++) { flota[i].km += 1000; // Modifica original } } int main(void) { struct Auto autos[1] = {{50000}}; sumarKm(autos, 1); printf("Km final: %d\n", autos[0].km); return 0; }

15 Expresión 5: Aritmética de Punteros en RAM

Las 4 Equivalencias Maestras

  • v == &v[0] (el nombre es la dirección de inicio).
  • *(v + i) == v[i] (desplazar y desreferenciar).
  • (v + i) == &v[i] (dirección del elemento i).
  • v + 1 avanza sizeof(tipo) bytes automáticamente.
expresion5.c Punteros y Arreglos
#include <stdio.h> int main(void) { int v[3] = {10, 20, 30}; int *p = v; printf("%d\n", *p); // 10 printf("%d\n", *(p + 1)); // 20 printf("%d\n", *(p + 2)); // 30 return 0; }

16 Trampa 1: La Precedencia de *p++ vs (*p)++

*p++ (Avanza la Dirección)

int v[2] = {10, 20}; int *p = v; int x = *p++; // Toma v[0] y LUEGO p apunta a v[1]

El operador ++ tiene mayor prioridad que *. Se incrementa el puntero (la dirección), no el número guardado.

(*p)++ (Incrementa el Valor)

int v[2] = {10, 20}; int *p = v; (*p)++; // El 10 se transforma en 11. p sigue en v[0]

Los paréntesis fuerzan a desreferenciar primero. Se suma 1 al contenido de la celda de memoria.

17 Trampa 2: ¿Cuándo va & en scanf?

❌ Errores Clásicos de Examen
int edad; scanf("%d", edad); // FALTA & (Crash/segfault) char nombre[30]; scanf("%s", &nombre); // SOBRA & (nombre ya es dir)
✅ La Regla Definitiva
int edad; scanf("%d", &edad); // CORRECTO: variable simple char nombre[30]; scanf("%s", nombre); // CORRECTO: arreglo de char

📌 Regla Mnemotécnica: scanf siempre exige una dirección de memoria. Si le pasás una variable simple (int, float), agregale &. Si le pasás un arreglo o string, su nombre ya es una dirección.

18 Trampa 3: cadena1 == cadena2 NUNCA Compara Texto

❌ El Error Fatal
char a[] = "clave"; char b[] = "clave"; if (a == b) { // ¡Compara DIRECCIONES de RAM! printf("Iguales"); // Nunca entra aca }

a y b son dos arreglos distintos ubicados en posiciones de memoria diferentes. Por eso a == b siempre da false.

✅ La Solución con strcmp
#include <string.h> if (strcmp(a, b) == 0) { printf("Son iguales"); // Compara contenido }

strcmp recorre carácter por carácter hasta '\0'. Devuelve 0 cuando el contenido alfanumérico es idéntico.

19 Trampa 4: Pasar Struct por Valor vs por Referencia

❌ Paso por Valor (No Modifica Original)
void cambiar(struct Punto p) { p.x = 99; // Cambia una COPIA local } // En main: punto.x sigue valiendo su valor inicial
✅ Paso por Referencia con Puntero
void cambiar(struct Punto *p) { p->x = 99; // Modifica la memoria original } // En main: cambiar(&punto);

💡 Regla: Si querés que una función modifique los campos de una struct, pasale su dirección con & y recibí con struct Nombre *ptr usando flecha ->.

20 Trampa 5: Arreglos sin Tamaño en Funciones

¿Por qué C no sabe el tamaño?

Cuando un arreglo se pasa como parámetro: void f(int v[]), en realidad se convierte en un puntero int *v. No transporta información sobre cuántos elementos tiene.

Por eso sizeof(v) dentro de la función devolverá el tamaño de un puntero (4 u 8 bytes), nunca el tamaño del vector.

tamano_obligatorio.c Buena Práctica
// Siempre enviar 'tamano' como parametro adicional: void mostrar(int v[], int tamano) { for (int i = 0; i < tamano; i++) { printf("%d ", v[i]); } }

21 La Imagen Completa: 4 Pilares en Armonía

En proyectos profesionales de C, los 4 pilares trabajan coordinados en una única estructura:

1. Structs

Definen el modelo de datos agrupando variables heterogéneas (textos, números, estados, fechas).

2. Arreglos

Permiten almacenar múltiples registros simulando una base de datos en memoria RAM.

3. Punteros

Brindan eficiencia y mutabilidad: permiten modificar registros originales sin copias pesadas.

4. Funciones

Aportan modularidad y orden: cada tarea (cargar, buscar, transferir, listar) tiene su propia función.

26 Desafío de Examen 1: ¿Qué imprime este código?

Leé atentamente el siguiente programa y determiná mentalmente la salida exacta de la consola:

#include <stdio.h> void f(int *p, int x) { *p += 10; x += 10; } int main(void) { int a = 5, b = 5; f(&a, b); printf("a=%d, b=%d\n", a, b); return 0; }
👁️ Ver respuesta explicada

Salida exacta: a=15, b=5

¿Por qué? Porque a fue pasada por referencia con &a, de modo que *p += 10 alteró la casilla original. En cambio, b fue pasada por valor: la función modificó su propia copia local x, dejando intacta a b.

27 Desafío de Examen 2: Encontrá el Bug

#include <stdio.h> #include <string.h> struct Usuario { char clave[10]; }; int main(void) { struct Usuario u; // ERROR: u.clave = "1234"; // No se puede asignar arreglos con = strcpy(u.clave, "secreta12345"); // ¿Que peligro hay aca? printf("%s\n", u.clave); return 0; }
👁️ Ver explicación del peligro

Peligro: Desbordamiento de Búfer (Buffer Overflow)

El arreglo clave tiene capacidad para 10 bytes (máximo 9 letras + '\0'). La cadena "secreta12345" mide 12 letras + 1 nulo = 13 bytes. strcpy escribirá fuera del arreglo, corrompiendo la memoria adyacente. La solución es agrandar el arreglo o usar strncpy.

28 Ejercicio de Examen: El Mejor Alumno de la Escuela

Consigna

Dado un arreglo de struct Alumno { char nombre[30]; float promedio; }, creá una función que reciba el arreglo y devuelva mediante un puntero el índice o los datos del alumno con el promedio más alto.

👁️ Ver solución modelo en C
#include <stdio.h> struct Alumno { char nombre[30]; float promedio; }; void obtenerMejor(struct Alumno curso[], int n, struct Alumno *ganador) { int posMax = 0; for (int i = 1; i < n; i++) { if (curso[i].promedio > curso[posMax].promedio) { posMax = i; } } *ganador = curso[posMax]; // Copia la struct completa } int main(void) { struct Alumno clase[2] = {{"Pedro", 7.5}, {"Maria", 9.8}}; struct Alumno mejor; obtenerMejor(clase, 2, &mejor); printf("Mejor: %s (%.1f)\n", mejor.nombre, mejor.promedio); return 0; }
