01 Hoja de Ruta y Conexión con la Unidad 05

Lo que aprendimos en la Unidad 05

  • El operador & nos da la dirección de memoria donde vive una variable (&x).
  • Un puntero (int *p) es una variable que guarda esa dirección de memoria.
  • El operador * viaja hasta esa dirección y nos permite leer o modificar el valor guardado (*p = 100;).

Lo que vamos a dominar hoy (Secciones 20 a 24)

  • 20. Paso por valor vs. referencia: por qué cambiar(x) deja x = 5 sin cambios.
  • 21. Modificar la variable original: cambiar(&x) con void cambiar(int *numero).
  • 22. Punteros y funciones: combinar punteros y parámetros normales en incrementar(&x, 5).
  • 23. Devolver varios valores: dividir(10, 3, &cociente, &resto) e intercambiar(&a, &b).
  • 24. Ejemplo estrella: minMax(vector, tamano, &minimo, &maximo) paso a paso.

02 20. El Problema: ¿Por Qué cambiar(x) No Cambia a x?

Explicación del Apunte (Sección 20)

Hasta ahora, cuando pasábamos una variable común a una función como void cambiar(int numero), la función recibía una copia del valor.

cambiar_copia.c Sección 20 del Apunte
#include <stdio.h> void cambiar(int numero) { numero = 100; } int main() { int x = 5; cambiar(x); printf("x vale: %d\n", x); return 0; }
Terminal Salida
$ ./cambiar_copia x vale: 5

🤔 Pregunta del Apunte: Si adentro de la función pusimos numero = 100;, ¿por qué en main la variable x sigue valiendo 5? Porque la función recibió una copia.

Miremos las cajitas en la memoria RAM cuando hacemos cambiar(x);:

Analogía de la Fotocopia

1
Tenés una hoja original llamada x que tiene escrito un 5 (en la dirección 1000).
2

3
La función escribe 100 arriba de la fotocopia (numero = 100) y luego la tira a la basura al terminar.
4
¡Tu hoja original x nunca fue tocada y sigue teniendo el 5!

04 21. Modificar la Variable Original con Punteros

La Solución del Apunte (Sección 21)

Con punteros podemos hacer que la función modifique la variable original: en vez de mandarle una copia del valor, le mandamos su dirección de memoria &x.

cambiar_con_puntero.c Sección 21 del Apunte
#include <stdio.h> void cambiar(int *numero) { *numero = 100; } int main() { int x = 5; cambiar(&x); printf("Ahora x = %d\n", x); return 0; }
Terminal Salida
$ ./cambiar_puntero Ahora x = 100

🎉 ¡Ahora sí cambió! La variable x de main pasó de valer 5 a valer 100.

05 ¿Qué Ocurrió Exactamente en cambiar(&x)?

Analicemos pieza por pieza las 3 partes que trabajan en equipo según la Sección 21 del apunte:

1. En main: cambiar(&x);

Mandamos &x, es decir, la dirección de memoria donde vive x (por ejemplo, la casilla 1000).

2. Parámetro: int *numero

La función recibe un puntero que apunta a un int. Ese puntero numero guarda la dirección 1000.

3. Cuerpo: *numero = 100;

Significa: "Guardar 100 en la variable ubicada en esa dirección". Como esa dirección era la de x, ahora x = 100.

06 Comparativa Directa: Por Valor vs. Por Referencia

📋 Paso por Valor (Recibe una copia)
void cambiar(int numero) { numero = 100; } // En main: int x = 5; cambiar(x); // x sigue valiendo 5
  • Llamada sin &: envía solo el número 5.
  • Parámetro sin *: crea otra caja independiente.
  • No puede modificar la variable de main.
🎯 Paso por Referencia con Punteros
void cambiar(int *numero) { *numero = 100; } // En main: int x = 5; cambiar(&x); // ¡x cambia a 100!
  • Llamada con &x: envía la dirección de x.
  • Parámetro con int *numero: recibe la dirección.
  • Con *numero = 100 modifica directamente a x.

07 22. Punteros y Funciones: incrementar

Ejemplo de la Sección 22 del Apunte

Una función puede recibir al mismo tiempo un puntero (para la variable que necesita modificar) y un valor común (para un dato que solo necesita leer).

incrementar.c Sección 22 del Apunte
#include <stdio.h> void incrementar(int *numero, int n) { *numero += n; } int main() { int x = 10; incrementar(&x, 5); printf("Resultado: x = %d\n", x); return 0; }

¿Por qué hacemos &x pero el 5 va sin &?

  • Primer parámetro (int *numero): La función necesita saber "¿Qué variable tengo que modificar?". Por eso le damos su dirección: &x.
  • Segundo parámetro (int n): Es solo cuánto queremos sumarle (5). No queremos modificar al 5, así que pasa por valor (copia).
  • *numero += n; equivale a *numero = *numero + n; (10 + 5 = 15).

09 23. Devolver Varios Valores Mediante Punteros

La Limitación de return (Sección 23)

Normalmente una función puede devolver un solo resultado mediante la instrucción return (como en int sumar(int a, int b) { return a + b; }). Pero muchas veces necesitamos que una función calcule y devuelva dos o más resultados a la vez.

El Caso de la División Entera

Si dividimos 10 entre 3, obtenemos dos resultados distintos:

  • El cociente entero: 10 / 3 = 3
  • El resto de la división: 10 % 3 = 1

Como en C no existe return cociente, resto;, ¿cómo hacemos para que una función nos entregue ambos valores?

La Solución con Punteros

Creamos dos variables en main (cociente y resto) y le pasamos a la función sus dos direcciones de memoria (&cociente y &resto).

Así, la función deposita cada resultado directamente en su casilla correspondiente usando *cociente = ... y *resto = ....

10 Función dividir del Apunte: Código y Uso

dividir.c Sección 23 del Apunte
#include <stdio.h> void dividir(int dividendo, int divisor, int *cociente, int *resto) { *cociente = dividendo / divisor; *resto = dividendo % divisor; } int main() { int cociente; int resto; dividir(10, 3, &cociente, &resto); printf("cociente = %d\n", cociente); printf("resto = %d\n", resto); return 0; }
Terminal Salida
$ ./dividir cociente = 3 resto = 1

Parámetros de Entrada vs. de Salida

• De entrada (por valor): dividendo (10) y divisor (3).
• De salida (punteros): *cociente (recibe &cociente) y *resto (recibe &resto).

11 Cómo Funciona dividir(10, 3, &cociente, &resto) en RAM

Observá cómo los dos punteros de la función apuntan hacia las dos variables declaradas en main():

Variables en dividir()

  • dividendo = 10 (copia del 10)
  • divisor = 3 (copia del 3)
  • cociente = 0x1000 (apunta a cociente de main)
  • resto = 0x1004 (apunta a resto de main)

Efecto en las cajas de main()

  • *cociente = 10 / 3;
    Viaja a la dirección 0x1000 y escribe un 3.
  • *resto = 10 % 3;
    Viaja a la dirección 0x1004 y escribe un 1.

💡 Por eso en main() ni siquiera hacía falta darle valor inicial a int cociente; int resto; antes de llamar a dividir: la función misma se encarga de rellenar ambas cajas.

12 Otro Clásico con Punteros: intercambiar(int *a, int *b)

En el 2do Bimestre vimos que para intercambiar dos valores en un ordenamiento usábamos una variable aux. Si queremos poner esa lógica en una función intercambiar, necesitamos punteros porque debe modificar ambas variables:

intercambiar.c Swap con aux
#include <stdio.h> void intercambiar(int *a, int *b) { int aux = *a; *a = *b; *b = aux; } int main() { int x = 10, y = 20; intercambiar(&x, &y); printf("x = %d, y = %d\n", x, y); return 0; }

13 ¿Por Qué intercambiar Fallaría Sin Punteros?

❌ Intercambio por Valor (Solo cambia las copias)
void intercambiarMal(int a, int b) { int aux = a; a = b; b = aux; } // En main: intercambiarMal(x, y); // ¡x sigue siendo 10 e y sigue siendo 20!

Intercambia las copias locales a y b adentro de la función, pero al terminar la función esas copias desaparecen y x e y en main quedan intactas.

✅ Intercambio por Referencia (Cambia los originales)
void intercambiar(int *a, int *b) { int aux = *a; *a = *b; *b = aux; } // En main: intercambiar(&x, &y); // Ahora x vale 20 e y vale 10.

Al recibir &x y &y y usar *a y *b, el intercambio ocurre directamente sobre las casillas de memoria de main.

14 24. Ejemplo Estrella del Apunte: minMax

Objetivo del Ejercicio (Sección 24)

Recibir un arreglo de enteros y su tamaño, y devolver mediante punteros tanto el mínimo como el máximo en un solo recorrido.

¿Qué conocimientos une este ejemplo?

  • Arreglos como parámetros (Sección 2: int vector[], int tamano).
  • Búsqueda de menor y mayor (vista en el 2do Bimestre inicializando con vector[0]).
  • Devolver varios valores con punteros (Sección 23: int *minimo, int *maximo).

La Firma de la Función

void minMax(int vector[], int tamano, int *minimo, int *maximo)

Recibe 4 argumentos: 2 de entrada (el vector y su cantidad de elementos) y 2 punteros de salida (dónde guardar el mínimo y el máximo).

15 El Algoritmo minMax Paso a Paso

min_max.c Sección 24 del Apunte
void minMax(int vector[], int tamano, int *minimo, int *maximo) { *minimo = vector[0]; *maximo = vector[0]; for(int i = 1; i < tamano; i++) { if(vector[i] < *minimo) { *minimo = vector[i]; } if(vector[i] > *maximo) { *maximo = vector[i]; } } }

Análisis Línea por Línea

  • *minimo = vector[0]; y *maximo = vector[0];: asumimos inicialmente que el primer elemento es a la vez el menor y el mayor.
  • for(int i = 1; i < tamano; i++): recorremos desde la posición 1 (porque la 0 ya la cargamos).
  • if(vector[i] < *minimo): si el elemento actual es menor al mínimo actual apuntado, actualizamos *minimo = vector[i];.
  • if(vector[i] > *maximo): si supera al máximo actual apuntado, actualizamos *maximo = vector[i];.

18 Ejemplo Nivel 3: return de Éxito + Resultados por Puntero

¿Qué pasa en dividir si alguien pasa divisor = 0? En C profesional es muy común usar el return para indicar si la operación fue válida (1 o true) y los punteros para devolver los resultados:

division_segura.c Nivel 3
#include <stdio.h> #include <stdbool.h> bool dividirSeguro(int div, int dsor, int *coc, int *res) { if (dsor == 0) { return false; // No se puede dividir por 0 } *coc = div / dsor; *res = div % dsor; return true; } int main() { int c, r; if (dividirSeguro(10, 3, &c, &r)) { printf("Cociente: %d, Resto: %d\n", c, r); } return 0; }

Por qué este patrón es tan útil

  • Evita que el programa se cuelgue al dividir por cero.
  • Permite poner la llamada adentro de un if (...) y al mismo tiempo recibir c y r cargados.
  • Es exactamente la misma idea que usaremos más adelante en el ejercicio integrador de Transferencia Bancaria del apunte.

19 Devolver Tres Resultados: Suma, Promedio y Cantidad de Aprobados

estadisticas_notas.c 3 Punteros de Salida
#include <stdio.h> void analizarNotas(int v[], int n, int *suma, float *prom, int *aprob) { *suma = 0; *aprob = 0; for (int i = 0; i < n; i++) { *suma += v[i]; if (v[i] >= 6) { (*aprob)++; } } *prom = (float)(*suma) / n; } int main() { int notas[4] = {8, 4, 9, 7}; int s, a; float p; analizarNotas(notas, 4, &s, &p, &a); printf("Suma: %d | Prom: %.2f | Aprob: %d\n", s, p, a); return 0; }
Terminal Salida
$ ./estadisticas Suma: 28 | Prom: 7.00 | Aprob: 3

⚠️ Detalle clave: Para sumar 1 a un puntero con ++ escribimos (*aprob)++ con paréntesis (o bien *aprob += 1;) para que incremente el valor apuntado y no la dirección.

20 Ejemplo Nivel 4: Ordenar Dos Variables de Menor a Mayor

Cómo pensar el problema paso a paso

Queremos una función void ordenarDos(int *menor, int *mayor) a la que le pasemos dos variables &x e &y en cualquier orden y se asegure de que en la primera quede el valor más chico y en la segunda el más grande.

ordenar_dos.c Nivel 4
#include <stdio.h> void ordenarDos(int *menor, int *mayor) { if (*menor > *mayor) { int aux = *menor; *menor = *mayor; *mayor = aux; } } int main() { int a = 50, b = 12; ordenarDos(&a, &b); printf("a = %d, b = %d\n", a, b); return 0; }

Razonamiento Lógico

  • Comparamos los valores apuntados: if (*menor > *mayor) (¿50 > 12?).
  • Si estaban al revés, ejecutamos el intercambio con aux sobre *menor y *mayor.
  • Si ya estaban en orden, no hace nada. Al volver a main, a vale 12 y b vale 50.

21 Integrando Strings (Unidad 04) + Punteros (Unidad 06)

#include <stdio.h> void contarLetras(char cad[], int *mayus, int *minus) { *mayus = 0; *minus = 0; for (int i = 0; cad[i] != '\0'; i++) { if (cad[i] >= 'A' && cad[i] <= 'Z') { *mayus += 1; } else if (cad[i] >= 'a' && cad[i] <= 'z') { *minus += 1; } } } int main() { int M, m; contarLetras("Hola Mundo", &M, &m); printf("Mayus: %d | Minus: %d\n", M, m); return 0; }

22 Guía de Diseño: ¿Cuándo Uso return y Cuándo Punteros?

Usá return normal cuando...

  • La función calcula un único valor nuevo a partir de sus entradas:
    • int sumar(int a, int b)
    • int contarCaracter(char cad[], char c)
    • bool esPalindromo(char cad[], int lon)
  • No necesitás alterar las variables que estaban en main().

Usá parámetros puntero (* y &) cuando...

  • Querés modificar directamente una variable existente en main():
    • void cambiar(int *numero)
    • void incrementar(int *numero, int n)
  • Necesitás que la función devuelva 2 o más resultados:
    • void dividir(int a, int b, int *coc, int *res)
    • void minMax(int v[], int n, int *min, int *max)

23 Error Frecuente #1: Olvidar el * Adentro de la Función

❌ Escribir numero = 100; sin asterisco
void cambiar(int *numero) { numero = 100; // ¡MAL! Cambia la dirección, no el valor }

numero es el papelito con la dirección. Si hacés numero = 100; sin *, hacés que el puntero apunte a la dirección de memoria 100, ¡y la variable x de main queda sin cambios!

✅ Desreferenciar siempre con *numero = 100;
void cambiar(int *numero) { *numero = 100; // ¡BIEN! Modifica la celda apuntada }

El asterisco *numero viaja hasta la dirección recibida y deposita el 100 adentro de la variable original x.

24 Error Frecuente #2: Olvidar el & al Llamar a la Función

❌ Pasar la variable sin & cuando espera puntero
int cociente, resto; // ¡ERROR! Pasa valores basura en vez de direcciones dividir(10, 3, cociente, resto);

El compilador dará una advertencia de tipos incompatibles (int vs int *) y el programa intentará escribir en direcciones inválidas, causando un cuelgue inmediato.

✅ Enviar las direcciones con &cociente, &resto
int cociente, resto; // ¡BIEN! Envía las direcciones de ambas cajas dividir(10, 3, &cociente, &resto);

Regla de oro: si el parámetro en la definición de la función tiene * (ej. int *cociente), en la llamada desde main le pasás & (&cociente).

25 Error Frecuente #3: Olvidar el * en las Comparaciones de minMax

❌ Comparar vector[i] < minimo (sin *)
if (vector[i] < minimo) { // ¡MAL! *minimo = vector[i]; }

Estás comparando un número del vector (ej. 5) contra la dirección de memoria guardada en minimo (ej. 0x7ffe...), en lugar de compararlo contra el valor mínimo actual.

✅ Usar *minimo tanto al comparar como al asignar
if (vector[i] < *minimo) { // ¡BIEN! *minimo = vector[i]; }

Adentro de minMax, cada vez que quieras leer o escribir el valor del mínimo o máximo, tenés que escribir *minimo y *maximo.

26 Error Frecuente #4: ¿Por Qué el Vector No Lleva & en minMax?

Mirá bien la llamada del apunte: minMax(numeros, 5, &minimo, &maximo);. ¿Por qué minimo y maximo llevan & pero numeros no?

Variables simples (int minimo)

Una variable entera común pasa por copia a menos que le pongamos explícitamente el operador & (&minimo) para enviar su dirección.

Arreglos (int numeros[5])

Como vimos en la Sección 2 y profundizaremos en la Unidad 07, el nombre de un arreglo por sí solo ya representa la dirección de memoria de su primer elemento. Por eso escribimos simplemente numeros.

27 Error Frecuente #5: La Trampa de *numero++ vs. *numero += 1

❌ Escribir *numero++; sin paréntesis
void sumarUnoMal(int *numero) { *numero++; // ¡CUIDADO! Mueve el puntero a otra dirección }

Por precedencia de operadores en C, ++ se aplica primero al puntero numero (cambiando la dirección a la que apunta) y no al número entero guardado en x.

✅ Usar *numero += 1; o (*numero)++;
void sumarUnoBien(int *numero) { *numero += 1; // O también: (*numero)++; }

Tal como hace el apunte en incrementar con *numero += n;, usar += o poner paréntesis (*numero)++ garantiza que sumamos sobre el valor apuntado.

28 Buenas Prácticas al Usar Punteros en Funciones

Orden y Claridad en los Parámetros

  • Primero las entradas, al final las salidas: Como en dividir(dividendo, divisor, &cociente, &resto) y minMax(vector, tamano, &minimo, &maximo), colocá los datos de entrada primero y los punteros de resultado al final.
  • Nombres descriptivos: Llamar a los punteros *cociente, *resto, *minimo y *maximo deja claro qué resultado se guarda en cada uno.

31 Ejercicio 3: Contar Pares e Impares de un Vector

Enunciado

Siguiendo el modelo de minMax (Sección 24), escribí una función void contarParesImpares(int vector[], int tamano, int *pares, int *impares) que recorra un arreglo y devuelva mediante punteros cuántos números son pares y cuántos son impares. Probala con {4, 7, 10, 3, 8, 1}.

Lo que ya notamos hoy

Cuando pasamos un arreglo a una función (como numeros en minMax), no hizo falta ponerle & adelante, y aun así las funciones pueden acceder al arreglo original.

34 Resumen de la Unidad 06 y Checklist

Conceptos Clave para Recordar

  • Por defecto, C pasa las variables simples por valor (copia): los cambios adentro de la función no afectan al original.
  • Para que una función modifique una variable de main, enviamos su dirección con &variable y la recibimos en un puntero int *p.
  • Adentro de la función usamos *p = valor para escribir en la casilla original.
  • Con varios parámetros puntero podemos devolver 2, 3 o más resultados desde una misma función.
