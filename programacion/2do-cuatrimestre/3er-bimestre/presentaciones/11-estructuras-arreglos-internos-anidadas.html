01 Hoja de Ruta y Conexión con la Unidad 10

Lo que aprendimos en la Unidad 10

  • Un arreglo de Structs (struct Alumno clase[30];) es un vector donde cada posición guarda un alumno.
  • Allí el corchete iba pegado al vector: clase[i].promedio.
  • Vimos en la Unidad 08 un alumno con 3 variables sueltas: nota1, nota2, nota3.

Lo que vamos a dominar hoy (Secciones 35 y 36)

  • 35. Structs con arreglos internos: guardar un vector float notas[3]; adentro de struct Estudiante.
  • Calcular el promedio recorriendo e.notas[i] con un for.
  • Combinar arreglo de estudiantes + arreglo de notas (curso[i].notas[j]).
  • 36. Structs anidados: meter struct Fecha dentro de struct Persona y acceder con doble punto (persona.nacimiento.dia) o con puntero (ptr->nacimiento.anio).

02 El Problema: ¿Por Qué No Conviene nota1, nota2, nota3?

En la Sección 28 del apunte habíamos escrito una estructura con 3 notas separadas. Pero ¿qué pasa si un estudiante rinde 10 materias en el año?

❌ Con campos numerados a mano
struct Alumno { char nombre[30]; float nota1; float nota2; float nota3; // ¿Y si fueran 10 notas? };

No podés recorrer nota1, nota2, nota3 con un ciclo for. Tenés que sumarlas una por una a mano.

✅ Con un arreglo interno (Sección 35)
struct Estudiante { char nombre[50]; float notas[3]; };

Todas las notas viven en un vector adentro del estudiante y se pueden recorrer con un for sin importar si son 3 o 30.

04 Cómo Acceder a las Notas Internas: estudiante.notas[0]

Si declaramos una variable struct Estudiante estudiante;, ¿cómo accedemos a su primera nota?

acceso_notas.c Página 33 del Apunte
estudiante.notas[0] = 8.5; // Primera nota del estudiante estudiante.notas[1] = 7.0; // Segunda nota del estudiante estudiante.notas[2] = 9.5; // Tercera nota del estudiante
1
estudiante → Es una sola variable estructura (no un arreglo de estudiantes). Por eso lleva punto . directamente.
2
.notas → Entramos al campo notas, que es un arreglo de 3 float.
3
[0] → Elegimos el casillero 0 de ese arreglo interno (la primera nota del estudiante).

05 Comparación Visual: ¿Dónde Va el Corchete [ ]?

El corchete [i] siempre va pegado a lo que sea un arreglo. Compará lado a lado la Unidad 10 con la Unidad 11:

Caso A: Arreglo de Structs (Unidad 10)

struct Alumno clase[30]; // Muchos alumnos, 1 promedio c/u: clase[i].promedio = 8.5;

¿Quién tiene corchetes en su declaración? clase[30].
Por eso escribimos clase[i].promedio.

Caso B: Struct con Arreglo Interno (Unidad 11)

struct Estudiante estudiante; // 1 estudiante, muchas notas: estudiante.notas[i] = 8.5;

¿Quién tiene corchetes en su declaración? notas[3].
Por eso escribimos estudiante.notas[i].

06 Ejemplo Nivel 1: Cargar y Mostrar las 3 Notas de un Estudiante

nivel1_estudiante.c Nivel 1
#include <stdio.h> #include <string.h> struct Estudiante { char nombre[50]; float notas[3]; }; int main() { struct Estudiante estudiante; strcpy(estudiante.nombre, "Martina"); estudiante.notas[0] = 8.0; estudiante.notas[1] = 9.5; estudiante.notas[2] = 10.0; printf("Estudiante: %s\n", estudiante.nombre); for(int i = 0; i < 3; i++) { printf("Nota %d: %.2f\n", i + 1, estudiante.notas[i]); } return 0; }

Observá el ciclo for

Como estudiante es siempre el mismo, queda fijo a la izquierda del punto. Lo único que cambia en cada vuelta del for es el índice i dentro de estudiante.notas[i] (va valiendo 0, 1 y 2).

Salida bash
Estudiante: Martina Nota 1: 8.00 Nota 2: 9.50 Nota 3: 10.00

07 Función del Apunte: calcularPromedio(struct Estudiante e)

En la página 33 del apunte vemos cómo calcular el promedio de un struct Estudiante combinando todo lo aprendido:

calcular_promedio.c Sección 35 del Apunte
float calcularPromedio(struct Estudiante e) { float suma = 0; for(int i = 0; i < 3; i++) { suma += e.notas[i]; } return suma / 3; }

6 Conceptos que combina esta función (según el apunte)

  • 1. Struct: recibe struct Estudiante e.
  • 2. Arreglo: accede al vector interno e.notas[i].
  • 3. Ciclo for: recorre desde i = 0 hasta 2.
  • 4. Acumulador: suma += e.notas[i];.
  • 5. Función: encapsula el cálculo.
  • 6. return: devuelve el promedio suma / 3.

08 Ejemplo Nivel 2: Traza Completa de calcularPromedio

main_promedio_interno.c Nivel 2
#include <stdio.h> struct Estudiante { char nombre[50]; float notas[3]; }; float calcularPromedio(struct Estudiante e) { float suma = 0; for(int i = 0; i < 3; i++) { suma += e.notas[i]; } return suma / 3; } int main() { struct Estudiante est = {"Lucas", {7.0, 8.0, 9.0}}; float prom = calcularPromedio(est); printf("Promedio de %s: %.2f\n", est.nombre, prom); return 0; }

09 Curiosidad de Memoria: Arreglo Suelto vs Arreglo Dentro de Struct

Cuando pasás un vector suelto: void f(float notas[])

En C, un arreglo suelto no se copia al pasarlo a una función: se envía el puntero a su primer elemento.

Cuando pasás struct Estudiante e por valor

Como el arreglo notas[3] está adentro de la caja de la Struct, al pasar struct Estudiante e por valor C copia la caja entera (incluyendo las 3 notas). Si querés modificar las notas originales desde una función, recibís un puntero struct Estudiante *e y escribís e->notas[i].

puntero_arreglo_interno.c Modificar notas con puntero
void sumarPuntoExtra(struct Estudiante *e) { for(int i = 0; i < 3; i++) { e->notas[i] += 1.0; // e es puntero (->), notas es arreglo ([i]) } }

10 Combinación Total: Un Curso de Estudiantes con 3 Notas Cada Uno

¿Qué pasa si ahora creamos un arreglo de struct Estudiante? Por ejemplo: struct Estudiante curso[4];. ¡Tenemos un arreglo de estructuras donde cada estructura tiene adentro su propio arreglo de notas!

doble_indice.c curso[i].notas[j]
struct Estudiante curso[4]; // Nota 2 del estudiante 0: curso[0].notas[2] = 9.5;

Primer índice: curso[i]

Elige a qué estudiante del curso nos referimos (por ejemplo, estudiante i).

Segundo índice: .notas[j]

Elige qué examen de ese estudiante estamos leyendo o guardando (nota j).

11 Ejemplo Nivel 3: Recorrer Todo el Curso y sus Notas

curso_con_notas.c Nivel 3
#include <stdio.h> struct Estudiante { char nombre[50]; float notas[3]; }; float calcularPromedio(struct Estudiante e) { float suma = 0; for(int j = 0; j < 3; j++) { suma += e.notas[j]; } return suma / 3; } int main() { struct Estudiante curso[2] = { {"Ana", {8.0, 9.0, 10.0}}, {"Bruno", {6.0, 7.0, 8.0}} }; for(int i = 0; i < 2; i++) { float p = calcularPromedio(curso[i]); printf("%s -> Promedio: %.2f\n", curso[i].nombre, p); } return 0; }

Mirá qué limpio queda al reutilizar la función

En main recorremos a cada estudiante con i y le pasamos curso[i] (un struct Estudiante individual) a la función calcularPromedio que ya teníamos hecha.

Salida bash

12 36. Structs Anidados: ¿Por Qué Meter una Struct Dentro de Otra?

Imaginá que queremos guardar la fecha de nacimiento de una persona, la fecha de ingreso de un empleado y la fecha de vencimiento de un producto.

❌ Sin anidar: repetir 3 ints en cada Struct
struct Persona { char nombre[50]; int diaNac; int mesNac; int anioNac; };

Si una persona tiene fecha de nacimiento y fecha de alta, tendrías 6 variables sueltas mezcladas.

✅ Con Structs Anidados (Sección 36)
struct Fecha { int dia; int mes; int anio; }; struct Persona { char nombre[50]; struct Fecha nacimiento; };

Creamos el molde struct Fecha una vez y lo usamos como campo dentro de struct Persona.

13 36. Structs Anidados: Definición y Jerarquía del Apunte

Definición del Apunte (Sección 36, pág. 34)

Una Struct puede contener otra Struct. Para que el compilador conozca el tamaño de la estructura interna, siempre declaramos primero la estructura más chiquita (struct Fecha) arriba, y después la estructura que la contiene (struct Persona).

structs_anidados.c Sección 36
struct Fecha { int dia; int mes; int anio; }; struct Persona { char nombre[50]; struct Fecha nacimiento; };

Árbol Jerárquico del Apunte

Persona
├── nombre
└── nacimiento
    ├── dia
    ├── mes
    └── anio

Es como una caja grande (Persona) que adentro guarda otra cajita más chica (nacimiento) con 3 divisiones.

16 Inicializar con Llaves { } y Leer con scanf

Inicialización directa con llaves anidadas

struct Persona p = { "Sofia", {21, 9, 2005} };

Las llaves internas {21, 9, 2005} cargan en orden dia, mes y anio del campo nacimiento.

Lectura por teclado con scanf

scanf("%s", persona.nombre); scanf("%d", &persona.nacimiento.dia); scanf("%d", &persona.nacimiento.mes); scanf("%d", &persona.nacimiento.anio);

Como dia, mes y anio son de tipo int, colocamos & al principio de toda la expresión.

17 Enviar una Struct Anidada o su Sub-Struct a una Función

Una enorme ventaja de separar struct Fecha es que podemos crear funciones que trabajen solo con una struct Fecha, y pasarles persona.nacimiento:

funciones_anidadas.c Modularidad
#include <stdio.h> struct Fecha { int dia; int mes; int anio; }; struct Persona { char nombre[50]; struct Fecha nacimiento; }; void imprimirFecha(struct Fecha f) { printf("%02d/%02d/%d\n", f.dia, f.mes, f.anio); } int calcularEdad(struct Persona p, int anioActual) { return anioActual - p.nacimiento.anio; } int main() { struct Persona per = {"Tomas", {10, 5, 2006}}; imprimirFecha(per.nacimiento); printf("Edad aprox: %d\n", calcularEdad(per, 2026)); return 0; }

Fijate en las dos llamadas:

  • imprimirFecha(per.nacimiento): Como per.nacimiento es de tipo struct Fecha, encaja perfecto en el parámetro struct Fecha f.
  • calcularEdad(per, 2026): Recibe toda la struct Persona y adentro usa p.nacimiento.anio.
Salida bash
10/05/2006 Edad aprox: 20

18 Punteros a Structs Anidados: ¿Cuándo Usar -> y Cuándo .?

¿Qué pasa si una función recibe un puntero a struct Persona (struct Persona *ptr) para modificar su fecha de nacimiento?

puntero_anidado.c ptr->nacimiento.anio
void corregirAnio(struct Persona *ptr, int nuevoAnio) { ptr->nacimiento.anio = nuevoAnio; }

¿Por qué el primero es flecha (->)?

Porque ptr es un puntero a struct Persona. Para entrar de ptr a su campo nacimiento hay que desreferenciar con ->.

¿Por qué el segundo es punto (.)?

Porque dentro de struct Persona, el campo struct Fecha nacimiento; no es un puntero, es una estructura normal guardada por valor. Por eso lleva .anio.

19 Programa Completo Modificando una Struct Anidada por Puntero

modificar_fecha_puntero.c Puntero + Anidamiento
#include <stdio.h> struct Fecha { int dia; int mes; int anio; }; struct Persona { char nombre[50]; struct Fecha nacimiento; }; void actualizarFecha(struct Persona *p, int d, int m, int a) { p->nacimiento.dia = d; p->nacimiento.mes = m; p->nacimiento.anio = a; } int main() { struct Persona alu = {"Valen", {1, 1, 2000}}; actualizarFecha(&alu, 14, 7, 2007); printf("%s nacio el %d/%d/%d\n", alu.nombre, alu.nacimiento.dia, alu.nacimiento.mes, alu.nacimiento.anio); return 0; }

20 Ejemplo Nivel 4: Construyendo una Solución Paso a Paso

Problema de Examen (Nivel 4)

Tenemos un arreglo struct Persona grupo[4]; donde cada persona tiene su nombre y su struct Fecha nacimiento. Queremos escribir una función que cuente cuántas personas nacieron en un mes determinado (por ejemplo, en el mes 9, septiembre).

1
¿Qué recibe la función? El arreglo struct Persona grupo[], su cantidad int tamano y el mes buscado int mesBuscado.
2
¿Cómo accedemos al mes de la persona i? Primero elegimos la persona con grupo[i], luego entramos a .nacimiento y luego a .mes → grupo[i].nacimiento.mes.
3
¿Qué devolvemos? Un contador int contador inicializado en 0 que se incrementa cada vez que coincide el mes.

21 Código Completo del Ejemplo Nivel 4 y Traza

#include <stdio.h> struct Fecha { int dia; int mes; int anio; }; struct Persona { char nombre[50]; struct Fecha nacimiento; }; int contarPorMes(struct Persona grupo[], int tamano, int mesBuscado) { int cont = 0; for(int i = 0; i < tamano; i++) { if(grupo[i].nacimiento.mes == mesBuscado) { cont++; } } return cont; } int main() { struct Persona grupo[4] = { {"Ana", {12, 9, 2005}}, {"Luis", {3, 4, 2004}}, {"Sol", {28, 9, 2006}}, {"Teo", {19, 9, 2005}} }; int total = contarPorMes(grupo, 4, 9); printf("Nacidos en septiembre: %d\n", total); return 0; }

23 ¿Cómo Saber Quién es Mayor Comparando Dos struct Fecha?

No podemos escribir if (p1.nacimiento < p2.nacimiento) porque C no compara structs con <. Comparamos primero el año, si empatan el mes, y si empatan el día:

comparar_fechas.c Comparación Jerárquica
// Devuelve 1 si f1 es anterior (más vieja) que f2, o 0 si no: int esAnterior(struct Fecha f1, struct Fecha f2) { if(f1.anio != f2.anio) { return f1.anio < f2.anio; } if(f1.mes != f2.mes) { return f1.mes < f2.mes; } return f1.dia < f2.dia; }

💡 Si los años son distintos (ej: 2004 vs 2006), ya sabemos cuál es anterior sin mirar el mes. Solo cuando los años son iguales pasamos a desempatar por mes, y luego por dia.

24 Errores Frecuentes de Principiantes (Parte 1)

Error #1: Declarar las estructuras en el orden inverso (usar struct Fecha antes de haberla definido).

❌ Incorrecto: Persona antes que Fecha
struct Persona { char nombre[50]; struct Fecha nacimiento; // ¿Cuánto mide Fecha? }; struct Fecha { int dia, mes, anio; };

Error de compilación (incomplete type): Al leer struct Persona, el compilador todavía no sabe qué campos tiene struct Fecha.

✅ Correcto: Primero la struct interna
struct Fecha { int dia, mes, anio; }; struct Persona { char nombre[50]; struct Fecha nacimiento; };

Regla: Definí siempre primero los bloques más pequeños (Fecha) y debajo las estructuras que los contienen (Persona).

25 Errores Frecuentes de Principiantes (Parte 2)

Error #2: Saltearse el nombre del campo intermedio (nacimiento) o usar el nombre del tipo (Fecha) en vez del nombre del campo.

❌ Incorrecto: Saltear el campo o usar el tipo
// Error A: saltearse .nacimiento persona.dia = 15; // Error B: poner el nombre del tipo persona.Fecha.dia = 15;

Persona no tiene un campo llamado dia directo, y Fecha es el nombre del molde, no de la variable interna.

✅ Correcto: variable.campoStruct.campoFinal
persona.nacimiento.dia = 15; persona.nacimiento.mes = 8; persona.nacimiento.anio = 2005;

Seguimos los nombres de las variables/campos declarados: persona → nacimiento → dia.

26 Errores Frecuentes de Principiantes (Parte 3)

Error #3: En calcularPromedio(struct Estudiante e), olvidarse de inicializar el acumulador float suma = 0; o dividir afuera por un número equivocado.

❌ Incorrecto: Acumulador con basura
float calcularPromedio(struct Estudiante e) { float suma; // ¡Basura de RAM! for(int i = 0; i < 3; i++) { suma += e.notas[i]; } return suma / 3; }

Si no inicializás suma = 0;, suma las 3 notas sobre cualquier valor basura que hubiera en memoria.

✅ Correcto: Inicializar float suma = 0;
float calcularPromedio(struct Estudiante e) { float suma = 0; for(int i = 0; i < 3; i++) { suma += e.notas[i]; } return suma / 3; }

Exactamente como muestra la página 33 del apunte: acumulador en cero antes del for.

28 Buenas Prácticas al Diseñar Structs Complejas

Cuándo usar un arreglo interno

  • Siempre que una entidad tenga varios valores del mismo significado y mismo tipo (ej: las 3 notas de un alumno, las 4 temperaturas del día, los 12 pagos mensuales de un socio).
  • Nunca crees pago1, pago2, pago3...: usá un vector interno para poder recorrerlo con for.

Cuándo usar una Struct anidada

  • Cuando varios campos forman un concepto propio con sentido (ej: struct Fecha con día, mes y año, o struct Direccion con calle, número y código postal).
  • Elegí nombres de campo cortos y descriptivos: nacimiento, ingreso, domicilio.

30 Ejercicio 1: Nota Más Alta de un Estudiante

Enunciado

Dada struct Estudiante { char nombre[50]; float notas[3]; };, escribí una función float mayorNota(struct Estudiante e) que recorra el arreglo interno e.notas y devuelva la nota más alta de ese estudiante.

💻 Ver solución paso a paso
float mayorNota(struct Estudiante e) { float max = e.notas[0]; for(int i = 1; i < 3; i++) { if(e.notas[i] > max) { max = e.notas[i]; } } return max; }

💡 Inicializamos max con la primera nota e.notas[0] y comparamos contra e.notas[1] y e.notas[2].

31 Ejercicio 2: Verificar Si un Estudiante Aprobó Todas las Materias

Enunciado

Con la misma struct Estudiante, escribí una función int aproboTodo(struct Estudiante e) que devuelva 1 si las 3 notas de e.notas son mayores o iguales a 6.0, o 0 si desaprobó alguna.

💻 Ver solución paso a paso
int aproboTodo(struct Estudiante e) { for(int i = 0; i < 3; i++) { if(e.notas[i] < 6.0f) { return 0; // Encontró una nota desaprobada } } return 1; // Las 3 notas fueron >= 6.0 }

💡 Igual que en esPalindromo, si encontramos una nota menor a 6 cortamos inmediatamente con return 0;. Si termina el ciclo sin fallar, retorna 1.
