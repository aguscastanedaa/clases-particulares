02 15. Punteros: El Tema Más Importante del Material

Definición del Apunte

Ahora viene probablemente uno de los temas más importantes y más difíciles de todo el material:
Un puntero es una variable que guarda una dirección de memoria.

Lo que conocíamos hasta ahora

Hasta ahora, cuando declarábamos una variable común como:

int edad = 19;

Nos imaginábamos simplemente una cajita llamada edad que adentro guarda el número 19.

edad int
19

03 ¿Dónde Vive Realmente int edad = 19;?

Esa cajita llamada edad no flota en el aire: está guardada en algún casillero físico de la memoria RAM. Cada casillero tiene un número de ubicación llamado dirección de memoria.

Ejemplo Imaginario del Apunte

Supongamos imaginariamente que la variable edad cayó en el casillero número 1000 de la memoria:

Dirección: 1000
Valor:     19

edad ↓
1000 → 19

👉 Un puntero nos permite guardar ese número 1000 (la dirección) adentro de otra variable.

Dirección: 1000
edad int
19
La variable tiene dos datos clave:
su valor (19) y su dirección (1000).

04 16. Direcciones de Memoria y cómo Obtenerlas

Regla del Apunte

Cada variable está almacenada en una posición de memoria. Podemos obtener su dirección utilizando el símbolo ampersand: &.

imprimir_direccion.c Sección 16 del Apunte
#include <stdio.h> int main() { int edad = 19; printf("%d\n", edad); // 19 printf("%p\n", &edad); // dirección de memoria return 0; }
Terminal Salida Real
$ ./direccion 19 0x7ffe1234abcd

🔍 ¿Qué es ese 0x7ffe1234abcd? No es el contenido de edad, sino la ubicación física de edad en la memoria RAM expresada en sistema hexadecimal (por eso empieza con 0x).

05 ¿Por Qué Usamos %p y No %d?

La diferencia está en qué tipo de información le estamos pasando a printf:

printf("%d", edad);

  • Le pasamos edad (sin &).
  • Contiene el valor numérico entero 19.
  • Usamos %d porque %d espera recibir un número int común.

printf("%p", &edad);

  • Le pasamos &edad (con &).
  • Contiene la dirección de memoria donde está guardada edad.
  • Usamos %p porque viene del inglés pointer (puntero) y está diseñado específicamente para imprimir direcciones de memoria.

💡 Nota de compatibilidad C99: Muchos compiladores aceptan printf("%p", &edad) directamente, o bien printf("%p", (void*)&edad) para evitar advertencias estrictas de formato.

07 17. El Operador & (Operador de Dirección)

Definición del Apunte

El operador & significa literalmente: "Dame la dirección de memoria de esta variable."

Ejemplo Conceptual del Apunte

Si declaramos int edad = 19; y esa variable está alojada en la dirección 1000:

edad
┌──────┐
│  19  │
└──────┘
   ↑ dirección 1000

Entonces: &edad → 1000

¡Por eso scanf siempre llevaba &!

Desde la primera clase de C escribíamos:

scanf("%d", &edad);

Ahora todo cierra: a scanf no le importaba qué número tenía edad antes, sino que necesitaba la dirección de memoria &edad para ir hasta esa casilla y depositar ahí el número que escribiste por teclado.

08 18. El Operador *: Declarar un Puntero

¿Cómo creamos una variable capaz de guardar una dirección?

No podemos guardar una dirección de memoria en un int común. Necesitamos declarar una variable puntero colocando un asterisco * entre el tipo de dato y el nombre.

declaracion_puntero.c Sección 18 del Apunte
int edad = 19; int *puntero = &edad;

1. int *puntero

Significa: puntero es una variable de tipo puntero a un int (solo puede apuntar a variables enteras).

2. = &edad

Obtenemos la dirección donde vive edad (1000) y la guardamos adentro de puntero.

3. Resultado

Decimos que ahora puntero apunta a edad.

09 Representación en Memoria RAM: puntero → edad

Veamos qué hay exactamente en la memoria RAM después de ejecutar int edad = 19; int *puntero = &edad;:

Dirección: 1000
edad int
19
▲ apunta a la dirección 1000
Dirección propia: 2050
puntero int *

Observaciones Clave del Esquema

  • Existen dos cajitas en la memoria RAM: edad y puntero.
  • Adentro de la cajita edad está guardado el número 19.
  • Adentro de la cajita puntero está guardado el número 1000 (que es la dirección de edad).
  • Por eso dibujamos una flecha que sale de puntero y llega a edad.

10 ¿Qué Significa *puntero Cuando Ya Está Creado?

Definición del Apunte (Sección 18)

Escribir *puntero significa:
"Dame el valor que está guardado en la dirección a la que apunta el puntero."

leer_con_asterisco.c Desreferenciar
#include <stdio.h> int main() { int edad = 19; int *puntero = &edad; printf("%d\n", *puntero); // Imprime 19 return 0; }

El viaje paso a paso de *puntero

1
Mira qué dirección tiene anotada puntero adentro (1000).
2
El operador * viaja por la memoria RAM hasta la casilla 1000 (donde vive edad).
3
Abre esa casilla y nos devuelve el valor que hay adentro: 19.

11 ¡Atención! Los Dos Significados del Símbolo *

Una de las mayores dudas al empezar es ver el símbolo * en dos lugares distintos. Su significado depende de dónde aparezca:

Uso 1: Al Declarar la Variable

int *puntero;

Acá tiene el tipo int adelante. No está buscando ningún valor todavía: solo le avisa a C que la nueva variable puntero es de tipo "puntero a entero".

Uso 2: Al Usar el Puntero (Desreferenciar)

printf("%d", *puntero); *puntero = 25;

Acá aparece sin el int adelante, en medio de una instrucción. Actúa como el operador que dice: "Andá a la dirección guardada en puntero y accedé al valor de esa variable".

12 Modificar el Valor Usando *puntero = 25;

Con *puntero no solo podemos leer el 19: si lo ponemos a la izquierda de un =, ¡modificamos directamente la variable apuntada!

modificar_con_puntero.c Escritura Indirecta
#include <stdio.h> int main() { int edad = 19; int *puntero = &edad; printf("Antes: %d\n", edad); *puntero = 25; printf("Despues: %d\n", edad); return 0; }
Terminal Salida
$ ./modificar Antes: 19 Despues: 25

😮 ¡Mirá lo que pasó! Nunca escribimos edad = 25;. Pero como puntero apunta a la dirección 1000 (la casilla de edad), hacer *puntero = 25; guardó el 25 en esa casilla y cambió a edad.

13 19. & y * — La Diferencia Fundamental

Partiendo de las dos líneas del apunte: int edad = 19; e int *puntero = &edad;, repasemos qué significa cada expresión:

&edad

Significa: ¿Dónde está edad?
Devuelve: Su dirección de memoria (1000).

puntero

Contiene: La dirección de edad.
Devuelve: Esa misma dirección guardada (1000).

*puntero

Significa: ¿Qué valor hay en esa dirección?
Devuelve: 19.

En resumen, la diferencia del apunte sería:

  • & → obtener la DIRECCIÓN de memoria.
  • puntero → una variable que GUARDA una dirección de memoria.
  • * → ir a esa dirección y "AGARRAR" el VALOR que hay ahí.

14 La Analogía de la Casa (Sección 19 del Apunte)

Imaginemos una casa real para entender las 4 piezas sin ninguna duda:

📍

📝

18 Ejemplo Nivel 3: Un Puntero Puede Cambiar de Destino

En la analogía de la casa, podemos borrar la dirección escrita en el papelito (puntero) y anotar la dirección de otra casa distinta:

nivel3_cambiar_destino.c Nivel 3
#include <stdio.h> int main() { int a = 10; int b = 20; int *p; p = &a; // p apunta a 'a' *p = 15; // cambia 'a' a 15 p = &b; // ahora p apunta a 'b' *p = 99; // cambia 'b' a 99 printf("a = %d, b = %d\n", a, b); return 0; }

Notá la diferencia: p = &b; (sin *) cambia la dirección guardada en el papelito; *p = 99; (con *) modifica la variable apuntada.

19 ¿Pueden Dos Punteros Apuntar a la Misma Variable?

¡Sí! Es como tener dos papelitos distintos donde anotamos la dirección de la misma casa:

dos_punteros.c Alias en Memoria
#include <stdio.h> int main() { int edad = 19; int *p1 = &edad; int *p2 = &edad; *p1 = 30; printf("edad: %d\n", edad); printf("*p2: %d\n", *p2); return 0; }

¿Qué muestra por pantalla?

$ ./dos_punteros edad: 30 *p2: 30

Como tanto p1 como p2 guardan la dirección 1000 (la de edad), cuando *p1 = 30; modifica esa casilla, al mirar a través de *p2 vemos inmediatamente el 30.

20 El Tipo del Puntero Debe Coincidir con la Variable

¿Por qué declaramos int *, float * o char * si todas son direcciones?

Porque cuando hacés *puntero, el compilador de C necesita saber cuántos bytes leer a partir de esa dirección y cómo interpretarlos (un char ocupa 1 byte, un int 4 bytes, un double 8 bytes).

tipos_punteros.c Correspondencia de Tipos
#include <stdio.h> int main() { int edad = 19; float precio = 150.5f; char letra = 'A'; int *pEdad = &edad; // int* apunta a int float *pPrecio = &precio; // float* apunta a float char *pLetra = &letra; // char* apunta a char printf("%d | %.1f | %c\n", *pEdad, *pPrecio, *pLetra); return 0; }

21 Operaciones Matemáticas Usando *puntero

Como *puntero representa el valor entero guardado en la variable apuntada, podemos usarlo en cualquier suma, resta, multiplicación o comparación igual que un int normal:

aritmetica_desreferencia.c Cálculos
#include <stdio.h> int main() { int x = 10; int y = 4; int *px = &x; int *py = &y; int suma = *px + *py; // 10 + 4 = 14 *px = *px * 3; // x pasa a valer 30 printf("Suma: %d, Nuevo x: %d\n", suma, x); return 0; }

Cómo leer cada línea en voz alta

  • int suma = *px + *py;
    "Sumá el valor apuntado por px (10) más el valor apuntado por py (4)".
  • *px = *px * 3;
    "Tomá el valor apuntado por px (10), multiplicalo por 3 y guardá el resultado (30) en la casilla apuntada por px".

22 Ejemplo Nivel 4: Apuntar al Mayor de Dos Números

Problema de Razonamiento

Tenemos dos cuentas o puntajes int a = 40; int b = 75; y queremos usar un único puntero int *pMayor para que apunte a la variable más grande y le sume un premio de 100 puntos.

nivel4_apuntar_mayor.c Nivel 4
#include <stdio.h> int main() { int a = 40, b = 75; int *pMayor; if (a > b) { pMayor = &a; } else { pMayor = &b; } *pMayor += 100; // Premia a la variable apuntada printf("a = %d | b = %d\n", a, b); return 0; }
Terminal Salida
$ ./apuntar_mayor a = 40 | b = 175

💡 Una vez que el if decide a qué dirección apunta pMayor, el resto del programa opera sobre *pMayor sin necesitar más condicionales.

23 ¿Qué es NULL en un Puntero?

El papelito en blanco

En C existe una constante especial llamada NULL (definida en <stdio.h> y <stdlib.h>) que vale dirección 0 y significa: "Este puntero no apunta a ninguna variable válida en este momento".

puntero_null.c Verificación Segura
#include <stdio.h> int main() { int *puntero = NULL; if (puntero != NULL) { printf("Valor: %d\n", *puntero); } else { printf("El puntero no apunta a nada aun.\n"); } return 0; }

¿Para qué sirve inicializar en NULL?

  • Si todavía no sabés a qué variable va a apuntar un puntero, inicializalo en NULL.
  • Así podés preguntar con un if (puntero != NULL) antes de usar *puntero.
  • Recordá que en strchr y strstr o en malloc también devolvían NULL cuando no encontraban nada.

24 Error Crítico #1: Puntero Sin Inicializar (Puntero Salvaje)

❌ Desreferenciar un puntero sin asignarle dirección
int *puntero; // Tiene dirección basura *puntero = 19; // ¡CRASH! Violación de segmento

En la analogía de la casa: tenés un papel con una dirección aleatoria inventada y te metés por la fuerza a esa casa. El sistema operativo detiene tu programa inmediatamente (Segmentation Fault).

✅ Primero apuntar a una variable real, luego usar *
int edad; int *puntero = &edad; // Apunta a una caja válida *puntero = 19; // Ahora sí guarda 19 en edad

Un puntero necesita que primero exista una variable (o bloque dinámico) a la cual apuntar antes de poder hacer *puntero = ....

25 Error Crítico #2: Desreferenciar un Puntero NULL

❌ Aplicar * cuando el puntero vale NULL
int *p = NULL; printf("%d\n", *p); // ¡CRASH! Intenta leer la dirección 0

NULL indica explícitamente "ninguna casa". Si hacés *p cuando p es NULL, intentás entrar a la dirección 0 de la RAM, que está prohibida.

✅ Asignar una dirección válida o verificar antes
int edad = 19; int *p = &edad; if (p != NULL) { printf("%d\n", *p); // Seguro: imprime 19 }

Siempre asegurate de que el puntero apunte a una variable antes de aplicarle el operador *.

26 Error Crítico #3: Olvidar el & al Asignar el Puntero

❌ Guardar el valor en vez de la dirección
int edad = 19; int *puntero = edad; // ¡MAL! Falta el &

Si escribís puntero = edad, estás guardando el número 19 como si fuera la dirección de memoria 0x00000013, en lugar de la dirección donde vive edad.

✅ Usar siempre &variable para obtener su dirección
int edad = 19; int *puntero = &edad; // ¡BIEN! Guarda la dirección

Recordá: un puntero guarda direcciones, por lo tanto del lado derecho de la asignación a un puntero tiene que haber una dirección (como &edad o NULL).

27 Error Crítico #4: Confundir %d y %p en printf

❌ Usar %d con una dirección o olvidar el *
int edad = 19; int *puntero = &edad; // Quería imprimir 19 pero olvidó el asterisco: printf("Edad: %d\n", puntero);

Imprime un número gigante sin sentido (parte de la dirección de memoria convertida a entero) en vez de 19.

✅ %d para valores (edad, *puntero) y %p para direcciones
int edad = 19; int *puntero = &edad; printf("Edad: %d\n", *puntero); // 19 printf("Dir: %p\n", (void*)puntero); // 0x7ffe...

Si querés ver el número entero apuntado, poné *puntero con %d. Si querés ver la dirección, poné puntero o &edad con %p.

28 Curiosidad Clave: scanf con una Variable vs. con un Puntero

Esta comparación te demuestra si entendiste de verdad qué guarda un puntero:

scanf_puntero.c Razonamiento
#include <stdio.h> int main() { int edad = 0; int *puntero = &edad; // Ambas líneas hacen EXACTAMENTE lo mismo: // scanf("%d", &edad); scanf("%d", puntero); printf("Leido: %d\n", edad); return 0; }

¿Por qué scanf("%d", puntero) no lleva &?

Porque scanf pide como segundo argumento la dirección de memoria de la variable entera donde debe guardar el dato.

Como puntero ya es igual a &edad (ya contiene esa dirección), pasarle puntero es exactamente lo mismo que pasarle &edad.

29 Buenas Prácticas al Trabajar con Punteros

Reglas de Seguridad

  • Inicializá siempre tus punteros en el momento de declararlos: ya sea con la dirección de una variable (int *p = &x;) o con NULL (int *p = NULL;).
  • Dibujá las cajitas y las flechas en una hoja de papel cuando tengas que seguir un código con punteros: ver a qué variable apunta la flecha evita el 99% de las confusiones.
  • Leé el código en castellano: leé &x como "la dirección de x" y leé *p como "la variable apuntada por p".

Estilo de Escritura: ¿int *p o int* p?

En C ambas formas son válidas, pero en el apunte escribimos el asterisco pegado al nombre:

int *puntero = &edad;

Escribir int *puntero nos recuerda que *puntero es un int, y evita confusiones si alguien declara varias variables en una misma línea.

30 Ejercicio 1: Predecir la Salida Paso a Paso

Enunciado

Sin ejecutarlo en la computadora, hacé la traza mental del siguiente programa y determiná qué valores exactos de numero y *ptr se imprimen al final:

#include <stdio.h> int main() { int numero = 10; int *ptr = &numero; *ptr = *ptr + 5; numero = numero * 2; printf("numero = %d, *ptr = %d\n", numero, *ptr); return 0; }
💻 Ver solución y explicación paso a paso

1. numero empieza en 10 y ptr apunta a numero.
2. *ptr = *ptr + 5; le suma 5 a la variable apuntada (numero pasa a valer 15).
3. numero = numero * 2; multiplica 15 * 2 (numero pasa a valer 30).
4. Como ptr sigue apuntando a numero, imprime: numero = 30, *ptr = 30.

33 Puente hacia la Unidad 06: ¿Para Qué Queremos Punteros?

La gran pregunta de todo estudiante

"Si estoy adentro de main() y tengo la variable edad ahí mismo, ¿para qué haría *puntero = 25; en vez de escribir directamente edad = 25;?"

Adentro de la misma función

Tenés toda la razón: adentro de main() lo hacemos solo para practicar y entender cómo funcionan los operadores & y *.

Entre distintas funciones (Unidad 06)

Cuando llamamos a otra función (ej. cambiar(&x) o dividir(10, 3, &cociente, &resto)), esa función no tiene acceso directo a las variables de main(). ¡Pasarle un puntero con la dirección es la única forma de que la función modifique nuestras variables originales!

34 Resumen de la Unidad 05 y Checklist

Conceptos Esenciales (Secciones 15 a 19)

  • Puntero: variable que guarda una dirección de memoria (ej. 1000).
  • edad vs &edad: edad es ¿QUÉ hay? (19, %d); &edad es ¿DÓNDE está? (0x7ffe..., %p).
  • Operador &: "Dame la dirección de memoria de esta variable".
  • Operador *: "Ir a esa dirección y agarrar el valor que hay ahí".
  • Analogía: Casa = variable | Dirección = &variable | Papel = puntero | Entrar = *puntero.
