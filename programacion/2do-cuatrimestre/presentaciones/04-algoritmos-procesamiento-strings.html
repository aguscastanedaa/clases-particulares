Lo que ya sabemos sobre Strings

  • El carácter nulo '\0' marca exactamente dónde termina el texto útil.

02 8. Comparar Strings: ¿Por Qué No Usar ==?

Diferencia MUY importante respecto a los números

Con variables numéricas podemos hacer if (a == b). Pero con Strings no debemos comparar directamente con if (nombre1 == nombre2) porque los Strings son arreglos.

❌ Comparación Directa de Arreglos
char palabra1[] = "hola"; char palabra2[] = "hola"; if (palabra1 == palabra2) { // ¡FALSO! No compara las letras }

El nombre de un arreglo representa su ubicación en memoria. Como son dos vectores distintos en RAM, palabra1 == palabra2 da falso aunque tengan las mismas letras.

✅ Idea Conceptual del Apunte

Para comparar su contenido manualmente debemos recorrer ambos arreglos carácter por carácter:

posición 0 → 'h' == 'h' ✔️
posición 1 → 'o' == 'o' ✔️
posición 2 → 'l' == 'l' ✔️
posición 3 → 'a' == 'a' ✔️
posición 4 → '\0' == '\0' ✔️

04 Algoritmo del Apunte: sonIguales

son_iguales.c Sección 8 del Apunte
#include <stdbool.h> bool sonIguales(char a[], char b[]) { int i = 0; while(a[i] != '\0' && b[i] != '\0') { if(a[i] != b[i]) { return false; } i++; } return a[i] == b[i]; }

Desglose pieza por pieza

  • while(a[i] != '\0' && b[i] != '\0'): sigue iterando mientras ambas cadenas tengan letras por comparar.
  • if(a[i] != b[i]) return false;: apenas difiere un carácter, corta y retorna falso.
  • i++;: avanza a la siguiente casilla.
  • return a[i] == b[i];: comprueba que ambas hayan llegado al '\0' al mismo tiempo.

05 El Secreto de return a[i] == b[i];

¿Por qué no ponemos simplemente return true; al salir del while? Analicemos dos trazas:

Caso 1: "hola" vs "hola"

ia[i]b[i]¿Sigue el while?
0..3'h','o','l','a''h','o','l','a'Sí (iguales, i++)
4'\0''\0'No (ambos son '\0')

Al salir con i = 4: evalúa a[4] == b[4] ➔ '\0' == '\0' ➔ devuelve true.

Caso 2: "hola" vs "holas"

ia[i]b[i]¿Sigue el while?
0..3'h','o','l','a''h','o','l','a'Sí (iguales, i++)
4'\0''s'No (a[4] llegó a '\0')

Al salir con i = 4: evalúa a[4] == b[4] ➔ '\0' == 's' ➔ devuelve false. ¡Detecta distinta longitud!

08 Función contarCaracter y Conceptos Integrados

int contarCaracter(char cadena[], char caracter) { int contador = 0; for(int i = 0; cadena[i] != '\0'; i++) { if(cadena[i] == caracter) { contador++; } } return contador; }

  • Ciclo for hasta '\0'.
  • Condicional if y comparación (==).
  • Variable contador (contador++).
  • Funciones con retorno entero (return contador;).

10 10. Buscar Subcadenas vs. Comprobar Prefijo

¿Qué es una subcadena?

Una subcadena es una cadena más corta que aparece adentro de otra. Por ejemplo, en "Hola mundo" la subcadena "mundo" está contenida; y en "programacion" la subcadena "gram" también está contenida.

Caso A: ¿Comienza con "pro"?

Cadena:    p r o g r a m a c i o n
Subcadena: p r o

Comparamos los caracteres iniciales: 'p'=='p', 'r'=='r', 'o'=='o'. Todos coinciden ➔ Resultado: Sí (true).

Caso B: ¿Comienza con "gram"?

Cadena:    p r o g r a m a c i o n
Subcadena: g r a m

Aunque "gram" está adentro de la palabra, en la posición 0 tenemos 'p' != 'g'. No empieza con "gram" ➔ Resultado: No (false).

11 Algoritmo del Apunte: comienzaCon

comienza_con.c Sección 10 del Apunte
#include <stdbool.h> bool comienzaCon(char cadena[], char subcadena[]) { int i = 0; while(subcadena[i] != '\0') { if(cadena[i] != subcadena[i]) { return false; } i++; } return true; }

¿Por qué el while mira a subcadena[i]?

Solo necesitamos verificar tantas letras como tenga el prefijo buscado (subcadena):

  • Si subcadena es "pro", el ciclo da 3 vueltas (índices 0, 1 y 2).
  • Cuando llega a subcadena[3] que es '\0', significa que todas las letras del prefijo coincidieron.
  • ¿Y si cadena era más corta (ej. "pr")? En i = 2, cadena[2] es '\0', que es distinto de 'o', y retorna false sin salirse de memoria.

14 Sustituir Todas las Apariciones de un Carácter

Uno de los ejercicios clásicos del apunte pide: Sustituir la aparición de un carácter por otro.

La idea en cada casilla i es:
¿Este carácter cadena[i] es el que estoy buscando?

16 12. Convertir Mayúsculas y Minúsculas (Tabla ASCII)

Objetivo del Ejercicio

Recorrer una cadena y convertir las mayúsculas en minúsculas y las minúsculas en mayúsculas. Por ejemplo: "Hola Mundo" se transforma en "hOLA mUNDO".

¿Cómo sabemos si es mayúscula o minúscula?

En C, cada carácter tiene un código numérico ASCII asociado y las letras del alfabeto inglés están ordenadas en rangos continuos:

  • Mayúsculas 'A', 'B', ..., 'Z' ➔ van del 65 al 90.
    Comprobación: if (cadena[i] >= 'A' && cadena[i] <= 'Z')
  • Minúsculas 'a', 'b', ..., 'z' ➔ van del 97 al 122.
    Comprobación: if (cadena[i] >= 'a' && cadena[i] <= 'z')

La Constante Mágica: 32

La distancia entre cualquier letra mayúscula y su correspondiente minúscula en la tabla ASCII siempre es exactamente 32:

'A' = 65   ──(+32)──►   'a' = 97
'H' = 72   ──(+32)──►   'h' = 104
'o' = 111  ──(-32)──►   'O' = 79

• Mayúscula a minúscula: + 32  |  Minúscula a mayúscula: - 32

17 Algoritmo cambiarMayusculasMinusculas

cambiar_mayus_minus.c Sección 12 del Apunte
void cambiarMayusculasMinusculas(char cadena[]) { for(int i = 0; cadena[i] != '\0'; i++) { if(cadena[i] >= 'A' && cadena[i] <= 'Z') { cadena[i] = cadena[i] + 32; } else if(cadena[i] >= 'a' && cadena[i] <= 'z') { cadena[i] = cadena[i] - 32; } } }

18 13. Invertir un String: La Idea del Espejo

Problema del Apunte

Dada una cadena original (ej. "Hola"), generar otra cadena resultado de invertir la primera ("aloH").

Cadena Original (longitud = 4):

Pos 0
'H'
Pos 1
'o'
Pos 2
'l'
Pos 3
'a'
Pos 4
'\0'

Cadena Invertida (copiando de atrás hacia adelante):

Pos 0
'a'
Pos 1
'l'
Pos 2
'o'
Pos 3
'H'
Pos 4
'\0'

¿De dónde sale longitud - 1 - i?

Si longitud = 4, la última letra válida está en longitud - 1 = 3 (porque en la posición 4 está el '\0'). A medida que i sube (0, 1, 2, 3), restamos i para bajar (3, 2, 1, 0):

i = 0 → invertida[0] = cadena[4 - 1 - 0] = cadena[3] ('a')
i = 1 → invertida[1] = cadena[4 - 1 - 1] = cadena[2] ('l')
i = 2 → invertida[2] = cadena[4 - 1 - 2] = cadena[1] ('o')
i = 3 → invertida[3] = cadena[4 - 1 - 3] = cadena[0] ('H')

19 Algoritmo del Apunte: invertirString

invertir_string.c Sección 13 del Apunte
#include <stdio.h> #include <string.h> void invertirString(char cadena[], char invertida[], int longitud) { for(int i = 0; i < longitud; i++) { invertida[i] = cadena[longitud - 1 - i]; } invertida[longitud] = '\0'; } int main() { char orig[] = "Hola"; char inv[10]; invertirString(orig, inv, 4); printf("Original: %s\n", orig); printf("Invertida: %s\n", inv); return 0; }
Terminal Salida
$ ./invertir Original: Hola Invertida: aloH

¡Nunca olvides invertida[longitud] = '\0';!

El ciclo for copia únicamente las 4 letras (posiciones 0, 1, 2 y 3). Si no agregás manualmente el '\0' en la posición longitud (4), invertida no tendrá marca de fin y printf("%s", inv) imprimirá basura de la memoria.

20 14. Palíndromos: Definición y Ejemplos del Apunte

¿Qué es una palabra palíndroma?

Una palabra palíndroma es aquella que se lee exactamente igual de adelante hacia atrás que de atrás hacia adelante.

"radar"

→ r a d a r
← r a d a r

Es Palíndromo (5 letras)

"reconocer"

→ r e c o n o c e r
← r e c o n o c e r

Es Palíndromo (9 letras)

"neuquen"

→ n e u q u e n
← n e u q u e n

Es Palíndromo (7 letras)

💡 Estrategia sin usar otro vector: En vez de gastar memoria creando una cadena invertida, comparamos directamente los extremos simétricos de la misma palabra acercándonos hacia el centro.

21 Algoritmo del Apunte: esPalindromo

es_palindromo.c Sección 14 del Apunte
#include <stdbool.h> bool esPalindromo(char cadena[], int longitud) { for(int i = 0; i < longitud / 2; i++) { if(cadena[i] != cadena[longitud - 1 - i]) { return false; } } return true; }

24 Ejemplo Nivel 3: Invertir sobre el Mismo Vector

¿Y si combinamos la idea de esPalindromo (ir hasta longitud / 2) con una variable auxiliar aux para invertir el String sin usar otro arreglo?

invertir_in_place.c Nivel 3
#include <stdio.h> void invertirEnSitio(char cad[], int lon) { for (int i = 0; i < lon / 2; i++) { char aux = cad[i]; cad[i] = cad[lon - 1 - i]; cad[lon - 1 - i] = aux; } } int main() { char palabra[] = "Hola"; invertirEnSitio(palabra, 4); printf("Invertida: %s\n", palabra); return 0; }

¿Por qué también frena en lon / 2?

En "Hola" (longitud 4):

  • i = 0: intercambia cad[0] ('H') con cad[3] ('a') ➔ "aolH".
  • i = 1: intercambia cad[1] ('o') con cad[2] ('l') ➔ "aloH".
  • Si siguiera hasta lon, ¡volvería a intercambiarlos dejándola como al principio!

25 Ejemplo Nivel 4: Cómo Pensar un Problema Combinado

Desafío de Integración (Secciones 12 + 14)

Si probamos esPalindromo("Neuquen", 7) da false porque 'N' (78) es distinto de 'n' (110). ¿Cómo diseñamos un verificador de palíndromos que no distinga mayúsculas de minúsculas?

1
Dividir el problema: Creamos una pequeña función auxiliar char aMinuscula(char c) que, si recibe una letra entre 'A' y 'Z', devuelve c + 32; si no, devuelve c sin cambios.
2
Reutilizar la lógica de extremos: En el ciclo for (int i = 0; i < longitud / 2; i++), tomamos el carácter izquierdo y el derecho pasándolos por aMinuscula antes de compararlos.
3
Sin alterar el original: Así "Neuquen" o "Radar" dan true sin modificar el vector original.

26 Código Nivel 4: Palíndromo Sin Importar Mayúsculas

palindromo_insensible.c ASCII + Palíndromo
#include <stdio.h> #include <stdbool.h> char aMinuscula(char c) { if (c >= 'A' && c <= 'Z') { return c + 32; } return c; } bool esPalindromoFlex(char cad[], int lon) { for (int i = 0; i < lon / 2; i++) { if (aMinuscula(cad[i]) != aMinuscula(cad[lon - 1 - i])) { return false; } } return true; } int main() { printf("Neuquen: %d\n", esPalindromoFlex("Neuquen", 7)); printf("Radar: %d\n", esPalindromoFlex("Radar", 5)); return 0; }
Terminal Salida
$ ./palindromo_flex Neuquen: 1 Radar: 1

27 Errores Frecuentes #1: El return true Prematuro

Uno de los errores más comunes en exámenes al programar sonIguales, comienzaCon o esPalindromo:

❌ Poner else return true; adentro del ciclo
for(int i = 0; i < longitud / 2; i++) { if(cadena[i] != cadena[longitud - 1 - i]) { return false; } else { return true; // ¡ERROR GRAVE! } }

Si probás "rabanor", en i = 0 compara 'r' == 'r' y ¡devuelve true en la primera vuelta sin mirar el resto de las letras!

✅ Retornar true recién al terminar el ciclo
for(int i = 0; i < longitud / 2; i++) { if(cadena[i] != cadena[longitud - 1 - i]) { return false; // Corta si falla } } return true; // Recién tras revisar TODO

Para saber que una propiedad falla basta un contraejemplo; para afirmar que se cumple hay que terminar todo el recorrido.

28 Errores Frecuentes #2: El '\0' y el Índice Final

❌ Usar longitud - i y olvidar '\0'
for(int i = 0; i < longitud; i++) { // En i=0 copia cadena[longitud], ¡que es '\0'! invertida[i] = cadena[longitud - i]; } // Y encima olvida cerrar con '\0' al final

Si en i = 0 copiás cadena[longitud] en invertida[0], colocás el '\0' al principio y la cadena invertida queda vacía ("").

✅ Usar longitud - 1 - i y cerrar con '\0'
for(int i = 0; i < longitud; i++) { invertida[i] = cadena[longitud - 1 - i]; } invertida[longitud] = '\0';

La última letra visible siempre está en longitud - 1, y el terminador nulo se escribe afuera del ciclo en invertida[longitud].

29 Buenas Prácticas al Procesar Strings

Hábitos recomendados

  • Usá literales de carácter ('A', 'Z', 'a', 'z') en las condiciones if en vez de memorizar números como 65 o 122: es mucho más legible.
  • Distinguí siempre comilla simple 'a' (un char para comparar una casilla cadena[i]) de comilla doble "a" (un String).
  • Cuando generes una nueva cadena en otro arreglo, verificá que tenga capacidad suficiente para las letras más el '\0'.

30 Ejercicio 1: Contar Vocales Minúsculas

Enunciado

Escribí una función int contarVocales(char cadena[]) que reciba un String y devuelva cuántas vocales minúsculas ('a', 'e', 'i', 'o', 'u') contiene. Probala en main() con la palabra "programacion" (debe devolver 5).

💻 Ver solución paso a paso
#include <stdio.h> int contarVocales(char cadena[]) { int contador = 0; for (int i = 0; cadena[i] != '\0'; i++) { char c = cadena[i]; if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u') { contador++; } } return contador; } int main() { char palabra[] = "programacion"; printf("Vocales: %d\n", contarVocales(palabra)); // Muestra 5 return 0; }

31 Ejercicio 2: Pasar Todo un Texto a Mayúsculas

Enunciado

Basándote en la Sección 12 del apunte, escribí una función void pasarAMayusculas(char cadena[]) que convierta únicamente las letras minúsculas ('a'..'z') a mayúsculas restando 32, dejando intactas las que ya eran mayúsculas, los espacios o los signos. Probala con "Hola C 2025!" (debe quedar "HOLA C 2025!").

💻 Ver solución paso a paso
#include <stdio.h> void pasarAMayusculas(char cadena[]) { for (int i = 0; cadena[i] != '\0'; i++) { if (cadena[i] >= 'a' && cadena[i] <= 'z') { cadena[i] = cadena[i] - 32; } } } int main() { char texto[] = "Hola C 2025!"; pasarAMayusculas(texto); printf("%s\n", texto); // HOLA C 2025! return 0; }

32 Ejercicio 3: Comprobar si Termina con un Sufijo

Enunciado

En el apunte hicimos comienzaCon. Ahora escribí bool terminaCon(char cadena[], int lonCad, char sufijo[], int lonSuf) que compruebe si los últimos caracteres de cadena coinciden con sufijo. Por ejemplo, "archivo.txt" (11) termina con ".txt" (4) ➔ true.

💻 Ver solución paso a paso
#include <stdio.h> #include <stdbool.h> bool terminaCon(char cadena[], int lonCad, char sufijo[], int lonSuf) { if (lonSuf > lonCad) { return false; } int inicio = lonCad - lonSuf; for (int i = 0; i < lonSuf; i++) { if (cadena[inicio + i] != sufijo[i]) { return false; } } return true; } int main() { printf("Es .txt: %d\n", terminaCon("archivo.txt", 11, ".txt", 4)); return 0; }

33 Mapa Completo de las Secciones 8 a 14

Algoritmos de Consulta (No modifican)

  • 8. sonIguales(a, b): recorre mientras ninguno sea '\0'; al final retorna a[i] == b[i].
  • 9. contarCaracter(cad, c): acumula en un contador cada vez que cad[i] == c.
  • 10. comienzaCon(cad, sub): recorre hasta que sub[i] == '\0' verificando igualdad inicial.
  • 14. esPalindromo(cad, lon): compara cad[i] con cad[lon - 1 - i] hasta lon / 2.

Algoritmos de Transformación (Modifican)

  • 11. Sustituir carácter: recorre el String y si cad[i] == buscar asigna cad[i] = reemplazar.
  • 12. cambiarMayusculasMinusculas(cad): suma 32 si está en 'A'..'Z' y resta 32 si está en 'a'..'z'.
  • 13. invertirString(cad, inv, lon): copia inv[i] = cad[lon - 1 - i] y cierra con inv[lon] = '\0'.
