02 Comparación Manual de Cadenas

Comprobar posición por posición si dos arreglos de caracteres son idénticos.

son_iguales.c bool manual
#include <stdbool.h> bool sonIguales(char a[], char b[]) { int i = 0; while(a[i] != '\0' && b[i] != '\0') { if(a[i] != b[i]) { return false; // Al primer carácter distinto, aborta } i++; } // Son iguales si y solo si ambas alcanzaron el '\0' al mismo tiempo return a[i] == b[i]; }

💡 Detalle del return a[i] == b[i]; final: Si una palabra es "hola" y la otra es "holas", el bucle termina en i=4. Ahí a[4] == '\0' pero b[4] == 's'. La comparación final devuelve false de forma impecable.

03 Contar Apariciones de un Carácter

Recorrer una palabra y contar cuántas veces se repite una letra (ej. 'a' en "banana").

contar_caracter.c Contador
int contarCaracter(char cadena[], char caracter) { int contador = 0; for(int i = 0; cadena[i] != '\0'; i++) { if(cadena[i] == caracter) { contador++; } } return contador; }

Las posiciones 1, 3 y 5 coinciden con 'a'.
Resultado: contador = 3.

04 Comprobar si Comienza con una Subcadena

¿Empieza "programacion" con el prefijo "pro"? Algoritmo de verificación inicial.

comienza_con.c Prefijos
bool comienzaCon(char cadena[], char subcadena[]) { int i = 0; // Recorremos hasta que termine la subcadena que queremos buscar while(subcadena[i] != '\0') { if(cadena[i] != subcadena[i]) { return false; } i++; } return true; }

Lógica del Algoritmo

Comparamos cadena[0] == subcadena[0] ('p' == 'p'), luego cadena[1] == subcadena[1] ('r' == 'r'), luego cadena[2] == subcadena[2] ('o' == 'o'). Como subcadena[3] == '\0', el bucle finaliza con éxito y devuelve true.

06 Inversión de Mayúsculas y Minúsculas (ASCII +32)

El Secreto de la Tabla ASCII

En la codificación ASCII estándar, las letras mayúsculas ('A'-'Z') van del valor 65 al 90, y las minúsculas ('a'-'z') del 97 al 122.

'a' (97) - 'A' (65) = 32
  • Para pasar de MAYÚSCULA a minúscula: c + 32.
  • Para pasar de minúscula a MAYÚSCULA: c - 32.
toggle_case.c ASCII 32
void cambiarMayusMinus(char cadena[]) { for(int i = 0; cadena[i] != '\0'; i++) { if(cadena[i] >= 'A' && cadena[i] <= 'Z') { cadena[i] = cadena[i] + 32; } else if(cadena[i] >= 'a' && cadena[i] <= 'z') { cadena[i] = cadena[i] - 32; } } }

07 Invertir un String

Dada una cadena, generar otra cadena con sus caracteres en orden inverso ("Hola" ➔ "aloH").

invertir_string.c Espejo
void invertirString(char cadena[], char invertida[], int longitud) { for(int i = 0; i < longitud; i++) { invertida[i] = cadena[longitud - 1 - i]; } // Obligatorio: colocar el carácter terminador al final invertida[longitud] = '\0'; }

Explicación de la fórmula longitud - 1 - i

Si la longitud es 4 ("Hola", índices 0 a 3):
Para i = 0 ➔ toma cadena[4 - 1 - 0] = cadena[3] ('a').
Para i = 1 ➔ toma cadena[4 - 1 - 1] = cadena[2] ('l').
Para i = 2 ➔ toma cadena[4 - 1 - 2] = cadena[1] ('o').
Para i = 3 ➔ toma cadena[4 - 1 - 3] = cadena[0] ('H').
Finalmente, en la posición 4 se escribe el '\0'.

08 Detección de Palíndromos

Una palabra es palíndroma si se lee igual de izquierda a derecha que de derecha a izquierda ("radar", "reconocer", "neuquen").

es_palindromo.c O(N/2)
bool esPalindromo(char cadena[], int longitud) { for(int i = 0; i < longitud / 2; i++) { if(cadena[i] != cadena[longitud - 1 - i]) { return false; // Corte temprano } } return true; }

¿Por qué solo iteramos hasta longitud / 2?

En "radar" (longitud 5):

i = 0 ➔ compara cad[0] ('r') con cad[4] ('r') ✔️
i = 1 ➔ compara cad[1] ('a') con cad[3] ('a') ✔️

Como longitud / 2 = 5 / 2 = 2, el bucle se detiene ahí. La letra central 'd' no necesita compararse consigo misma.

09 Resumen y Autoevaluación

Puntos Clave del Módulo

  • Para recorrer texto usamos siempre cadena[i] != '\0'.
  • Al invertir un string, nunca olvides colocar el '\0' al final.
  • La diferencia entre mayúsculas y minúsculas en ASCII es constante: 32.
  • Para palíndromos, basta con comparar los extremos hasta la mitad longitud / 2.
