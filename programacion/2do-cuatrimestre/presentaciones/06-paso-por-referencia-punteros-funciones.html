Paso por Referencia, Punteros y Funciones

Cómo alterar variables originales desde funciones y devolver múltiples resultados usando punteros como parámetros de salida.

Paso por valor (copia) Referencia con punteros Múltiples retornos Ejemplos: dividir y minMax

💡 Guía de navegación: Usá la barra espaciadora o las flechas del teclado (→ / ←) para avanzar diapositiva por diapositiva.

01 Objetivos Pedagógicos

La barrera del paso por valor

En C, todas las funciones reciben sus argumentos por valor (copia). Si modificás una variable dentro de la función, el cambio muere al cerrarse la llave }.

Los punteros son la herramienta que nos permite romper esa barrera: al pasarle a la función la dirección de la variable original, la función adquiere la capacidad de modificarla de verdad.

Lo que vas a dominar en esta clase

  • Demostrar experimentalmente por qué el paso por valor no altera el original.
  • Aprender la sintaxis: &variable en la llamada y int *param en la cabecera.
  • Utilizar *param = nuevo_valor; para alterar el dato original en RAM.
  • Superar la limitación de return y devolver múltiples valores.
  • Analizar el ejemplo de división (cociente y resto simultáneos).
  • Analizar el algoritmo minMax para calcular los extremos de un vector.

02 El Problema: Paso por Valor

¿Por qué este código no funciona como uno esperaría?

cambiar_fallido.c Por Valor
void cambiar(int numero) { numero = 100; } int main(void) { int x = 5; cambiar(x); printf("x = %d\n", x); // Imprime 5 !! return 0; }

¿Qué ocurrió en la memoria RAM?

1
En main, la variable x vive en su propia celda con el valor 5.
2
Al llamar a cambiar(x), C crea una caja nueva independiente en el Stack llamada numero y copia el 5.
3
La función hace numero = 100, modificando su propia copia local.
4
Al terminar la función, numero es destruida. La variable x de main nunca se enteró.

03 La Solución: Modificar la Variable Original

En lugar de mandar el número 5, enviamos la dirección de memoria &x.

cambiar_exitoso.c Punteros
void cambiar(int *numero) { *numero = 100; // Modifica la celda apuntada } int main(void) { int x = 5; cambiar(&x); // Enviamos &x (su dirección) printf("x = %d\n", x); // Imprime 100 !! return 0; }

Mecánica del Éxito

1
&x entrega la dirección de memoria de x (ej. 0x1000).
2
El parámetro int *numero guarda esa dirección 0x1000.
3
La orden *numero = 100 significa: "Andá a la celda 0x1000 y guardá el número 100".
4
Como esa celda es físicamente la variable x, su valor cambió en la memoria real.

04 Ejemplo: Función incrementar

Modificar una variable sumándole una cantidad determinada n.

incrementar.c += con *ptr
#include <stdio.h> void incrementar(int *numero, int n) { *numero += n; } int main(void) { int x = 10; incrementar(&x, 5); printf("x = %d\n", x); // x = 15 incrementar(&x, 20); printf("x = %d\n", x); // x = 35 return 0; }

¿Por qué &x pero n solo?

Notá la asimetría intencional en la llamada:

incrementar(&x, 5);
  • &x porque queremos modificar la variable x.
  • 5 (o una variable n) porque solo queremos leer su valor para sumarlo, sin alterar el dato que lo originó.

05 Devolver Varios Valores: División Entera

Un return solo puede devolver un dato. Con punteros podemos devolver dos, tres o más resultados simultáneos.

division_modular.c Cociente y Resto
#include <stdio.h> void dividir(int dividendo, int divisor, int *cociente, int *resto) { *cociente = dividendo / divisor; *resto = dividendo % divisor; } int main(void) { int c, r; dividir(10, 3, &c, &r); printf("Cociente: %d\n", c); // 3 printf("Resto: %d\n", r); // 1 return 0; }

💡 Concepto de Parámetros de Salida: Las variables c y r se declaran vacías en main. Se le envían sus direcciones &c y &r a la función, y esta se encarga de rellenarlas con los resultados.

06 Ejemplo Integrador: Mínimo y Máximo de un Vector

Una única función que recorre el vector y devuelve ambos extremos a la vez.

min_max.c Vector + Punteros
void minMax(int vector[], int tamano, int *minimo, int *maximo) { *minimo = vector[0]; *maximo = vector[0]; for(int i = 1; i < tamano; i++) { if(vector[i] < *minimo) { *minimo = vector[i]; } if(vector[i] > *maximo) { *maximo = vector[i]; } } }

Llamada y Uso en main()

Pasamos &min y &max para que la función almacene ambos resultados directamente:

int numeros[5] = {45, 12, 89, 3, 67}; int min, max; minMax(numeros, 5, &min, &max); printf("Min: %d | Max: %d\n", min, max);
> Min: 3 | Max: 89

07 Resumen y Autoevaluación

Puntos Clave del Módulo

  • C solo tiene paso por valor; el paso por referencia se implementa pasando direcciones de memoria.
  • Si querés que una función modifique tu variable, pasale &variable.
  • La función debe declarar el parámetro como puntero: int *ptr.
  • Dentro de la función usamos *ptr = valor para guardar el resultado.
  • Es el patrón estándar de C para devolver múltiples resultados.

Checklist de Autoevaluación

✓ ¿Por qué void f(int x) { x = 10; } no modifica a la variable de main?
✓ ¿Qué operador uso en la llamada de dividir(10, 3, &c, &r)?
✓ ¿Por qué en minMax usamos *minimo = vector[i] y no minimo = ...?
