02 La Anatomía de un Vector Dinámico Real

La Tríada Fundamental

Un vector dinámico profesional no es sólo un puntero. Está compuesto por tres variables que trabajan en equipo:

🎯

1. Puntero (datos)

La dirección de memoria en el Heap donde empieza el bloque contiguo de elementos.

📦

2. Capacidad (capacidad)

El total de casillas reservadas actualmente con malloc/realloc (ej. 10 casillas).

📝

3. Cantidad (tamano)

Cuántos elementos válidos ingresó realmente el usuario hasta el momento (ej. 4 cargados).

Visualización del estado en RAM:
[0]15
[1]28
[2]42
[3]09
[4]vacío
[5]vacío

Cantidad = 4 (elementos útiles) | Capacidad = 6 (espacio total reservado)

03 El Ciclo de Vida del Vector Dinámico

1
Inicialización: Reservar una capacidad inicial pequeña (ej. 2 o 4 casillas) con malloc() y validar que no sea NULL. cantidad = 0;.
2
Inserción & Auto-expansión: Antes de guardar un nuevo valor, verificar: if (cantidad == capacidad). Si está lleno, duplicar capacidad (capacidad *= 2) con realloc() seguro. Luego guardar el dato y hacer cantidad++;.
3
Operaciones: Recorrer, buscar, modificar u ordenar usando exactamente la misma sintaxis de corchetes v[i] desde 0 hasta cantidad - 1.
4
Destrucción obligatoria: Al cerrar el programa o terminar el módulo, devolver la memoria al sistema con free(vector); vector = NULL;.

04 ¿Por qué podemos usar v[i] con punteros?

La Regla de Oro del Compilador C

En C, los corchetes v[i] son simplemente "azúcar sintáctico" (*syntactic sugar*). El compilador traduce automáticamente:

v[i]  ≡  *(v + i)

En Vectores Estáticos

int v[5]; v[2] = 40; // Guarda en la casilla 2

En Vectores Dinámicos

int *v = (int *)malloc(5 * sizeof(int)); v[2] = 40; // ¡Exactamente la misma sintaxis!

✨ ¡Esto significa que todas las funciones y algoritmos que programaste antes (búsquedas, sumatorias, promedios) funcionan con memoria dinámica sin cambiar nada!

05 Vectores Dinámicos de Estructuras (struct)

Combinando Registros Compuestos con el Heap

Imaginá un sistema escolar: no sabemos cuántos alumnos se van a inscribir. Creamos un vector dinámico donde cada celda es una estructura Alumno completa:

alumnos_dinamico.c
typedef struct { int legajo; char nombre[30]; float promedio; } Alumno; // Reservamos espacio para N alumnos en el Heap Alumno *lista = (Alumno *)malloc(n * sizeof(Alumno)); if (lista == NULL) return 1; // Acceso con corchetes y operador punto: lista[0].legajo = 1001; strcpy(lista[0].nombre, "Lucía Gómez"); lista[0].promedio = 9.5;

06 Ordenar Estructuras Dinámicas con Burbuja

ordenar_alumnos.c
// Ordena los alumnos por promedio de mayor a menor void ordenarPorPromedio(Alumno *arr, int n) { for (int i = 0; i < n - 1; i++) { for (int j = 0; j < n - 1 - i; j++) { if (arr[j].promedio < arr[j + 1].promedio) { // Swap de la estructura completa (copia legajo, nombre y promedio) Alumno temp = arr[j]; arr[j] = arr[j + 1]; arr[j + 1] = temp; } } } }

💡 Poder de C: Al hacer Alumno temp = arr[j];, C copia todos los campos internos de la estructura de golpe, manteniendo la consistencia de cada alumno.

07 Proyecto Integrador: Sistema de Estudiantes

El Desafío de Cierre del 2do Cuatrimestre

Funcionalidades del Sistema

  • Menú de opciones interactivo (1 a 5).
  • 1. Agregar alumno: Auto-expande con realloc() si se llena.
  • 2. Listar alumnos: Recorre e imprime en formato prolijo.
  • 3. Buscar por legajo: Búsqueda secuencial rápida.
  • 4. Ordenar por mérito: Ordenamiento de burbuja.
  • 5. Salir: Libera la memoria con free().

Conceptos Aplicados

  • struct para agrupar campos heterogéneos.
  • Punteros y memoria dinámica en el Heap.
  • malloc(), realloc() seguro con temp y free().
  • Bucles anidados y condicionales.
  • Modularización con funciones limpias.

08 Código del Proyecto: Función main()

sistema_gestion.c (Parte 1)
#include <stdio.h> #include <stdlib.h> #include <string.h> typedef struct { int legajo; char nombre[30]; float promedio; } Alumno; int main(void) { int capacidad = 2, cantidad = 0, opcion = 0; Alumno *alumnos = (Alumno *)malloc(capacidad * sizeof(Alumno)); if (alumnos == NULL) { printf("Sin memoria\n"); return 1; } do { printf("\n--- SISTEMA DE GESTION DE ALUMNOS ---\n"); printf("1. Agregar Alumno | 2. Listar | 3. Buscar | 4. Ordenar | 5. Salir\nOpcion: "); scanf("%d", &opcion); if (opcion == 1) { if (cantidad == capacidad) { capacidad *= 2; Alumno *temp = (Alumno *)realloc(alumnos, capacidad * sizeof(Alumno)); if (temp == NULL) { printf("Error al reasignar\n"); break; } alumnos = temp; printf(" [Capacidad expandida a %d lugares]\n", capacidad); } printf("Legajo: "); scanf("%d", &alumnos[cantidad].legajo); printf("Nombre: "); scanf("%s", alumnos[cantidad].nombre); printf("Promedio: "); scanf("%f", &alumnos[cantidad].promedio); cantidad++; } /* resto de opciones en la siguiente slide */ } while (opcion != 5); free(alumnos); alumnos = NULL; printf("Memoria liberada exitosamente. Fin del programa.\n"); return 0; }

11 Checklist del Programador Senior en C

Reglas de Oro

  • Toda reserva dinámica con malloc, calloc o realloc debe validarse contra NULL.
  • A todo malloc / calloc le corresponde un free exactamente una vez.
  • Después de hacer free(p), siempre escribir p = NULL; para evitar punteros colgantes.
  • Para redimensionar con realloc(), utilizar siempre un puntero auxiliar temp.

Errores a Erradicar

  • Nunca acceder al índice N (los índices van de 0 a N - 1).
  • Nunca leer variables locales sin inicializar antes.
  • No perder punteros sin liberarlos (fugas de memoria).
  • Nunca hacer free() sobre una variable estática del Stack.
