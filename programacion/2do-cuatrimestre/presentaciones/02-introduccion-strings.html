Introducción a los Strings en C

El texto bajo la lupa del hardware: arreglos de caracteres char[], el carácter terminador '\0' y su almacenamiento en memoria.

01 Objetivos Pedagógicos

La verdad sobre las cadenas en C

A diferencia de otros lenguajes donde una palabra es un objeto mágico de tipo String, en C no existe un tipo de dato primitivo para texto.

El texto en C es estrictamente un arreglo unidimensional de bytes de tipo char. Comprender esto desde el primer día te evitará incontables dolores de cabeza y fallos de segmentación.

Lo que vas a dominar en esta clase

  • Saber qué es un string en C y cómo se define con char[].
  • Diferenciar un carácter único ('A') de una cadena ("A").
  • Entender la función vital del terminador nulo '\0'.
  • Aprender por qué una palabra de N letras necesita N + 1 casillas de RAM.
  • Utilizar el especificador de formato %s en printf.
  • Construir el algoritmo manual para calcular la longitud de una cadena.

02 ¿Qué es un String en C?

Definición Fundamental

En C, un String no es un tipo de dato especial: es simplemente un arreglo de caracteres (char[]) que finaliza con un byte especial llamado carácter nulo: '\0'.

declaracion_string.c char[]
char nombre[] = "Agustin";

Bajo la superficie, el compilador reserva en memoria un arreglo de 8 elementos tipo char:

0
'A'
1
'g'
2
'u'
3
's'
4
't'
5
'i'
6
'n'
7
'\0'

03 El Guardián de la Memoria: El '\0'

¿Por qué existe el '\0'?

En la memoria RAM, los datos de tu programa están rodeados por bytes pertenecientes a otras variables o procesos.

C necesita una señal de alto inequívoca para saber dónde termina el texto: "Acá termina el String". Esa marca es el byte con valor numérico 0, escrito como '\0' (carácter nulo).

La regla del N + 1

Si querés guardar una palabra de 4 letras como "Hola", necesitás como mínimo un arreglo de 5 posiciones:

[ H ][ o ][ l ][ a ][ \0 ]

Si declarás char palabra[4] = "Hola"; cometerás un error grave: no habrá espacio para el '\0' y C imprimirá basura de memoria.

04 Diferencia Crucial: char vs String

Un solo carácter vs una secuencia de caracteres: cuidado estricto con las comillas.

Un solo carácter: char

char letra = 'A';
  • Usa comillas simples: ' '.
  • Ocupa exactamente 1 byte en memoria.
  • Guarda directamente el código ASCII (ej. 65).
  • NO lleva terminador '\0'.
  • Se imprime con el especificador %c.

Una cadena de texto: String

char nombre[] = "Agustin";
  • Usa comillas dobles: " ".
  • Es un arreglo de varios char.
  • El compilador añade automáticamente el '\0' al final.
  • Ocupa longitud + 1 bytes en memoria.
  • Se imprime con el especificador %s.

⚠️ ¡Ojo con 'A' vs "A"! 'A' es un carácter simple de 1 byte. En cambio, "A" es un string de 2 bytes: ['A', '\0'].

05 Impresión de Strings: El Formato %s

Así como usábamos %d para enteros y %f para flotantes, para cadenas usamos %s (de string).

imprimir_string.c printf %s
#include <stdio.h> int main(void) { char nombre[] = "alumno"; printf("String: %s\n", nombre); return 0; }
Terminal de salida bash
String: alumno

¿Cómo funciona printf("%s", nombre) internamente?

printf recibe la dirección inicial de nombre, lee el primer carácter e imprime 'a', pasa al siguiente e imprime 'l'... y continúa avanzando de celda en celda por la memoria hasta que encuentra el '\0'. En ese instante exacto se detiene.

06 Recorrer un String: El Patrón Universal

El bucle canónico para procesar cadenas carácter por carácter.

recorrido_string.c for con != '\0'
char nombre[] = "Hola"; for(int i = 0; nombre[i] != '\0'; i++) { printf("%c\n", nombre[i]); }

Explicación de la condición nombre[i] != '\0'

Significa literalmente: "Mientras el carácter en la posición i no sea el terminador nulo, seguí procesando".

i = 0 ➔ 'H' (imprime)  |  i = 1 ➔ 'o' (imprime)  |  i = 2 ➔ 'l' (imprime)  |  i = 3 ➔ 'a' (imprime)  |  i = 4 ➔ '\0' (falso, sale del bucle).

07 Cálculo Manual de Longitud

Cómo contar los caracteres reales de una cadena sin bibliotecas externas.

longitud_manual.c while
int longitud(char cadena[]) { int contador = 0; while(cadena[contador] != '\0') { contador++; } return contador; }

¿Por qué devuelve 4 para "Hola" y no 5?

1
'H' es un carácter real (contador pasa a 1).
2
'o' es un carácter real (contador pasa a 2).
3
'l' es un carácter real (contador pasa a 3).
4
'a' es un carácter real (contador pasa a 4).
5
'\0' marca el final: el while se detiene sin incrementarse.

✅ El '\0' sirve para marcar el final, pero no forma parte de la longitud del texto.

08 Resumen y Autoevaluación

Puntos Clave del Módulo

  • Un String en C es un arreglo de caracteres (char[]).
  • Siempre finaliza con el carácter nulo '\0'.
  • Las comillas simples '' son para char; las dobles "" para Strings.
  • Siempre reservá 1 byte extra para el terminador nulo.
  • Para imprimir un string usamos %s.
  • Para recorrerlo usamos cadena[i] != '\0'.
