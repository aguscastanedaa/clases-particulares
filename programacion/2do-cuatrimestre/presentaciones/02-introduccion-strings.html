  • Un char guarda un único símbolo o letra entre comillas simples, como 'A'.

02 El Problema: ¿Cómo Guardamos una Palabra Entera?

Hasta ahora sabemos guardar números enteros (int), números con coma (float) y una sola letra suelta (char letra = 'A';). Pero ¿qué pasa si queremos guardar el nombre de una persona como "Agustin"?

❌ En un solo char NO entra
char letra = 'A'; // Solo 1 carácter

Una variable char común tiene espacio para una única letra. No puede guardar una palabra completa.

✅ La idea genial de C: Un vector de char
char nombre[] = "Agustin";

Si una palabra es una fila de letras una al lado de la otra, ¡podemos guardarla en un arreglo de caracteres (char[])!

03 3. ¿Qué es un String en C?

Definición Exacta del Apunte (pág. 4)

En C no existe un tipo de dato llamado string. Para guardar texto utilizamos un char[]. Es decir: un String es un arreglo de caracteres.

04 4. El '\0': La Señal de "Fin del Texto"

Definición del Apunte (pág. 5)

El '\0' (carácter nulo o terminador) indica: "Acá termina el String". Esto es fundamental en el lenguaje C.

Por ejemplo, cuando escribimos:

char nombre[] = "Hola";

Internamente en memoria tenemos 5 casilleros (las 4 letras + el '\0'):

nombre[0]
'H'
nombre[1]
'o'
nombre[2]
'l'
nombre[3]
'a'
nombre[4]
'\0'

05 ¿Por Qué Existe el '\0'? La Regla de N + 1

¿Por qué existe el '\0'?

Porque C necesita alguna manera de saber: "¿Hasta dónde llega este texto?".

Imaginá que tenés un arreglo char frase[50] pero adentro solo guardaste "Hola". Gracias al '\0' en la posición 4, C lee H-o-l-a, ve el '\0' y frena sin imprimir los 45 casilleros sobrantes.

La Regla de Oro: N + 1 casilleros

Un String de N letras visibles necesita siempre N + 1 posiciones en memoria para poder guardar el '\0' al final:

  • "Sol" (3 letras) ➔ ocupa 4 casilleros.
  • "Hola" (4 letras) ➔ ocupa 5 casilleros.
  • "Agustin" (7 letras) ➔ ocupa 8 casilleros.

💡 Nota importante: Aunque se escribe con dos símbolos en el código (barra invertida + cero: '\0'), para C es un único carácter especial cuyo valor numérico es 0.

06 Diferencia Crucial: char vs String

El apunte remarca que esta distinción es importantísima. En C, las comillas simples y las comillas dobles significan cosas completamente distintas:

Comilla Simple 'A' ➔ Un solo carácter

char letra = 'A';
  • Guarda un único carácter en 1 casillero.
  • Usa obligatoriamente comillas simples ' '.
  • No lleva '\0'.
  • Se imprime con %c.

Comilla Doble "Agustin" ➔ Un String

char nombre[] = "Agustin";
  • Guarda una cadena de caracteres (arreglo).
  • Usa obligatoriamente comillas dobles " ".
  • Agrega automáticamente el '\0' al final.
  • Se imprime completa con %s.

07 Pregunta Trampa de Examen: ¿Es lo mismo 'A' que "A"?

Aunque ambas tengan una sola letra A, en la memoria RAM son totalmente diferentes:

char letra = 'A'; (Carácter)
1 casillero
'A'

Es una variable simple de tipo char. Ocupa exactamente 1 byte.

char texto[] = "A"; (String)
Pos 0
'A'
Pos 1
'\0'

Las comillas dobles crean un arreglo de 2 casilleros: la letra 'A' y el terminador '\0'.

08 Cómo Declarar e Inicializar un String en C

1
Con tamaño automático (la más cómoda cuando ya conocemos el texto):
char nombre[] = "Agustin"; // C cuenta 7 letras + 1 para '\0' = tamaño 8
2
Con capacidad máxima fija (ideal para leer por teclado o modificar después):
char palabra[30] = "Hola"; // Reserva 30 casilleros; usa 5 ('H','o','l','a','\0')
3
Carácter por carácter con llaves (manual, recordando poner el '\0'):
char saludo[5] = {'H', 'o', 'l', 'a', '\0'}; // Equivalente a "Hola"

09 Imprimir un String Completo con %s

Regla del Apunte (pág. 5)

IMPORTANTE: Si queremos imprimir un String en C debemos usar %s (que viene de string), así como antes usábamos %d para enteros o %f para flotantes.

imprimir_string.c Apunte pág. 5
char nombre[] = "alumno"; printf("String: %s", nombre); // ➔ imprime "String: alumno"

¿Cómo funciona %s por dentro?

printf arranca en nombre[0] y va imprimiendo letra por letra automáticamente hasta que se topa con el carácter '\0'. ¡No hace falta usar un for solo para mostrar la palabra entera!

Tabla de especificadores

• %d ➔ número entero (int)
• %f ➔ número con coma (float)
• %c ➔ un solo carácter (nombre[0])
• %s ➔ todo el String (nombre)

10 Leer un String por Teclado con scanf("%s", ...)

Para pedirle al usuario que ingrese una palabra por teclado, también usamos el especificador %s:

leer_palabra.c Entrada con %s
#include <stdio.h> int main() { char palabra[30]; printf("Ingrese su nombre: "); scanf("%s", palabra); printf("Hola, %s!\n", palabra); return 0; }
Terminal Interactivo
$ ./leer_palabra Ingrese su nombre: Agustin Hola, Agustin!

⚠️ Detalle clave: En scanf("%s", palabra); no se pone el símbolo & adelante de palabra porque el nombre de un arreglo ya indica dónde guardarlo, y scanf agrega el '\0' solo.

11 Acceder a una Letra Puntual: nombre[i]

Como un String es un arreglo char[], podemos consultar o cambiar cualquier letra usando su índice entre corchetes:

acceso_letras.c Nivel 1
#include <stdio.h> int main() { char nombre[] = "Hola"; printf("Palabra completa: %s\n", nombre); printf("Primera letra: %c\n", nombre[0]); printf("Tercera letra: %c\n", nombre[2]); return 0; }
Terminal Salida
$ ./acceso_letras Palabra completa: Hola Primera letra: H Tercera letra: l

Observá la diferencia: nombre es todo el String y usa %s; en cambio, nombre[0] es un solo char y usa %c.

12 6. Recorrer un String con un Ciclo for

Explicación del Apunte (págs. 10–11)

Como un String es un arreglo de char, podemos recorrerlo con un for. Pero en vez de necesitar el tamaño numérico, usamos una condición mucho mejor: avanzar mientras no lleguemos al '\0'.

recorrer_hola.c Apunte pág. 10
char nombre[] = "Hola"; for(int i = 0; nombre[i] != '\0'; i++) { printf("%c\n", nombre[i]); }

13 ¿Qué Está Haciendo el for? Desglose Conceptual

for(int i = 0; nombre[i] != '\0'; i++)
1
Inicio (int i = 0): Empezamos parados en la primera letra del String (posición 0).
2
Condición (nombre[i] != '\0'): Significa: "Mientras el carácter actual NO sea el final del String, seguimos".
3
Paso (i++): En cada vuelta avanzamos una casilla hacia la derecha hasta encontrar el '\0'.

📌 Consejo del Apunte (pág. 11): Cuando trabajemos con Strings, vamos a ver muchísimo for(int i = 0; cadena[i] != '\0'; i++). Aprendétela conceptualmente: "Recorro el String hasta encontrar el final."

15 ¿Por Qué a una Función de Strings NO le Pasamos tamano?

Compará cómo pasábamos un vector de enteros en la Unidad 01 vs cómo pasamos un String ahora:

Vector de enteros (Unidad 01)

void mostrarVector(int v[], int tamano)

Un vector de int no tiene marca de final. Si no enviamos int tamano, la función no sabe dónde parar.

String / Arreglo de char (Unidad 02)

int longitud(char cadena[])

Un String sí lleva su propio freno incluido ('\0'). Por eso alcanza con enviar char cadena[] como único parámetro.

16 7. Longitud de un String (Cálculo Manual)

Explicación del Apunte (pág. 11)

Muchas veces necesitamos saber cuántos caracteres tiene un String. Podemos hacerlo manualmente contando cuántas posiciones avanzamos antes de chocar con el '\0':

longitud_manual.c Apunte pág. 11
int longitud(char cadena[]) { int contador = 0; while(cadena[contador] != '\0') { contador++; } return contador; }

17 Pregunta del Apunte: ¿Por Qué Devuelve 4 y No 5?

Si tenemos char palabra[] = "Hola"; y llamamos a longitud(palabra), la función devuelve 4. ¿Por qué devuelve 4 si el arreglo ocupa 5 casilleros en memoria?

Cuenta: 1
'H'
Cuenta: 2
'o'
Cuenta: 3
'l'
Cuenta: 4
'a'
No se cuenta
'\0'

📌 Respuesta del Apunte (pág. 12): Porque H → 1, o → 2, l → 3, a → 4, y '\0' no es parte del texto. El '\0' sirve para marcar el final, pero no lo contamos como carácter del String.

19 Dos Formas Equivalentes de Contar la Longitud

Tanto con while (como muestra el apunte) como con for, la lógica es exactamente la misma:

con_while.c Versión Apunte
int longitud(char cadena[]) { int contador = 0; while(cadena[contador] != '\0') { contador++; } return contador; }
con_for.c Versión con for
int longitud(char cadena[]) { int contador = 0; for(int i = 0; cadena[i] != '\0'; i++) { contador++; } return contador; }

💡 En la Unidad 03 veremos que la librería <string.h> ya trae esta misma función lista para usar bajo el nombre strlen(cadena).

20 Ejemplo Nivel 3: Inspeccionar Posición por Posición

Armemos una función que muestre cada letra junto con su número de casillero y al final informe la longitud total:

inspeccionar_string.c Nivel 3
#include <stdio.h> void detallarString(char cadena[]) { int i = 0; while(cadena[i] != '\0') { printf("Posicion %d -> '%c'\n", i, cadena[i]); i++; } printf("Fin en posicion %d ('\\0')\n", i); } int main() { char texto[] = "Sol"; detallarString(texto); return 0; }
Terminal Salida
$ ./inspeccionar Posicion 0 -> 'S' Posicion 1 -> 'o' Posicion 2 -> 'l' Fin en posicion 3 ('\0')

21 Ejemplo Nivel 3: Contar Cuántas Veces Aparece la Letra 'a'

Combinando el recorrido hasta '\0' con un condicional if, podemos analizar el contenido de cualquier palabra:

contar_letra_a.c Nivel 3
#include <stdio.h> int contarLetraA(char cadena[]) { int cant = 0; for(int i = 0; cadena[i] != '\0'; i++) { if(cadena[i] == 'a') { cant++; } } return cant; } int main() { char fruta[] = "banana"; printf("Letras 'a': %d\n", contarLetraA(fruta)); return 0; }
Terminal Salida
$ ./contar_letra_a Letras 'a': 3

Mirá la condición: if(cadena[i] == 'a') usa comillas simples porque cadena[i] es un solo carácter (char).

22 Ejemplo Nivel 4: Razonamiento para Contar Vocales

Supongamos que en un examen nos piden escribir una función int contarVocales(char cadena[]) que devuelva cuántas vocales minúsculas tiene una palabra. ¿Cómo lo pensamos paso a paso?

1
Definir la entrada y salida: Entra char cadena[] y sale un entero (int) con la cantidad de vocales.
2
Crear el contador en cero: int vocales = 0; antes de iniciar el ciclo.
3
Recorrer hasta el final del String: Usar el patrón estándar for(int i = 0; cadena[i] != '\0'; i++).
4
Evaluar cada carácter: Si cadena[i] es igual a 'a', 'e', 'i', 'o' o 'u' (usando el operador lógico O ||), sumamos vocales++.

23 Implementación Nivel 4: contarVocales

contar_vocales.c Nivel 4
#include <stdio.h> int contarVocales(char cadena[]) { int vocales = 0; for(int i = 0; cadena[i] != '\0'; i++) { char c = cadena[i]; if(c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u') { vocales++; } } return vocales; } int main() { char palabra[] = "programacion"; int total = contarVocales(palabra); printf("Palabra: %s\n", palabra); printf("Cantidad de vocales: %d\n", total); return 0; }
Terminal Salida
$ ./contar_vocales Palabra: programacion Cantidad de vocales: 5

💡 Guardar char c = cadena[i]; en cada vuelta hace que la línea del if quede mucho más corta y prolija de leer.

24 Experimento Mental: ¿Qué Pasa si Cambiamos una Letra?

Como el String es un arreglo char[], podemos modificar cualquiera de sus casilleros asignándole otro carácter con comillas simples:

modificar_letra.c C99
#include <stdio.h> int main() { char palabra[] = "pato"; palabra[0] = 'g'; // Cambia 'p' por 'g' printf("%s\n", palabra); return 0; }
Terminal Salida
$ ./modificar_letra gato

¿Y si hiciéramos palabra[2] = '\0';? Entonces printf("%s", palabra) imprimiría solo "ga", porque encuentra el terminador antes.

25 Detalle Importante: scanf("%s", ...) y los Espacios

¿Qué pasa si con scanf("%s", texto); el usuario escribe dos palabras separadas por un espacio, como "Juan Perez"?

Con scanf("%s", texto)

scanf("%s", texto);

%s corta la lectura en el primer espacio en blanco o Enter. Si escribís Juan Perez, solo guarda "Juan".

¿Y si necesitamos leer con espacios?

scanf(" %[^\n]", texto);

Usando " %[^\n]" o la función fgets(texto, 30, stdin), C lee toda la oración completa hasta que el usuario presiona Enter.

26 Errores Frecuentes (Parte 1): Olvidar el Espacio para '\0'

Uno de los errores más peligrosos en C es declarar el arreglo con la cantidad justa de letras visibles, olvidando el casillero extra para el '\0':

❌ Sin lugar para el '\0'
// "Hola" tiene 4 letras, pero necesita 5 lugares char nombre[4] = "Hola";

En 4 casilleros solo entran 'H', 'o', 'l', 'a'. Al no haber un 5° casillero para el '\0', printf no sabe dónde frenar y sigue leyendo basura de la memoria.

✅ Reservando N + 1 (o dejando [])
char nombre[5] = "Hola"; // O mejor aún: char nombre2[] = "Hola";

Con tamaño 5 (o con [] vacíos al inicializar), quedan guardados [H][o][l][a][\0] de forma 100% segura.

27 Errores Frecuentes (Parte 2): Confundir ' ' y " "

❌ Mezclar comillas simples y dobles
char letra = "A"; // ERROR char nombre[] = 'Agustin'; // ERROR if(nombre[i] == "a") // ERROR

Comparar nombre[i] == "a" intenta comparar un carácter contra un String completo, lo cual no funciona en C.

✅ Cada comilla en su lugar
char letra = 'A'; // 1 char: simple char nombre[] = "Agustin"; // String: doble if(nombre[i] == 'a') // 1 casilla: simple

Siempre que mires una sola casilla nombre[i] o el terminador '\0', usá comillas simples.

28 Errores Frecuentes (Parte 3): Asignar con = Luego de Declarar

Como un String es un arreglo, solo podés usar = "texto" en la misma línea donde lo declarás:

❌ Asignar un arreglo después con =
char nombre[20]; nombre = "Agustin"; // ¡No compila en C!

En C no se puede copiar un arreglo entero con el signo = una vez que ya fue declarado.

✅ Inicializar al declarar (o usar strcpy)
char nombre[20] = "Agustin"; // ¡Válido!

Si necesitás cambiar el texto completo más adelante en el programa, en la Unidad 03 aprenderemos a usar strcpy(nombre, "Agustin");.

29 Errores Frecuentes (Parte 4): Confundir %c con %s

❌ Cruzando los especificadores
char nombre[] = "Hola"; printf("%c", nombre); // Mal: nombre es String printf("%s", nombre[0]); // Mal: nombre[0] es char
✅ Especificador acorde al dato
char nombre[] = "Hola"; printf("%s\n", nombre); // Bien: todo el String printf("%c\n", nombre[0]); // Bien: 1 sola letra

💡 Regla práctica: Si tiene corchetes con índice (nombre[i]) es un carácter (%c). Si va el nombre solo sin corchetes (nombre) es todo el String (%s).

30 Buenas Prácticas al Trabajar con Strings

Al declarar en memoria

  • Si inicializás un texto fijo, usá char texto[] = "Hola"; para que el compilador calcule solo el + 1 del '\0'.
  • Si vas a leer por teclado con scanf, reservá un margen cómodo (por ejemplo char palabra[50];).

Al recorrer en ciclos y funciones

  • Usá siempre la condición centinela cadena[i] != '\0' en lugar de adivinar cuántos caracteres escribió el usuario.
  • Recordá que longitud(cadena) cuenta solo los caracteres visibles y nunca suma el '\0'.

31 Ejercicio de Aplicación 1: Contar Espacios en una Frase

Enunciado del Ejercicio 1

Escribí una función int contarEspacios(char frase[]) que recorra un String hasta encontrar '\0' y devuelva cuántos espacios en blanco (' ') contiene. Probala en main() con "Hola mundo en C".

💻 Ver solución paso a paso
#include <stdio.h> int contarEspacios(char frase[]) { int espacios = 0; for(int i = 0; frase[i] != '\0'; i++) { if(frase[i] == ' ') { espacios++; } } return espacios; } int main() { char texto[] = "Hola mundo en C"; printf("Espacios encontrados: %d\n", contarEspacios(texto)); // 3 return 0; }

33 Ejercicio Integrador Tipo Examen (3)

Ejercicio 3: Mostrar un String separado por guiones

Escribí una función void mostrarConGuiones(char cadena[]) que recorra un String e imprima cada carácter seguido de un guion -, excepto después de la última letra (por ejemplo, para "Hola" debe mostrar H-o-l-a). Pista: mirá si el siguiente casillero cadena[i + 1] es distinto de '\0'.

💻 Ver solución completa
#include <stdio.h> void mostrarConGuiones(char cadena[]) { for(int i = 0; cadena[i] != '\0'; i++) { printf("%c", cadena[i]); if(cadena[i + 1] != '\0') { printf("-"); } } printf("\n"); } int main() { char nombre[] = "Hola"; mostrarConGuiones(nombre); // Imprime: H-o-l-a return 0; }
