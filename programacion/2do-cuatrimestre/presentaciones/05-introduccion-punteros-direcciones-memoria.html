Punteros y Direcciones de Memoria

El núcleo del poder en C: cómo ubicar variables en la memoria RAM, los operadores & y *, y el control directo de direcciones.

Dirección &variable Desreferenciación *ptr Formato %p Analogía de la casa

💡 Guía de navegación: Usá la barra espaciadora o las flechas del teclado (→ / ←) para avanzar diapositiva por diapositiva.

01 Objetivos Pedagógicos

El tema cumbre del programador en C

Los punteros son considerados habitualmente el tema más desafiante de la programación inicial. Sin embargo, cuando se explican desde la arquitectura física de la memoria, se vuelven completamente intuitivos.

Un puntero no es magia: es simplemente una variable ordinaria que, en vez de guardar una edad o un precio, guarda un número que representa una casilla de la RAM.

Lo que vas a dominar en esta clase

  • Comprender qué es físicamente una dirección de memoria en la RAM.
  • Aprender a imprimir direcciones reales con el especificador %p.
  • Dominar el operador de dirección & ("dame la dirección de...").
  • Declarar variables puntero con tipo *nombre.
  • Dominar el operador de indirección * ("dame el valor que hay en...").
  • Comprender la analogía didáctica de la casa y el papel con la dirección.

02 Direcciones de Memoria en la RAM

Toda variable vive en una celda física de la memoria del computador.

direccion_memoria.c %d vs %p
#include <stdio.h> int main(void) { int edad = 19; printf("Valor: %d\n", edad); printf("Direccion: %p\n", &edad); return 0; }
Terminal de salida bash
Valor: 19 Direccion: 0x7ffe1234abcd

¿Por qué %p y no %d?

%d imprime un número entero ordinario en base 10. %p (de pointer) está diseñado específicamente para imprimir direcciones de memoria en formato hexadecimal (ej. 0x7ffe1234abcd), que es la dirección física de la celda de RAM donde el sistema operativo guardó a edad.

03 ¿Qué es un Puntero?

Definición Concreta

Un puntero es una variable que almacena como contenido la dirección de memoria de otra variable.

puntero_basico.c int *ptr
int edad = 19; // Declaramos el puntero y le asignamos la dirección int *puntero = &edad; printf("edad: %d\n", edad); // 19 printf("&edad: %p\n", &edad); // 0x1000 printf("puntero: %p\n", puntero); // 0x1000 printf("*puntero: %d\n", *puntero); // 19
Dirección: 0x1000
edad int
19
▲ apunta a
Dirección: 0x2050
puntero int*
0x1000

04 La Pareja Dinámica: & y *

Son operaciones complementarias e inversas.

Operador de Dirección: &

&variable

Significa: "¿Dónde está esta variable?"

Toma una variable cualquiera y te entrega su dirección física en la RAM.

Operador de Indirección: *

*puntero

Significa: "¿Qué valor hay en la dirección a la que apunta?"

Viaja hasta la casilla de memoria guardada en el puntero y lee o escribe su contenido.

¡Cuidado con el doble uso del asterisco *!

1. En la declaración (int *p;): le avisa al compilador que la variable p será un puntero.
2. En una expresión (*p = 50; o x = *p;): es el operador de desreferenciación para acceder al valor apuntado.

06 Errores Frecuentes con Punteros

❌ Puntero No Inicializado (Puntero Salvaje)
int *p; // Contiene basura *p = 50; // ¡CRASH! Segmentation Fault

Un puntero recién declarado apunta a una dirección aleatoria de la memoria RAM. Modificarlo es intentar escribir en una dirección desconocida del sistema operativo.

✅ Siempre Inicializar o Asignar NULL
int valor = 0; int *p = &valor; // Seguro // O si no tiene destino aún: int *q = NULL;

Inicializarlo con la dirección de una variable válida o con NULL (cero) garantiza control y seguridad en la ejecución.

07 Resumen y Autoevaluación

Puntos Clave del Módulo

  • &x obtiene la dirección física en memoria de x.
  • int *p declara que p es una variable que guardará una dirección.
  • *p viaja a la dirección y accede al valor allí guardado.
  • Para imprimir direcciones usamos printf("%p", p);.
  • Nunca desreferencies un puntero que no apunte a una variable real.
