Estructuras (struct) en C

Modelando entidades del mundo real: tipos de datos heterogéneos, operador punto, typedef y vectores de structs

struct Operador Punto (.) typedef Vectores de Alumnos

💡 Guía de navegación: Usá la barra espaciadora o las flechas del teclado (→ / ←) para avanzar diapositiva por diapositiva.

01 Objetivos de Aprendizaje

La limitación de los vectores

Un vector solo puede almacenar elementos del **mismo tipo** (todos int o todos float).

Pero en la vida real, una entidad como un **Alumno** tiene un número de legajo (int), una inicial (char), un promedio general (float) y un estado de regularidad (bool). ¿Cómo agrupamos datos de tipos distintos bajo un solo nombre? Con un struct.

Lo que vas a dominar hoy

  • Comprender qué es un tipo de dato compuesto (struct).
  • Declarar plantillas de estructuras con sus campos o miembros.
  • Acceder y modificar campos usando el **operador punto (.)**.
  • Simplificar el código profesional con typedef.
  • Crear y recorrer **vectores de estructuras**.
  • Resolver búsquedas y filtros en listas de registros.

02 ¿Qué es un struct?

Definición

Una **estructura (`struct`)** es un tipo de dato definido por el usuario que permite empaquetar una o más variables de **diferentes tipos** bajo un mismo identificador.

struct Alumno Entidad Compuesta
int legajo
1042
int edad
16
float promedio
8.75
bool regular
true

03 Declaración y el Operador Punto (.)

definicion_struct.c Sintaxis Básica
#include <stdbool.h> // 1. Molde o plantilla de la estructura: struct Alumno { int legajo; int edad; float promedio; bool regular; }; // ¡Atención!: El punto y coma final es obligatorio int main(void) { // 2. Creamos una variable real de ese tipo: struct Alumno a1; // 3. Asignamos valores a cada campo con el operador PUNTO (.): a1.legajo = 1042; a1.edad = 16; a1.promedio = 8.75f; a1.regular = true; printf("Legajo: %d - Promedio: %.2f\n", a1.legajo, a1.promedio); return 0; }

04 La Elegancia de typedef

Sin typedef (Tedioso)

Cada vez que declarás una variable tenés que escribir las dos palabras: struct Alumno.

struct Alumno a1;
struct Alumno a2;

Con typedef (Profesional)

Crea un alias para que Alumno funcione como un tipo nativo igual que int.

typedef struct {
  int legajo;
  float promedio;
} Alumno;

Alumno a1, a2; // ¡Directo y limpio!

05 Vectores de Estructuras (Tablas de Registros)

La combinación más poderosa: un arreglo donde cada casillero es un alumno completo:

vector_alumnos.c Vector de structs
#define CANT 3 typedef struct { int legajo; float promedio; } Alumno; // Declaramos un vector con 3 alumnos e inicializamos sus campos: Alumno curso[CANT] = { {101, 7.5f}, {102, 9.8f}, {103, 6.2f} }; // Acceso con corchetes y punto: curso[i].campo printf("El promedio del segundo alumno es: %.1f\n", curso[1].promedio);

06 Algoritmo: Encontrar al Alumno con Mayor Promedio

mejor_alumno.c Búsqueda en Structs
// Asumimos que el primer alumno tiene el mejor promedio: int indiceMejor = 0; for (int i = 1; i < CANT; i++) { if (curso[i].promedio > curso[indiceMejor].promedio) { indiceMejor = i; // Actualizamos el índice campeón } } printf("El mejor alumno es legajo %d con promedio %.2f\n", curso[indiceMejor].legajo, curso[indiceMejor].promedio);

💡 Consejo clave: En lugar de guardar solo el valor numérico del promedio, guardamos el **índice indiceMejor**. De ese modo, al final tenemos acceso a **todos los datos del alumno ganador** (su legajo, edad, promedio, etc.).

07 Resumen de la Unidad y Checklist

Puntos Clave

  • struct: Agrupa datos de distintos tipos (heterogéneos).
  • Punto y coma: struct Nombre { ... }; lleva ; al final.
  • Operador punto (.): Accede a los campos de una estructura.
  • typedef: Evita tener que repetir struct al declarar variables.
  • Vector de structs: lista[i].campo para listas de registros.
