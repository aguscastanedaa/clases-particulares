Ordenamiento de Vectores

Poniendo orden en el caos: el Método de la Burbuja (Bubble Sort), la operación swap y búsqueda binaria

01 Objetivos de Aprendizaje

¿Por qué ordenar es tan importante?

Buscá una palabra en un diccionario de 100.000 términos. Si el diccionario estuviera desordenado, tendrías que leer palabra por palabra (búsqueda lineal). Te llevaría horas.

Como el diccionario está **ordenado alfabéticamente**, abrís al medio y encontrás la palabra en 5 segundos. Ordenar datos es uno de los problemas más estudiados de las ciencias de la computación.

Lo que vas a dominar hoy

  • Comprender la **operación de intercambio (swap)** con variable auxiliar.
  • Entender la intuición física del **Método de la Burbuja**.
  • Dominar los **bucles anidados** necesarios para ordenar.
  • Seguir una simulación paso a paso con traza gráfica.
  • Optimizar el algoritmo con una **bandera booleana** inteligente.
  • Entender por qué un vector ordenado permite la **Búsqueda Binaria**.

02 El Bloque Fundamental: El Intercambio (Swap)

Si tenemos dos vasos (uno con jugo y otro con agua) y queremos intercambiarlos, necesitamos un tercer vaso vacío:

❌ El Error Fatal sin Variable Temporal
a = b; // El valor original de 'a' SE PIERDE
b = a; // Ahora ambos tienen el valor de 'b'

¡Sobreescribiste a antes de guardar una copia de su valor! Ambos quedan iguales.

✅ La Técnica Swap con 'temp'
int temp = a; // 1. Guardamos copia de 'a'
a = b; // 2. Pasamos 'b' a la caja 'a'
b = temp; // 3. Pasamos la copia vieja a 'b'

¡Intercambio 100% perfecto sin perder ningún dato!

03 La Intuición del Método de la Burbuja (Bubble Sort)

La Metáfora Física

Imaginá un tubo con agua. Las burbujas de aire más livianas van subiendo a la superficie, mientras que los elementos más pesados se hunden al fondo.

1
Comparaciones Adyacentes: Recorremos el vector de izquierda a derecha comparando parejas vecinas: vector[j] contra vector[j + 1].
2
Intercambio si están desordenados: Si el de la izquierda es mayor que el de la derecha (vector[j] > vector[j + 1]), ¡los intercambiamos con temp!
3
Al final de la primera pasada: El número más grande de todo el vector habrá "burbujeado" inevitablemente hasta la última posición.
4
Repetir: Repetimos el proceso $N - 1$ veces para que todos los elementos encuentren su lugar.

04 Simulación Visual: Pasada a Pasada

Ordenemos de menor a mayor el vector: {5, 1, 4, 2, 8}:

P1
Vector inicial: [5, 1, 4, 2, 8]
• Compara 5 y 1 ➔ ¿5 > 1? Sí ➔ Swap ➔ [1, 5, 4, 2, 8]
• Compara 5 y 4 ➔ ¿5 > 4? Sí ➔ Swap ➔ [1, 4, 5, 2, 8]
• Compara 5 y 2 ➔ ¿5 > 2? Sí ➔ Swap ➔ [1, 4, 2, 5, 8]
• Compara 5 y 8 ➔ ¿5 > 8? No ➔ Queda igual ➔ [1, 4, 2, 5, 8]
✓ El 8 (el mayor) ya está en su lugar final definitivo.
P2
Segunda pasada:
• Compara 1 y 4 (Ok), 4 y 2 (Swap ➔ [1, 2, 4, 5, 8]), 4 y 5 (Ok).
✓ El 5 y el 8 ya están en su lugar.

05 El Código en C de Bubble Sort

bubble_sort.c Doble Bucle
void ordenarBurbuja(int v[], int n) { for (int i = 0; i < n - 1; i++) // Bucle de pasadas { for (int j = 0; j < n - 1 - i; j++) // Bucle de comparaciones adyacentes { if (v[j] > v[j + 1]) // Si están invertidos... { int temp = v[j]; // Intercambio v[j] = v[j + 1]; v[j + 1] = temp; } } } }

💡 Notá el j < n - 1 - i: como en cada pasada i el elemento mayor ya queda colocado al final, no hace falta volver a compararlo en las pasadas siguientes.

06 Optimización con Bandera Booleana

¿Qué pasa si el vector ya estaba casi ordenado desde el principio?

burbuja_optimizada.c Con Flag stdbool.h
for (int i = 0; i < n - 1; i++) { bool huboCambio = false; // Asumimos que ya está ordenado for (int j = 0; j < n - 1 - i; j++) { if (v[j] > v[j + 1]) { int temp = v[j]; v[j] = v[j + 1]; v[j + 1] = temp; huboCambio = true; // Hubo al menos un swap } } // Si en toda la pasada no hubo ningún cambio, ¡ya terminamos! if (!huboCambio) { break; } }

07 El Premio de Ordenar: Búsqueda Binaria

Dividir y Vencer en O(log N)

Una vez que un vector está ordenado, **no hace falta buscar uno por uno**. Podemos aplicar la Búsqueda Binaria:

1
Miramos el **elemento del medio**.
2
¿Es el buscado? ¡Golazo, terminamos en 1 solo paso!
3
¿El buscado es **menor**? Descartamos toda la mitad derecha. Repetimos solo en la mitad izquierda.
4
¿El buscado es **mayor**? Descartamos toda la mitad izquierda. Repetimos solo en la mitad derecha.

⚡ ¡En un arreglo de 1.000.000 de datos, la búsqueda binaria encuentra cualquier número en como máximo **20 comparaciones**!

08 Resumen de la Unidad y Checklist

Síntesis

  • Swap: Requiere variable temp para no perder datos.
  • Bubble Sort: Compara parejas adyacentes e intercambia.
  • Doble bucle: Uno para las pasadas y otro para las parejas.
  • Optimización con Flag: Evita pasadas inútiles si ya está ordenado.
  • Búsqueda binaria: Solo funciona en vectores previamente ordenados.

Checklist de Autoevaluación

✓ ¿Por qué falla el intercambio si no uso la variable temp?
✓ ¿Qué elemento queda siempre en su posición final tras la primera pasada?
✓ ¿Cómo ayuda una bandera booleana a acelerar el algoritmo?
✓ ¿Por qué la búsqueda binaria exige que el vector esté ordenado?
