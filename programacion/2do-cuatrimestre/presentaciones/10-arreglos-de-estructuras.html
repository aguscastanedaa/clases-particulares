01 Hoja de Ruta y Conexión con la Unidad 09

Lo que aprendimos hasta ahora

  • Una struct agrupa varios datos distintos (ej: nombre, legajo, promedio) bajo un solo molde.
  • Con el operador punto (.) accedemos a los campos de una variable estructura.
  • Con un puntero a estructura y el operador flecha (->) modificamos una estructura original desde una función.

Lo que vamos a dominar hoy (Secciones 32, 33, 34 y 38)

  • Declarar un arreglo de Structs como struct Alumno clase[30];.
  • Acceder a cada casillero y campo mediante clase[i].campo.
  • Recorrer, cargar y mostrar listas de registros con ciclos for.
  • Pasar arreglos de structs a funciones: mejorPromedio y actualizarKilometraje.
  • Buscar por legajo o nombre (con strcmp) y ordenar un arreglo de estructuras.

02 El Problema: ¿Qué Pasa Cuando Tenemos 30 Alumnos?

Con una sola estructura pudimos representar a un alumno. Pero en una escuela real tenemos un curso de 30 alumnos. Sin arreglos de estructuras, tendríamos dos malas opciones:

❌ Opción 1: 30 variables sueltas
struct Alumno alu1; struct Alumno alu2; struct Alumno alu3; // ... ¡así hasta alu30!

No se pueden recorrer con un for. Tendríamos que repetir 30 veces cada printf o comparación.

❌ Opción 2: Vectores paralelos sueltos
char nombres[30][50]; int legajos[30]; float promedios[30];

Los datos de un mismo alumno quedan desparramados en 3 arreglos distintos. Si ordenamos uno y olvidamos otro, ¡se mezclan los datos!

✅ La solución profesional: Crear un único vector donde cada casillero guarde un struct Alumno completo.

03 32. Arreglos de Structs: Definición del Apunte

Definición del Apunte

Podemos tener un vector donde cada posición sea una Struct. Así combinamos el orden numerado de los vectores con la capacidad de las estructuras de agrupar distintos tipos de datos.

arreglo_structs.c Sección 32
struct Alumno { char nombre[50]; int legajo; float promedio; }; // Creamos el arreglo de 30 alumnos: struct Alumno clase[30];

¿Qué acabamos de crear?

Ahora tenemos 30 posiciones numeradas desde la 0 hasta la 29:

clase[0]
clase[1]
clase[2]
...
clase[29]

Y cada posición tiene adentro sus propios 3 campos: nombre, legajo y promedio.

05 Desglose Sintáctico: ¿Cómo Accedemos a un Campo?

Miremos el ejemplo exacto de la página 32 del apunte para cargar datos en el primer alumno:

acceso_elemento.c Ejemplo del Apunte
clase[0].legajo = 1234; clase[0].promedio = 8.5;
1
clase → Es el nombre del arreglo completo (las 30 carpetas).
2
clase[0] → Con el corchete elegimos qué alumno queremos (el de la posición 0). El resultado de clase[0] ya es una variable de tipo struct Alumno.
3
.legajo → Como clase[0] es una struct normal, usamos el operador punto (.) para entrar a su campo legajo y guardarle 1234.

06 ¿Y Cómo Cargamos el Campo nombre?

Recordá lo que vimos en la unidad de Strings: en C no podemos asignar un arreglo de caracteres con = después de declararlo. Tenemos tres formas válidas:

1. Con strcpy

strcpy(clase[0].nombre, "Ana");

Copia el texto "Ana" y su '\0' dentro del campo nombre del alumno 0.

2. Al inicializar con { }

struct Alumno clase[2] = { {"Ana", 1234, 8.5}, {"Luis", 1235, 9.0} };

Cada llave interna {...} inicializa un alumno completo en orden.

3. Leyendo con scanf

scanf("%s", clase[0].nombre);

Como nombre es un arreglo de char, ya representa su dirección (no lleva &).

07 Ejemplo Nivel 1: Cargar y Mostrar 2 Alumnos

nivel1_dos_alumnos.c Nivel 1
#include <stdio.h> #include <string.h> struct Alumno { char nombre[50]; int legajo; float promedio; }; int main() { struct Alumno clase[2]; strcpy(clase[0].nombre, "Ana"); clase[0].legajo = 1234; clase[0].promedio = 8.5; strcpy(clase[1].nombre, "Bruno"); clase[1].legajo = 1235; clase[1].promedio = 9.2; printf("%s - Leg: %d - Prom: %.2f\n", clase[0].nombre, clase[0].legajo, clase[0].promedio); printf("%s - Leg: %d - Prom: %.2f\n", clase[1].nombre, clase[1].legajo, clase[1].promedio); return 0; }

Explicación línea por línea

  • Definimos el molde struct Alumno afuera de main.
  • Reservamos lugar para 2 alumnos con struct Alumno clase[2];.
  • Llenamos los 3 campos de clase[0] y luego los 3 campos de clase[1].
  • Vemos que repetir esto a mano para 30 alumnos sería larguísimo: necesitamos un ciclo for.
Salida en consola bash
Ana - Leg: 1234 - Prom: 8.50 Bruno - Leg: 1235 - Prom: 9.20

08 33. Recorrer un Arreglo de Structs con for

Explicación del Apunte (Sección 33)

Para recorrer el arreglo utilizamos un for. La idea es visitar clase[0], clase[1], clase[2], clase[3]... y en cada vuelta acceder a sus campos usando clase[i].campo.

recorrer_arreglo_structs.c Código del Apunte
for(int i = 0; i < tamano; i++) { printf("%s\n", clase[i].nombre); printf("%d\n", clase[i].legajo); printf("%.2f\n", clase[i].promedio); }

%s para nombre: Imprime la cadena de caracteres hasta su '\0'.

%d para legajo: Imprime el número entero del legajo.

%.2f para promedio: Imprime el float con 2 decimales.

09 Ejemplo Nivel 2: Recorrido Completo y Tabla de Seguimiento

recorrido_clase.c Nivel 2
#include <stdio.h> struct Alumno { char nombre[50]; int legajo; float promedio; }; int main() { struct Alumno clase[3] = { {"Ana", 101, 8.50}, {"Luis", 102, 6.00}, {"Sol", 103, 9.75} }; int tamano = 3; for(int i = 0; i < tamano; i++) { printf("%s | %d | %.2f\n", clase[i].nombre, clase[i].legajo, clase[i].promedio); } return 0; }

1° 0 "Ana" 101 8.50
2° 1 "Luis" 102 6.00
3° 2 "Sol" 103 9.75
Fin 3 3 < 3 es Falso → termina el for
Terminal bash

10 Cómo Cargar un Arreglo de Structs con scanf

Cuando el usuario ingresa los datos por teclado dentro de un ciclo for, prestá especial atención a qué campos llevan el operador dirección &:

cargar_alumnos.c Lectura por teclado
for(int i = 0; i < tamano; i++) { printf("Ingrese nombre del alumno %d: ", i + 1); scanf("%s", clase[i].nombre); // SIN & porque nombre ya es char[50] printf("Ingrese legajo: "); scanf("%d", &clase[i].legajo); // CON & porque legajo es un int printf("Ingrese promedio: "); scanf("%f", &clase[i].promedio); // CON & porque promedio es un float }

🔑 Regla de oro para scanf: Mirá el tipo del último campo después del punto. Como legajo es int y promedio es float, necesitan & adelante de toda la expresión (&clase[i].legajo). Como nombre es un arreglo char[50], su nombre ya es la dirección del primer carácter.

11 Filtrar y Contar Registros que Cumplen una Condición

Combinando el recorrido for con un if adentro, podemos filtrar o contar alumnos según cualquiera de sus campos (por ejemplo, cuántos aprobaron con promedio mayor o igual a 7.0):

contar_aprobados.c Filtro + Contador
#include <stdio.h> struct Alumno { char nombre[50]; int legajo; float promedio; }; int main() { struct Alumno clase[4] = { {"Ana", 101, 8.5}, {"Luis", 102, 5.0}, {"Sol", 103, 9.0}, {"Juan", 104, 7.0} }; int aprobados = 0; for(int i = 0; i < 4; i++) { if(clase[i].promedio >= 7.0) { printf("Aprobo: %s\n", clase[i].nombre); aprobados++; } } printf("Total aprobados: %d\n", aprobados); return 0; }

¿Qué ventaja nos da la Struct acá?

Evaluamos la condición sobre un campo (clase[i].promedio >= 7.0), pero cuando se cumple tenemos acceso inmediato a todos los demás datos de esa misma persona (como clase[i].nombre o clase[i].legajo) en el mismo índice i.

Salida bash
Aprobo: Ana Aprobo: Sol Aprobo: Juan Total aprobados: 3

12 34. Funciones con Arreglos de Structs

Concepto del Apunte (Sección 34)

También podemos enviar un arreglo de Structs a una función. Igual que con los vectores de enteros, pasamos el arreglo indicando los corchetes vacíos struct Alumno clase[] y un segundo parámetro int tamano con la cantidad de elementos.

mejor_promedio.c Sección 34 del Apunte
float mejorPromedio(struct Alumno clase[], int tamano) { float mayor = clase[0].promedio; for(int i = 1; i < tamano; i++) { if(clase[i].promedio > mayor) { mayor = clase[i].promedio; } } return mayor; }

📌 Cómo se llama desde main (según el apunte): float mejor = mejorPromedio(clase, 30); (pasamos solo el nombre del arreglo clase, sin corchetes).

13 Desglose Paso a Paso de mejorPromedio

1
Firma de la función: float mejorPromedio(struct Alumno clase[], int tamano)
Recibe el arreglo clase[] y su cantidad de elementos tamano. Devuelve un float porque el promedio es un número con decimales.
2
Inicialización con el primero: float mayor = clase[0].promedio;
Tomamos el promedio del alumno en la posición 0 como campeón provisorio. ¡Nunca inicialices con 0 o con clase[0] a secas!
3
Ciclo desde i = 1: for(int i = 1; i < tamano; i++)
Arrancamos en 1 porque el alumno 0 ya está guardado en mayor. Si el promedio del alumno i supera a mayor, actualizamos mayor = clase[i].promedio;.
4
Retorno del resultado: return mayor;
Al terminar de revisar todos los alumnos, devolvemos el mayor promedio encontrado.

14 Traza Completa de mejorPromedio

main_mejor_promedio.c Programa Completo
#include <stdio.h> struct Alumno { char nombre[50]; int legajo; float promedio; }; float mejorPromedio(struct Alumno clase[], int tamano) { float mayor = clase[0].promedio; for(int i = 1; i < tamano; i++) { if(clase[i].promedio > mayor) { mayor = clase[i].promedio; } } return mayor; } int main() { struct Alumno clase[4] = { {"Ana", 101, 7.50}, {"Bruno", 102, 9.20}, {"Carla", 103, 8.40}, {"Diego", 104, 9.80} }; float mejor = mejorPromedio(clase, 4); printf("Mejor promedio: %.2f\n", mejor); return 0; }
Paso i clase[i].promedio > mayor mayor
Inicio - clase[0] = 7.50 - 7.50
i = 1 1 9.20 (Bruno) 9.20 > 7.50 (Sí) 9.20
i = 2 2 8.40 (Carla) 8.40 > 9.20 (No) 9.20
i = 3 3 9.80 (Diego) 9.80 > 9.20 (Sí) 9.80
Salida bash
Mejor promedio: 9.80

15 Variante Clave: ¿Cómo Saber Quién Tuvo el Mejor Promedio?

mejorPromedio nos devuelve el número 9.80, pero ¿cómo hacemos si en un examen nos piden imprimir el nombre y el legajo del mejor alumno? Devolvemos la posición (índice) donde está ese alumno:

indice_mejor_alumno.c Devolver índice
int indiceMejorAlumno(struct Alumno clase[], int tamano) { int posMayor = 0; for(int i = 1; i < tamano; i++) { if(clase[i].promedio > clase[posMayor].promedio) { posMayor = i; } } return posMayor; }

Uso en main()

int idx = indiceMejorAlumno(clase, 4); printf("Abanderado: %s\n", clase[idx].nombre); printf("Legajo: %d\n", clase[idx].legajo); printf("Promedio: %.2f\n", clase[idx].promedio);

💡 Conocer el índice ganador idx nos abre la carpeta completa clase[idx] con todos sus datos.

16 38. Arreglos de Structs + Punteros: Modificación Directa

Explicación del Apunte (Sección 38, pág. 35)

También podemos modificar directamente elementos de un arreglo de Structs dentro de una función. La función recorre flota[0], flota[1], flota[2]... y modifica directamente los datos originales.

actualizar_kilometraje.c Sección 38 del Apunte
void actualizarKilometraje(struct Vehiculo flota[], int tamano) { for(int i = 0; i < tamano; i++) { if(flota[i].anio < 2015) { flota[i].kilometraje += 1000; } } }

17 ¿Por Qué Modifica el Original y Por Qué Usamos Punto (.)?

Esta es una de las preguntas más importantes para entender cómo conecta la Sección 25 (Punteros y Arreglos) con la Sección 38:

1. ¿Por qué modifica el arreglo original?

Cuando pasamos una sola struct (void f(struct Vehiculo v)), C hace una copia. Pero cuando pasamos un arreglo (struct Vehiculo flota[]), el nombre del arreglo envía la dirección de memoria de su primer elemento (es un puntero encubierto). Por eso flota[i] toca las celdas reales de main.

2. ¿Por qué usamos . y no -> en flota[i].anio?

Porque los corchetes [i] ya desreferencian el puntero (recordá que flota[i] equivale a *(flota + i)). Entonces flota[i] ya no es un puntero, sino la estructura Vehiculo número i en persona. Y a una estructura directa se le aplica el punto ..

💡 Compará: Puntero a un solo vehículo: vehiculoPtr->anio (usa flecha). Arreglo de vehículos indexado en i: flota[i].anio (usa punto después de [i]).

19 ¿Y Si Queremos Modificar Un Solo Elemento con una Función?

Supongamos que ya tenemos una función que recibe el puntero a un solo alumno: void cambiarPromedio(struct Alumno *a, float nuevo). ¿Cómo le mandamos el alumno de la posición 2 del arreglo?

pasar_un_elemento.c &clase[i]
void cambiarPromedio(struct Alumno *a, float nuevo) { a->promedio = nuevo; } // En main, para modificar solo al alumno 2: cambiarPromedio(&clase[2], 9.50);

Mirá la diferencia

  • clase solo → Es la dirección de todo el arreglo.
  • clase[2] → Es la estructura del alumno 2 (por valor).
  • &clase[2] → Es la dirección de memoria de la casilla 2 (de tipo struct Alumno *). Adentro de esa función sí usamos a->promedio.

20 Ejemplo Nivel 3: Buscar un Alumno por su Legajo

Una operación fundamental en cualquier sistema es buscar un registro por su número identificador (legajo) y devolver en qué posición está (o -1 si no existe):

buscar_por_legajo.c Nivel 3
int buscarPorLegajo(struct Alumno clase[], int tamano, int legajoBuscado) { for(int i = 0; i < tamano; i++) { if(clase[i].legajo == legajoBuscado) { return i; // Lo encontró en la posición i } } return -1; // Terminó el for y no estaba }

¿Por qué devolvemos i o -1?

  • Las posiciones válidas de un vector van de 0 a tamano - 1.
  • Si encontramos que clase[i].legajo == legajoBuscado, el return i; corta la función en el acto y nos da su casillero.
  • Si el ciclo termina sin éxito, retorna -1 (un índice imposible) para avisar que ese legajo no figura en el curso.

21 Uso de buscarPorLegajo en un Programa Completo

main_buscar_legajo.c Programa Completo
#include <stdio.h> struct Alumno { char nombre[50]; int legajo; float promedio; }; int buscarPorLegajo(struct Alumno clase[], int tamano, int buscado) { for(int i = 0; i < tamano; i++) { if(clase[i].legajo == buscado) { return i; } } return -1; } int main() { struct Alumno clase[3] = { {"Ana", 1001, 8.5}, {"Bruno", 1005, 9.0}, {"Carla", 1009, 7.5} }; int pos = buscarPorLegajo(clase, 3, 1005); if(pos != -1) { printf("Encontrado: %s (Prom: %.2f)\n", clase[pos].nombre, clase[pos].promedio); } else { printf("Legajo inexistente.\n"); } return 0; }

Seguimiento de la llamada

1. Llamamos a buscarPorLegajo(clase, 3, 1005).
2. En i = 0: 1001 == 1005 es Falso.
3. En i = 1: 1005 == 1005 es Verdadero → retorna 1.
4. En main, pos vale 1 (distinto de -1), así que imprimimos clase[1].nombre y clase[1].promedio.

Salida bash
Encontrado: Bruno (Prom: 9.00)

22 Búsqueda por Nombre Combinando Structs + strcmp

¿Y si queremos buscar a un alumno por su nombre? Como clase[i].nombre es un String, no podemos usar ==; usamos strcmp de <string.h>:

buscar_por_nombre.c Structs + Strings
#include <stdio.h> #include <string.h> struct Alumno { char nombre[50]; int legajo; float promedio; }; int buscarPorNombre(struct Alumno clase[], int tamano, char buscado[]) { for(int i = 0; i < tamano; i++) { if(strcmp(clase[i].nombre, buscado) == 0) { return i; } } return -1; } int main() { struct Alumno clase[2] = { {"Ana", 101, 8.5}, {"Carla", 102, 9.1} }; int pos = buscarPorNombre(clase, 2, "Carla"); if(pos != -1) { printf("Carla tiene legajo %d\n", clase[pos].legajo); } return 0; }

¡Atención a esta combinación!

  • clase[i].nombre es el arreglo de caracteres del alumno i.
  • strcmp(clase[i].nombre, buscado) == 0 compara letra por letra ambos textos y devuelve 0 cuando son exactamente iguales.
  • Esta es una pregunta clásica de examen porque evalúa vectores, structs y strings al mismo tiempo.

23 Ejemplo Nivel 4: ¿Cómo Ordenar un Arreglo de Structs?

Supongamos que queremos armar el ranking del curso ordenando a los alumnos de mayor a menor promedio. ¿Cómo adaptamos el método burbuja que aprendimos con vectores?

1. ¿Qué comparamos en el if?

Comparamos el campo por el cual queremos ordenar:
if (clase[j].promedio < clase[j + 1].promedio)

2. ¿Qué intercambiamos con aux?

¡Intercambiamos la estructura completa! Declaramos struct Alumno aux; y movemos toda la carpeta de una vez.

intercambio_struct.c Swap de Struct Completa
struct Alumno aux = clase[j]; clase[j] = clase[j + 1]; clase[j + 1] = aux; // Se copian nombre, legajo y promedio juntos

24 Programa Completo: Ranking Ordenado por Promedio

ordenar_alumnos.c Burbuja con Structs
#include <stdio.h> struct Alumno { char nombre[50]; int legajo; float promedio; }; void ordenarPorPromedio(struct Alumno clase[], int tamano) { for(int i = 0; i < tamano - 1; i++) { for(int j = 0; j < tamano - 1 - i; j++) { if(clase[j].promedio < clase[j + 1].promedio) { struct Alumno aux = clase[j]; clase[j] = clase[j + 1]; clase[j + 1] = aux; } } } } int main() { struct Alumno clase[3] = { {"Ana", 101, 7.50}, {"Sol", 102, 9.80}, {"Luis", 103, 8.40} }; ordenarPorPromedio(clase, 3); for(int i = 0; i < 3; i++) { printf("%d) %s - %.2f\n", i + 1, clase[i].nombre, clase[i].promedio); } return 0; }

¿Por qué no hay que intercambiar campo por campo?

En C, una variable estructura se puede asignar a otra del mismo tipo con = (copia todos sus bytes, incluido el arreglo char nombre[50] que vive adentro). Así jamás se desfasan el nombre, el legajo y el promedio.

Salida bash
1) Sol - 9.80 2) Luis - 8.40 3) Ana - 7.50

25 Errores Frecuentes de Principiantes (Parte 1)

Error #1: Poner el corchete [i] al final del campo en lugar de ponerlo en el arreglo de estructuras.

❌ Incorrecto: Corchete en el campo
clase.legajo[0] = 1234; clase.promedio[i] = 8.5;

Error de compilación: clase es un arreglo (no tiene punto directamente), y legajo es un simple int, no un vector.

✅ Correcto: Primero [i], luego .campo
clase[0].legajo = 1234; clase[i].promedio = 8.5;

Regla: Como clase es el arreglo de 30 alumnos, el índice [i] siempre va pegado a clase.

26 Errores Frecuentes de Principiantes (Parte 2)

Error #2: Intentar imprimir o comparar la estructura entera sin especificar el campo.

❌ Incorrecto: Olvidar el campo
printf("%f", clase[i]); if(clase[i] > mayor) { mayor = clase[i]; }

Error: clase[i] es toda la ficha del alumno (nombre + legajo + promedio). C no sabe cuál de los tres datos querés imprimir o comparar con >.

✅ Correcto: Especificar .promedio
printf("%.2f", clase[i].promedio); if(clase[i].promedio > mayor) { mayor = clase[i].promedio; }

Correcto: Indicamos explícitamente el campo numérico .promedio para mostrarlo o compararlo.

27 Errores Frecuentes de Principiantes (Parte 3)

Error #3: Confundir cuándo usar . y cuándo usar -> al recibir un arreglo de structs en una función.

❌ Incorrecto: Usar flecha después de [i]
void actualizar(struct Vehiculo flota[], int n) { for(int i = 0; i < n; i++) { flota[i]->kilometraje += 1000; } }

Error de compilación: flota[i] no es un puntero, ya es el struct Vehiculo de la posición i.

✅ Correcto: Usar punto después de [i]
void actualizar(struct Vehiculo flota[], int n) { for(int i = 0; i < n; i++) { flota[i].kilometraje += 1000; } }

Correcto: Después de indexar con [i], tenemos una estructura directa y accedemos con .kilometraje.

28 Buenas Prácticas con Arreglos de Estructuras

Hábitos recomendados

  • Definir el struct una sola vez arriba de todas las funciones para que tanto main como las funciones auxiliares conozcan el tipo.
  • Pasar siempre la cantidad de elementos reales int tamano junto con el arreglo.
  • Al buscar máximos o mínimos (como en mejorPromedio), inicializar con el elemento [0] y arrancar el ciclo en i = 1.

Modularizar por responsabilidad

  • Una función para mostrar la lista (mostrarClase).
  • Una función para calcular estadísticas (mejorPromedio, contarAprobados).
  • Una función para actualizar datos en bloque (actualizarKilometraje).
  • Así main() queda limpio, corto y fácil de leer.

29 Cuadro Comparativo: ¿Qué Tipo Tiene Cada Expresión?

Dado struct Alumno clase[30];, repasemos qué representa exactamente cada expresión:

Expresión ¿Qué tipo de dato es? ¿Para qué se usa?
clase struct Alumno [] (dirección de clase[0]) Pasar todo el arreglo a una función: mejorPromedio(clase, 30)
clase[i] struct Alumno (una estructura entera) Pasar un alumno por copia o intercambiar con aux = clase[i]
&clase[i] struct Alumno * (puntero a un alumno) Pasar la dirección de un alumno para modificarlo con ->
clase[i].legajo int (el entero del legajo) Leer, comparar o asignar: clase[i].legajo = 1234;
&clase[i].legajo int * (dirección del entero) Leer ese campo con scanf("%d", &clase[i].legajo);
clase[i].nombre char[50] (arreglo de caracteres) Usar en printf("%s", ...), scanf("%s", ...) o strcmp

30 Ejercicio 1: Promedio General de Todo el Curso

Enunciado

Dada la estructura struct Alumno { char nombre[50]; int legajo; float promedio; };, escribí una función float promedioDelCurso(struct Alumno clase[], int tamano) que sume los promedios de todos los alumnos del arreglo y devuelva el promedio general del curso.

💻 Ver solución paso a paso
float promedioDelCurso(struct Alumno clase[], int tamano) { float suma = 0; for(int i = 0; i < tamano; i++) { suma += clase[i].promedio; } return suma / tamano; }

💡 Acumulamos clase[i].promedio en la variable suma durante todo el ciclo for y al final dividimos por tamano.

31 Ejercicio 2: Descuento en Productos con Mucho Stock

Enunciado

Se tiene struct Producto { char nombre[40]; float precio; int stock; };. Escribí una función void aplicarLiquidacion(struct Producto lista[], int tamano) que recorra el arreglo y, a todos los productos cuyo stock sea mayor a 100, les reduzca el precio en un 20% (multiplicándolo por 0.80).

💻 Ver solución paso a paso
void aplicarLiquidacion(struct Producto lista[], int tamano) { for(int i = 0; i < tamano; i++) { if(lista[i].stock > 100) { lista[i].precio = lista[i].precio * 0.80f; } } }

💡 Igual que en actualizarKilometraje del apunte, la función modifica directamente el campo lista[i].precio del arreglo original.

32 Ejercicio 3: Vehículo con Menor Kilometraje

Enunciado

Usando struct Vehiculo { char patente[10]; int anio; int kilometraje; };, escribí una función int menorKilometraje(struct Vehiculo flota[], int tamano) que devuelva el menor kilometraje de toda la flota, y mostrá un main() de prueba con 3 vehículos.

33 Resumen de la Unidad 10 y Checklist

Conceptos Clave (Secciones 32, 33, 34 y 38)

  • Declaración: struct Alumno clase[30]; crea 30 estructuras numeradas de 0 a 29.
  • Acceso: clase[i].campo (primero elegimos el índice [i] y luego el campo con .).
  • Recorrido: Un ciclo for(int i = 0; i < tamano; i++) procesa todos los registros.
  • Funciones: Reciben struct Alumno clase[], int tamano. Pueden calcular valores (mejorPromedio) o modificar el arreglo original directamente (actualizarKilometraje).
