Arreglos de Estructuras

Bases de datos en memoria RAM: vectores donde cada celda es un registro completo, búsquedas de mejor promedio y mutación en masa de colecciones.

struct Alumno clase[30] clase[i].campo mejorPromedio actualizarKilometraje

💡 Guía de navegación: Usá la barra espaciadora o las flechas del teclado (→ / ←) para avanzar diapositiva por diapositiva.

01 Objetivos Pedagógicos

Construyendo colecciones realistas

Tener un solo alumno o un solo empleado es insuficiente. Los sistemas del mundo real procesan listas: cursos enteros, catálogos de productos, inventarios o nóminas de personal.

Un arreglo de estructuras combina la potencia del orden y los índices de un vector con la riqueza de datos de una struct.

Lo que vas a dominar en esta clase

  • Declarar vectores de estructuras: struct Alumno clase[30].
  • Entender la anatomía de acceso: clase[i].promedio.
  • Recorrer e imprimir colecciones completas con bucles for.
  • Enviar arreglos de structs a funciones para análisis estadístico.
  • Implementar algoritmos de búsqueda del máximo registro (mejorPromedio).
  • Mutar campos de registros almacenados en arreglos (caso Vehiculo).

02 ¿Qué es un Arreglo de Estructuras?

Es un vector ordinario donde cada casillero individual contiene una instancia completa de la estructura.

03 Acceder y Recorrer con un Bucle for

Regla de Acceso: clase[i].campo

Primero especificamos qué elemento del vector queremos con [i], y luego con el punto . elegimos qué campo de esa estructura queremos leer o escribir.

mostrar_clase.c for loop
void mostrarClase(struct Alumno clase[], int tamano) { for(int i = 0; i < tamano; i++) { printf("Alumno %d:\n", i + 1); printf(" Nombre: %s\n", clase[i].nombre); printf(" Legajo: %d\n", clase[i].legajo); printf(" Promedio: %.2f\n", clase[i].promedio); } }

04 Búsqueda de Máximo: mejorPromedio

Función del apunte que recorre el vector de registros y encuentra la calificación más alta.

mejor_promedio.c Búsqueda de Extremos
float mejorPromedio(struct Alumno clase[], int tamano) { // Asumimos que el primer alumno tiene el mayor promedio: float mayor = clase[0].promedio; for(int i = 1; i < tamano; i++) { if(clase[i].promedio > mayor) { mayor = clase[i].promedio; } } return mayor; }

💡 Uso en main: float mejor = mejorPromedio(clase, 30);. ¡Funciona igual que con un vector de números simples, pero accediendo a clase[i].promedio!

05 Modificación Masiva: Flota de Vehículos

Al pasar un arreglo de estructuras a una función, sus campos se pueden modificar directamente.

flota_vehiculos.c Modificación Directa
struct Vehiculo { char patente[10]; int anio; int kilometraje; }; void actualizarKilometraje(struct Vehiculo flota[], int tamano) { for(int i = 0; i < tamano; i++) { // Condicional sobre el año del vehículo: if(flota[i].anio < 2015) { flota[i].kilometraje += 1000; // Modifica la celda real } } }

¿Por qué se modifican sin usar * ni ->? Porque flota es un arreglo, y al pasarlo a la función se pasa la dirección de su primer elemento. flota[i] ya resuelve la memoria exacta del vehículo i.

06 Resumen y Autoevaluación

Puntos Clave del Módulo

  • Un arreglo de structs almacena múltiples registros contiguos en memoria.
  • La sintaxis canónica de acceso es vector[indice].campo.
  • Al enviar el vector a una función enviamos tipo vector[] y su tamano.
  • Los campos de los registros pueden modificarse directamente en las funciones.

Checklist de Autoevaluación

✓ ¿Sé qué diferencia hay entre clase[0] y clase[0].legajo?
✓ ¿Por qué en flota[i].anio usamos punto y no flecha? (Porque flota[i] es la struct directa).
✓ ¿Puedo escribir la función para buscar al alumno con mejor nota?
