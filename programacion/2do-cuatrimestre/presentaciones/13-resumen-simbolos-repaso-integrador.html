02 Cómo Descifrar Expresiones Complejas

Un método paso a paso para no perderse en líneas densas de código.

Analicemos esta expresión real:

empresa.sucursales[i]->gerente.sueldo
1
empresa es una estructura directa. Usamos . para acceder a sus miembros.
2
sucursales es un arreglo. Usamos [i] para elegir la sucursal número i.
3
La sucursal [i] es un puntero a otra estructura. Por eso usamos -> para acceder al gerente.
4
El gerente es una estructura anidada directa. Usamos . para leer su sueldo.

03 Mapa Conceptual: Todo Conectado

1. Vectores & Strings

Un string es un vector de char que termina en '\0'. El nombre del arreglo representa la dirección del primer elemento: v == &v[0].

2. Punteros & Funciones

C pasa parámetros por valor. Para modificar variables remotas o arreglos, pasamos direcciones con & y las recibimos como punteros con *.

3. Structs & Flecha

Agrupan datos heterogéneos. Si tenemos la struct directa usamos .; si tenemos un puntero usamos -> para evitar escribir (*p).campo.

🚀 La Síntesis: Cuando combinás structs con arreglos y punteros, tenés el 100% de los bloques fundamentales con los que están construidos los sistemas operativos, motores de bases de datos y videojuegos modernos.

04 Autoevaluación Interactiva

Poné a prueba tu comprensión antes de rendir el examen.

❓ Pregunta 1: ¿Qué imprime este fragmento?
int a = 5; int *p = &a; *p = *p + 10; printf("%d\n", a);

Respuesta: 15. p apunta a la variable a. *p lee 5, le suma 10 (15) y lo vuelve a guardar en la celda de a.

❓ Pregunta 2: ¿Qué error fatal tiene esta comparación?
char cad1[] = "clave"; if (cad1 == "clave") { ... }

Respuesta: Compara las direcciones de memoria RAM, no el contenido del texto. Se debe usar siempre if (strcmp(cad1, "clave") == 0).

❓ Pregunta 3: ¿Por qué usamos emp->salario en vez de emp.salario?

Respuesta: Porque emp es un puntero a la estructura (guarda su dirección). Si usáramos ., el compilador daría error porque un puntero no tiene campos directos. La flecha -> desreferencia y accede en una sola operación.
