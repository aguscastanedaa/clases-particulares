Estructuras con Arreglos Internos y Anidadas

Composición de datos avanzada: cuando un registro alberga un vector en su interior y cómo anidar una estructura dentro de otra.

notas[3] dentro de Estudiante struct Fecha en Persona persona.nacimiento.dia Promedio con acumulación

💡 Guía de navegación: Usá la barra espaciadora o las flechas del teclado (→ / ←) para avanzar diapositiva por diapositiva.

01 Objetivos Pedagógicos

Jerarquía y composición de datos

En problemas de complejidad real, una entidad no se compone únicamente de valores primitivos sueltos.

Un estudiante posee una serie de notas (vector interno), y una persona posee una fecha de nacimiento que a su vez tiene día, mes y año (estructura anidada). En esta unidad aprenderás la sintaxis y la mecánica en memoria para anidar estos componentes sin confusión.

Lo que vas a dominar en esta clase

  • Declarar una estructura que incluye un arreglo interno (ej. float notas[3]).
  • Acceder a elementos del arreglo interno: estudiante.notas[0].
  • Recorrer arreglos internos con bucles para cálculos estadísticos.
  • Declarar estructuras compuestas por otras estructuras (anidamiento).
  • Navegar jerarquías profundas con el operador punto doble: persona.nacimiento.dia.

02 Structs con Arreglos Internos

Un campo dentro de la estructura puede ser un vector completo de tamaño fijo.

estudiante.h Arreglo Interno
struct Estudiante { char nombre[50]; float notas[3]; // Vector de 3 notas };

Árbol de Acceso en Memoria

Estudiante
├── nombre (char[50])
└── notas (float[3])
    ├── notas[0]
    ├── notas[1]
    └── notas[2]

Para acceder a la primera nota escribimos: estudiante.notas[0].

03 Procesar el Arreglo Interno

Cálculo del promedio iterando sobre el arreglo interno de la estructura.

promedio_estudiante.c for sobre notas
struct Estudiante { char nombre[50]; float notas[3]; }; float calcularPromedio(struct Estudiante e) { float suma = 0.0f; for(int i = 0; i < 3; i++) { suma += e.notas[i]; } return suma / 3.0f; }
main.c Uso y Acceso
int main(void) { struct Estudiante est = { "Lucia", {9.0f, 8.5f, 10.0f} }; printf("Promedio: %.2f\n", calcularPromedio(est)); return 0; }
Terminal de salida bash
Promedio: 9.17

04 Estructuras Anidadas: struct dentro de struct

Modularizar modelos reutilizando estructuras más pequeñas como campos.

anidamiento.c Fecha y Persona
struct Fecha { int dia; int mes; int anio; }; struct Persona { char nombre[50]; struct Fecha nacimiento; // Struct anidada };

Jerarquía Visual en RAM

Persona
├── nombre (char[50])
└── nacimiento (struct Fecha)
    ├── dia (int)
    ├── mes (int)
    └── anio (int)

Cada nivel de jerarquía se atraviesa encadenando el operador punto: persona.nacimiento.dia.

05 Asignación e Impresión de Estructuras Anidadas

uso_anidadas.c punto encadenado
#include <stdio.h> #include <string.h> int main(void) { struct Persona p; strcpy(p.nombre, "Martin"); // Acceso jerárquico paso a paso: p.nacimiento.dia = 15; p.nacimiento.mes = 8; p.nacimiento.anio = 2002; printf("Nombre: %s\n", p.nombre); printf("Nacimiento: %02d/%02d/%d\n", p.nacimiento.dia, p.nacimiento.mes, p.nacimiento.anio); return 0; }

Regla del Doble Punto

El primer punto ingresa a la variable anidada: p.nacimiento.

El segundo punto ingresa al campo concreto: .dia, .mes o .anio.

Terminal de salida bash
Nombre: Martin Nacimiento: 15/08/2002

06 Resumen y Autoevaluación

Puntos Clave del Módulo

  • Un arreglo dentro de una struct se indexa tras el punto: est.notas[i].
  • Una struct dentro de otra se accede encadenando puntos: a.b.c.
  • Esto permite modelar entidades complejas del mundo real sin variables sueltas.
  • Facilita la modularidad al poder escribir funciones para cada subtipo (ej. imprimirFecha(p.nacimiento)).

Checklist de Autoevaluación

✓ ¿Sé cómo declarar una estructura con un vector interno de flotantes?
✓ ¿Por qué persona.nacimiento = 15; da error de compilador? (Porque nacimiento es la struct Fecha, no el día).
✓ ¿Puedo pasar solo la subestructura p.nacimiento a una función que reciba struct Fecha? (Sí, ¡perfectamente!).
