Punteros a Estructuras y el Operador Flecha (->)

Cómo combinar struct + punteros para modificar registros originales desde funciones, la equivalencia emp->salario == (*emp).salario y el caso de aumento salarial

30. Punteros a Structs 31. Operador -> (*emp).salario 37. Structs + Punteros aumentarSalario(&empleado, 10)

💡 Guía de estudio: Usá las flechas del teclado (→ / ←) o la barra espaciadora para avanzar por las 35 diapositivas de esta unidad.

01 Hoja de Ruta y Conexión con las Unidades 06 y 08

Las dos piezas que hoy vamos a unir

  • De la Unidad 06 (Punteros): Para que una función modifique una variable original de main, le pasamos su dirección con & y la recibimos con un puntero *.
  • De la Unidad 08 (Structs): Si pasamos una struct por valor, la función recibe una copia y el original no cambia.

Lo que vamos a dominar hoy (Secciones 30, 31 y 37)

  • Declarar un puntero a una estructura: struct Empleado *emp = &empleado;.
  • Cuándo usar el operador punto . y cuándo el operador flecha ->.
  • Por qué emp->salario equivale a (*emp).salario y por qué *emp.salario falla.
  • Programar funciones como aumentarSalario(&empleado, 10) que modifican la estructura original.

02 El Problema de Pasar una Struct por Valor

Imaginemos que tenemos un empleado con un salario de $100.000 y queremos hacer una función que le aumente el sueldo un 10%. Mirá qué pasa si la pasamos por valor:

intento_fallido_por_valor.c ¡No cambia en main!
#include <stdio.h> struct Empleado { char nombre[50]; int edad; float salario; }; void aumentarMal(struct Empleado emp, float porc) { emp.salario += emp.salario * porc / 100; } int main() { struct Empleado empleado = {"Ana", 30, 100000}; aumentarMal(empleado, 10); printf("Salario en main: %.2f\n", empleado.salario); return 0; }
Terminal Salida
$ ./intento_fallido Salario en main: 100000.00

Dos problemas a la vez:

  1. No modifica el original: aumentó el sueldo en la copia local emp y empleado en main quedó igual.
  2. Copia innecesaria de memoria: copió los 58 bytes de la estructura en cada llamada.

03 30. Punteros a Structs: La Solución del Apunte

Sección 30 del Apunte (Página 30)

Ahora podemos combinar: Struct + puntero. En lugar de mandar una copia de toda la estructura, creamos la variable struct Empleado empleado; y le pasamos a la función su dirección de memoria: &empleado.

Código de la página 30 del Apunte Struct + Puntero
struct Empleado { char nombre[50]; int edad; float salario; }; void aumentarSalario(struct Empleado *emp, float porcentaje) { emp->salario += emp->salario * porcentaje / 100; } // En main creamos la variable y pasamos su dirección: // struct Empleado empleado; // aumentarSalario(&empleado, 10);

04 ¿Qué Es Exactamente un Puntero a una Struct?

Igual que int *p guarda la dirección de memoria de un int, un puntero struct Empleado *emp es una variable que guarda la dirección de memoria donde empieza una estructura struct Empleado:

Declaración y asignación Sintaxis
// 1. Creamos la estructura real: struct Empleado empleado; // 2. Creamos un puntero que apunta a ella: struct Empleado *emp = &empleado;
Dirección: 0x7000
emp struct Empleado *

Dirección: 0x4000

05 Desglose Pieza por Pieza de la Declaración

struct Empleado *emp = &empleado;

struct Empleado *

Indica el tipo del puntero: "puntero a una estructura de tipo struct Empleado".

emp

Es el nombre de nuestra variable puntero. Adentro suyo solo se guarda una dirección de memoria (ej: 0x4000).

= &empleado;

El operador & obtiene la dirección de memoria donde está guardada la variable empleado. ¡Sí lleva &!

📌 Diferencia clave con los arreglos: El nombre de un arreglo ya es una dirección (no lleva &), pero el nombre de una variable struct representa a la caja entera; por eso para obtener su dirección siempre usamos &empleado.

06 31. El Operador Flecha (->)

Explicación del Apunte (Página 30)

• Cuando tenemos una Struct normal (struct Empleado empleado;), usamos el punto . ➔ empleado.salario.
• Pero cuando tenemos un puntero a una Struct (struct Empleado *emp;), usamos la flecha -> ➔ emp->salario.

Struct normal (Tengo la caja en la mano)

empleado.salario = 100000;

empleado es la estructura misma. Usamos el operador punto . para abrir el campo salario.

Puntero a Struct (Tengo la dirección en un papel)

emp->salario = 100000;

emp->salario significa: "Acceder al campo salario de la Struct a la que apunta emp".

07 Cómo Se Escribe -> y Qué Hace Exactamente

El operador flecha -> se escribe con dos caracteres pegados (sin espacio en el medio): un guion medio (-) seguido del símbolo mayor que (>).

1

Mira el puntero emp

Lee la dirección de memoria guardada adentro de emp (por ejemplo, 0x4000).

2

Viaja a esa dirección

Se traslada por la memoria RAM hasta encontrar la estructura original empleado.

3

Entra al campo

Abre la cajita interna indicada después de la flecha (salario, edad o nombre).

🎯 Analogía cotidiana: Si tenés la caja frente a vos, la abrís directamente con el punto (empleado.salario). Si tenés un papel con la dirección de dónde está la caja, seguís la flecha del mapa (emp->salario) hasta la caja y la abrís.

08 La Equivalencia Conceptual: emp->salario vs (*emp).salario

Una forma de entenderlo (Página 31 del Apunte)

Si tenemos struct Empleado *emp;, entonces escribir emp->salario es equivalente conceptualmente a escribir (*emp).salario.

Desglose en dos pasos (*emp).salario
// Paso 1: *emp // -> obtenemos la Struct apuntada. // Paso 2: .salario // -> accedemos al campo de esa Struct. (*emp).salario = 120000; emp->salario = 120000; // ¡Hacen exactamente lo mismo!

Conclusión del Apunte

"Por eso emp->salario es simplemente una forma más cómoda de escribir (*emp).salario."

En lugar de tener que poner paréntesis, asterisco y punto cada vez, la flecha -> hace los dos pasos en uno solo.

09 ¿Por Qué *emp.salario Sin Paréntesis Da Error?

Una duda muy común es: "¿Por qué hay que escribir (*emp).salario con paréntesis y no *emp.salario?". La respuesta está en la prioridad (precedencia) de los operadores en C:

❌ Sin paréntesis: *emp.salario
*emp.salario = 50000; // ❌ ERROR de compilación

Qué pasa: El punto . tiene más prioridad que el asterisco *. Entonces C intenta hacer primero emp.salario, ¡pero emp es un puntero, no una struct!

✅ Con paréntesis (*emp).salario o flecha emp->salario
(*emp).salario = 50000; // ✅ Válido emp->salario = 50000; // ✅ Más cómodo y claro

Por qué funciona: Primero desreferencia el puntero emp para llegar a la estructura y recién después entra al campo salario.

10 Ejemplo Nivel 1: Usar un Puntero a Struct en main

Veamos primero dentro de main cómo un puntero emp lee y modifica los campos de empleado usando ->:

nivel1_flecha_en_main.c Nivel 1 • Inicial
#include <stdio.h> struct Empleado { char nombre[50]; int edad; float salario; }; int main() { struct Empleado empleado = {"Laura", 28, 80000.0}; struct Empleado *emp = &empleado; printf("Antes: $%.2f\n", emp->salario); emp->salario = 95000.0; emp->edad = 29; printf("Despues: %s (%d anios) cobra $%.2f\n", empleado.nombre, empleado.edad, empleado.salario); return 0; }
Terminal Salida
$ ./nivel1_flecha Antes: $80000.00 Despues: Laura (29 anios) cobra $95000.00

Observá cómo cambiamos emp->salario y emp->edad a través del puntero, y cuando imprimimos empleado.edad y empleado.salario con punto, ¡la variable original cambió!

11 37. Combinar Structs + Punteros + Funciones

Sección 37 del Apunte (Páginas 34 y 35)

Acá unimos los cuatro conceptos centrales del cuatrimestre:
struct + puntero + función + modificación.

Función del Apunte (Pág. 30 y 34) aumentarSalario
void aumentarSalario(struct Empleado *emp, float porcentaje) { emp->salario += emp->salario * porcentaje / 100; }

¿Qué significa la llamada?

En main escribimos:
aumentarSalario(&empleado, 10);

Tal como explica el apunte, esto significa:
"Te paso la dirección de este empleado para que puedas modificarlo."
Y adentro, emp->salario permite acceder y actualizar directamente su salario original.

12 Desglose de la Fórmula de Aumento Salarial

Analicemos con números reales qué calcula la línea emp->salario += emp->salario * porcentaje / 100; cuando el salario inicial es 100000 y el porcentaje es 10:

emp->salario += emp->salario * porcentaje / 100; // Es equivalente a escribir: emp->salario = emp->salario + (emp->salario * porcentaje / 100);

1. Calcula el aumento

emp->salario * 10 / 100
100000 * 10 / 100 = 10000.
El 10% de 100.000 es 10.000.

2. Lo suma al actual

El operador += suma ese 10000 al salario que ya tenía:
100000 + 10000 = 110000.

3. Guarda en el original

Como usa emp->salario, el nuevo valor 110.000 queda guardado directamente en empleado.salario de main.

13 Ejemplo Nivel 2: Programa Completo de aumentarSalario

nivel2_aumentar_salario.c Nivel 2 • Apunte pág. 30
#include <stdio.h> struct Empleado { char nombre[50]; int edad; float salario; }; void aumentarSalario(struct Empleado *emp, float porcentaje) { emp->salario += emp->salario * porcentaje / 100; } int main() { struct Empleado empleado = {"Carlos", 35, 100000.0}; printf("Salario inicial: $%.2f\n", empleado.salario); aumentarSalario(&empleado, 10); printf("Con 10%% aumento: $%.2f\n", empleado.salario); return 0; }
Terminal Salida
$ ./nivel2_aumentar_salario Salario inicial: $100000.00 Con 10% aumento: $110000.00

• En main usamos . (empleado.salario) porque empleado es una struct.
• En aumentarSalario usamos -> (emp->salario) porque emp es un puntero.

15 Modificar Strings y Varios Campos mediante ->

Con un puntero a estructura podemos inicializar o actualizar todos los campos de una struct dentro de una función, incluyendo campos de tipo String con strcpy(emp->nombre, ...):

cargar_empleado_puntero.c Inicialización por Puntero
#include <stdio.h> #include <string.h> struct Empleado { char nombre[50]; int edad; float salario; }; void inicializarEmpleado(struct Empleado *emp, int edad, float sal) { strcpy(emp->nombre, "Nuevo Ingreso"); emp->edad = edad; emp->salario = sal; } int main() { struct Empleado e1; inicializarEmpleado(&e1, 22, 75000.0); printf("%s | %d anios | $%.2f\n", e1.nombre, e1.edad, e1.salario); return 0; }
Terminal Salida
$ ./cargar_empleado Nuevo Ingreso | 22 anios | $75000.00

Declaramos struct Empleado e1; vacío en main y le pasamos &e1 a inicializarEmpleado para que rellene sus tres cajitas internas.

16 Detalle Importante: scanf con un Puntero a Struct

¿Qué pasa si adentro de una función que recibe struct Empleado *emp queremos pedir datos por teclado con scanf?

scanf_con_flecha.c ¡Atención al &!
void cargarPorTeclado(struct Empleado *emp) { scanf("%s", emp->nombre); // String (char[50]): NO lleva & scanf("%d", &emp->edad); // int: SÍ lleva & adelante scanf("%f", &emp->salario); // float: SÍ lleva & adelante }

Por qué emp->nombre no lleva &

Porque el campo nombre es un arreglo de caracteres (char[50]), y como vimos en la Unidad 07, el nombre de un arreglo ya evalúa a la dirección de su primer carácter.

Por qué &emp->edad sí lleva &

Porque emp->edad es el número entero guardado en el campo edad. Como -> tiene mayor prioridad que &, &emp->edad significa &(emp->edad): la dirección de ese campo entero.

17 Ejemplo Nivel 3: Función que Modifica y Devuelve Estado

Un patrón muy usado en C (y clave para los ejercicios integradores del apunte) es que una función reciba un puntero a struct para modificarla y además devuelva con return un 1 (éxito) o 0 (error):

nivel3_vender_producto.c Nivel 3 • Validación + Flecha
#include <stdio.h> struct Producto { char nombre[40]; int stock; }; int vender(struct Producto *prod, int cantidad) { if (cantidad <= 0 || prod->stock < cantidad) { return 0; // No alcanza el stock } prod->stock -= cantidad; return 1; // Venta exitosa } int main() { struct Producto item = {"Monitor", 10}; if (vender(&item, 3) == 1) { printf("Venta OK. Stock restante: %d\n", item.stock); } return 0; }
Terminal Salida
$ ./nivel3_vender Venta OK. Stock restante: 7

• Si hay stock suficiente, prod->stock -= cantidad; descuenta del producto original y retorna 1.
• Si no alcanza, retorna 0 sin tocar el stock.

18 Funciones que Reciben Dos Punteros a Struct

¿Y si una operación necesita modificar dos estructuras al mismo tiempo (por ejemplo, intercambiar los datos de dos puntos o transferir de un registro a otro)? Pasamos las direcciones de ambas con &:

intercambiar_puntos.c 2 Punteros a Struct
#include <stdio.h> struct Punto { int x; int y; }; void intercambiarPuntos(struct Punto *a, struct Punto *b) { struct Punto aux = *a; *a = *b; *b = aux; } int main() { struct Punto p1 = {1, 2}; struct Punto p2 = {8, 9}; intercambiarPuntos(&p1, &p2); printf("p1=(%d,%d) p2=(%d,%d)\n", p1.x, p1.y, p2.x, p2.y); return 0; }
Terminal Salida
$ ./intercambiar_puntos p1=(8,9) p2=(1,2)

Mirá qué potente: *a representa la estructura completa apuntada por a. Con *a = *b; intercambiamos todos los campos de golpe.

19 Comparativa Definitiva: Struct por Valor vs Puntero a Struct

Característica Struct por Valor (Unidad 08) Puntero a Struct (Unidad 09)
Encabezado de la función void mostrar(struct Empleado emp) void aumentar(struct Empleado *emp)
Cómo se llama desde main mostrar(empleado); (sin &) aumentar(&empleado); (con &)
Operador para acceder a campos Operador punto: emp.salario Operador flecha: emp->salario
¿Qué viaja por memoria? Una copia de todos los campos Solo la dirección de memoria (8 bytes)
¿Modifica el original en main? NO (solo cambia la copia local) SÍ (modifica la variable original)

20 Regla Visual Infalible: ¿Uso Punto . o Flecha ->?

Ante cualquier duda en un ejercicio o examen, mirá cómo fue declarada la variable que tenés a la izquierda:

¿Fue declarada SIN asterisco? ➔ Usá .

struct Empleado empleado; empleado.edad = 30; empleado.salario = 90000;

No tiene * en su declaración: es una variable struct directa ➔ lleva punto (.).

¿Fue declarada CON asterisco? ➔ Usá ->

struct Empleado *emp = &empleado; emp->edad = 30; emp->salario = 90000;

Tiene * en su declaración: es un puntero a struct ➔ lleva flecha (->).

21 Ejemplo Nivel 4 (Tipo Examen): Planteo Paso a Paso

Problema Integrador: Ascenso y Bono por Antigüedad

Dado un struct Empleado con nombre, edad, antiguedad y salario:
Escribir una función int evaluarAscenso(struct Empleado *emp, float bonoExtra) que reciba un puntero al empleado:
1. Si su antiguedad >= 5 años, le sume un 20% a su salario actual más el bonoExtra fijo, y retorne 1.
2. Si tiene menos de 5 años de antigüedad, solo le aumente un 5% sin bono extra y retorne 0.

1

Recibir Puntero

Como hay que modificar el salario original, el parámetro debe ser struct Empleado *emp.

2

Verificar Antigüedad

Evaluamos if (emp->antiguedad >= 5) usando el operador flecha ->.

3

Actualizar y Retornar

Actualizamos emp->salario según corresponda y devolvemos 1 o 0.

22 Ejemplo Nivel 4: Código Completo y Salida

nivel4_ascenso_empleado.c Nivel 4 • Modelo Examen
#include <stdio.h> struct Empleado { char nombre[50]; int edad; int antiguedad; float salario; }; int evaluarAscenso(struct Empleado *emp, float bonoExtra) { if (emp->antiguedad >= 5) { emp->salario += (emp->salario * 20 / 100) + bonoExtra; return 1; } emp->salario += emp->salario * 5 / 100; return 0; } int main() { struct Empleado e1 = {"Elena", 34, 7, 200000.0}; int ascendio = evaluarAscenso(&e1, 15000.0); printf("%s | Ascenso: %d | Nuevo sueldo: $%.2f\n", e1.nombre, ascendio, e1.salario); return 0; }
Terminal Salida
$ ./nivel4_ascenso Elena | Ascenso: 1 | Nuevo sueldo: $255000.00

• antiguedad es 7 >= 5.
• 20% de 200000 es 40000.
• Suma 40000 + 15000 = 55000.
• e1.salario pasa a $255.000 y retorna 1.

23 Tip Profesional: Pasar Puntero para No Copiar Estructuras Grandes

¿Qué pasa si solo queremos mostrar una estructura muy grande, sin modificarla, pero tampoco queremos que C copie cientos de bytes al pasarla por valor?

mostrar_con_puntero.c Eficiencia en RAM
void mostrarEmpleado(struct Empleado *emp) { printf("Nombre: %s\n", emp->nombre); printf("Edad: %d\n", emp->edad); printf("Salario: $%.2f\n", emp->salario); }

Las 2 grandes ventajas de los punteros a Struct

  1. Poder modificar la estructura original desde adentro de la función (como en aumentarSalario).
  2. Ahorrar memoria y velocidad, ya que en vez de duplicar toda la caja solo viajan los 8 bytes de su dirección.

24 Aplicar varios Aumentos Consecutivos sobre el Mismo Registro

Como aumentarSalario(&empleado, porcentaje) modifica directamente la variable en memoria, si la llamamos dos veces seguidas el segundo aumento se calcula sobre el salario ya actualizado:

aumentos_acumulados.c Acumulación
#include <stdio.h> struct Empleado { char nombre[50]; int edad; float salario; }; void aumentarSalario(struct Empleado *emp, float porcentaje) { emp->salario += emp->salario * porcentaje / 100; } int main() { struct Empleado emp = {"Diego", 40, 100000.0}; aumentarSalario(&emp, 10); // Pasa a 110000 aumentarSalario(&emp, 20); // +20% de 110000 = +22000 printf("Salario final: $%.2f\n", emp.salario); return 0; }
Terminal Salida
$ ./aumentos_acumulados Salario final: $132000.00

• 1° llamada (+10%): de 100.000 sube a 110.000.
• 2° llamada (+20%): el 20% de 110.000 es 22.000 ➔ llega a $132.000.

25 Errores Frecuentes de Principiantes (Parte 1)

❌ Error 1: Usar el operador punto . en un puntero
void aumentarSalario(struct Empleado *emp, float p) { emp.salario += emp.salario * p / 100; // ❌ ERROR }

Mensaje del compilador: "member reference type 'struct Empleado *' is a pointer; did you mean to use '->'?".

✅ Correcto: Usar el operador flecha -> en punteros
void aumentarSalario(struct Empleado *emp, float p) { emp->salario += emp->salario * p / 100; // ✅ OK }

Por qué funciona: Como emp es un puntero (struct Empleado *), accedemos a sus campos con ->.

26 Errores Frecuentes de Principiantes (Parte 2)

❌ Error 2: Olvidar el & al llamar a la función desde main
struct Empleado empleado = {"Ana", 30, 100000}; aumentarSalario(empleado, 10); // ❌ Falta el &

Por qué falla: La función espera una dirección de memoria (struct Empleado *), no la estructura por valor.

✅ Correcto: Pasar la dirección con &empleado
struct Empleado empleado = {"Ana", 30, 100000}; aumentarSalario(&empleado, 10); // ✅ Pasa su dirección

Por qué funciona: &empleado entrega exactamente el puntero struct Empleado * que la función necesita.

27 Errores Frecuentes de Principiantes (Parte 3)

❌ Error 3: Escribir *emp.salario sin paréntesis
struct Empleado *emp = &empleado; *emp.salario = 90000; // ❌ Error por precedencia

Por qué falla: El operador punto . se evalúa antes que *, intentando hacer *(emp.salario).

✅ Correcto: Usar emp->salario o (*emp).salario
struct Empleado *emp = &empleado; emp->salario = 90000; // ✅ Limpio y sin errores

Por qué funciona: El operador flecha -> fue creado justamente para evitar ese problema de paréntesis.

28 Errores Frecuentes (Parte 4): Puntero a Struct Sin Inicializar

❌ Error 4: Usar emp->... sin apuntarlo a ninguna struct
struct Empleado *emp; // ❌ No apunta a nada emp->edad = 25; // 💥 Crash del programa

Por qué falla: emp solo es un papel para anotar una dirección; si no creaste la caja struct Empleado, apunta a basura.

✅ Correcto: Apuntar siempre a una variable struct existente
struct Empleado empleado; struct Empleado *emp = &empleado; // ✅ Apunta a empleado emp->edad = 25;

Por qué funciona: Primero existe la estructura real en memoria y luego el puntero guarda su dirección con &.

29 Buenas Prácticas con Punteros a Structs

✔️ Cuándo elegir cada forma

  • Si la función debe modificar algún campo de la estructura (sueldo, saldo, stock, edad, estado): recibí siempre un puntero a struct (struct Empleado *emp).
  • Preferí siempre emp->campo en lugar de (*emp).campo: es el estándar universal en C y mucho más fácil de leer.

🧠 Cómo leer tu propio código

  • Leé la flecha -> en voz alta como: "el campo ... de la struct apuntada por ...".
  • Verificá siempre la pareja: si en los parámetros de la función pusiste *emp, en la llamada desde main tiene que aparecer &empleado.

31 Ejercicios de Práctica (Parte 2)

Ejercicio 3: Aplicar descuento a un producto si supera un precio

Dada struct Producto { char nombre[40]; float precio; };, escribí una función int aplicarDescuento(struct Producto *prod, float porcentaje) que, si el precio es mayor a 10000, le descuente ese porcentaje en la estructura original y retorne 1 (o retorne 0 sin modificarlo si cuesta 10000 o menos).

💻 Ver solución paso a paso
#include <stdio.h> struct Producto { char nombre[40]; float precio; }; int aplicarDescuento(struct Producto *prod, float porcentaje) { if (prod->precio > 10000.0) { prod->precio -= prod->precio * porcentaje / 100.0; return 1; } return 0; } int main() { struct Producto p = {"Auriculares", 20000.0}; if (aplicarDescuento(&p, 15.0) == 1) { printf("Precio con descuento: $%.2f\n", p.precio); // $17000.00 } return 0; }

34 Resumen de la Unidad 09 y Checklist

Ideas Clave (Secciones 30, 31 y 37)

  • Para que una función modifique una struct original, le pasamos su dirección con &empleado y la recibimos con un puntero struct Empleado *emp.
  • En una variable struct normal usamos punto (empleado.salario); en un puntero a struct usamos flecha (emp->salario).
  • emp->salario es exactamente equivalente a (*emp).salario.
