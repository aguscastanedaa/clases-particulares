malloc(), free() y sizeof()

El ciclo de vida en el Heap: pedir memoria con precisión, verificar contra NULL y prevenir fugas de memoria

sizeof() en bytes malloc() & Heap Validación ptr == NULL free() & Memory Leaks

💡 Guía de navegación: Usá la barra espaciadora o las flechas del teclado (→ / ←) para avanzar diapositiva por diapositiva.

01 Objetivos de Aprendizaje

Gestionar la memoria como un profesional

En lenguajes de alto nivel como Python o JavaScript hay un "recolector de basura" (*Garbage Collector*) que limpia la memoria automáticamente en segundo plano.

En C tenés control absoluto sobre la máquina: vos pedís los bytes exactos al sistema operativo y vos sos el responsable de devolverlos cuando ya no se usan. Es un gran poder y una gran responsabilidad.

Lo que vas a dominar hoy

  • Utilizar el operador sizeof() para calcular bytes portables.
  • Reservar memoria dinámica con malloc().
  • Aplicar la regla obligatoria de validación contra NULL.
  • Liberar la memoria devuelta con free().
  • Evitar punteros colgantes (*dangling pointers*).
  • Comprender qué es una **Fuga de Memoria (*Memory Leak*)** y cómo evitarla.

02 El Operador sizeof()

¿Por qué no escribir "4" a mano?

El tamaño de los tipos de datos puede variar entre un procesador de 32 bits, 64 bits o un microcontrolador embebido. El operador sizeof() calcula en tiempo de compilación el **tamaño exacto en bytes** en la computadora actual.

tamanios.c
printf("Tamaño de int: %zu bytes\n", sizeof(int)); // Típicamente 4 printf("Tamaño de float: %zu bytes\n", sizeof(float)); // Típicamente 4 printf("Tamaño de double: %zu bytes\n", sizeof(double)); // Típicamente 8 printf("Tamaño de char: %zu bytes\n", sizeof(char)); // Siempre 1

03 La Función malloc() (Memory Allocation)

Pedir Memoria al Heap

Pertenece a la biblioteca <stdlib.h>. Le solicita al sistema operativo un bloque contiguo de memoria en el Heap de la cantidad de bytes que le pidas.

int *ptr = (int *)malloc(sizeof(int));
1
sizeof(int) ➔ Calcula cuántos bytes se necesitan (4 bytes).
2
malloc(...) ➔ Busca un bloque libre de 4 bytes en el Heap y devuelve un puntero genérico (void *) a su primer byte.
3
(int *) ➔ Convierte (castea) el puntero genérico a un puntero a entero para asignarlo a int *ptr.

04 La Regla de Oro: Chequear contra NULL

La RAM de la computadora no es infinita

Si el sistema operativo se queda sin memoria o no puede concederte el bloque solicitado, malloc() **devuelve NULL**.

❌ Código Suicida (Sin validar)
int *ptr = malloc(sizeof(int));
*ptr = 42; // Si falló malloc, ptr es NULL ➔ CRASH!
✅ Código Blindado y Seguro
int *ptr = (int *)malloc(sizeof(int));
if (ptr == NULL) {
  printf("Error: Sin memoria\n");
  return 1; // Terminamos seguro
}
*ptr = 42; // 100% seguro

05 Liberación con free()

Devolver lo que no es tuyo

A diferencia de las variables del Stack (que mueren solas), la memoria del Heap **queda ocupada para siempre** hasta que tu programa finalice o la liberes explícitamente con free(ptr);.

liberacion_correcta.c
// 1. Liberamos la memoria en el Heap: free(ptr); // 2. Buena práctica profesional inmediata: ptr = NULL;

💡 ¿Por qué poner ptr = NULL?: Porque después de free, la variable ptr sigue teniendo anotada la dirección vieja en el Heap (puntero colgante / dangling pointer). Poniendo ptr = NULL; neutralizamos el puntero para no usarlo por error.

06 ¿Qué es una Fuga de Memoria (Memory Leak)?

La Pesadilla de los Servidores

Una **fuga de memoria (*memory leak*)** ocurre cuando reservás memoria con malloc() y luego perdés el puntero que la apuntaba **sin haber llamado a free()**.

fuga_ejemplo.c
void funcionConFuga(void) { int *p = (int *)malloc(1000000 * sizeof(int)); // 4 MB pedidos // Hacemos cosas... // ¡FALTA free(p)! Al salir de la función, 'p' se destruye en el Stack, // pero los 4 MB en el Heap quedan flotando e inaccesibles para siempre. }

⚠️ Si esta función se ejecuta 1.000 veces (ej. cada vez que un usuario hace clic), el programa consumirá 4 GB de RAM hasta que el sistema operativo lo cierre forzosamente.

07 Programa Completo: El Ciclo de Vida Perfecto

ciclo_dinamico.c Estándar Seguro
#include <stdio.h> #include <stdlib.h> int main(void) { // 1. Reserva en el Heap int *edad = (int *)malloc(sizeof(int)); // 2. Validación obligatoria if (edad == NULL) { printf("Error: No se pudo asignar memoria.\n"); return 1; } // 3. Uso mediante desreferenciación (*) *edad = 17; printf("La edad guardada en el Heap es: %d\n", *edad); // 4. Liberación limpia free(edad); edad = NULL; return 0; }

08 Resumen de la Unidad y Checklist

Reglas de Oro

  • sizeof(tipo): Calcula bytes exactos portables.
  • malloc(bytes): Pide memoria contigua en el Heap.
  • Siempre verificar: if (ptr == NULL) antes de usar.
  • free(ptr): Devuelve la memoria al sistema.
  • Neutralizar: ptr = NULL; tras el free.
  • Memory Leak: Olvidar el free y perder el puntero.
