Recorridos y Búsquedas en Vectores

El poder de los bucles sobre arreglos: carga interactiva, acumuladores, máximos y el algoritmo de búsqueda lineal

Patrón for (int i = 0; i < N; i++) Suma y Promedio Máximo y Mínimo Búsqueda Lineal

💡 Guía de navegación: Usá la barra espaciadora o las flechas del teclado (→ / ←) para avanzar diapositiva por diapositiva.

01 Objetivos de Aprendizaje

La unión mágica: Vectores + Bucles

En la unidad anterior vimos que acceder a mano a cada casillero (notas[0], notas[1], ...) sigue siendo tedioso.

El verdadero poder de la informática surge al usar la **variable contadora de un bucle for como el índice entre corchetes [i]**. Con solo 3 líneas de código podemos procesar vectores de 10, 1.000 o 1.000.000 de elementos.

Lo que vas a dominar hoy

  • El **patrón universal de recorrido** con for.
  • Cargar datos desde el teclado con scanf en un vector.
  • Calcular la suma acumulada y el promedio con decimales.
  • Encontrar el **máximo** y el **mínimo** sin caer en la trampa del cero.
  • Implementar el algoritmo de **Búsqueda Lineal** paso a paso.

02 El Patrón Universal de Recorrido

patron_recorrido.c El Molde Sagrado
#define TAM 5 int numeros[TAM] = {10, 20, 30, 40, 50}; for (int i = 0; i < TAM; i++) { printf("En la posición [%d] está el valor: %d\n", i, numeros[i]); }
1
int i = 0; ➔ El bucle inicia en 0, coincidiendo con el primer casillero del vector.
2
i < TAM; ➔ Usamos < estricto (menor a 5), por lo que las vueltas serán exactamente 0, 1, 2, 3, 4. ¡Nunca se desborda!
3
numeros[i] ➔ En cada ciclo, i se reemplaza por su valor actual, accediendo a cada celda de forma automática.

03 Carga Interactiva con scanf()

¿Cómo pedirle al usuario que llene un vector desde la terminal?

carga_vector.c scanf + vector
int valores[4]; for (int i = 0; i < 4; i++) { printf("Ingresa el valor para el casillero [%d]: ", i); scanf("%d", &valores[i]); // ¡Notar el operador &! }

¿Por qué se pone &valores[i]?

Porque valores[i] es un número entero común (el contenido de la celda i). Como aprendimos en el 1er cuatrimestre, scanf necesita la **dirección de memoria de esa celda concreta**, por lo que anteponemos el ampersand &.

04 Acumuladores: Suma y Promedio

promedio_vector.c Acumulador
int notas[4] = {7, 9, 8, 10}; int suma = 0; // ¡Inicializar siempre en 0! for (int i = 0; i < 4; i++) { suma += notas[i]; } // Casteo a float para no perder decimales: float promedio = (float)suma / 4.0f; printf("Suma total: %d | Promedio: %.2f\n", suma, promedio);

💡 Traza mental: suma arranca en 0. Vuelta 0: 0 + 7 = 7. Vuelta 1: 7 + 9 = 16. Vuelta 2: 16 + 8 = 24. Vuelta 3: 24 + 10 = 34. Promedio: 34 / 4 = 8.50.

05 Encontrar el Máximo (¡Evitá la Trampa del Cero!)

❌ La Trampa: int maximo = 0;

Si el vector almacena temperaturas de invierno bajo cero: {-5, -2, -8, -12}, tu programa dirá que el máximo es 0... ¡un número que ni siquiera existía en el vector!

✅ La Solución: Asumir el primero

Inicializá con el primer elemento real del vector: int maximo = vector[0];. Y luego compará a partir del índice 1. ¡Funciona para positivos, negativos y ceros!

int maximo = notas[0]; // Asumimos que el primero es el campeón for (int i = 1; i < 4; i++) { if (notas[i] > maximo) { maximo = notas[i]; // Encontramos a uno más grande } }

06 Búsqueda Lineal (Secuencial)

¿Cómo saber si un valor buscado existe en el vector y en qué posición está?

[0]
14
[1]
9
[2]
42
[3]
18

Estrategia: Preguntamos celda por celda: "¿Sos vos el 42?". Si lo encontramos, guardamos la posición y cortamos con break. Si el bucle termina y nadie respondió, el elemento no existe en el arreglo.

07 Implementación de Búsqueda Lineal

busqueda_lineal.c Algoritmo Completo
int datos[5] = {14, 9, 42, 18, 7}; int buscado = 42; int posicionEncontrada = -1; // -1 significa "no encontrado aún" for (int i = 0; i < 5; i++) { if (datos[i] == buscado) { posicionEncontrada = i; // Guardamos la posición break; // Salimos del bucle anticipadamente } } if (posicionEncontrada != -1) { printf("¡Elemento encontrado en el índice [%d]!\n", posicionEncontrada); } else { printf("El elemento %d no está en el vector.\n", buscado); }

08 Resumen de la Unidad y Checklist

Herramientas del Día

  • for (int i = 0; i < N; i++): El recorrido canónico.
  • &vector[i]: Para leer valores con scanf.
  • Acumulador: suma += vector[i] (iniciar en 0).
  • Máximo/Mínimo: Iniciar con vector[0].
  • Búsqueda Lineal: Centinela pos = -1 y break al hallar.

Checklist de Autoevaluación

✓ ¿Sé por qué el bucle de recorrido usa i < N y no i <= N?
✓ ¿Por qué inicializar el valor máximo en 0 puede provocar un bug?
✓ ¿Qué función cumple break dentro de una búsqueda lineal?
✓ ¿Por qué usamos -1 como valor inicial de posición no encontrada?
