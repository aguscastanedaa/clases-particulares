Funciones con Retorno y Arreglos como Parámetros

De la ejecución secuencial a la ingeniería modular: cómo calcular y devolver valores con return y procesar colecciones completas en funciones.

Funciones con retorno Palabra clave return Vectores como parámetros Envío explícito del tamaño

01 Objetivos Pedagógicos

¿Por qué este tema es el punto de partida?

En el primer cuatrimestre vimos funciones sencillas y procedimientos void. En esta nueva etapa necesitamos que las funciones se comporten como módulos matemáticos y transformadores de datos capaces de dialogar con arreglos, strings y estructuras complejas.

Comprender el retorno y el paso de vectores es el puente obligatorio antes de abordar los strings y los punteros en C.

Lo que vas a dominar en esta clase

  • Comprender la analogía de la función como máquina procesadora.
  • Diferenciar con total precisión entre return y printf.
  • Construir funciones que devuelven enteros (int) y reales (float).
  • Aprender a pasar un arreglo a una función con la sintaxis tipo vector[].
  • Entender por qué C exige enviar el tamaño de forma obligatoria.
  • Evitar la confusión clásica entre enviar numeros vs numeros[0].

02 ¿Qué es una Función con Retorno?

Una función es un bloque de código reusable que realiza una tarea específica.

Podemos imaginar una función como una máquina procesadora:

Entrada (Parámetro)
➔
Proceso interno
➔
Resultado (return)
doble.c C99
int doble(int numero) { return numero * 2; } int main(void) { int valor = doble(5); printf("Resultado: %d\n", valor); // 10 return 0; }

Paso a paso de la llamada

1
En main(), llamamos a doble(5). El argumento 5 viaja a la función.
2
El parámetro numero recibe una copia con el valor 5.
3
La expresión numero * 2 evalúa a 10.
4
return 10; devuelve ese valor al punto exacto donde se invocó, asignándolo a valor.

03 Diferencia Crucial: return vs printf

Uno de los errores más comunes de los principiantes es confundir mostrar un valor con devolverlo.

❌ Imprimir en pantalla (Efecto visual)
void sumarMal(int a, int b) { printf("%d\n", a + b); }

printf dibuja caracteres de texto en la consola de la terminal. No le entrega ningún dato al resto del programa. El resultado no se puede guardar, comparar ni reutilizar.

✅ Devolver un valor (Dato útil en RAM)
int sumarBien(int a, int b) { return a + b; }

return entrega el dato al programa que llamó. Ahora podemos hacer: int total = sumarBien(5, 3) * 10;. ¡El valor devuelto es un número real listo para procesar!

💡 Regla mnemotécnica: Si el programa necesita hacer una cuenta y seguir operando con el resultado en otra parte, la función DEBE devolver un valor con return. Si solo es un mensaje o informe final, puede ser void.

04 Ejemplo con Flotantes: calcularDescuento

Aplicación práctica con tipos de coma flotante (float) extraída del apunte teórico.

Fórmula Financiera

Para calcular el precio con descuento:

precioFinal = precio - (precio * desc / 100)

Si el precio es $1000 y el descuento es 20%:
Descuento = $200.
Precio Final = $800.

descuento.c float return
#include <stdio.h> float calcularDescuento(float precio, float descuento) { return precio - (precio * descuento / 100.0f); } int main(void) { float precioFinal = calcularDescuento(1000.0f, 20.0f); printf("Precio final a abonar: $%.2f\n", precioFinal); // Imprime: Precio final a abonar: $800.00 return 0; }

05 Arreglos / Vectores como Parámetros

Cómo delegar el procesamiento de colecciones de datos a una función.

mostrar_vector.c Arreglos
void mostrarVector(int vector[], int tamano) { for(int i = 0; i < tamano; i++) { printf("Elemento en [%d]: %d\n", i, vector[i]); } }

1. Parámetro vector[]

Los corchetes vacíos [] indican que la función recibirá un arreglo de enteros. No especificamos tamaño dentro de los corchetes en el parámetro.

2. Parámetro tamano

Cantidad exacta de casilleros válidos que la función debe procesar. Es indispensable para que el bucle for sepa cuándo detenerse.

06 ¿Por qué C Exige Enviar el Tamaño?

El Arreglo no guarda su longitud en memoria

En lenguajes de alto nivel como Python, Java o JavaScript, un arreglo es un objeto que conoce su longitud (arr.length).

En lenguaje C puro, un arreglo es simplemente una secuencia de bytes contiguos en la memoria RAM. El arreglo no almacena ninguna etiqueta con cuántos elementos tiene.

El Recorrido Controlado

Si tenemos:
int numeros[5] = {10, 20, 30, 40, 50};

Al llamar a mostrarVector(numeros, 5);, la función sabe exactamente que debe recorrer:

posición 0 ➔ posición 1 ➔ posición 2 ➔ posición 3 ➔ posición 4

⚠️ Sin el tamaño, el bucle continuaría leyendo memoria prohibida fuera del arreglo (Segmentation Fault).

07 Procesar y Sumar Elementos de un Vector

Función con acumulador que recibe un arreglo y devuelve el total con return.

sumar_vector.c Acumulador
#include <stdio.h> int sumarVector(int vector[], int tamano) { int suma = 0; for(int i = 0; i < tamano; i++) { suma += vector[i]; } return suma; } int main(void) { int numeros[4] = {10, 20, 30, 40}; int resultado = sumarVector(numeros, 4); printf("La suma total es: %d\n", resultado); // 100 return 0; }

08 Regla Fundamental: numeros vs numeros[0]

¡Atención a este detalle sintáctico!

Cuando pasamos un arreglo a una función, solo escribimos su nombre sin corchetes:

✅ Forma Correcta
sumarVector(numeros, 4);

El identificador numeros representa al arreglo completo (en realidad, la dirección de inicio en memoria). La función recibe el acceso a toda la colección.

❌ Error Común
sumarVector(numeros[0], 4);

numeros[0] es un único elemento entero (en nuestro ejemplo, el número 10), ¡no el vector! Provoca un error de compilación por incompatibilidad de tipos (esperaba int[] y recibió int).

09 Ejercicio Práctico: Cálculo de Promedio

Escribí una función que reciba un vector de calificaciones enteras y devuelva su promedio como float.

🔍 Ver solución explicada paso a paso
float calcularPromedio(int notas[], int cantidad) { if (cantidad <= 0) return 0.0f; // Protección defensiva int acumulador = 0; for (int i = 0; i < cantidad; i++) { acumulador += notas[i]; } // Casteo explícito a float para evitar división entera return (float)acumulador / cantidad; }

Notá el casteo (float)acumulador: si dividimos dos enteros en C, el resultado trunca los decimales. Al castear uno a float, C realiza una división real con precisión decimal exacta.

10 Resumen y Autoevaluación

Puntos Clave del Módulo

  • return finaliza la ejecución de la función y devuelve un dato a quien la llamó.
  • Los tipos simples se pasan por valor (copia independiente).
  • Para recibir un arreglo usamos tipo nombre[].
  • Siempre debemos enviar la variable tamano junto al arreglo.
  • Para enviar el arreglo, pasamos su nombre simple: v y no v[0].
