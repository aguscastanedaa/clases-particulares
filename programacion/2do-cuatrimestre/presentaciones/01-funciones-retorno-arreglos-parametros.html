  • Crear y recorrer vectores (arreglos) desde la posición 0 hasta tamaño - 1.

02 ¿Qué Problema Resuelven las Funciones con Retorno?

Imaginá que en distintas partes de un programa de ventas necesitás calcular precios con descuento o sumar totales. Si escribís toda la cuenta suelta dentro de main():

❌ Todo mezclado en main()
  • Repetís la misma fórmula una y otra vez.
  • Si cambia la fórmula, tenés que corregirla en 10 lugares distintos.
  • El código principal se vuelve largo y difícil de leer.
✅ Con Funciones con Retorno
  • Escribís la lógica una sola vez dentro de una función con nombre claro.
  • Le enviás los datos de entrada (parámetros).
  • La función calcula y te devuelve el resultado listo para guardar o usar.

03 1. Funciones con Retorno: La Máquina Procesadora

Definición del Apunte

Una función es un bloque de código que realiza una tarea específica. Podemos pensar una función como una máquina que recibe una entrada, realiza un proceso y entrega un resultado.

Entrada
5
➔
Proceso
función doble (× 2)
➔
Resultado
10

💡 Analogía cotidiana: Es como una licuadora o una calculadora: vos ponés los ingredientes (entrada), la máquina trabaja por dentro (proceso) y te entrega el vaso servido (resultado).

04 Primer Ejemplo del Apunte: doble

Veamos cómo se escribe en lenguaje C la máquina que calcula el doble de un número entero:

funcion_doble.c Apunte pág. 2
int doble(int numero) { return numero * 2; }

¿Qué entra a la máquina?

Entra un número entero guardado en el parámetro int numero. Si la llamamos con 5, entonces numero vale 5.

¿Qué sale de la máquina?

Calcula numero * 2 (que da 10) y la palabra clave return expulsa ese 10 hacia afuera como resultado final.

05 Desglose Pieza por Pieza de la Sintaxis

int doble(int numero) { return numero * 2; }
1
Tipo de retorno (int adelante del nombre): Promete qué tipo de dato va a devolver la función. Como devuelve un entero, escribimos int.
2
Nombre de la función (doble): Identificador con el que vamos a invocar a la función desde main().
3
Parámetro de entrada ((int numero)): Variable local que recibe el dato enviado desde afuera al momento de llamarla.
4
Sentencia return numero * 2;: Evalúa la expresión a su derecha y entrega ese valor como respuesta de la función.

06 ¿Qué Significa return? Ejemplo sumar

Definición del Apunte: return permite que una función devuelva un resultado al lugar donde fue llamada.

sumar.c Apunte pág. 2
int sumar(int a, int b) { return a + b; } // En main hacemos: int resultado = sumar(5, 3);

¿Qué ocurre paso a paso?

Cuando ejecutamos int resultado = sumar(5, 3);:

1) a recibe 5, b recibe 3
2) La función hace: 5 + 3 ➔ 8
3) Y devuelve: 8
4) Entonces: resultado = 8;

07 Diferencia Crucial: Funciones void vs Con Retorno

No es lo mismo mostrar un dato en pantalla con printf que devolver un resultado con return:

📢 Función void (Solo muestra)
void mostrarSuma(int a, int b) { printf("%d\n", a + b); }

Imprime el número en la consola, pero no devuelve nada. No podés hacer int x = mostrarSuma(5, 3); ni usar ese valor en otra cuenta.

⚙️ Función con Retorno (Devuelve el dato)
int sumar(int a, int b) { return a + b; }

Entrega el número 8 a main(). Ahí vos decidís si querés guardarlo en una variable, multiplicarlo por 2 o imprimirlo con printf.

08 Modelo Mental en Memoria RAM: El Viaje de los Datos

¿Qué pasa en la memoria RAM cuando main() ejecuta int resultado = sumar(5, 3);?

1. LLAMADA EN MAIN
sumar(5, 3)

Los valores 5 y 3 se copian en los parámetros de la función.

2. VARIABLES DE SUMAR
a = [ 5 ]   b = [ 3 ]

sumar calcula a + b (8) y ejecuta return 8;.

3. REGRESO A MAIN
resultado = [ 8 ]

La llamada sumar(5, 3) es reemplazada por el valor devuelto 8.

📌 Regla clave: Pensá que en el momento en que la función ejecuta return 8;, toda la expresión sumar(5, 3) se transforma mágicamente en un 8.

09 Ejemplo Nivel 1: Programa Completo con doble y sumar

nivel1_retorno.c Nivel 1
#include <stdio.h> int doble(int numero) { return numero * 2; } int sumar(int a, int b) { return a + b; } int main() { int r1 = doble(5); int resultado = sumar(5, 3); printf("El doble de 5 es: %d\n", r1); printf("La suma de 5 y 3 es: %d\n", resultado); return 0; }
Terminal Salida
$ ./nivel1_retorno El doble de 5 es: 10 La suma de 5 y 3 es: 8

Observá dónde se definen las funciones: arriba de main(), para que el compilador ya las conozca cuando las llamamos.

10 Tercer Ejemplo del Apunte: calcularDescuento

Las funciones no solo devuelven enteros (int). Si trabajamos con dinero o porcentajes, podemos recibir y devolver números con decimales (float):

descuento.c Apunte págs. 2–3
float calcularDescuento(float precio, float descuento) { return precio - (precio * descuento / 100); }

¿Cómo se usa en el programa?

float precioFinal = calcularDescuento(1000, 20);

Cálculo interno paso a paso

• precio = 1000, descuento = 20
• Descuento en pesos: 1000 * 20 / 100 = 200
• Resta final: 1000 - 200 = 800
• Resultado devuelto: 800

11 Ejemplo Nivel 2: Seguimiento de calcularDescuento

tienda_descuentos.c Nivel 2
#include <stdio.h> float calcularDescuento(float precio, float descuento) { return precio - (precio * descuento / 100); } int main() { float precioFinal = calcularDescuento(1000, 20); float oferta = calcularDescuento(500, 10); printf("Precio 1: %.0f\n", precioFinal); printf("Precio 2: %.0f\n", oferta); return 0; }
Llamada precio descuento Cálculo Retorno
1° llamada 1000 20 1000 - 200 800
2° llamada 500 10 500 - 50 450
Terminal Salida
$ ./tienda_descuentos Precio 1: 800 Precio 2: 450

12 Propiedad Clave: return Corta la Función

Además de devolver el resultado, ejecutar return finaliza inmediatamente la función y regresa el control a quien la llamó.

❌ Código inalcanzable después de return
int doble(int numero) { return numero * 2; printf("Terminé\n"); // ¡NUNCA SE EJECUTA! }
✅ return como último paso del camino
int doble(int numero) { int res = numero * 2; return res; // Cierra la función y devuelve res }

💡 Esta propiedad es muy útil cuando buscamos algo en un vector o validamos una condición: apenas encontramos la respuesta, podemos hacer return y salir sin seguir dando vueltas.

13 2. Arreglos / Vectores como Parámetros

Definición del Apunte (pág. 3)

Una función no solo puede recibir números sueltos: también puede recibir un vector/arreglo como parámetro para recorrerlo, mostrarlo o hacer cálculos sobre todos sus elementos.

mostrar_vector.c Apunte pág. 3
void mostrarVector(int vector[], int tamano) { for(int i = 0; i < tamano; i++) { printf("%d\n", vector[i]); } }

Mirá con atención los paréntesis de la función: recibe dos parámetros trabajando en equipo.

14 Desglose de void mostrarVector(int vector[], int tamano)

void mostrarVector(int vector[], int tamano)

1° Parámetro: int vector[]

Es el arreglo que queremos recorrer. Los corchetes vacíos [] le avisan al compilador de C: "Acá no viene un solo entero, viene un vector de enteros de cualquier longitud".

2° Parámetro: int tamano

Es la cantidad de elementos que tiene ese arreglo. Nos sirve como límite del ciclo: for(int i = 0; i < tamano; i++).

💡 Gracias a que los corchetes [] están vacíos y el tamaño entra como parámetro, la misma función mostrarVector sirve para mostrar un vector de 3, de 5 o de 100 números.

15 ¿Por Qué Tenemos que Enviar También el Tamaño?

Pregunta del Apunte (pág. 3)

¿Por qué tenemos que enviar también el tamaño?
Porque C necesita saber hasta dónde recorrer el arreglo. Cuando un vector entra a una función, no trae adherida una etiqueta con su cantidad de casilleros.

int numeros[5] = {10, 20, 30, 40, 50}; mostrarVector(numeros, 5);
posición 0
10
posición 1
20
posición 2
30
posición 3
40
posición 4
50

Al recibir tamano = 5, la función sabe que debe recorrer: posición 0, posición 1, posición 2, posición 3 y posición 4.

16 Ejemplo Completo en C: mostrarVector en Acción

demo_mostrar_vector.c Apunte pág. 3
#include <stdio.h> void mostrarVector(int vector[], int tamano) { for(int i = 0; i < tamano; i++) { printf("%d\n", vector[i]); } } int main() { int numeros[5] = {10, 20, 30, 40, 50}; mostrarVector(numeros, 5); return 0; }
Terminal Salida
$ ./demo_mostrar 10 20 30 40 50

Aunque en main el arreglo se llama numeros, adentro de la función lo usamos con el nombre de su parámetro: vector[i].

17 Ejemplo del Apunte: Sumar Elementos (sumarVector)

Ahora unamos los dos grandes temas de hoy: una función que recibe un vector como parámetro y devuelve un resultado con return.

sumar_vector.c Apunte págs. 3–4
int sumarVector(int vector[], int tamano) { int suma = 0; for(int i = 0; i < tamano; i++) { suma += vector[i]; } return suma; }
1
Inicializamos el acumulador int suma = 0; antes de empezar a recorrer.
2
En cada vuelta del for, sumamos el elemento actual: suma += vector[i];.
3
Al terminar el ciclo, devolvemos el total acumulado con return suma;.

19 ⚠️ Algo MUY Importante: numeros vs numeros[0]

Advertencia Destacada del Apunte (pág. 4)

Cuando pasamos un arreglo a una función, escribimos solamente el nombre del arreglo sin corchetes.

✅ Forma Correcta
sumarVector(numeros, 4);

numeros (sin corchetes) representa todo el arreglo que estamos enviando a la función.

❌ Forma Incorrecta
sumarVector(numeros[0], 4);

numeros[0] es un solo elemento (el número entero 10), ¡no el arreglo completo!

21 Regla Mnemotécnica: Los 3 Lugares de los Corchetes

Para no confundirte nunca con los corchetes al trabajar con vectores y funciones, recordá esta tabla:

Momento Cómo se escribe ¿Lleva corchetes?
1. Al crear el vector en main int numeros[4] = {10, 20, 30, 40}; ✅ Sí, con el tamaño: [4]
2. En el encabezado de la función int sumarVector(int vector[], int tamano) ✅ Sí, vacíos: vector[]
3. Al llamar a la función sumarVector(numeros, 4); ❌ NO lleva corchetes (solo el nombre)
4. Al usar un casillero adentro del for suma += vector[i]; ✅ Sí, con el índice: [i]

22 Ejemplo Nivel 3: Contar Números Pares en una Función

Combinemos lo aprendido con condicionales: creemos una función que reciba un vector y su tamaño, y devuelva cuántos números pares contiene.

contar_pares.c Nivel 3
int contarPares(int vector[], int tamano) { int contador = 0; for(int i = 0; i < tamano; i++) { if(vector[i] % 2 == 0) { contador++; } } return contador; }

🔍 Patrón de Contador en Función: 1) int contador = 0; afuera del ciclo, 2) if(condicion) contador++; adentro del for, y 3) return contador; al final.

24 Ejemplo Nivel 4: Pensar buscarMaximo y buscarMinimo

¿Cómo diseñamos una función que reciba un vector y nos devuelva el mayor (o el menor) de sus elementos? Construyamos el razonamiento paso a paso:

1
Punto de partida seguro: Asumimos provisoriamente que el primer elemento es el mayor: int maximo = vector[0]; (¡nunca inicialices en 0 por si todos son negativos!).
2
Recorrido comparativo: Recorremos desde i = 1 hasta i < tamano comparando cada casillero contra nuestro récord actual.
3
Actualización: Si encontramos un vector[i] > maximo, actualizamos maximo = vector[i];.
4
Retorno: Al terminar todo el ciclo, devolvemos el campeón con return maximo;.

25 Implementación Nivel 4: buscarMaximo y buscarMinimo

max_min_funciones.c Nivel 4
#include <stdio.h> int buscarMaximo(int vector[], int tamano) { int max = vector[0]; for(int i = 1; i < tamano; i++) { if(vector[i] > max) { max = vector[i]; } } return max; } int buscarMinimo(int vector[], int tamano) { int min = vector[0]; for(int i = 1; i < tamano; i++) { if(vector[i] < min) { min = vector[i]; } } return min; } int main() { int notas[5] = {7, 10, 4, 9, 8}; printf("Mayor: %d\n", buscarMaximo(notas, 5)); printf("Menor: %d\n", buscarMinimo(notas, 5)); return 0; }
Terminal Salida
$ ./max_min_funciones Mayor: 10 Menor: 4

Mirá qué limpio queda main(): incluso podemos llamar a buscarMaximo(notas, 5) directamente dentro del printf porque la función devuelve un int.

26 El Poder Modular: Una Función que Usa a Otra Función

Si ya tenemos escrita sumarVector, ¡no hace falta volver a programar el ciclo for para calcular el promedio! Podemos llamarla desde promedioVector:

promedio_modular.c Reutilización
#include <stdio.h> int sumarVector(int vector[], int tamano) { int suma = 0; for(int i = 0; i < tamano; i++) { suma += vector[i]; } return suma; } float promedioVector(int vector[], int tamano) { int total = sumarVector(vector, tamano); return (float)total / tamano; } int main() { int notas[4] = {7, 8, 9, 10}; printf("Promedio: %.2f\n", promedioVector(notas, 4)); // 8.50 return 0; }

27 ¿Qué Pasa si una Función Modifica vector[i]?

A diferencia de una variable suelta, cuando pasamos un arreglo a una función, la función trabaja sobre los casilleros reales del arreglo.

duplicar_elementos.c C99
#include <stdio.h> void duplicarVector(int vector[], int tamano) { for(int i = 0; i < tamano; i++) { vector[i] = vector[i] * 2; } } int main() { int v[3] = {5, 10, 15}; duplicarVector(v, 3); printf("%d %d %d\n", v[0], v[1], v[2]); return 0; }
Terminal Salida
$ ./duplicar 10 20 30

💡 Esto nos permite crear funciones como cargarVector o ordenarVector que actualizan directamente el vector de main (veremos el porqué profundo en la unidad de Punteros).

28 Errores Frecuentes de Principiantes (Parte 1)

Error clásico: llamar a una función con retorno pero no guardar ni usar el valor que devuelve:

❌ Llamada "al aire" (Se pierde el resultado)
int main() { sumar(5, 3); // Devuelve 8, pero nadie lo atrapa return 0; }

La función hace la suma y devuelve 8, pero como no se asigna a ninguna variable ni se pasa a printf, el valor se descarta.

✅ Guardar el retorno en una variable
int main() { int resultado = sumar(5, 3); printf("Suma: %d\n", resultado); return 0; }

Atrapamos el valor devuelto dentro de int resultado y luego lo mostramos o seguimos operando con él.

29 Errores Frecuentes de Principiantes (Parte 2)

Error muy común en exámenes: poner el return adentro del ciclo for en un acumulador:

❌ return adentro del for (Corta en i = 0)
int sumarVector(int vector[], int tamano) { int suma = 0; for(int i = 0; i < tamano; i++) { suma += vector[i]; return suma; // ¡ERROR! Sale en la 1° vuelta } }

Suma únicamente vector[0] e inmediatamente termina la función sin recorrer el resto del vector.

✅ return afuera, después de cerrar el for
int sumarVector(int vector[], int tamano) { int suma = 0; for(int i = 0; i < tamano; i++) { suma += vector[i]; } return suma; // Recién cuando sumó TODOS }

El ciclo termina de dar todas las vueltas de 0 a tamano - 1 y recién ahí devuelve suma.

30 Errores Frecuentes (Parte 3): Cómo Pasar el Vector

❌ Pasar numeros[0]
sumarVector(numeros[0], 4);

Envía solo el primer número entero en vez del arreglo.

❌ Poner corchetes vacíos
sumarVector(numeros[], 4);

Error de sintaxis: [] solo va en la declaración, nunca al llamar.

✅ Solo el nombre
sumarVector(numeros, 4);

Envía el arreglo completo y la cantidad de elementos.

📌 Recordá siempre la regla del apunte: numeros[0] es un solo elemento; en cambio, numeros representa el arreglo que estamos enviando.

31 Buenas Prácticas de Programación con Funciones

Diseño limpio de funciones

  • Nombres con verbos claros: calcularDescuento, mostrarVector, sumarVector, contarPares.
  • Una sola responsabilidad: Si una función se llama sumarVector, que solo calcule y devuelva la suma (sin meter printf ni scanf adentro).
  • Coherencia de tipos: Si el encabezado dice float, asegurate de que la variable devuelta o la división conserve los decimales.

Trabajo seguro con vectores

  • Siempre recibir int tamano: Usá siempre i < tamano en el for en lugar de clavar un número fijo como i < 5.
  • Inicializar acumuladores en 0: Siempre escribí int suma = 0; al comenzar la función.
  • Inicializar máximo/mínimo en vector[0]: Evitá inicializar en 0 o en números arbitrarios.

33 Ejercicio Integrador Tipo Examen (3)

Ejercicio 3: Sumar únicamente los elementos positivos de un vector

Creá una función int sumarPositivos(int vector[], int tamano) que recorra el arreglo y sume solamente los números estrictamente mayores a 0. En main(), probala con el arreglo {-5, 10, -2, 30, 15} y mostrá el resultado devuelto.

#include <stdio.h> int sumarPositivos(int vector[], int tamano) { int suma = 0; for(int i = 0; i < tamano; i++) { if(vector[i] > 0) { suma += vector[i]; } } return suma; } int main() { int movimientos[5] = {-5, 10, -2, 30, 15}; int total = sumarPositivos(movimientos, 5); printf("Suma de positivos: %d\n", total); // Imprime 55 (10 + 30 + 15) return 0; }

34 Resumen de la Unidad 01 y Checklist

Conceptos Clave del Apunte

  • Máquina de funciones: Entrada → proceso → resultado.
  • Palabra clave return: Devuelve el valor calculado al lugar donde se llamó a la función.
  • Vector como parámetro: void mostrarVector(int vector[], int tamano).
  • Envío del tamaño: Obligatorio para que C sepa hasta qué posición recorrer.
  • Llamada correcta: Se escribe sumarVector(numeros, 4) y nunca numeros[0].
