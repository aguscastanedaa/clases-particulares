Diagonales de una Matriz

Geometría y relaciones algebraicas de índices: diagonal principal (i == j), secundaria (i + j == N - 1) y algoritmos O(N)

Matrices Cuadradas (NxN) Diagonal Principal [i][i] Secundaria [i][N-1-i] Optimización a 1 Solo Bucle

💡 Guía de navegación: Usá la barra espaciadora o las flechas del teclado (→ / ←) para avanzar diapositiva por diapositiva.

01 Objetivos de Aprendizaje

Condición Previa Obligatoria

Las diagonales solo tienen sentido geométrico en **matrices cuadradas**, es decir, aquellas que tienen exactamente la misma cantidad de filas que de columnas ($N \times N$).

En álgebra lineal, gráficos por computadora (transformaciones 3D) y videojuegos, las operaciones con diagonales son el pan de cada día.

Lo que vas a dominar hoy

  • Identificar los elementos de la Diagonal Principal.
  • Comprender la regla matemática de la principal: i == j.
  • Identificar los elementos de la Diagonal Secundaria.
  • Descubrir la relación algebraica secundaria: i + j == N - 1.
  • Aprender a procesar diagonales con **un solo bucle eficiente**.
  • Conocer las zonas triangulares (superior e inferior).

03 La Diagonal Principal: i == j

Regla Matemática

Un elemento pertenece a la diagonal principal si y solo si su número de fila es **exactamente igual** a su número de columna: fila == columna.

En una matriz de $N=3$, los casilleros son: [0][0], [1][1] y [2][2].

❌ Forma Ineficiente (Doble bucle)
for (int i=0; i<N; i++) {
  for (int j=0; j<N; j++) {
    if (i == j) suma += m[i][j];
  }
}

Da $N^2$ vueltas y descarta casi todas.

✅ Forma Eficiente (1 Solo Bucle)
for (int i = 0; i < N; i++) {
  suma += m[i][i]; // ¡Directo!
}

Va directo al blanco en solo $N$ vueltas ($O(N)$).

04 La Diagonal Secundaria: i + j == N - 1

La Relación Inversa

A medida que bajamos una fila (i aumenta), la columna debe retroceder un paso (j disminuye). La suma de ambas coordenadas es siempre constante: i + j = N - 1.

Despejando j obtenemos la fórmula mágica: j = N - 1 - i.

Fila (i) Cálculo de j: (3 - 1 - i) Coordenada Resultante Valor en el gráfico
i = 0 j = 2 - 0 = 2 m[0][2] 3 (esquina superior derecha)
i = 1 j = 2 - 1 = 1 m[1][1] 5 (centro)
i = 2 j = 2 - 2 = 0 m[2][0] 7 (esquina inferior izquierda)

05 Código Profesional: Suma de Diagonales en O(N)

suma_diagonales.c Un Solo Bucle
#define N 3 int sumaPrincipal = 0; int sumaSecundaria = 0; for (int i = 0; i < N; i++) { sumaPrincipal += matriz[i][i]; // Diagonal Principal sumaSecundaria += matriz[i][N - 1 - i]; // Diagonal Secundaria } printf("Suma Diagonal Principal: %d\n", sumaPrincipal); printf("Suma Diagonal Secundaria: %d\n", sumaSecundaria);

⚡ ¡Máxima Eficiencia!: Calculamos ambas diagonales en simultáneo en una sola pasada de $N$ ciclos, sin necesidad de anidar bucles ni usar condicionales.

06 Zonas Triangulares de una Matriz

La diagonal principal divide a toda matriz cuadrada en dos mitades simétricas:

Triangular Superior: i < j

Son todos los elementos que están estrictamente **por encima** de la diagonal principal.

La columna es mayor que la fila (ej. [0][1], [0][2], [1][2]).

Triangular Inferior: i > j

Son todos los elementos que están estrictamente **por debajo** de la diagonal principal.

La fila es mayor que la columna (ej. [1][0], [2][0], [2][1]).

07 Resumen de la Unidad y Checklist

Fórmulas Clave

  • Requisito: La matriz debe ser cuadrada ($N \times N$).
  • Diagonal Principal: matriz[i][i] (cuando i == j).
  • Diagonal Secundaria: matriz[i][N - 1 - i] (cuando i + j == N - 1).
  • Eficiencia: Se resuelven con 1 solo bucle for en $O(N)$.
  • Triangulares: i < j (arriba) e i > j (abajo).
