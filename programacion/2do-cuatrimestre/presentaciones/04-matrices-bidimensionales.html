Matrices Bidimensionales

Pensando en dos dimensiones: tablas de filas y columnas, memoria contigua por filas y bucles anidados

Filas y Columnas [i][j] Row-Major Order en RAM Bucles Anidados (i, j) Sumas por Fila y Columna

💡 Guía de navegación: Usá la barra espaciadora o las flechas del teclado (→ / ←) para avanzar diapositiva por diapositiva.

01 Objetivos de Aprendizaje

De la línea al plano

Un vector es una estructura unidimensional (1D): como una línea recta de datos.

Una matriz es bidimensional (2D): tiene **filas y columnas**. Es el equivalente directo a una planilla de Excel, un tablero de ajedrez o tatetí, o la cuadrícula de píxeles de una imagen digital.

Lo que vas a dominar hoy

  • Comprender qué es una matriz y cómo declararla: [FILAS][COLUMNAS].
  • Aprender a orientarte con los dos índices: [fila][columna].
  • Entender cómo se organiza en la RAM (*Row-Major Order*).
  • Dominar el recorrido completo con **dos bucles for anidados**.
  • Imprimir matrices con formato tabular prolijo.
  • Calcular totales globales, sumas por filas y sumas por columnas.

02 Declaración y Doble Coordenada

Sintaxis en C:

tipo nombre[FILAS][COLUMNAS];

matriz_ejemplo.c
// Una matriz de 2 filas y 3 columnas: int tabla[2][3] = { {10, 20, 30}, // Fila 0 {40, 50, 60} // Fila 1 };

Acceso por Coordenadas

• tabla[0][0] es el valor 10.
• tabla[0][2] es el valor 30.
• tabla[1][1] es el valor 50.
• tabla[1][2] es el valor 60 (última celda).

¡Ambos índices empiezan siempre en 0!

04 La Matriz en la Memoria RAM Física

La Realidad del Hardware: La RAM no tiene 2D

Físicamente, la memoria RAM es una sola tira recta de celdas unidimensionales. ¿Cómo guarda C una tabla de dos dimensiones? Mediante el método **Row-Major Order** (orden por filas mayores):

1
Se guarda en RAM primero **toda la Fila 0**: tabla[0][0], tabla[0][1], tabla[0][2].
2
Inmediatamente después, pegadita, se guarda **toda la Fila 1**: tabla[1][0], tabla[1][1], tabla[1][2].

✓ Por esta razón, el compilador necesita saber obligatoriamente cuántas columnas hay, para calcular cuánto debe saltar en la RAM para pasar a la siguiente fila.

05 El Recorrido Canónico con Bucles Anidados

imprimir_matriz.c Doble for
#define FILAS 3 #define COLS 3 for (int i = 0; i < FILAS; i++) // Bucle exterior: maneja las filas { for (int j = 0; j < COLS; j++) // Bucle interior: maneja las columnas { printf("%4d", matriz[i][j]); // Imprime cada celda con ancho de 4 } printf("\n"); // ¡Salto de línea al terminar cada fila! }

💡 Cómo piensa la CPU: Con i = 0, el bucle j da todas sus vueltas (0, 1, 2) e imprime la fila 0 completa. Termina el bucle de j, se imprime el salto de línea \n, y i pasa a valer 1 para hacer lo mismo con la siguiente fila.

06 Suma Total de los Elementos

suma_matriz.c Acumulador 2D
int sumaTotal = 0; for (int i = 0; i < FILAS; i++) { for (int j = 0; j < COLS; j++) { sumaTotal += matriz[i][j]; } } float promedio = (float)sumaTotal / (FILAS * COLS); printf("Total: %d | Promedio general: %.2f\n", sumaTotal, promedio);

07 Procesamiento por Filas (Ej: Puntaje por Alumno)

Si cada fila representa un alumno y cada columna una materia:

suma_por_filas.c
for (int i = 0; i < FILAS; i++) { int sumaFila = 0; // ¡Se resetea a cero para cada nuevo alumno! for (int j = 0; j < COLS; j++) { sumaFila += notas[i][j]; } printf("Total del alumno [%d]: %d\n", i, sumaFila); }

⚠️ Detalle vital: La variable sumaFila = 0; debe ubicarse **adentro del bucle i**, para que al pasar al alumno siguiente su acumulador vuelva a arrancar desde cero.

08 Resumen de la Unidad y Checklist

Puntos Clave

  • Matriz: Arreglo 2D con filas y columnas ([i][j]).
  • Dimensiones: [0 a FILAS-1] y [0 a COLS-1].
  • Row-Major: Filas contiguas una tras otra en RAM.
  • Recorrido: Doble bucle anidado (i para filas, j para cols).
  • Impresión: Usar \n al terminar cada fila exterior.
