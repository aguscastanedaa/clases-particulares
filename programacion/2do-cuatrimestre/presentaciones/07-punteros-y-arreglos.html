Relación entre Punteros y Arreglos

La íntima conexión de C: cómo los nombres de vectores son direcciones, la aritmética de punteros p + 1 y la equivalencia *(p + i) == v[i].

v == &v[0] Aritmética de punteros p + 1 *(p + i) vs v[i] Diferencias y límites

💡 Guía de navegación: Usá la barra espaciadora o las flechas del teclado (→ / ←) para avanzar diapositiva por diapositiva.

01 Objetivos Pedagógicos

Desmitificar la equivalencia

Muchos cursos dicen erróneamente: "los arreglos y los punteros son exactamente lo mismo". Esto no es cierto y genera errores graves de memoria.

En esta unidad aprenderás la relación real: el nombre de un arreglo decae a la dirección de su primer elemento, permitiendo recorrer la colección mediante punteros y entender por qué las funciones pueden alterar vectores originales.

Lo que vas a dominar en esta clase

  • Comprender que numeros equivale a &numeros[0].
  • Asignar un arreglo a un puntero: int *p = numeros;.
  • Aprender cómo funciona la aritmética de punteros (p + 1).
  • Entender la desreferenciación indexada: *(p + i).
  • Comprobar por qué numeros[i] es en realidad azúcar sintáctico de *(numeros + i).
  • Identificar las diferencias reales entre arreglos y punteros.

02 El Nombre del Arreglo es una Dirección

En cualquier expresión en C, el nombre de un arreglo evalúa a la dirección de su primer elemento.

arreglo_direccion.c Direcciones
#include <stdio.h> int main(void) { int numeros[3] = {10, 20, 30}; printf("numeros: %p\n", numeros); printf("&numeros[0]: %p\n", &numeros[0]); return 0; }
Terminal de salida bash
numeros: 0x7ffe40a0 &numeros[0]: 0x7ffe40a0

🎯 Conclusión: Escribir numeros es exactamente lo mismo que escribir &numeros[0]. Ambas expresiones señalan al primer casillero en la memoria RAM.

03 Apuntar a un Arreglo con int *p

puntero_a_vector.c Asignación
int numeros[3] = {10, 20, 30}; // No hace falta el & porque numeros ya es una dirección: int *p = numeros; printf("%d\n", *p); // Imprime 10 printf("%d\n", *(p + 1)); // Imprime 20 printf("%d\n", *(p + 2)); // Imprime 30

04 Aritmética de Punteros: ¿Qué significa p + 1?

¡No suma 1 byte, suma el tamaño del tipo de dato!

Cuando hacés p + 1 sobre un puntero a entero (int *), el compilador sabe que un int ocupa 4 bytes. Por lo tanto, p + 1 avanza físicamente 4 bytes hacia adelante en la memoria para alcanzar el casillero siguiente.

p + 0

0x1000

Primer elemento numeros[0].

p + 1

0x1000 + (1 * 4) = 0x1004

Segundo elemento numeros[1].

p + 2

0x1000 + (2 * 4) = 0x1008

Tercer elemento numeros[2].

05 La Equivalencia: *(p + i) y v[i]

El operador corchete [] es en realidad una forma abreviada de desreferenciación con suma.

Notación de Arreglo (Corchetes) Notación de Punteros (Desreferenciación) Valor Obtenido
numeros[0] *p  o  *(p + 0) 10
numeros[1] *(p + 1) 20
numeros[2] *(p + 2) 30
numeros[i] *(p + i) Elemento en posición i

💡 Por qué las funciones pueden modificar arreglos: Cuando llamamos a funcion(numeros, 5), no se copia el vector; se pasa la dirección inicial 0x1000. Dentro de la función, escribir vector[i] = 99 modifica directamente la memoria RAM original.

06 Diferencias y Límites de la Equivalencia

Un Arreglo (int a[5])

  • Reserva un bloque contiguo fijo de memoria (ej. 20 bytes).
  • Su nombre a es una constante: NO se puede reasignar (a = otro; es ilegal).
  • sizeof(a) devuelve el tamaño total del arreglo en bytes (5 * 4 = 20).

Un Puntero (int *p)

  • Es una variable independiente que solo ocupa 4 u 8 bytes (tamaño de una dirección).
  • Es variable: puede apuntar a a, luego a b, o a NULL (p = q; es legal).
  • sizeof(p) devuelve 8 bytes (en 64 bits), sin importar a cuántos enteros apunte.

07 Resumen y Autoevaluación

Puntos Clave del Módulo

  • El nombre de un arreglo representa la dirección de su primer elemento (v == &v[0]).
  • p + 1 avanza en memoria un número de bytes igual a sizeof(tipo).
  • *(p + i) y v[i] son idénticos en resultado.
  • Los arreglos son constantes fijas; los punteros son variables móviles.

Checklist de Autoevaluación

✓ ¿Por qué int *p = numeros; no necesita el operador &?
✓ Si p vale 0x1000 y apunta a un int de 4 bytes, ¿cuánto vale p + 2? (0x1008).
✓ ¿Puedo reasignar el nombre de un arreglo con v = nuevo;? (No, da error).
