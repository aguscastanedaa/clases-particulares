01 Hoja de Ruta y Conexión con la Unidad 06

Lo que ya sabemos de Punteros y Vectores

  • Un vector almacena varios datos del mismo tipo en casillas numeradas desde 0.
  • El operador & obtiene la dirección de memoria de una variable.
  • Un puntero (int *p) guarda una dirección de memoria.
  • El operador * (desreferencia) accede al valor guardado en esa dirección.

Lo que vamos a descubrir hoy (Sección 25)

  • Por qué el nombre de un arreglo (numeros) representa la dirección de su primera casilla (&numeros[0]).
  • Cómo apuntar un puntero a un vector: int *p = numeros;.
  • Cómo funciona *p, *(p + 1) y *(p + 2) en la memoria RAM.
  • Por qué las funciones pueden modificar los elementos originales de un arreglo.

03 25. Punteros y Arreglos: Definición del Apunte

Definición Central (Página 26 del Apunte)

Los arreglos y los punteros están muy relacionados porque el nombre de un arreglo representa la dirección de su primer elemento. Por eso podemos usar punteros para recorrer y modificar arreglos, y podemos pasar arreglos a funciones para que trabajen sobre el arreglo original.

Esquema conceptual del apunte Sección 25
int numeros[3] = {10, 20, 30}; // Conceptualmente: // numeros // ↓ // [10][20][30] // ↑ // primera posición

En palabras sencillas

Cuando en C escribís el nombre del vector solo —por ejemplo, numeros sin corchetes—, el lenguaje lo traduce automáticamente como: "la dirección de memoria donde empieza la casilla 0".

04 Analogía Cotidiana: El Pasillo de Departamentos

Imaginá que un vector numeros[3] es una fila de 3 departamentos pegados uno al lado del otro en un mismo pasillo:

Depto 0 (Puerta 1000)
10
Depto 1 (Puerta 1004)
20
Depto 2 (Puerta 1008)
30

¿Qué es el nombre numeros?

Es el cartel en la entrada del pasillo que dice: "El edificio empieza en la Puerta 1000" (justo donde está el Depto 0).

¿Por qué alcanza con saber dónde empieza?

Como todos los departamentos están pegados en fila sin huecos, si sabés dónde está el Depto 0, dando 1 paso llegás al Depto 1 y dando 2 pasos llegás al Depto 2.

05 Cómo Vive int numeros[3] en la Memoria RAM

Cada número entero (int) ocupa 4 bytes en la memoria. Cuando declaramos int numeros[3] = {10, 20, 30};, la memoria reserva 3 casillas contiguas de 4 bytes cada una:

Dirección: 0x1000
numeros[0] int (4B)
10
Dirección: 0x1004
numeros[1] int (4B)
20
Dirección: 0x1008
numeros[2] int (4B)
30

🔍 Observá las direcciones: 0x1000, 0x1004, 0x1008. Saltan de 4 en 4 porque cada int ocupa 4 bytes (1000, 1001, 1002 y 1003 pertenecen a numeros[0]).

Imprimamos con %p el nombre del arreglo solo y la dirección de su primera casilla:

✅ Regla de oro: numeros y &numeros[0] imprimen exactamente la misma dirección de memoria (0x7ffe1000).

07 Apuntar un Puntero a un Arreglo: int *p = numeros;

Como el nombre numeros ya es la dirección del primer elemento, podemos guardarla directamente en un puntero int *p:

Fragmento del Apunte (Pág. 26) Sintaxis
int numeros[3] = {10, 20, 30}; int *p = numeros;

int *p

Declara una variable puntero llamada p capaz de guardar la dirección de memoria de un int.

= numeros;

Guarda en p la dirección donde empieza el vector (&numeros[0]). No lleva & porque numeros ya es esa dirección.

¿Es igual a &numeros[0]?

Sí: escribir int *p = numeros; es 100% idéntico a escribir int *p = &numeros[0];.

08 Acceder al Primer Elemento: ¿Qué Nos Da *p?

primer_elemento.c *p
int numeros[3] = {10, 20, 30}; int *p = numeros; printf("%d", *p); // 10

Paso a paso mental

  1. p contiene la dirección 0x1000 (la de numeros[0]).
  2. El operador * en *p dice: "Andá a la dirección guardada en p y agarrá el valor que hay ahí".
  3. En 0x1000 está guardado el número 10.

09 El Código del Apunte: *p, *(p + 1) y *(p + 2)

Veamos el ejemplo exacto de la página 26 del apunte y qué imprime cada línea:

apunte_seccion_25.c Apunte pág. 26
#include <stdio.h> int main() { int numeros[3] = {10, 20, 30}; int *p = numeros; printf("%d\n", *p); // 10 printf("%d\n", *(p + 1)); // 20 printf("%d\n", *(p + 2)); // 30 return 0; }
Terminal Salida
$ ./apunte_seccion_25 10 20 30
  • *p ➔ valor en la 1° casilla (10)
  • *(p + 1) ➔ avanza 1 casilla y lee su valor (20)
  • *(p + 2) ➔ avanza 2 casillas y lee su valor (30)

10 Aritmética de Punteros: ¿Qué Hace Realmente p + 1?

¡Atención! Sumar 1 a un puntero NO suma 1 byte

En C, cuando sumás un número entero k a un puntero p, el compilador calcula automáticamente:
Nueva dirección = Dirección base + k * sizeof(tipo).

p + 0

0x1000 + 0 * 4 = 0x1000

Apunta a numeros[0].
Al desreferenciar *(p + 0) obtenemos 10.

p + 1

0x1000 + 1 * 4 = 0x1004

Salta 4 bytes hasta numeros[1].
Al desreferenciar *(p + 1) obtenemos 20.

p + 2

0x1000 + 2 * 4 = 0x1008

Salta 8 bytes hasta numeros[2].
Al desreferenciar *(p + 2) obtenemos 30.

💡 ¿Por qué entonces un puntero necesita saber su tipo (int * vs char *)? Porque gracias al tipo, C sabe si al hacer p + 1 tiene que avanzar 1 byte (en un char *), 4 bytes (en un int * o float *) u 8 bytes (en un double *).

11 ¿Por Qué Son Obligatorios los Paréntesis en *(p + 1)?

En lenguaje C, el operador de desreferencia * tiene mayor prioridad (se resuelve antes) que la suma +. Compará estas dos expresiones con int numeros[3] = {10, 80, 30};:

Con paréntesis: *(p + 1)

printf("%d", *(p + 1)); // Da 80
  1. Primero resuelve el paréntesis (p + 1): avanza la dirección a la casilla 1.
  2. Después aplica *: lee el valor guardado en la casilla 1 (80).

Sin paréntesis: *p + 1

printf("%d", *p + 1); // Da 11
  1. Primero resuelve *p: lee el valor de la casilla 0 (que vale 10).
  2. Después le suma 1 a ese número: 10 + 1 = 11. ¡No avanzó de casilla!

12 La Equivalencia Fundamental entre Arreglos y Punteros

Dado int numeros[3] = {10, 20, 30}; e int *p = numeros; (con base en 0x1000), estas expresiones son exactamente equivalentes:

Posición i Dirección con Arreglo Dirección con Puntero Valor con Corchetes Valor con Puntero Resultado
i = 0 &numeros[0] p  o  (p + 0) numeros[0] *p  o  *(p + 0) 10 (en 0x1000)
i = 1 &numeros[1] (p + 1) numeros[1] *(p + 1) 20 (en 0x1004)
i = 2 &numeros[2] (p + 2) numeros[2] *(p + 2) 30 (en 0x1008)
General i &numeros[i] (p + i) numeros[i] *(p + i) Elemento i

🔑 Secreto interno de C: Cuando escribís numeros[i], el compilador de C lo traduce internamente como *(numeros + i). ¡Los corchetes [] son una abreviatura de sumar y desreferenciar!

13 Ejemplo Nivel 1: Mostrar Direcciones y Valores

Veamos un programa completo e introductorio que muestra para cada casilla su dirección y su valor usando el puntero p:

nivel1_explorar_vector.c Nivel 1 • Inicial
#include <stdio.h> int main() { int numeros[3] = {10, 20, 30}; int *p = numeros; printf("Pos 0: dir=%p val=%d\n", p, *p); printf("Pos 1: dir=%p val=%d\n", p + 1, *(p + 1)); printf("Pos 2: dir=%p val=%d\n", p + 2, *(p + 2)); return 0; }
Terminal Salida
$ ./nivel1_explorar_vector Pos 0: dir=0x7ffe1000 val=10 Pos 1: dir=0x7ffe1004 val=20 Pos 2: dir=0x7ffe1008 val=30

• Sin * (p, p + 1, p + 2): obtenemos la dirección de cada casilla.
• Con * (*p, *(p + 1), *(p + 2)): obtenemos el valor adentro de cada casilla.

14 Recorrer un Vector con un Ciclo for y Punteros

Así como reemplazamos numeros[0], numeros[1], numeros[2] por numeros[i] dentro de un for, podemos reemplazar *(p + 0), *(p + 1), *(p + 2) por *(p + i):

Forma Clásica con Corchetes numeros[i]
int numeros[3] = {10, 20, 30}; for (int i = 0; i < 3; i++) { printf("%d\n", numeros[i]); }
Forma con Puntero y Desplazamiento *(p + i)
int numeros[3] = {10, 20, 30}; int *p = numeros; for (int i = 0; i < 3; i++) { printf("%d\n", *(p + i)); }

🔄 En cada vuelta del ciclo, p sigue apuntando al inicio (0x1000), mientras que i vale 0, luego 1 y luego 2, calculando *(p + 0), *(p + 1) y *(p + 2).

15 Modificar Elementos de un Arreglo Usando un Puntero

El apunte destaca que "podemos usar punteros para recorrer y modificar arreglos". Si ponemos *p o *(p + i) a la izquierda del signo =, escribimos directamente adentro del arreglo original:

modificar_con_puntero.c Escritura en RAM
#include <stdio.h> int main() { int numeros[3] = {10, 20, 30}; int *p = numeros; *p = 99; // Cambia numeros[0] de 10 a 99 *(p + 2) = 500; // Cambia numeros[2] de 30 a 500 printf("%d - %d - %d\n", numeros[0], numeros[1], numeros[2]); // 99 - 20 - 500 return 0; }

🎯 Como p apunta a las mismas celdas de memoria que numeros, modificar *(p + 2) es modificar numeros[2]. No hay dos vectores distintos: hay un único vector en la memoria RAM.

16 Ejemplo Nivel 2: Sumar y Duplicar con Punteros

nivel2_duplicar_y_sumar.c Nivel 2 • Ciclo + Puntero
#include <stdio.h> int main() { int numeros[4] = {5, 10, 15, 20}; int *p = numeros; int suma = 0; for (int i = 0; i < 4; i++) { *(p + i) = *(p + i) * 2; suma += *(p + i); } for (int i = 0; i < 4; i++) { printf("%d ", numeros[i]); } printf("\nSuma total: %d\n", suma); return 0; }
Terminal Salida
$ ./nivel2_duplicar_y_sumar 10 20 30 40 Suma total: 100

Observá que en el primer for duplicamos cada casilla usando *(p + i), y en el segundo for imprimimos numeros[i]: todos los valores del vector original quedaron duplicados.

18 Por Qué las Funciones Modifican el Arreglo Original

Explicación del Apunte (Sección 25)

"El nombre de un arreglo representa la dirección de su primer elemento. Por eso... podemos pasar arreglos a funciones para que trabajen sobre el arreglo original."

Lo que NO hace C

Si tenés un vector de 10.000 enteros y llamás a procesar(numeros, 10000), C jamás copia los 10.000 enteros. Copiar todo el vector sería lentísimo y gastaría muchísima memoria.

Lo que SÍ hace C

Como numeros es la dirección del primer elemento (0x1000), a la función solo viaja esa dirección (un puntero). Por eso la función lee y escribe directamente sobre el vector original de main.

// Para el compilador de C, estos dos encabezados de función significan EXACTAMENTE lo mismo: void cargarCeros(int vector[], int tamano); void cargarCeros(int *vector, int tamano);

19 Modelo en Memoria: main y la Función Apuntan al Mismo Vector

vector_en_funcion.c Paso de Arreglo
#include <stdio.h> void triplicarPrimero(int *v) { v[0] = v[0] * 3; // o *v = *v * 3; } int main() { int numeros[3] = {10, 20, 30}; triplicarPrimero(numeros); printf("%d\n", numeros[0]); // 30 return 0; }

¿Qué ocurre en la memoria RAM?

  1. En main, numeros está en 0x1000 con {10, 20, 30}.
  2. Llamamos a triplicarPrimero(numeros) enviando la dirección 0x1000.
  3. El parámetro int *v recibe 0x1000.
  4. Al hacer v[0] = v[0] * 3, modifica la dirección 0x1000.
  5. Al volver a main, numeros[0] ahora vale 30.

20 Ejemplo Nivel 3: Función que Modifica un Arreglo con Punteros

Combinemos funciones, arreglos y aritmética de punteros: una función sumarBonus que le suma puntos extra a cada nota del arreglo original usando *(p + i):

nivel3_bonus_notas.c Nivel 3 • Función + Puntero
#include <stdio.h> void sumarBonus(int *p, int tamano, int extra) { for (int i = 0; i < tamano; i++) { *(p + i) += extra; } } int main() { int notas[4] = {6, 7, 5, 8}; sumarBonus(notas, 4, 2); for (int i = 0; i < 4; i++) { printf("Nota %d: %d\n", i, notas[i]); } return 0; }
Terminal Salida
$ ./nivel3_bonus_notas Nota 0: 8 Nota 1: 9 Nota 2: 7 Nota 3: 10

• En main pasamos notas (que decae a &notas[0]).
• La función lo recibe como int *p.
• Adentro del ciclo, *(p + i) += extra; actualiza cada casilla de notas en main.

21 Otra Técnica Clásica en C: Avanzar el Puntero con p++

Como un puntero p es una variable, también podemos moverlo casilla por casilla haciendo p++ (que suma 1 * sizeof(int) a la dirección guardada en p):

puntero_movil.c Avance con p++
#include <stdio.h> int main() { int numeros[3] = {10, 20, 30}; int *p = numeros; for (int i = 0; i < 3; i++) { printf("%d\n", *p); p++; // p pasa a apuntar al siguiente int } return 0; }

Diferencia entre *(p + i) y p++

  • Con *(p + i): p queda quieto apuntando siempre a numeros[0] y calculamos el salto con + i.
  • Con p++: p cambia su valor en cada vuelta (de 0x1000 pasa a 0x1004, luego a 0x1008).
  • Recomendación: Usá *(p + i) para no perder la referencia al inicio del arreglo.

22 ¿Arreglo y Puntero Son Exactamente lo Mismo? ¡No!

Aunque están íntimamente relacionados, hay dos diferencias fundamentales entre int numeros[3] e int *p:

1. El nombre del arreglo es CONSTANTE

numeros está atado para siempre a la dirección donde nació (0x1000). No se puede cambiar a dónde apunta:

numeros = numeros + 1; // ❌ ERROR de compilación numeros++; // ❌ ERROR de compilación

2. El puntero es una VARIABLE móvil

p es una variable que guarda direcciones. Puede apuntar primero a numeros, después avanzar o apuntar a otra variable:

p = p + 1; // ✅ VÁLIDO: ahora apunta a numeros[1] p++; // ✅ VÁLIDO: ahora apunta a numeros[2]

23 Diferencia en Memoria: Qué Reserva Cada Uno

Declarar un arreglo: int numeros[3];

  • Reserva espacio para 3 números enteros reales en memoria (3 * 4 = 12 bytes).
  • Ahí adentro se guardan los valores 10, 20 y 30.
  • sizeof(numeros) devuelve 12 bytes.

Declarar un puntero: int *p;

  • Reserva espacio para una sola dirección de memoria (8 bytes en sistemas de 64 bits).
  • No crea casillas para guardar enteros; necesita apuntar a un arreglo o variable que ya exista.
  • sizeof(p) devuelve 8 bytes.

⚠️ Cuidado: Si declarás int *p; sin inicializarlo (sin hacer p = numeros;) e intentás hacer *p = 10;, tu programa fallará porque p no apunta a ningún arreglo válido todavía.

24 ¡Ahora Todo Cierra! Por Qué scanf("%s", nombre) No Lleva &

En las Unidades 02 a 04 aprendimos que un String es un arreglo de caracteres (char nombre[20];) y que en scanf se pasaba sin &. Ahora sabemos exactamente por qué:

Variable simple vs Arreglo char Comparación
int edad; char nombre[20]; scanf("%d", &edad); // Lleva & para dar su dirección scanf("%s", nombre); // ¡nombre YA ES &nombre[0]!

La explicación completa

scanf siempre necesita recibir una dirección de memoria (un puntero) para poder guardar lo que escribe el usuario.

• En un int edad, usamos &edad para obtener su dirección.
• En char nombre[20], el nombre del arreglo nombre ya representa la dirección de su primer elemento (&nombre[0]).

25 Ejemplo Nivel 4 (Tipo Examen): Planteo del Problema

Enunciado Integrador

Escribir una función int limpiarYMaximo(int *v, int tamano, int *maximo) que reciba un arreglo de enteros mediante un puntero y realice dos tareas en un solo recorrido:
1. Reemplace todos los números negativos del arreglo original por 0 y cuente cuántos reemplazó.
2. Encuentre el valor máximo (luego de limpiar) y lo guarde en *maximo.
3. Devuelva con return la cantidad de negativos reemplazados.

1

Recorrer con *(v + i)

Si *(v + i) < 0, asignamos *(v + i) = 0; y sumamos 1 al contador de cambios.

2

Actualizar *maximo

En i == 0 o cuando *(v + i) > *maximo, guardamos *maximo = *(v + i);.

3

Retornar cambios

Al finalizar el ciclo, hacemos return cambios; y verificamos en main.

26 Ejemplo Nivel 4: Código Completo y Ejecución

nivel4_limpiar_y_maximo.c Nivel 4 • Integrador
#include <stdio.h> int limpiarYMaximo(int *v, int tamano, int *maximo) { int cambios = 0; for (int i = 0; i < tamano; i++) { if (*(v + i) < 0) { *(v + i) = 0; cambios++; } if (i == 0 || *(v + i) > *maximo) { *maximo = *(v + i); } } return cambios; } int main() { int datos[5] = {-4, 12, -9, 25, 8}; int max; int corregidos = limpiarYMaximo(datos, 5, &max); printf("Vector: %d %d %d %d %d\n", datos[0], datos[1], datos[2], datos[3], datos[4]); printf("Negativos corregidos: %d | Maximo: %d\n", corregidos, max); return 0; }
Terminal Salida
$ ./nivel4 Vector: 0 12 0 25 8 Negativos corregidos: 2 | Maximo: 25

¡Tres efectos a la vez!
1. Modificó el arreglo datos en main.
2. Escribió el máximo en max vía puntero.
3. Devolvió 2 con return.

27 Errores Frecuentes de Principiantes (Parte 1)

❌ Error 1: Escribir *p + 1 para ir al segundo elemento
int v[3] = {10, 50, 90}; int *p = v; printf("%d", *p + 1); // Imprime 11, ¡no 50!

Por qué falla: Sin paréntesis, *p agarra el 10 de la primera casilla y le suma 1. Nunca avanza a la segunda casilla.

✅ Correcto: Usar paréntesis *(p + 1)
int v[3] = {10, 50, 90}; int *p = v; printf("%d", *(p + 1)); // Imprime 50

Por qué funciona: Primero suma 1 posición a la dirección p y recién después desreferencia con *.

28 Errores Frecuentes de Principiantes (Parte 2)

❌ Error 2: Intentar incrementar el nombre del arreglo
int numeros[3] = {10, 20, 30}; numeros++; // ❌ Error de compilación

Por qué falla: El nombre de un arreglo no es una variable modificable; su dirección base es fija y constante.

✅ Correcto: Usar un puntero auxiliar o sumar sin reasignar
int numeros[3] = {10, 20, 30}; int *p = numeros; p++; // ✅ p sí es una variable puntero

Por qué funciona: Guardamos la dirección inicial en p y desplazamos p (o usamos *(p + i)).

29 Errores Frecuentes (Parte 3): Salirse del Arreglo

❌ Error 3: Desplazarse fuera de rango con *(p + 3)
int numeros[3] = {10, 20, 30}; int *p = numeros; printf("%d", *(p + 3)); // ❌ Basura de RAM

Por qué falla: Si el arreglo tiene tamaño 3, los desplazamientos válidos son + 0, + 1 y + 2. *(p + 3) equivale a numeros[3] (no existe).

✅ Correcto: Respetar siempre 0 <= i < tamano
int numeros[3] = {10, 20, 30}; int *p = numeros; printf("%d", *(p + 2)); // ✅ Último elemento: 30

Por qué funciona: El último elemento válido de un arreglo de N elementos está siempre en *(p + N - 1).

30 Buenas Prácticas con Punteros y Arreglos

✔️ Qué hacer siempre

  • Pasar siempre el tamaño del arreglo junto con el puntero a las funciones: void mostrar(int *v, int tamano), porque adentro de la función el puntero solo conoce dónde empieza el vector, no dónde termina.
  • Preferir *(p + i) o v[i] con un índice i claro antes que modificar el puntero base con p++ si después vas a necesitar volver al inicio del arreglo.
  • Colocar siempre los paréntesis en *(p + i) cuando quieras acceder al elemento i.

🧠 Cuándo usar cada notación

  • Notación de corchetes numeros[i]: Es la más legible en el día a día para recorrer vectores normales.
  • Notación de punteros *(p + i): Es indispensable para comprender cómo funciona C por debajo, resolver ejercicios de examen de aritmética de punteros y trabajar más adelante con memoria dinámica.

31 Ejercicios de Práctica (Parte 1)

Ejercicio 1: Predecir la salida de código con punteros

Dado int v[4] = {4, 8, 15, 16}; int *p = v;, ¿qué imprimen exactamente estas tres líneas?
a) printf("%d\n", *(p + 2));    b) printf("%d\n", *p + 2);    c) printf("%d\n", *(p + 3) - *p);

💻 Ver solución paso a paso
// a) *(p + 2) accede a la posición 2 del arreglo (v[2]) -> Imprime 15 // b) *p + 2 toma el primer elemento (*p = 4) y le suma 2 -> Imprime 6 // c) *(p + 3) es v[3] (16) y *p es v[0] (4). 16 - 4 -> Imprime 12

Ejercicio 2: Contar pares usando exclusivamente un puntero

Dado int numeros[5] = {7, 12, 5, 20, 8}; y un puntero int *p = numeros;, escribí un ciclo for que cuente cuántos números pares hay usando *(p + i) (sin escribir corchetes en el ciclo).

💻 Ver solución paso a paso
#include <stdio.h> int main() { int numeros[5] = {7, 12, 5, 20, 8}; int *p = numeros; int pares = 0; for (int i = 0; i < 5; i++) { if (*(p + i) % 2 == 0) { pares++; } } printf("Cantidad de pares: %d\n", pares); // Muestra 3 return 0; }

Ejercicio 3: Invertir un arreglo in-place con punteros

Escribí una función void invertir(int *p, int tamano) que invierta los elementos del arreglo original usando la notación de punteros *(p + i) y una variable auxiliar aux. Probalo en main con int v[4] = {10, 20, 30, 40}; para que quede {40, 30, 20, 10}.

💻 Ver solución paso a paso
#include <stdio.h> void invertir(int *p, int tamano) { for (int i = 0; i < tamano / 2; i++) { int aux = *(p + i); *(p + i) = *(p + tamano - 1 - i); *(p + tamano - 1 - i) = aux; } } int main() { int v[4] = {10, 20, 30, 40}; invertir(v, 4); for (int i = 0; i < 4; i++) { printf("%d ", v[i]); // Imprime: 40 30 20 10 } return 0; }

33 Resumen de la Unidad 07 y Checklist

Ideas Clave de la Sección 25

  • El nombre de un arreglo representa la dirección de su primer elemento: numeros == &numeros[0].
  • Podemos apuntar un puntero al inicio del arreglo con int *p = numeros; (sin &).
  • *p es numeros[0], *(p + 1) es numeros[1] y en general *(p + i) == numeros[i].
  • Al pasar un arreglo a una función, viaja la dirección de su primera casilla; por eso la función trabaja sobre el arreglo original.
