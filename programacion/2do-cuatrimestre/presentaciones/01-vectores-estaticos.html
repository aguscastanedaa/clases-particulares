02 ¿Qué es un Vector en C?

Definición Formal

Un vector (también llamado array o arreglo unidimensional) es una estructura de datos que permite almacenar una colección ordenada de elementos del mismo tipo en posiciones de memoria contiguas bajo un único nombre identificador.

1. Homogéneo

Todos sus casilleros deben guardar el mismo tipo de dato (todos int, o todos float, o todos char).

2. Tamaño Fijo (Estático)

En un vector estático, la cantidad de elementos se define al programarlo y no puede crecer ni achicarse en ejecución.

3. Memoria Contigua

En la RAM, los elementos están pegados uno al lado del otro en una hilera perfecta, sin huecos intermedios.

03 Analogía: El Casillero Postal Numerado

Un vector es como una hilera de casilleros postales en un edificio:

Índice [0]
8
Índice [1]
7
Índice [2]
10
Índice [3]
6
Índice [4]
9
  • El nombre de todo el mueble es notas.
  • El número entre corchetes [ ] es el índice o posición.
  • Lo que está adentro de cada casillero es el valor almacenado.
  • Para cambiar o consultar el casillero 2: notas[2] = 10;

04 Declaración e Inicialización en C

Las diferentes maneras de dar vida a un vector en código:

declaracion_vectores.c Sintaxis C
// 1. Declarar sin inicializar (los 5 casilleros tienen 'basura'): int edades[5]; // 2. Declarar con valores iniciales explícitos usando llaves { }: int notas[5] = {8, 7, 10, 6, 9}; // 3. Inicializar TODO el vector a ceros (buena práctica profesional): int ceros[10] = {0}; // 4. El compilador cuenta los elementos por vos: int pares[] = {2, 4, 6, 8}; // Reserva automáticamente 4 elementos

⚠️ ¡Cuidado con el tamaño estático!: En C estándar convencional, el número dentro de los corchetes al declarar un vector estático debe ser una constante o valor conocido al compilar (ej: #define TAM 10 o un número literal como 5).

05 La Regla de Oro: Índices en Base Cero

¡En C siempre se empieza a contar desde el 0!

Si un vector tiene 5 elementos, sus posiciones válidas son 0, 1, 2, 3 y 4. ¡El índice 5 NO pertenece al vector!

¿Por qué desde 0 y no desde 1?

En C, el nombre del vector representa la dirección del primer casillero en RAM. El índice indica el **desplazamiento (offset)**:

Dirección = Inicio + (índice × 4 bytes)

Para el primer elemento nos desplazamos 0 bytes. Por eso es vector[0].

El resumen de límites

  • Primer elemento: vector[0]
  • Segundo elemento: vector[1]
  • Tercer elemento: vector[2]
  • Último elemento de tamaño N: vector[N - 1]

06 El Peligro Mortal: Desbordamiento (Out of Bounds)

❌ Acceso Fuera de Límites
int notas[5] = {8, 7, 10, 6, 9};

// ¡ERROR GRAVÍSIMO!
notas[5] = 10;

¿Qué hace C?: C NO comprueba los límites para ser ultrarrápido. Intentará escribir en el casillero 6 de la memoria, sobreescribiendo otra variable o destruyendo datos del programa (Buffer Overflow / Crash).

✅ Rango Correcto y Seguro
int notas[5] = {8, 7, 10, 6, 9};

// El último es el índice 4:
notas[4] = 10;

Cualquier índice $0 \le i \le 4$ es 100% seguro y válido en un vector de tamaño 5.

07 El Vector en la Memoria RAM Física

Si declaramos int arr[3] = {15, 20, 25}; en una máquina de 32 bits (4 bytes por int):

Dirección: 0x1000
arr[0] 4B
15
Dirección: 0x1004
arr[1] 4B
20
Dirección: 0x1008
arr[2] 4B
25

🔍 Observá las direcciones: 0x1000, 0x1004, 0x1008... ¡Avanzan exactamente de a 4 bytes! Cada elemento se aloja inmediatamente al lado del anterior. El operador sizeof(arr) devolverá $3 \times 4 = 12\text{ bytes}$.

#include <stdio.h> int main(void) { // Declaramos un vector de 3 temperaturas float temp[3]; temp[0] = 18.5f; temp[1] = 22.0f; temp[2] = 15.3f; printf("Temperatura inicial: %.1f °C\n", temp[0]); printf("Temperatura final: %.1f °C\n", temp[2]); // Modificamos el segundo casillero: temp[1] = 25.0f; printf("Temperatura corregida: %.1f °C\n", temp[1]); return 0; }

09 Resumen de la Unidad y Checklist

Puntos Cardinales

  • Vector: Colección contigua y homogénea de datos.
  • Declaración: tipo nombre[TAMANIO];
  • Índices: Siempre van desde 0 hasta TAMANIO - 1.
  • Vector estático: Tamaño inmutable tras compilar.
  • Out of bounds: Desbordamiento no advertido por C; causa bugs graves.
