Estructuras (struct) y Modelado de Datos

Creando tipos de datos personalizados: cómo agrupar variables heterogéneas, el operador punto . y el pasaje de estructuras a funciones.

struct y campos Operador punto (.) Estructuras por valor Modelado de Alumnos y Puntos

💡 Guía de navegación: Usá la barra espaciadora o las flechas del teclado (→ / ←) para avanzar diapositiva por diapositiva.

01 Objetivos Pedagógicos

Superando la limitación homogénea

Los vectores y matrices en C tienen una gran limitación: todos sus elementos deben ser del mismo tipo (todos int o todos float).

En el mundo real, los objetos son heterogéneos: un alumno tiene un nombre (texto), una edad (entero) y un promedio (decimal). La palabra clave struct nos permite crear el molde para representar entidades completas.

Lo que vas a dominar en esta clase

  • Comprender qué problema resuelve una estructura.
  • Declarar moldes de tipo struct con campos heterogéneos.
  • Instanciar variables struct (ej. struct Persona p1;).
  • Acceder a sus miembros para lectura y escritura con el operador punto (.).
  • Pasar estructuras a funciones por valor y comprender la copia de datos.
  • Entender la relación directa con Bases de Datos y Clases de POO.

02 Declaración de una Struct: El "Molde"

Analogía del Molde de Cocina

Una struct es un plano o molde de cocina: no ocupa memoria por sí misma hasta que creás una variable concreta usando esa forma.

persona.h Molde
struct Persona { char nombre[50]; int edad; float altura; };
instanciar.c Uso
int main(void) { // Creamos la variable real en memoria: struct Persona persona1; // Accedemos con el operador punto (.) persona1.edad = 20; persona1.altura = 1.75f; strcpy(persona1.nombre, "Agustin"); return 0; }

03 El Operador Punto . y la Caja con Cajitas

Podemos visualizar una estructura como una caja grande rotulada que contiene cajitas internas etiquetadas.

persona1 struct Persona
.nombre (char[50])
"Agustin"
.edad (int)
20
.altura (float)
1.75 m

Sintaxis de Acceso

variable.campo

persona1.edad significa literalmente: "Entrá a la caja persona1 y dame el valor del campo edad".

💡 Relación con POO y BD: Esta estructura es el ancestro directo de las tablas SQL (donde cada campo es una columna) y de las Clases de la Programación Orientada a Objetos.

04 Enviar Estructuras a Funciones (Paso por Valor)

Podemos pasar una estructura completa como argumento a una función.

punto.c struct Punto
struct Punto { int x; int y; }; void imprimirPunto(struct Punto p) { printf("(%d, %d)\n", p.x, p.y); } int main(void) { struct Punto punto; punto.x = 10; punto.y = 20; imprimirPunto(punto); // Imprime: (10, 20) return 0; }

¿Qué significa que sea por valor?

La función imprimirPunto recibe una copia completa e independiente de la estructura original.

✔️ Ideal para: leer datos, imprimir o hacer cálculos.
🔒 Seguridad: Si modificás p.x = 99 adentro de la función, el punto de main no cambia.
⚠️ Costo: Si la estructura tiene muchos campos grandes, copiarla consume tiempo y memoria de Stack.

05 Ejemplo Completo: Alumno y Cálculo de Promedio

Modelado de un alumno con 3 notas parciales y función de cálculo.

alumno_struct.c Molde y Función
struct Alumno { char nombre[30]; float nota1; float nota2; float nota3; }; float calcularPromedio(struct Alumno alumno) { return (alumno.nota1 + alumno.nota2 + alumno.nota3) / 3.0f; }
main.c Uso en main
int main(void) { struct Alumno a1; a1.nota1 = 8.0f; a1.nota2 = 6.0f; a1.nota3 = 9.0f; float prom = calcularPromedio(a1); printf("Promedio final: %.2f\n", prom); return 0; }
Terminal de salida bash
Promedio final: 7.67

06 Resumen y Autoevaluación

Puntos Clave del Módulo

  • Una struct agrupa datos de diferente tipo bajo un solo identificador.
  • El molde define los campos; la variable real reserva la memoria.
  • El operador punto . accede a los miembros de una variable struct.
  • Al pasar una struct por valor, la función trabaja con una copia inofensiva.

Checklist de Autoevaluación

✓ ¿Sé cuál es la diferencia entre declarar struct Auto { ... }; y struct Auto miAuto;?
✓ ¿Por qué para asignar texto a persona1.nombre usamos strcpy?
✓ ¿Qué ocurre con la variable original si una función modifica un campo de una struct pasada por valor? (No cambia).
