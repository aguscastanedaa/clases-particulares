02 26. Structs: ¿Qué Problema Resuelven?

Definición del Apunte (Pág. 27)

Una struct permite agrupar varios datos relacionados bajo un mismo nombre.

Supongamos que queremos representar a una persona en nuestro programa. Una persona tiene tres datos de distinto tipo:

Sin struct (Variables sueltas) Desordenado
char nombre[50]; int edad; float altura;

¿Por qué no alcanza con variables sueltas?

Si tenés 3 personas tendrías 9 variables sueltas (nombre1, edad1, altura1, nombre2...). Y si querés pasar una persona a una función, tendrías que pasar todos los datos por separado. ¡Necesitamos empaquetarlos juntos!

03 Crear una Struct: El Concepto de "Molde"

En lugar de tener las tres variables por separado, las agrupamos definiendo una estructura:

Definición en el Apunte (Pág. 27) struct Persona
struct Persona { char nombre[50]; int edad; float altura; }; // Ahora creamos una variable: struct Persona persona1;

Analogía del Apunte: El "Molde"

"Podemos pensarlo como un “molde” para crear siempre con la misma “forma” distintas cosas."

• struct Persona { ... }; dibuja el plano o molde (todavía no existe ninguna persona).
• struct Persona persona1; usa ese molde para fabricar una variable real en la memoria RAM.

04 Desglose Pieza por Pieza de una struct

struct Persona { char nombre[50]; // Campo 1: String de hasta 49 letras + '\0' int edad; // Campo 2: Número entero float altura; // Campo 3: Número con decimales }; // ¡Atención al punto y coma obligatorio al cerrar la llave!

1. struct Persona

La palabra clave struct seguida del nombre del tipo (por convención empieza con Mayúscula: Persona, Punto, Alumno).

2. Campos o Miembros

Adentro de las llaves { } declaramos las variables internas llamadas campos (nombre, edad, altura).

3. El }; final

A diferencia de las funciones o del if, la llave de cierre de una struct termina siempre con punto y coma };.

05 27. Acceder a los Campos de un Struct: Operador .

Para entrar a un campo específico de nuestra variable persona1 (tanto para guardar un dato como para leerlo), utilizamos el operador punto (.):

Ejemplo del Apunte (Pág. 27) Operador .
// Para guardar valores: persona1.edad = 20; persona1.altura = 1.75; // Para leer: printf("%d", persona1.edad);

¿Cómo se lee persona1.edad?

Tal como explica el apunte:
persona1.edad significa: "El campo edad de persona1".

Primero escribís el nombre de la variable (persona1), luego un punto (.) y finalmente el nombre del campo (edad).

06 Analogía del Apunte: "Una Caja con Cajitas Adentro"

El apunte propone una imagen mental genial para no confundirse nunca:

📦 Caja grande: persona1 struct Persona
🏷️ Cajita .nombre (char[50])
"Lucia"
🏷️ Cajita .edad (int)
20
🏷️ Cajita .altura (float)
1.75

Cada cajita tiene su propio tipo

  • persona1.nombre es un String (char[50]) ➔ usa %s.
  • persona1.edad es un entero (int) ➔ usa %d.
  • persona1.altura es un decimal (float) ➔ usa %.2f.

Conexión con Bases de Datos y POO

El apunte subraya que este concepto está directamente conectado con Bases de Datos (donde cada fila de una tabla tiene columnas nombre, edad, altura) y con la Programación Orientada a Objetos (POO).

07 ¿Cómo Guardamos el nombre Adentro de una Struct?

Recordá lo que aprendimos en la Unidad 03 sobre Strings: en C un arreglo de caracteres no se puede asignar con = después de declararlo. Por eso usamos strcpy (de <string.h>) o lo leemos con scanf:

❌ Incorrecto: Asignar un String con =
struct Persona persona1; persona1.nombre = "Juan"; // ❌ ERROR de compilación

persona1.nombre es un arreglo char[50], y el nombre de un arreglo no se puede reasignar con =.

✅ Correcto: Usar strcpy o inicializar al declarar
#include <string.h> struct Persona persona1; strcpy(persona1.nombre, "Juan"); // ✅ Copia letra por letra

strcpy copia los caracteres 'J', 'u', 'a', 'n' y el '\0' adentro del campo persona1.nombre.

08 Tres Formas Válidas de Cargar struct Persona

1. Campo por campo Con . y strcpy
struct Persona p1; strcpy(p1.nombre, "Ana"); p1.edad = 20; p1.altura = 1.68;
2. Al declarar Con llaves { }
// En el mismo orden // de los campos: struct Persona p2 = { "Ana", 20, 1.68 };
3. Por teclado Con scanf
struct Persona p3; scanf("%s", p3.nombre); scanf("%d", &p3.edad); scanf("%f", &p3.altura);

🔍 Detalle clave en scanf: p3.nombre es un arreglo char[50], por eso no lleva &. En cambio, p3.edad y p3.altura son variables numéricas comunes, por lo que sí llevan & (&p3.edad).

09 Ejemplo Nivel 1: Crear y Mostrar una struct Persona

nivel1_persona.c Nivel 1 • Completo
#include <stdio.h> #include <string.h> struct Persona { char nombre[50]; int edad; float altura; }; int main() { struct Persona persona1; strcpy(persona1.nombre, "Martina"); persona1.edad = 20; persona1.altura = 1.75; printf("Nombre: %s\n", persona1.nombre); printf("Edad: %d anios\n", persona1.edad); printf("Altura: %.2f m\n", persona1.altura); return 0; }
Terminal Salida
$ ./nivel1_persona Nombre: Martina Edad: 20 anios Altura: 1.75 m

• Definimos el molde struct Persona afuera y arriba de main para que cualquier función del archivo lo conozca.
• Adentro de main creamos persona1 y cargamos sus tres cajitas.

10 Un Mismo Molde, Múltiples Variables Independientes

Una vez definido struct Persona, podemos crear persona1, persona2, persona3... Cada una tiene sus propias cajitas separadas en la memoria RAM:

dos_personas.c Independencia
#include <stdio.h> struct Persona { char nombre[50]; int edad; float altura; }; int main() { struct Persona p1 = {"Lucas", 19, 1.80}; struct Persona p2 = {"Sofia", 22, 1.65}; printf("%s tiene %d anios\n", p1.nombre, p1.edad); printf("%s tiene %d anios\n", p2.nombre, p2.edad); return 0; }

¿Por qué no se mezclan?

Porque nunca escribimos edad suelto: siempre indicamos de qué caja queremos el dato (p1.edad es 19, mientras que p2.edad es 22).

11 28. Structs y Funciones: El Ejemplo de struct Punto

Sección 28 del Apunte (Pág. 28)

Podemos enviar una Struct completa como parámetro a una función, igual que enviamos un int o un float.

punto_apunte.c Apunte pág. 28
#include <stdio.h> struct Punto { int x; int y; }; void imprimirPunto(struct Punto p) { printf("(%d, %d)", p.x, p.y); } int main() { struct Punto punto; punto.x = 10; punto.y = 20; imprimirPunto(punto); return 0; }
Terminal Salida
$ ./punto_apunte (10, 20)

• En vez de pasar x e y sueltos, pasamos el paquete entero: imprimirPunto(punto);.
• Adentro de la función el parámetro se llama p, y accedemos a sus campos con p.x y p.y.

12 Desglose de una Función que Recibe un struct

void imprimirPunto(struct Punto p) { printf("(%d, %d)", p.x, p.y); }

1. Tipo del parámetro

El tipo completo incluye la palabra struct: escribimos struct Punto (no solo Punto).

2. Nombre local p

p es el nombre que recibe la copia dentro de la función. Adentro usamos p.x y p.y.

3. Orden en el archivo

La definición de struct Punto { ... }; debe estar escrita antes de la función imprimirPunto para que el compilador conozca ese tipo.

13 Ejemplo del Apunte: struct Alumno y calcularPromedio

Veamos el programa completo de las páginas 28 y 29 del apunte: modelar a un alumno que tiene 3 notas y una función que devuelve su promedio:

alumno_promedio_apunte.c Apunte págs. 28-29
#include <stdio.h> struct Alumno { char nombre[30]; float nota1; float nota2; float nota3; }; float calcularPromedio(struct Alumno alumno) { return (alumno.nota1 + alumno.nota2 + alumno.nota3) / 3; } int main() { struct Alumno alumno; alumno.nota1 = 8; alumno.nota2 = 6; alumno.nota3 = 9; float promedio = calcularPromedio(alumno); printf("Promedio: %.2f", promedio); return 0; }
Terminal Salida
$ ./alumno_promedio_apunte Promedio: 7.67

• calcularPromedio recibe un solo paquete (struct Alumno alumno).
• Suma 8 + 6 + 9 = 23 y divide por 3 ➔ retorna 7.6666....
• En main lo mostramos con %.2f ➔ 7.67.

15 29. Struct por Valor: ¿Qué Significa Realmente?

Definición del Apunte (Página 29)

Cuando pasamos una struct por valor, la función recibe una copia de la estructura original. Por eso podemos leer sus datos y hacer cálculos con ellos, pero si modificamos la estructura dentro de la función, el original no cambia.

¿Cuándo está perfecto pasar por valor?

Tal como enumera el apunte, está muy bien si solamente queremos:

  • Leer los datos de la estructura.
  • Calcular algo (ej: promedio, distancia entre dos puntos).
  • Mostrar algo por pantalla (ej: imprimirPunto).

¿Cuándo NO nos sirve el paso por valor?

Cuando queremos que la función modifique los campos de la estructura original de main (por ejemplo, subirle el sueldo a un empleado o actualizar el saldo de una cuenta). Para eso en la Unidad 09 usaremos punteros a structs.

16 Demostración: Modificar un Struct por Valor No Afecta a main

Comprobemos qué pasa si una función intenta cambiar p.x = 999; recibiendo la struct por valor:

copia_por_valor.c Experimento
#include <stdio.h> struct Punto { int x; int y; }; void intentarCambiar(struct Punto p) { p.x = 999; printf("Adentro de la funcion: x = %d\n", p.x); } int main() { struct Punto punto = {10, 20}; intentarCambiar(punto); printf("En main despues: x = %d\n", punto.x); return 0; }
Terminal Salida
$ ./copia_por_valor Adentro de la funcion: x = 999 En main despues: x = 10

🔍 En intentarCambiar se modificó la fotocopia p (que pasó a valer 999 y se destruyó al terminar la función). El punto original de main siguió valiendo 10.

17 Modelo en Memoria RAM: Dos Cajas Separadas

A diferencia de los vectores (donde solo viaja la dirección de inicio), cuando pasás una struct por valor, C duplica todas sus cajitas internas en otra zona de la memoria:

En main() — Dirección 0x2000
punto struct Punto (Original)
punto.x = 10  |  punto.y = 20
En intentarCambiar() — Dirección 0x3000
p struct Punto (Copia local)
p.x = 999  |  p.y = 20

📌 Sorpresa importante de C: Incluso si la struct tiene un arreglo adentro (como char nombre[30] en struct Alumno), al pasar la struct por valor ¡también se copia ese arreglo completo dentro de la copia!

18 Funciones que Reciben Dos Structs (Ejemplo del Apunte)

En la página 29, el apunte menciona que podemos recibir dos puntos por valor para calcular algo entre ellos, como por ejemplo evaluar si están en el mismo lugar o medir su diferencia:

dos_puntos.c 2 Structs por Valor
#include <stdio.h> struct Punto { int x; int y; }; int distanciaManhattan(struct Punto p1, struct Punto p2) { int dx = p2.x - p1.x; int dy = p2.y - p1.y; if (dx < 0) dx = -dx; if (dy < 0) dy = -dy; return dx + dy; } int main() { struct Punto a = {2, 3}; struct Punto b = {7, 9}; printf("Distancia: %d cuadras\n", distanciaManhattan(a, b)); return 0; }
Terminal Salida
$ ./dos_puntos Distancia: 11 cuadras

p1 recibe una copia de a (2, 3) y p2 recibe una copia de b (7, 9). Calcula (7 - 2) + (9 - 3) = 5 + 6 = 11.

19 Funciones que Retornan una struct con return

Así como una función puede recibir un struct Punto, también puede tener struct Punto como tipo de retorno y devolver un paquete completo con return:

retornar_struct.c return struct
#include <stdio.h> struct Punto { int x; int y; }; struct Punto sumarPuntos(struct Punto p1, struct Punto p2) { struct Punto resultado; resultado.x = p1.x + p2.x; resultado.y = p1.y + p2.y; return resultado; } int main() { struct Punto a = {10, 20}; struct Punto b = {5, 15}; struct Punto suma = sumarPuntos(a, b); printf("Suma: (%d, %d)\n", suma.x, suma.y); return 0; }
Terminal Salida
$ ./retornar_struct Suma: (15, 35)

¡Devolvimos x e y juntos en un solo return resultado;! En C una estructura completa se puede asignar con = a otra estructura del mismo tipo.

21 Ejemplo Nivel 3: Comparar Dos Estructuras en una Función

Construyamos una función struct Producto masBarato(struct Producto p1, struct Producto p2) que reciba dos productos por valor y retorne la estructura completa del más económico:

nivel3_comparar_productos.c Nivel 3 • Comparación
#include <stdio.h> struct Producto { char nombre[40]; float precio; int stock; }; struct Producto masBarato(struct Producto a, struct Producto b) { if (a.precio <= b.precio) { return a; } return b; } int main() { struct Producto prod1 = {"Teclado", 25000.0, 10}; struct Producto prod2 = {"Mouse", 14500.0, 25}; struct Producto elegido = masBarato(prod1, prod2); printf("Oferta: %s ($%.2f)\n", elegido.nombre, elegido.precio); return 0; }
Terminal Salida
$ ./nivel3_comparar_productos Oferta: Mouse ($14500.00)

Al devolver el struct Producto entero, en main tenemos disponibles tanto elegido.nombre como elegido.precio y elegido.stock.

22 Regla Importante: ¿Qué Operaciones Permiten las Structs?

✅ SÍ se puede: Asignar con =
struct Punto p1 = {10, 20}; struct Punto p2; p2 = p1; // ✅ Copia TODOS los campos

C permite copiar una estructura completa en otra del mismo tipo con una sola línea p2 = p1;.

❌ NO se puede: Comparar dos structs con ==
if (p1 == p2) { // ❌ ERROR de compilación ... }

En C no existe p1 == p2 entre estructuras. Debés comparar campo por campo: if (p1.x == p2.x && p1.y == p2.y).

23 Ejemplo Nivel 4 (Tipo Examen): Planteo Paso a Paso

Problema Integrador: Evaluación de Beca Estudiantil

Modelar un struct Alumno con nombre, nota1, nota2, nota3 y asistencia (porcentaje entero de 0 a 100).
1. Escribir float calcularPromedio(struct Alumno a).
2. Escribir int obtieneBeca(struct Alumno a) que retorne 1 si el promedio es mayor o igual a 8.0 y la asistencia es mayor o igual a 85, o 0 en caso contrario.

1

Diseñar el Molde

5 campos: char nombre[30], tres float para las notas y un int asistencia.

2

Reutilizar Funciones

Adentro de obtieneBeca(a) llamamos a calcularPromedio(a) para no repetir la fórmula.

3

Evaluar Condición

Combinamos prom >= 8.0 && a.asistencia >= 85 y mostramos el dictamen en main.

24 Ejemplo Nivel 4: Solución Completa en C

nivel4_beca_alumno.c Nivel 4 • Modelo Examen
#include <stdio.h> struct Alumno { char nombre[30]; float nota1, nota2, nota3; int asistencia; }; float calcularPromedio(struct Alumno a) { return (a.nota1 + a.nota2 + a.nota3) / 3.0; } int obtieneBeca(struct Alumno a) { float prom = calcularPromedio(a); if (prom >= 8.0 && a.asistencia >= 85) { return 1; } return 0; } int main() { struct Alumno alu = {"Mateo", 9.0, 8.0, 8.5, 90}; printf("Alumno: %s (Prom: %.2f)\n", alu.nombre, calcularPromedio(alu)); if (obtieneBeca(alu) == 1) { printf("Resultado: BECA APROBADA\n"); } else { printf("Resultado: No alcanza requisitos\n"); } return 0; }
Terminal Salida
$ ./nivel4_beca Alumno: Mateo (Prom: 8.50) Resultado: BECA APROBADA

Como ninguna función necesita alterar los datos de Mateo, el paso por valor es seguro, claro y directo.

25 ¿Cómo Modificar un Struct Usando Paso por Valor y return?

Antes de ver punteros a estructuras en la Unidad 09, existe una forma de actualizar una struct por valor: hacer que la función retorne la estructura modificada y sobrescribir la original en main:

mover_punto_return.c Actualizar con return
#include <stdio.h> struct Punto { int x; int y; }; struct Punto moverDerecha(struct Punto p, int pasos) { p.x += pasos; return p; } int main() { struct Punto punto = {10, 20}; punto = moverDerecha(punto, 5); printf("Nueva pos: (%d, %d)\n", punto.x, punto.y); return 0; }

¿Por qué en la Unidad 09 preferiremos punteros?

Porque hacer punto = moverDerecha(punto, 5); copia toda la estructura al entrar y vuelve a copiarla al salir con return. Si la estructura es grande, pasar su dirección con un puntero será mucho más rápido y directo.

26 Errores Frecuentes de Principiantes (Parte 1)

❌ Error 1: Olvidar el punto y coma ; al cerrar la struct
struct Punto { int x; int y; } // ❌ Falta el ; aquí

Qué ocurre: El compilador lanza un error extraño en la línea siguiente (por ejemplo, en int main()) porque cree que aún no terminaste de declarar la estructura.

✅ Correcto: Cerrar siempre la definición con };
struct Punto { int x; int y; }; // ✅ Punto y coma obligatorio

Por qué funciona: El ; le avisa al compilador de C que allí termina la definición del tipo struct Punto.

27 Errores Frecuentes de Principiantes (Parte 2)

❌ Error 2: Usar el nombre del molde en vez de la variable
struct Persona persona1; Persona.edad = 20; // ❌ Persona es el tipo, no la variable

Por qué falla: Persona es el plano o molde; no tiene memoria reservada para guardar un 20.

✅ Correcto: Usar el nombre de la variable creada
struct Persona persona1; persona1.edad = 20; // ✅ persona1 es la caja en RAM

Por qué funciona: El operador punto se aplica siempre sobre la variable concreta (persona1).

28 Errores Frecuentes de Principiantes (Parte 3)

❌ Error 3: Creer que una función por valor modifica el original
void cumplirAnios(struct Persona p) { p.edad++; // ❌ Solo aumenta la edad de la copia }

Por qué falla: Al recibir struct Persona p por valor, cuando termina cumplirAnios la copia p desaparece y en main la edad no cambió.

✅ Correcto: Retornar el struct (o usar punteros en la Unidad 09)
struct Persona cumplirAnios(struct Persona p) { p.edad++; return p; // ✅ Y en main: p1 = cumplirAnios(p1); }

Por qué funciona: Devolvemos la copia actualizada o bien pasamos un puntero struct Persona *p (próxima unidad).

29 Errores Frecuentes (Parte 4): Intentar Imprimir toda la Struct de Golpe

❌ Error 4: Pasar la struct entera a printf
struct Punto punto = {10, 20}; printf("%d", punto); // ❌ printf no sabe imprimir un struct

Por qué falla: printf solo conoce tipos básicos (%d, %f, %c, %s, %p), no tipos creados por nosotros.

✅ Correcto: Imprimir sus campos o crear imprimirPunto
struct Punto punto = {10, 20}; printf("(%d, %d)", punto.x, punto.y); // ✅ Campo por campo

Por qué funciona: Accedemos a cada cajita interna (punto.x y punto.y), que sí son int.

30 Buenas Prácticas al Diseñar y Usar struct

✔️ Organización del código

  • Definí tus struct arriba de todo (debajo de los #include y antes de las funciones) para que tanto main como todas tus funciones puedan usarlas.
  • Escribí el nombre del molde con Mayúscula inicial (struct Persona, struct Alumno) y las variables con minúscula (persona1, alumno) para distinguirlas a simple vista.
  • Creá una función dedicada para mostrar cada struct (como imprimirPunto) así no repetís printf en todo el programa.

🧠 Cuándo agrupar en una struct

  • Siempre que varios datos describan a una misma entidad (un alumno, una fecha, un punto, un empleado, una cuenta bancaria).
  • Si ves que una función recibe 4 o 5 parámetros sueltos que pertenecen al mismo objeto, es señal de que deberían ser una struct.

Ejercicio 3: Mejor nota de un struct Alumno

Dado el struct Alumno del apunte (con nombre, nota1, nota2 y nota3), escribí una función float mayorNota(struct Alumno alumno) que devuelva cuál fue la nota más alta de las 3 que se sacó ese alumno.

💻 Ver solución paso a paso
#include <stdio.h> struct Alumno { char nombre[30]; float nota1; float nota2; float nota3; }; float mayorNota(struct Alumno alumno) { float mayor = alumno.nota1; if (alumno.nota2 > mayor) { mayor = alumno.nota2; } if (alumno.nota3 > mayor) { mayor = alumno.nota3; } return mayor; } int main() { struct Alumno a = {"Franco", 8.0, 6.0, 9.5}; printf("Nota mas alta de %s: %.2f\n", a.nombre, mayorNota(a)); // 9.50 return 0; }

33 El Próximo Paso: ¿Y Si Queremos Modificar el Struct Original?

Hoy vimos en la Sección 29 que al pasar un struct por valor la función recibe una copia y el original no cambia. ¿Cómo logramos que una función como aumentarSalario modifique directamente la estructura original en main?

Lo que dominamos hoy (Unidad 08)

• Pasar la estructura por valor: void imprimirPunto(struct Punto p).
• Acceder con el operador punto (.): p.x, alumno.nota1.
• Ideal para leer, mostrar y calcular.

Lo que viene en la Unidad 09

• Pasar la dirección de la estructura con un puntero: struct Empleado *emp.
• Conocer el famoso operador flecha (->): emp->salario.
• Modificar los campos originales en memoria sin copiar toda la estructura.

34 Resumen de la Unidad 08 y Checklist

Conceptos Clave (Secciones 26 a 29)

  • Una struct agrupa varios datos relacionados de distinto tipo bajo un mismo nombre (funciona como un molde).
  • El operador punto . entra a una cajita específica de la variable: persona1.edad = 20;.
  • Para cargar un campo String después de declarar la variable usamos strcpy(persona1.nombre, "Ana");.
  • Al pasar una struct por valor a una función, viaja una copia: podemos leer y calcular, pero el original en main no cambia.
