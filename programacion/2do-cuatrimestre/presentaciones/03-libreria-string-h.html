01 Hoja de Ruta y Conexión con la Unidad 02

Lo que aprendimos en la Unidad 02

  • Un String en C es un arreglo char[] terminado en '\0'.
  • No se pueden copiar ni comparar arreglos directamente con = ni con ==.
  • Programamos a mano un ciclo while para contar la longitud de un String.

Lo que vamos a dominar hoy (Sección 5 del Apunte)

  • Cómo incluir y aprovechar la librería estándar #include <string.h>.
  • Las funciones fundamentales: strlen, strcpy, strcmp y strcat.
  • Búsqueda de caracteres y subcadenas: strchr y strstr (y su diferencia con "empieza con").
  • Las versiones con cantidad de caracteres: strncpy, strncmp y strncat.

Definición del Apunte (págs. 5–6)

04 1. strlen() — Obtener la Longitud

strlen viene de string length (longitud del String). Cuenta cuántos caracteres tiene la cadena hasta encontrar el '\0'.

ejemplo_strlen.c Apunte pág. 6
#include <string.h> char cadena[] = "Hola"; int longitud = strlen(cadena); // ➔ longitud: 4
Pos 0 (1°)
'H'
Pos 1 (2°)
'o'
Pos 2 (3°)
'l'
Pos 3 (4°)
'a'
Pos 4 (Freno)
'\0'

¿Qué cuenta? Cuenta los caracteres hasta encontrar '\0'. Por eso la longitud es 4 (el '\0' no se cuenta).

05 2. strcpy() — Copiar un String

strcpy significa string copy. Sirve para copiar una cadena dentro de otra (incluyendo su '\0' final).

ejemplo_strcpy.c Apunte pág. 7
char origen[] = "Hola"; char destino[20]; strcpy(destino, origen);

¿Cómo quedan las variables ahora?

origen  ➔ "Hola"
destino ➔ "Hola"

⚠️ Regla de oro del orden

La sintaxis es strcpy(destino, origen);.
El destino va primero, igual que cuando escribís una asignación destino = origen.

07 3. strcmp() — ¿Por Qué Falla cadena1 == cadena2?

Advertencia Muy Importante del Apunte (pág. 7)

Si queremos saber si dos Strings son iguales, NO hacemos if(cadena1 == cadena2). Eso no compara el contenido de las cadenas, sino las direcciones de memoria donde están guardados los dos arreglos.

❌ Comparar con == (Siempre da falso)
char c1[] = "Hola"; char c2[] = "Hola"; if(c1 == c2) { // ¡MAL! printf("Son iguales"); }

Como c1 y c2 son dos arreglos distintos en la memoria RAM, c1 == c2 da falso aunque tengan las mismas letras.

✅ Comparar con strcmp() == 0
char c1[] = "Hola"; char c2[] = "Hola"; if(strcmp(c1, c2) == 0) { printf("Son iguales"); }

strcmp revisa letra por letra ambas cadenas y devuelve 0 cuando no encuentra ninguna diferencia.

08 ¿Qué Valores Devuelve strcmp(cadena1, cadena2)?

strcmp significa string compare. Resta los códigos ASCII en la primera letra donde difieren y devuelve:

Valor devuelto Significado (Apunte pág. 7) Ejemplo
0 Los Strings son exactamente iguales (0 diferencias) strcmp("Hola", "Hola") ➔ 0
< 0 (negativo) El primero es menor alfabéticamente que el segundo strcmp("Ana", "Juan") ➔ < 0
> 0 (positivo) El primero es mayor alfabéticamente que el segundo strcmp("Zorro", "Ana") ➔ > 0

💡 Cómo recordarlo sin confundirte: Pensá a strcmp como un "contador de diferencia": si devuelve 0, hay cero diferencias (son iguales). Por eso siempre preguntamos if(strcmp(a, b) == 0).

09 4. strcat() — Unir (Concatenar) Strings

strcat significa string catenate (concatenar). Sirve para agregar una cadena al final de otra.

sin_espacio.c Apunte pág. 8
char nombre[30] = "Juan"; char apellido[] = "Perez"; strcat(nombre, apellido); // Resultado en nombre: // "JuanPerez"
con_espacio.c Apunte pág. 8
char nombre[30] = "Juan "; char apellido[] = "Perez"; strcat(nombre, apellido); // Resultado en nombre: // "Juan Perez"

📌 Detalle importante: strcat no inventa espacios. Pega el segundo String exactamente donde estaba el '\0' del primero. Además, el primer arreglo (nombre[30]) debe tener capacidad suficiente para alojar ambas palabras.

strchr sirve para buscar un carácter dentro de un String. La función devuelve un puntero a la primera aparición encontrada (o NULL si ese carácter no está).

13 ¿Cómo Usamos strchr() en la Práctica?

Aunque veremos punteros en detalle más adelante, usar strchr para saber si una letra existe o no es súper fácil: comparamos contra NULL (que significa "no encontrado"):

buscar_letra.c Apunte pág. 8
#include <stdio.h> #include <string.h> int main() { char cadena[] = "banana"; char *resultado = strchr(cadena, 'a'); if(resultado != NULL) { printf("La letra 'a' esta en la palabra!\n"); printf("Resto desde 'a': %s\n", resultado); } else { printf("No se encontro.\n"); } return 0; }
Terminal Salida
$ ./buscar_letra La letra 'a' esta en la palabra! Resto desde 'a': anana

Como resultado apunta a la primera 'a' de "banana", imprimir %s desde ahí muestra "anana".

14 6. strstr() — Buscar un Substring (Subcadena)

Explicación del Apunte (págs. 8–9)

strstr sirve para buscar un String dentro de otro String. Si lo encuentra, devuelve un puntero a donde comienza ese substring (y si no lo encuentra, devuelve NULL).

ejemplo_strstr.c Apunte págs. 8–9
char cadena[] = "programacion"; char *encontrado = strstr(cadena, "gram");
p   r   o   g   r   a   m   a   c   i   o   n
↑ acá empieza "gram"

💡 Como destaca el apunte: esto simplifica muchísimo cualquier ejercicio que pida comprobar si una cadena contiene una subcadena.

15 7. strstr() vs Comprobar si "Empieza con"

Distinción Clave del Apunte (pág. 9)

No es lo mismo preguntar "¿Contiene la subcadena?" que preguntar "¿La cadena comienza con esta subcadena?".

Caso 1: "programacion" y "pro"

• ¿Contiene "pro"? ➔ Sí (strstr lo encuentra).
• ¿Comienza con "pro"? ➔ Sí (está al principio, desde la posición 0).

Caso 2: "programacion" y "gram"

• ¿Contiene "gram"? ➔ Sí (proGRAMacion).
• ¿Comienza con "gram"? ➔ No (empieza con "pro", aunque strstr() encuentre "gram" en el medio).

📌 Conclusión del Apunte: Para saber si una palabra comienza con un prefijo, debemos revisar específicamente las primeras posiciones (o usar strncmp como veremos en un instante).

16 La Familia con n: Operar con una Cantidad de Caracteres

Habrás notado en la tabla del apunte que strcpy, strcmp y strcat tienen hermanas con una letra n en el medio:

strncpy(d, o, n)

Copia solamente los primeros n caracteres de origen en destino.

strncmp(a, b, n)

Compara solamente los primeros n caracteres de ambas cadenas.

strncat(d, o, n)

Agrega al final de destino solamente los primeros n caracteres de origen.

💡 La letra n viene de number of characters (cantidad de caracteres). Veamos los ejemplos exactos del apunte para cada una.

17 8. strncpy() — Copiar una Cantidad de Caracteres

Es una versión de strcpy() que permite indicar cuántos caracteres copiar: strncpy(destino, origen, cantidad);

ejemplo_strncpy.c Apunte pág. 9
char origen[] = "Programacion"; char destino[20]; strncpy(destino, origen, 4); destino[4] = '\0'; // Cerramos el String manualmente // Copia: "Prog"

⚠️ Advertencia Importante del Apunte (pág. 9)

strncpy() no siempre agrega automáticamente '\0' si se copian exactamente los primeros n caracteres de una cadena más larga. Por eso, conviene hacer siempre: destino[4] = '\0';.

18 Visualizando en RAM qué Hace strncpy(destino, origen, 4)

Cuando copiamos solo 4 letras de "Programacion", el '\0' de "Programacion" está recién en la posición 12, ¡así que no entra en los primeros 4 caracteres!

✅ Al agregar destino[4] = '\0'; colocamos el terminador justo después de las 4 letras copiadas (posiciones 0, 1, 2 y 3), dejando formado el String "Prog".

19 9. strncmp() — Comparar una Cantidad de Caracteres

Es parecido a strcmp(), pero podemos decirle cuántos caracteres comparar desde el inicio: strncmp(cadena1, cadena2, cantidad);

ejemplo_strncmp.c Apunte pág. 10
int res = strncmp("Hola", "Hola mundo", 4); // ➔ devuelve 0

¿Qué compara exactamente?

Compara solamente los primeros 4 caracteres:
• Cadena 1 (primeros 4): "Hola"
• Cadena 2 (primeros 4): "Hola"
Como son iguales, devuelve 0.

¡Ideal para "Comienza con"!

¿Te acordás del problema de saber si "programacion" empieza con "pro"? Con strncmp(palabra, "pro", 3) == 0 lo resolvés en una línea.

20 10. strncat() — Concatenar una Cantidad Determinada

Es parecido a strcat(), pero permite especificar cuántos caracteres del segundo String queremos agregar: strncat(destino, origen, cantidad);

ejemplo_strncat.c Apunte pág. 10
char cadena[30] = "Hola "; char otra[] = "mundo123"; strncat(cadena, otra, 5); // Resultado en cadena: "Hola mundo"

🔍 ¿Por qué da "Hola mundo"? Porque de "mundo123" toma solamente los primeros 5 caracteres ("mundo"), los pega al final de "Hola " y agrega automáticamente el '\0' final.

26 Errores Frecuentes (Parte 1): Olvidar el == 0 en strcmp

Este es el error número 1 en parciales de programación en C:

❌ Olvidar == 0 (Lógica invertida)
if(strcmp(c1, c2)) { printf("Son iguales"); // ¡MAL! }

En C, el número 0 significa Falso. Como strcmp devuelve 0 cuando son iguales, escribir if(strcmp(c1, c2)) entra al if ¡cuando son distintas!

✅ Escribir siempre == 0
if(strcmp(c1, c2) == 0) { printf("Son iguales"); // ¡BIEN! }

Y si querés preguntar si dos Strings son distintos, escribí explícitamente: if(strcmp(c1, c2) != 0).

27 Errores Frecuentes (Parte 2): Desbordar el Arreglo Destino

Tanto en strcpy como en strcat, el primer arreglo (destino) debe tener casilleros libres suficientes:

❌ Destino demasiado chico
char nombre[] = "Juan "; // Tamaño exacto: 6 char apellido[] = "Perez"; strcat(nombre, apellido); // ¡Desborda memoria!

nombre[] = "Juan " reservó solo 6 casilleros. Al querer pegarle "Perez" (5 letras más), escribe fuera del arreglo.

✅ Reservar capacidad amplia
char nombre[30] = "Juan "; // 30 casilleros char apellido[] = "Perez"; strcat(nombre, apellido); // Entra perfecto

Como en el ejemplo del apunte (pág. 8), declaramos char nombre[30] para que sobre lugar al concatenar.

28 Errores Frecuentes (Parte 3): Invertir destino y origen

❌ Poner el origen primero
char origen[] = "Hola"; char destino[20]; strcpy(origen, destino); // ¡Al revés!

Esto copia la basura que había en destino adentro de origen, destruyendo la palabra "Hola".

✅ El destino SIEMPRE va primero
char origen[] = "Hola"; char destino[20]; strcpy(destino, origen); // destino <- origen

Tanto en strcpy, strncpy, strcat como en strncat, el primer parámetro es quien recibe el cambio.

29 Errores Frecuentes (Parte 4): strchr vs strstr

❌ Confundir carácter y subcadena
// Mal: "a" tiene comillas dobles en strchr strchr(cadena, "a"); // Mal: 'a' tiene comillas simples en strstr strstr(cadena, 'a');
✅ Cada función con su tipo
// strchr busca 1 carácter (comilla simple) strchr(cadena, 'a'); // strstr busca un String (comilla doble) strstr(cadena, "gram");

📌 Mirá el nombre de la función: strchr termina en chr (carácter ➔ 'a'); strstr termina en str (string ➔ "gram").

31 Buenas Prácticas Profesionales con <string.h>

Seguridad en copias y uniones

  • Verificá siempre que el arreglo destino tenga tamaño suficiente para todas las letras más el '\0'.
  • Cuando uses strncpy(destino, origen, n), escribí inmediatamente debajo destino[n] = '\0';.

Claridad en comparaciones y búsquedas

  • Escribí siempre strcmp(a, b) == 0, < 0 o > 0 para que la condición se lea sin ambigüedad.
  • En strchr y strstr, compará siempre el resultado con != NULL antes de usarlo.

32 Ejercicio de Aplicación 1: Comparar Longitudes e Igualdad

Enunciado del Ejercicio 1

Dadas dos palabras, escribí un programa que informe con strcmp si son exactamente iguales. Si no lo son, que muestre cuál de las dos tiene mayor cantidad de caracteres usando strlen.

💻 Ver solución paso a paso
#include <stdio.h> #include <string.h> int main() { char p1[] = "Hola"; char p2[] = "Programacion"; if(strcmp(p1, p2) == 0) { printf("Las palabras son iguales.\n"); } else if(strlen(p1) > strlen(p2)) { printf("%s es mas larga (%d letras).\n", p1, (int)strlen(p1)); } else { printf("%s es mas larga (%d letras).\n", p2, (int)strlen(p2)); } return 0; }

35 Resumen de la Unidad 03 y Checklist

Resumen de <string.h>

  • strlen(s): Longitud sin contar '\0' ("Hola" ➔ 4).
  • strcpy(dest, orig) / strncpy: Copia Strings (destino va primero; en strncpy cerrar con '\0').
  • strcmp(a, b) / strncmp: Devuelve 0 si son iguales, < 0 o > 0.
  • strcat(dest, orig) / strncat: Agrega al final del primer String.
  • strchr(s, 'a') y strstr(s, "gram"): Buscan un carácter o un substring.

Checklist de Autoevaluación

✓ ¿Sé por qué if(c1 == c2) falla y por qué debo usar strcmp(c1, c2) == 0?
✓ ¿Recuerdo que en strcpy(destino, origen) el destino va primero?
✓ ¿Entiendo la diferencia entre "Juan" + "Perez" y "Juan " + "Perez" en strcat?
✓ ¿Distingo entre contener una subcadena (strstr) y empezar con ella (strncmp)?
✓ ¿Recuerdo agregar destino[n] = '\0'; después de usar strncpy?
