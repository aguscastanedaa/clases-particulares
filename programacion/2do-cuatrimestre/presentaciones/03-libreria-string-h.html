Biblioteca <string.h> y Operaciones con Cadenas

El arsenal estándar de C para manipular texto: copiar, comparar, concatenar y buscar subcadenas con seguridad y eficiencia.

strlen & strcpy strcmp vs == strcat & strchr strstr & versiones seguras 'n'

01 La Biblioteca <string.h>

C proporciona funciones optimizadas en #include <string.h> para evitar reinventar la rueda en tareas comunes.

Función Propósito Sintaxis Canónica Precaución Clave
strlen() Obtiene longitud int n = strlen(s); No cuenta el '\0'
strcpy() Copia una cadena en otra strcpy(dest, orig); dest debe tener espacio suficiente
strcmp() Compara dos cadenas if (strcmp(a, b) == 0) Devuelve 0 si son idénticas
strcat() Concatena (une al final) strcat(dest, orig); dest debe soportar la suma de ambas
strchr() Busca un carácter char *p = strchr(s, 'c'); Retorna puntero o NULL si no existe
strstr() Busca una subcadena char *p = strstr(s, "sub"); Retorna puntero al inicio del substring
strncpy/cmp/cat Versiones limitadas a N bytes strncpy(dest, orig, N); Puede requerir dest[N] = '\0' manual

02 strlen() y strcpy()

1. strlen() — Longitud del texto

Viene de string length. Cuenta caracteres hasta encontrar '\0':

char cad[] = "Hola"; int len = strlen(cad); // len = 4

Ojo: cad ocupa 5 bytes en RAM, pero strlen devuelve 4 porque el '\0' no se cuenta como carácter del texto.

2. strcpy() — Copiar cadenas

En C no podemos hacer destino = origen;. Se usa strcpy:

char origen[] = "Hola"; char destino[20]; // Capacidad holgada strcpy(destino, origen);

⚠️ Regla: El destino va PRIMERO: strcpy(destino, origen). Copia todo incluyendo el '\0'.

03 La Gran Trampa: strcmp() vs ==

¿Por qué NUNCA debés hacer if (cad1 == cad2)?

En C, los nombres de los arreglos representan sus direcciones de memoria. Si hacés cad1 == cad2, el programa no compara si las palabras dicen lo mismo; está preguntando si ambas variables ocupan la misma dirección de memoria física, lo cual siempre será falso aunque ambas contengan "Hola".

comparar_strings.c strcmp
#include <stdio.h> #include <string.h> int main(void) { char c1[] = "Hola"; char c2[] = "Hola"; if (strcmp(c1, c2) == 0) { printf("Son iguales en contenido.\n"); } return 0; }

Valores de Retorno de strcmp

0
Son idénticas: Todos los caracteres y el '\0' coinciden exactamente.
<0
c1 es menor alfabéticamente (según orden ASCII) que c2.
>0
c1 es mayor alfabéticamente que c2.

💡 strcmp("Hola", "Hola") devuelve 0. ¡Por eso evaluamos == 0!

04 strcat() — Concatenar Cadenas

Unir una cadena al final de otra existente.

concatenar.c strcat
char nombre[30] = "Juan "; // Debe tener espacio libre suficiente char apellido[] = "Perez"; strcat(nombre, apellido); printf("%s\n", nombre); // Imprime: Juan Perez

Peligro Crítico: Desbordamiento de Búfer (Buffer Overflow)

strcat(nombre, apellido) busca el '\0' de nombre y a partir de ahí empieza a escribir las letras de apellido. Si nombre no fue declarado con una capacidad de casillas suficiente para albergar a ambas cadenas combinadas, pisará variables adyacentes en la memoria RAM, destruyendo el programa.

05 Búsqueda: strchr() y strstr()

strchr() — Buscar un Carácter

Busca un char y devuelve un puntero a su primera aparición:

char cadena[] = "banana"; char *pos = strchr(cadena, 'a'); if (pos != NULL) { printf("Encontrado: %s\n", pos); // Imprime: anana }

Si el carácter no existe en el texto, devuelve NULL.

strstr() — Buscar una Subcadena

Busca un string dentro de otro:

char texto[] = "programacion"; char *sub = strstr(texto, "gram"); if (sub != NULL) { printf("Subcadena hallada: %s\n", sub); // Imprime: gramacion }

Retorna el puntero donde arranca la subcadena. Si no está contenida, devuelve NULL.

06 strstr() vs "¿Comienza con...?"

Diferencia Lógica Fundamental

No es lo mismo contener una subcadena en cualquier posición que comenzar con ella:

Caso: "programacion" y "gram"

proGRAMacion
  • strstr(cad, "gram") ➔ SÍ la encuentra.
  • ¿Empieza con "gram"? ➔ NO (empieza con "pro").

Caso: "programacion" y "pro"

PROgramacion
  • strstr(cad, "pro") ➔ SÍ la encuentra.
  • ¿Empieza con "pro"? ➔ SÍ (los primeros caracteres coinciden).

07 Operaciones Seguras con Límite 'n': strncpy, strncmp y strncat

Permiten limitar la operación a un número máximo de caracteres para evitar desbordes.

strncpy(dest, orig, n)

Copia solo los primeros n caracteres:

char orig[] = "Programacion"; char dest[20]; strncpy(dest, orig, 4); dest[4] = '\0'; // Obligatorio

⚠️ Si no hay un '\0' dentro de los n bytes, strncpy NO lo agrega. Debemos agregarlo manualmente.

strncmp(c1, c2, n)

Compara únicamente los primeros n caracteres:

if (strncmp("Hola", "Hola mundo", 4) == 0) { // Devuelve 0: ¡Coinciden! }

Ideal para verificar prefijos y protocolos (ej. verificar si una URL empieza con "http").

strncat(dest, orig, n)

Agrega como máximo n caracteres del origen:

char cad[30] = "Hola "; strncat(cad, "mundo123", 5); // cad tiene: "Hola mundo"

A diferencia de strncpy, strncat siempre añade el '\0' al final.

08 Resumen y Autoevaluación

Puntos Clave del Módulo

  • Incluir siempre #include <string.h>.
  • strlen cuenta caracteres útiles sin el '\0'.
  • Nunca uses == para comparar texto; usá strcmp(a, b) == 0.
  • En strcpy y strcat, el destino va primero y debe tener espacio holgado.
  • strchr busca un carácter; strstr busca un texto completo.
  • Ambas devuelven un puntero a la posición o NULL si fallan.

Checklist de Autoevaluación

✓ ¿Sé qué valor devuelve strcmp("auto", "auto")? (0).
✓ ¿Por qué destino[20] = origen; da error de compilación?
✓ ¿Qué peligro conlleva concatenar en un arreglo de tamaño insuficiente?
✓ ¿Sé qué precaución tomar con el '\0' al usar strncpy?
