Condicionales: if y else

Enseñándole a la máquina a tomar decisiones: bifurcaciones, caminos alternativos y diagramas de flujo

01 Objetivos de Aprendizaje

¿Por qué los programas necesitan tomar decisiones?

Hasta ahora, nuestros programas eran como un tren en una sola vía recta: ejecutaban cada línea sin importar nada.

En la vida real, el camino depende de las circunstancias: "Si llueve, llevo paraguas; si no, voy con lentes de sol". Las **estructuras condicionales** le otorgan inteligencia al código, permitiendo elegir un camino u otro según los datos reales.

Metas de hoy

  • Aprender a leer e interpretar **diagramas de flujo**.
  • Simular paso a paso qué ocurre con edades de 16, 18 y 20 años.
  • Resolver 3 problemas clásicos: mayoría de edad, signo numérico y paridad.

  • Evitar el mortal punto y coma tras el paréntesis del if.

02 El Ejemplo Canónico de Mayoría de Edad

El código fundamental de toma de decisiones en C:

mayoria_edad.c if - else
if (edad >= 18) { printf("Es mayor de edad\n"); } else { printf("Es menor de edad\n"); }
1
if (edad >= 18) ➔ Evalúa la condición entre paréntesis. ¿Es verdadera (1) o falsa (0)?
2
Si es VERDADERA: Entra al primer bloque entre llaves e imprime "Es mayor de edad". El bloque else es **totalmente ignorado y salteado**.
3
Si es FALSA: Saltea el primer bloque y salta directamente al bloque else, imprimiendo "Es menor de edad".

La Regla de Exclusión Mutua

En una estructura if - else, nunca jamás se pueden ejecutar ambos bloques a la vez, ni tampoco quedarse sin ejecutar ninguno. Se elige exactamente uno de los dos caminos según la condición.

05 Problema 2: Número Positivo, Negativo o Cero

¿Qué pasa si hay más de 2 alternativas? Usamos else if en cascada:

signo_numero.c if - else if - else
if (numero > 0) { printf("El número es POSITIVO\n"); } else if (numero < 0) { printf("El número es NEGATIVO\n"); } else { printf("El número es CERO (Neutro)\n"); }

💡 Cómo funciona la cascada: C evalúa la primera condición. Si es verdadera, ejecuta su bloque y salta al final de toda la estructura. Si es falsa, pasa al else if. Si todas fallan, cae en el else por descarte.

06 Problema 3: Determinar si un Número es Par

Combinando el operador módulo % con una decisión condicional:

par_impar.c Módulo + if
#include <stdio.h> int main(void) { int numero; printf("Ingresa un número entero: "); scanf("%d", &numero); if (numero % 2 == 0) { printf("El número %d es PAR\n", numero); } else { printf("El número %d es IMPAR\n", numero); } return 0; }

07 Condicionales Anidados (Complementario)

¿Qué es un if anidado?

Es simplemente colocar una estructura if **adentro del bloque de otro if**.

Se utiliza cuando una segunda decisión solo tiene sentido si la primera ya se cumplió previamente (decisiones subordinadas).

anidados.c
if (edad >= 18) { if (tieneLicencia == true) { printf("Puede manejar\n"); } else { printf("Mayor, pero sin carnet\n"); } }

08 Los Dos Errores Clásicos con if

❌ Error 1: Punto y coma tras el if
if (edad >= 18); // ¡PUNTO Y COMA TRÁGICO! { printf("Mayor\n"); }

El ; cierra el if inmediatamente en una instrucción vacía. El bloque de abajo **se ejecutará siempre**, sin importar la edad.

⚠️ Error 2: Omitir llaves {}
if (edad >= 18)
  printf("Paso 1\n");
  printf("Paso 2\n"); // ¡Se ejecuta siempre!

Sin llaves, solo la primera línea pertenece al if. **Regla de oro: poné llaves {} SIEMPRE.**

09 Resumen de la Unidad y Checklist

Puntos Clave

  • if (condicion): Ejecuta solo si es verdadera.
  • else: El camino obligatorio si la condición fue falsa.
  • else if: Encadena múltiples condiciones en cascada.
  • Llaves { }: Agrupan instrucciones en un bloque protegido.
  • ¡Nunca! pongas punto y coma luego del if (...).
