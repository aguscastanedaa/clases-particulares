Variables en C

La memoria de tus programas: cómo almacenar, modificar y manipular información en tiempo de ejecución

Cajas de Memoria Declaración & Asignación Inicialización = vs ==

💡 Guía de navegación: Usá la barra espaciadora o las flechas del teclado (→ / ←) para avanzar diapositiva por diapositiva.

01 Objetivos de Aprendizaje

¿Para qué sirve una variable?

Un programa que no recuerda datos no puede hacer nada útil. Necesita recordar vidas restantes, puntajes, nombres, precios, resultados matemáticos intermedios y mediciones.

Las variables son el mecanismo que nos brinda el lenguaje para darle nombre a espacios de la memoria RAM y trabajar con datos dinámicos que cambian con el tiempo.

Metas que vas a dominar hoy

  • Comprender la analogía de las cajas etiquetadas en RAM.
  • Identificar los 3 atributos de toda variable: Nombre, Tipo y Valor.
  • Diferenciar declaración, asignación e inicialización.
  • Entender cómo se sobrescribe un valor en memoria.
  • Dominar la diferencia fundamental entre = y ==.
  • Aplicar las reglas correctas para nombrar variables en C.
  • Interpretar tablas de seguimiento paso a paso.

02 La Analogía de las Cajas con Nombre

Imaginate una estantería infinita llena de cajas organizadas:

1. El Nombre (Identificador)

Es la etiqueta pegada al frente de la caja. Te permite referirte a ella sin tener que memorizar su compleja dirección numérica hexadecimal de memoria.

Ej: edad, precio

2. El Tipo de Dato

Es el tamaño y compartimento interno de la caja. Le dice a la computadora qué clase de cosas entran allí (números enteros, decimales, letras).

Ej: int, float, char

3. El Valor

Es el objeto real guardado dentro de la caja en este momento. Este contenido puede cambiar tantas veces como quieras.

Ej: 16, 1.75, 'A'

03 Declaración: Creando las Cajas

Veamos los ejemplos obligatorios de declaración en C:

declaraciones.c Declaración
int edad; float altura; char inicial; int otraEdad = 16;
1
int edad; ➔ Reserva memoria para un número entero llamado edad. Aún no tiene un valor asignado por nosotros (contiene "basura" de memoria).
2
float altura; ➔ Reserva memoria para un número decimal con coma flotante llamado altura.
3
char inicial; ➔ Reserva memoria de 1 byte para un único carácter alfanumérico llamado inicial.
4
int otraEdad = 16; ➔ Declaración con inicialización: Crea la caja y deposita inmediatamente el número 16 en el mismo acto.

04 Los 3 Momentos de una Variable

1. Declaración

Crear la variable avisándole al compilador su nombre y tipo.

int vidas;

La caja existe, pero su contenido es indefinido.

2. Asignación

Guardar un dato dentro de una variable ya existente mediante el signo =.

vidas = 3;

Ahora la caja contiene el valor 3.

3. Inicialización

Combinar los dos pasos anteriores en una única línea elegante.

int vidas = 3;

Nace directamente con su valor inicial seguro.

⚠️ ¡Regla de oro profesional!: Siempre que puedas, inicializá tus variables. Si lees una variable sin inicializar, C te devolverá cualquier número aleatorio residual ("basura") que haya quedado en esa celda de memoria RAM.

05 Modificación del Valor Almacenado

Una variable solo puede contener un único valor a la vez. Cuando asignás uno nuevo, el anterior se destruye:

modificacion.c Seguimiento
int score = 0; // Paso 1 score = 100; // Paso 2 score = 250; // Paso 3
Variable: score
RAM
250

(0 y 100 fueron eliminados)

Uso de variables en expresiones

Podés usar el valor de una variable para calcular el de otra sin modificar la original:
int bonus = score + 50; ➔ score sigue valiendo 250, mientras que bonus recibe 300.

06 Tabla de Seguimiento (Traza de Memoria)

Veamos cómo el procesador actualiza la RAM línea por línea:

Línea Ejecutada Acción Realizada Valor de a Valor de b Valor de c
int a = 10; Se crea 'a' con valor inicial 10 10 no existe no existe
int b = 5; Se crea 'b' con valor inicial 5 10 5 no existe
int c = a + b; Se calcula 10 + 5 y se guarda en 'c' 10 5 15
a = 20; Se sobreescribe 'a' con 20 20 (cambió) 5 15 (no cambia)
b = a * 2; Se busca 'a' (20) * 2 = 40 en 'b' 20 40 (cambió) 15

✓ Notá cómo cada asignación solo modifica la variable que está a la izquierda del =.

07 ¡ALERTA CRÍTICA!: Diferencia entre = y ==

Confundir estos dos operadores es el origen del 50% de los errores en programación:

El Operador = (UN SOLO SIGNO)

Es una ASIGNACIÓN (ACCIÓN)

Significa: "Tomá lo que está a la derecha y guardalo dentro de la caja de la izquierda".

edad = 18; // Guarda 18 en edad
El Operador == (DOS SIGNOS JUNTOS)

Es una COMPARACIÓN (PREGUNTA)

Significa: "¿El valor guardado a la izquierda es igual al de la derecha?". Devuelve verdadero o falso. No modifica ninguna caja.

edad == 18; // ¿Tiene edad el valor 18?

08 Reglas para Nombrar Variables en C

Reglas Obligatorias del Compilador

  • Solo pueden contener letras (a-z, A-Z), números (0-9) y guiones bajos (_).
  • Nunca pueden empezar con un número (2daEdad es inválido; edad2 es válido).
  • No se permiten espacios ni símbolos extraños (mi edad es inválido; mi_edad es válido).
  • No usar palabras reservadas de C (como int, float, return, main, if).

Buenas Prácticas Profesionales

  • Usá nombres descriptivos: precioFinal en vez de p o x.
  • Convención camelCase: primera palabra en minúscula y cada siguiente palabra con mayúscula (edadUsuario, puntosMaximos).
  • O convención snake_case: todo en minúsculas separado por guiones bajos (edad_usuario).

09 Errores Frecuentes con Variables

❌ Errores Clásicos

• Usar una variable sin declararla previamente:
  total = 100; ➔ error: 'total' undeclared
• Declarar dos veces la misma variable en el mismo bloque:
  int edad = 15; int edad = 20; ➔ redefinition
• Invertir el orden de la asignación:
  16 = edad; ➔ ¡La caja siempre va a la izquierda!

✅ Forma Correcta

• Declarar primero, usar después:
  int total; total = 100;
• Modificar sin volver a declarar:
  int edad = 15; edad = 20;
• Destino a la izquierda, valor a la derecha:
  edad = 16;

10 Desafío de Seguimiento: Predicción

Leé el siguiente código y resolvé mentalmente:

desafio_variables.c ¿Cuánto valen x e y?
int x = 8; int y = 3; x = x + y; y = x - y; x = x - y;

🔮 Pregunta: Al finalizar todas las líneas, ¿cuánto vale x y cuánto vale y?

👉 Clic acá para ver el resultado paso a paso

¡Resultado: x = 3 e y = 8! (¡Se intercambiaron los valores!)

  1. x = x + y ➔ 8 + 3 = 11. Ahora x = 11.
  2. y = x - y ➔ 11 - 3 = 8. Ahora y = 8 (el valor original de x).
  3. x = x - y ➔ 11 - 8 = 3. Ahora x = 3 (el valor original de y).

💡 Este es un famoso truco clásico de programación para intercambiar dos variables sin usar una tercera variable auxiliar.

11 Resumen de la Unidad y Checklist

Puntos Cardinales

  • Variable: Espacio de memoria con nombre, tipo y valor.
  • Declaración: Reserva la caja (int x;).
  • Asignación: Guarda el valor (x = 5;).
  • Sobreescritura: El valor nuevo reemplaza al anterior.
  • = vs ==: = guarda, == compara.
