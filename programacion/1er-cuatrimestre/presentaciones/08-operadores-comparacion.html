Operadores de Comparación

Hacer preguntas a la máquina: igualdad, desigualdad, orden y valores de verdad en C

== (Igual a) != (Distinto de) >, < (Mayor y Menor) >=, <= (Mayor/Menor o Igual)

💡 Guía de navegación: Usá la barra espaciadora o las flechas del teclado (→ / ←) para avanzar diapositiva por diapositiva.

01 Objetivos de Aprendizaje

¿Qué es una comparación?

Para que un programa tome decisiones inteligentes (por ejemplo: dejar pasar a un usuario, cobrar un descuento o avisar que se agotaron las vidas), primero debe ser capaz de **comparar dos valores**.

Una comparación es una **pregunta lógica**. A diferencia de una suma (que da otro número), una comparación solo puede responder una de dos cosas: **Verdadero (1)** o **Falso (0)**.

Lo que vas a dominar en esta clase

  • Comprender el concepto de **expresión relacional**.
  • Dominar los 6 operadores: ==, !=, >, <, >=, <=.
  • Aprender a formular cada comparación como una **pregunta clara**.
  • Analizar tablas de evaluación con edades de 16, 18 y 20 años.
  • Blindar tu código contra el error más destructivo: if (x = 10).
  • Preparar el terreno para las estructuras condicionales (if / else).

02 El Arsenal de los 6 Operadores

Los 6 símbolos con los que evaluamos relaciones en C:

Operador Nombre Formal Pregunta que le hace a la CPU Ejemplo de Código
== Igual a ¿Es el valor de la izquierda idéntico al de la derecha? edad == 18
!= Distinto de ¿Son los valores diferentes entre sí? edad != 18
> Mayor que ¿Es el de la izquierda estrictamente mayor? edad > 18
< Menor que ¿Es el de la izquierda estrictamente menor? edad < 18
>= Mayor o igual que ¿Es el de la izquierda mayor o exactamente igual? edad >= 18
<= Menor o igual que ¿Es el de la izquierda menor o exactamente igual? edad <= 18

03 Los 6 Ejemplos Obligatorios con edad

Veamos las 6 expresiones requeridas formuladas como preguntas cotidianas:

1. edad == 18

Pregunta: ¿Tiene exactamente 18 años?

Solo es verdadero si edad vale 18.

2. edad != 18

Pregunta: ¿Tiene una edad distinta a 18?

Es verdadero para cualquier edad salvo el 18.

3. edad > 18

Pregunta: ¿Es estrictamente mayor a 18?

Verdadero si tiene 19, 20, 21... (si tiene 18, es falso).

4. edad < 18

Pregunta: ¿Es estrictamente menor a 18?

Verdadero si tiene 17, 16, 15... (si tiene 18, es falso).

5. edad >= 18

Pregunta: ¿Tiene 18 o más años?

¡Incluye al 18! Verdadero para 18, 19, 20...

6. edad <= 18

Pregunta: ¿Tiene 18 o menos años?

¡Incluye al 18! Verdadero para 18, 17, 16...

04 Tabla de Evaluación: Tres Valores a Prueba

Simulemos las 6 comparaciones para tres alumnos de 16, 18 y 20 años:

Expresión Si edad = 16 Si edad = 18 Si edad = 20
edad == 18 FALSO (0) VERDADERO (1) FALSO (0)
edad != 18 VERDADERO (1) FALSO (0) VERDADERO (1)
edad > 18 FALSO (0) FALSO (0) ⚠️ VERDADERO (1)
edad < 18 VERDADERO (1) FALSO (0) ⚠️ FALSO (0)
edad >= 18 FALSO (0) VERDADERO (1) ✓ VERDADERO (1)
edad <= 18 VERDADERO (1) VERDADERO (1) ✓ FALSO (0)

👀 ¡Prestá especial atención a la columna del 18!: Con > da FALSO, pero con >= da VERDADERO. El igual incluido en >= y <= marca la diferencia en las fronteras.

05 El Peligro Mortal: = vs ==

❌ Lo que muchos principiantes escriben
if (edad = 18) // ¡UN SOLO SIGNO IGUAL!

¿Qué hace C realmente?: C **no compara**. Toma el 18 y lo guarda dentro de edad. Luego evalúa el valor 18, que como no es cero, ¡es considerado **SIEMPRE VERDADERO**! El código ejecutará el bloque sin importar qué edad tenía antes.

✅ La forma correcta con doble igual
if (edad == 18) // ¡DOBLE SIGNO IGUAL!

Lo que hace C: Comprueba sin modificar la memoria si edad tiene guardado el número 18.

06 Comparando Variables entre Sí

Podés comparar una variable contra un número fijo (constante) o dos variables entre sí:

comparacion_dos_variables.c Duelo de Variables
int puntuacionJugador1 = 450; int puntuacionJugador2 = 500; // ¿Ganó el jugador 2? bool ganoJugador2 = (puntuacionJugador2 > puntuacionJugador1); // ¿Hubo empate? bool huboEmpate = (puntuacionJugador1 == puntuacionJugador2);

Guardar el resultado de una comparación

Como ves arriba, el resultado de (puntuacionJugador2 > puntuacionJugador1) es un valor lógico (true / 1) que podés almacenar directamente adentro de una variable bool.

07 Desafío de Predicción: Verdadero o Falso

Dadas las variables int a = 7; int b = 10;, determiná mentalmente si cada expresión es 1 (Verdadera) o 0 (Falsa):

A) a + 3 == b
B) a != b - 3
C) b / 2 >= a
D) a <= 7
👉 Clic acá para verificar tus respuestas
  • A) 7 + 3 == 10 ➔ 10 == 10 ➔ VERDADERO (1).
  • B) 7 != 10 - 3 ➔ 7 != 7 ➔ FALSO (0) (porque 7 sí es igual a 7).
  • C) 10 / 2 >= 7 ➔ 5 >= 7 ➔ FALSO (0) (5 es menor que 7).
  • D) 7 <= 7 ➔ VERDADERO (1) (por el componente "o igual").

08 Resumen de la Unidad y Checklist

Puntos Clave

  • Toda comparación produce 1 (verdadero) o 0 (falso).
  • == compara igualdad; != compara desigualdad.
  • >= y <= incluyen el valor límite.
  • = es asignar, == es comparar (nunca los confundas).
  • Las comparaciones son la condición de entrada para los condicionales.
