Estructura de un Programa en C

Anatomía completa del esqueleto fundamental de todo código en C: de "Hola Mundo" al ejecutable

#include & Bibliotecas Función main() Llaves {} y Punto y Coma ; Compilación y Errores

💡 Guía de navegación: Usá la barra espaciadora o las flechas del teclado (→ / ←) para avanzar diapositiva por diapositiva.

01 Objetivos de Aprendizaje

¿Qué es el Lenguaje C?

Creado en 1972 por Dennis Ritchie en los Laboratorios Bell. Es uno de los lenguajes más influyentes y veloces de la historia.

Los sistemas operativos más importantes del planeta (el núcleo de Linux, gran parte de Windows y macOS), motores de bases de datos y sistemas embebidos de autos y aviones están programados en C. Además, lenguajes como C++, C#, Java, JavaScript y PHP heredaron su sintaxis de C.

Lo que vas a dominar en esta clase

  • Comprender el ciclo de compilación (código fuente → ejecutable).
  • Entender qué hace #include <stdio.h> y qué es una biblioteca.
  • Aprender por qué main() es la puerta de entrada obligatoria.
  • Descubrir el rol sagrado de las llaves {} y del punto y coma ;.
  • Entender el significado real de return 0;.
  • Reconocer y corregir los 5 errores de sintaxis más comunes.

02 ¿Cómo se ejecuta un programa en C?

A diferencia de otros lenguajes que se interpretan al vuelo, C es un lenguaje compilado:

1
Código Fuente (programa.c)
Es el texto legible escrito por vos en un editor de texto o entorno de desarrollo (IDE).
2
El Compilador (ej. GCC o Clang)
Un software traductor ultrarrápido que analiza la sintaxis, detecta errores y traduce el código C a código máquina binario (ceros y unos) que el procesador entiende directamente.
3
Archivo Ejecutable (programa.exe o binario)
El archivo final que el sistema operativo puede ejecutar directamente a máxima velocidad nativa, sin requerir ningún intermediario.

03 El Código Inicial Canónico

Este es el esqueleto mínimo y estándar de un programa en C:

hola_mundo.c C99 / C11
#include <stdio.h> int main(void) { printf("Hola mundo\n"); return 0; }
Terminal de Salida
$ gcc hola_mundo.c -o hola_mundo $ ./hola_mundo Hola mundo

A continuación, vamos a diseccionar cada palabra, carácter y símbolo sin dejar ningún misterio sin resolver.

04 ¿Para qué sirve #include y qué son las bibliotecas?

¿Qué es una Biblioteca (Librería)?

En programación no reinventamos la rueda cada vez. Una biblioteca (*header file*, extensión .h) es un paquete con cientos de funciones prefabricadas y optimizadas por expertos.

Tu computadora por defecto no sabe cómo comunicarse con el monitor para dibujar letras. Esa tarea tan compleja ya está resuelta adentro de la biblioteca estándar de C.

La Directiva #include

La almohadilla # le avisa al preprocesador que actúe antes de compilar. #include significa literalmente: "Copiar e incluir en este archivo todas las declaraciones de esa biblioteca".

#include <stdio.h>

Los signos menor y mayor < > indican que es una biblioteca del sistema estándar de C.

05 Las dos bibliotecas esenciales

1. <stdio.h> (Standard Input Output)

Su nombre viene de STanDard Input / Output Header (Cabecera Estándar de Entrada y Salida).

  • Nos proporciona printf() para mostrar texto y números en la pantalla.
  • Nos proporciona scanf() para leer lo que el usuario tipea en el teclado.
  • Sin ella: El compilador dará error al encontrar printf porque no sabrá qué significa.

2. <stdbool.h> (Standard Boolean)

Introducida en el estándar C99 (hace ya más de dos décadas).

  • Permite usar el tipo bool para valores de verdad.
  • Define las constantes lógicas true (verdadero) y false (falso).
  • La utilizaremos ampliamente cuando lleguemos a la unidad de booleanos y condicionales.

06 La función main(): El Punto de Entrada

¿Por qué se llama main y por qué es obligatoria?

En inglés, main significa "principal". En C, la función main es por convención y estándar internacional el punto de entrada obligatorio de cualquier programa convencional. Cuando hacés doble clic en un ejecutable o lo lanzás desde la terminal, el sistema operativo busca la función main() y empieza a ejecutar la primera instrucción que encuentra adentro.

int main(void)

int

Indica que al terminar, la función devolverá un número entero de estado al sistema operativo.

main

El nombre reservado e inmutable que busca el sistema operativo para iniciar.

(void)

Palabra que en C significa "vacío": explicita formalmente que nuestro programa no recibe argumentos externos de inicio.

07 Las Llaves {} y el Punto y Coma ;

Las Llaves { } : Delimitadores de Bloque

Las llaves delimitan las fronteras del código:

  • { marca el inicio del cuerpo de la función.
  • } marca el fin definitivo de la función.

Todo lo que esté entre esas llaves pertenece a main y se ejecutará en ese bloque.

El Punto y Coma ; : Fin de Sentencia

En nuestro idioma usamos un punto al final de cada oración para que el lector sepa dónde termina la idea.

En C, el compilador ignora los espacios en blanco y los saltos de línea. La única forma en que sabe que una instrucción terminó y empieza la siguiente es con el punto y coma ;.

¡Olvidar el ; es el error número 1 de todo principiante!

08 printf() y el significado de return 0;

printf("Hola mundo\n");

Es una llamada a la función de impresión de <stdio.h>.

  • El texto a imprimir va encerrado entre comillas dobles " ".
  • El símbolo \n es un carácter de escape especial que significa newline (salto de línea, equivalente a presionar Enter).

return 0;

Es la despedida formal del programa:

  • Devuelve el valor numérico 0 al sistema operativo (Windows, Linux o macOS).
  • En los sistemas operativos estándar, un código de retorno 0 significa: "El programa finalizó con total éxito, sin errores".
  • Cualquier número distinto de cero suele indicar un código de fallo o anomalía.

09 Los 5 errores típicos de principiantes

❌ Lo que nunca debés hacer

1. Main() con M mayúscula (C es case-sensitive, distingue mayúsculas).
2. Olvidar el punto y coma: printf("Hola").
3. No cerrar la llave: olvidar el } final.
4. Usar comillas curvas de procesador de texto: “Hola” en vez de "Hola".
5. Olvidar #include <stdio.h>.

✅ La forma correcta e impecable
#include <stdio.h>

int main(void)
{
    printf("Hola mundo\n");
    return 0;
}

11 Resumen de la Unidad y Checklist

Síntesis del Esqueleto en C

  • #include: Carga las bibliotecas necesarias.
  • stdio.h: Permite usar printf y scanf.
  • int main(void): El punto de entrada obligatorio del programa.
  • { }: Delimitan el cuerpo y bloque de instrucciones.
  • ;: Marca el final de cada instrucción.
  • return 0;: Notifica al SO que el programa terminó bien.
