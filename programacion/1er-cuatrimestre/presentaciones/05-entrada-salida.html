Entrada y Salida de Datos

Haciendo programas interactivos: comunicación entre el usuario humano y el código mediante printf y scanf

printf() & Formatos scanf() & Operador & %d, %f, %c Flujo Completo de Datos

💡 Guía de navegación: Usá la barra espaciadora o las flechas del teclado (→ / ←) para avanzar diapositiva por diapositiva.

01 Objetivos de Aprendizaje

¿Por qué este salto es emocionante?

Hasta ahora nuestros programas tenían datos fijos escritos en el código. Para cambiar un número teníamos que editar el archivo y recompilar.

Con la Entrada y Salida (E/S) tus programas cobran vida: le preguntan datos al usuario en vivo, esperan su respuesta por teclado, procesan la información y devuelven respuestas personalizadas en pantalla.

Metas de hoy

  • Distinguir con claridad entre Input (Entrada) y Output (Salida).
  • Dominar printf() para mostrar texto y variables combinadas.
  • Comprender los especificadores de formato: %d, %f, %c.
  • Entender qué significa el operador ampersand & en scanf().
  • Seguir el viaje completo del dato desde el teclado a la RAM y al monitor.
  • Detectar y evitar los errores más peligrosos de lectura.

02 El Programa Canónico Interactivo

Leé con atención este programa completo y probalo mentalmente:

pedir_edad.c C99 con stdio.h
#include <stdio.h> int main(void) { int edad; printf("Ingresa tu edad: "); scanf("%d", &edad); printf("Tu edad es %d\n", edad); return 0; }
Simulación en Terminal
$ ./pedir_edad Ingresa tu edad: 16 Tu edad es 16

03 El Viaje Completo de la Información

¿Qué pasa exactamente milisegundo a milisegundo al ejecutar este programa?

1
int edad; ➔ El sistema operativo reserva 4 bytes en la RAM (ej. dirección 0x7ffd10) etiquetados como edad.
2
printf("Ingresa tu edad: "); ➔ Envía los caracteres a la pantalla y deja el cursor titilando esperando al usuario.
3
scanf("%d", &edad); ➔ El programa se pausa por completo. El usuario escribe 16 y presiona Enter. scanf traduce los caracteres '1' y '6' al número binario entero 16 y lo guarda en la dirección dada por &edad.
4
printf("Tu edad es %d\n", edad); ➔ La CPU lee el 16 de la caja edad, lo reemplaza donde estaba el comodín %d y lo proyecta en la terminal.

04 Especificadores de Formato

¿Qué es un especificador de formato?

Es un comodín o marcador de posición que empieza con el símbolo porcentaje %. Le indica a printf y a scanf qué tipo de dato debe esperar y cómo debe transformarlo.

Especificador Tipo de Dato Uso en printf() Uso en scanf()
%d (o %i) int (Entero con signo) printf("%d", edad); scanf("%d", &edad);
%f float (Decimal) printf("%.2f", precio); scanf("%f", &precio);
%c char (Carácter único) printf("%c", letra); scanf(" %c", &letra);
%lf (complemento) double (Decimal doble precisión) printf("%f", d); scanf("%lf", &d);

💡 Nota pedagógica sobre %f y %lf: Para variables de tipo float, se utiliza siempre %f tanto al leer con scanf como al imprimir con printf. La mención de %lf (*long float*) aplica solo para variables de tipo double al momento de leer.

05 El Misterio del Operador & en scanf

Analogía del Cartero

Imaginá que le pedís al cartero que te entregue un paquete:

• Si le das edad: le estás dando una foto de lo que hay adentro de tu casa en este momento.
• Si le das &edad: le estás dando la dirección postal exacta de tu casa para que vaya y deposite el paquete adentro.

scanf necesita guardar un dato nuevo, por lo tanto necesita saber la dirección de memoria dónde guardarlo.

El Operador de Dirección (Address-of)

El símbolo & se llama formalmente operador de dirección.

&edad = 0x7ffd10
edad (int)
16

&edad le entrega a scanf el puntero 0x7ffd10 para que escriba directamente en esa celda de memoria RAM.

06 Dominando printf(): Múltiples Datos

Podés imprimir varias variables en una misma línea manteniendo el orden exacto:

multiples_variables.c Interpolación
int dia = 25; char mesInicial = 'M'; float temp = 22.458f; // Los comodines se reemplazan en orden estricto de izquierda a derecha: printf("Fecha: %d - Mes: %c - Temperatura: %.1f °C\n", dia, mesInicial, temp);
Salida: Fecha: 25 - Mes: M - Temperatura: 22.5 °C

🎯 Control de decimales: Con %.1f mostramos solo 1 decimal (redondea visualmente a 22.5). Con %.2f mostramos 2 decimales (22.46). Si ponés %f a secas, C mostrará 6 decimales por defecto (22.458000).

07 Errores Clásicos con scanf y printf

❌ El Error Más Grave: Olvidar el &
scanf("%d", edad); // ¡FALTA EL &!

Consecuencia: scanf interpretará el valor actual de edad como una dirección de memoria y tratará de escribir en un lugar prohibido. Tu programa colapsará con un Segmentation Fault (Crash) instantáneo.

⚠️ Poner \n dentro de scanf
scanf("%d\n", &edad); // ¡NO PONGAS \n ACÁ!

Consecuencia: El \n dentro del texto de scanf hace que el programa quede esperando infinitamente otro espacio o número adicional antes de continuar.

08 Programa Completo: Calculadora de Promedio

Un programa real que solicita dos notas y calcula el promedio con decimales:

promedio.c Programa Completo
#include <stdio.h> int main(void) { float nota1, nota2; printf("Ingresa la primera nota: "); scanf("%f", &nota1); printf("Ingresa la segunda nota: "); scanf("%f", &nota2); float promedio = (nota1 + nota2) / 2.0f; printf("El promedio final es: %.2f\n", promedio); return 0; }

09 Resumen de la Unidad y Checklist

Puntos Esenciales

  • printf(): Muestra texto y valores formateados en pantalla.
  • scanf(): Lee datos del teclado y pausa la ejecución.
  • %d, %f, %c: Especificadores para entero, float y char.
  • & (ampersand): Operador de dirección obligatorio en variables numéricas con scanf.
  • %.2f: Formatea la salida a 2 lugares decimales.
