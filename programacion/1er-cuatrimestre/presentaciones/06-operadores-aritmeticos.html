01 Objetivos de Aprendizaje

La computadora como supercalculadora

En el corazón de todo programa (desde la física de un videojuego 3D hasta un sistema contable) hay operaciones aritméticas constantes.

Sin embargo, las computadoras no hacen matemáticas exactamente igual que un ser humano con lápiz y papel. Hay reglas estrictas sobre cómo se dividen números enteros y cómo se calcula el resto.

Lo que vas a dominar en esta clase

  • Utilizar los 5 operadores aritméticos: +, -, *, /, %.
  • Entender por qué 7 / 2 da 3 y cómo obtener 3.5.
  • Comprender el operador módulo % y por qué es tan valioso.
  • Aplicar el criterio de divisibilidad numero % divisor == 0.
  • Determinar matemáticamente si un número es par o impar.
  • Dominar la precedencia y el uso de paréntesis.

03 ¿Por qué 7 / 2 produce 3?

La Regla de la División Entera

En C, cuando **ambos operandos son de tipo entero (int)**, el operador / realiza una división matemática entera (cociente euclidiano):

$7 \div 2 = 3$ y sobra $1$.
C simplemente se queda con el cociente entero (3) y **descarta/trunca** cualquier decimal. No redondea al más cercano: $7 / 2$ es $3$, y $9 / 10$ es $0$.

¿Cómo obtener el 3.5 con decimales?

Para que la división calcule decimales, **al menos uno de los números debe ser de tipo decimal (float o double)**:

float divDecimal = 7.0f / 2.0f; // Da 3.5 float divDecimal2 = 7.0f / 2; // Da 3.5

Al haber al menos un decimal, C convierte automáticamente toda la cuenta al dominio de números reales.

04 El Operador Módulo % (El Resto)

¿Qué hace exactamente?

El operador % no calcula un porcentaje. En programación, calcula el RESTO (sobrante) de la división entera entre dos números.

10 % 3 = 1

3 entra 3 veces en 10 (hace 9). Para llegar a 10 sobra 1.

14 % 5 = 4

5 entra 2 veces en 14 (hace 10). Para llegar a 14 sobran 4.

12 % 4 = 0

4 entra exactamente 3 veces en 12. ¡No sobra nada! Resto 0.

⚠️ Regla estricta de C: El operador % solo funciona con enteros (int). Intentar hacer 7.5 % 2 causará un error de compilación.

05 El Criterio de Divisibilidad

Una de las herramientas lógicas más utilizadas en la informática:

numero % divisor == 0
1
¿Por qué funciona?
Si el resto de dividir un número por otro es exactamente cero, significa que la división es **exacta**, es decir, no sobró nada. Por ende, numero es divisible por divisor (siempre que el divisor no sea cero).
2
El detector de Números Pares e Impares:
• Un número es par si al dividirlo por 2 sobra 0: numero % 2 == 0.
• Un número es impar si al dividirlo por 2 sobra 1: numero % 2 != 0.

06 Aplicaciones Prácticas de / y %

Descomponer Segundos en Minutos y Segundos

Si pasaron 135 segundos, ¿cuántos minutos y segundos son?

int totalSeg = 135; int minutos = totalSeg / 60; // 135 / 60 = 2 int segundos = totalSeg % 60; // 135 % 60 = 15

Resultado: 2 minutos y 15 segundos. ¡Combinación perfecta de / y %!

Reparto Equitativo y Sobrante

Repartir 23 caramelos entre 4 amigos:

int caramelos = 23, amigos = 4; int porAmigo = caramelos / amigos; // 5 int sobran = caramelos % amigos; // 3

Cada amigo recibe 5 caramelos y sobran 3 en el paquete.

07 Precedencia: El Orden de las Operaciones

C respeta la jerarquía matemática universal PEMDAS:

1
1º Paréntesis ( ): Tienen máxima prioridad absoluta. Todo lo encerrado adentro se resuelve primero.
2
2º Multiplicación *, División / y Módulo %: Se resuelven de izquierda a derecha.
3
3º Suma + y Resta -: Se resuelven al final, de izquierda a derecha.
❌ Error clásico en promedios
float prom = nota1 + nota2 / 2.0f;

Divide solo nota2 por 2 y luego le suma nota1. ¡Resultado completamente erróneo!

✅ Uso correcto de paréntesis
float prom = (nota1 + nota2) / 2.0f;

Suma primero las dos notas y luego divide el total por 2.

08 Errores Peligrosos con Operadores

💥 División por Cero
int x = 10 / 0; // O num % 0;

Consecuencia: Dividir por cero no existe en matemáticas. En C produce un fallo crítico instantáneo (Floating Point Exception / Crash) que congela el programa.

⚠️ Guardar int / int en un float
float x = 7 / 2; // ¡Dará 3.000000, no 3.5!

¿Por qué? Primero C evalúa 7 / 2 entre enteros (da 3), y recién después convierte ese 3 a float (3.0f). Para tener 3.5 usá 7.0f / 2.

09 Resumen de la Unidad y Checklist

Arsenal Aritmético

  • + , - , *: Operaciones directas.
  • int / int: Da cociente entero truncado (7 / 2 = 3).
  • float / float: Da resultado con decimales (7.0f / 2 = 3.5f).
  • %: Módulo, da el resto entero (7 % 2 = 1).
  • x % n == 0: Criterio infalible de divisibilidad.
  • ( ): Prioridad absoluta en el orden de evaluación.
