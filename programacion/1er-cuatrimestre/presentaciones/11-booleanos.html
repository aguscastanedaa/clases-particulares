Booleanos: bool, true y false

El tipo lógico por excelencia en C moderno: banderas de estado, interruptores y condiciones elegantes

<stdbool.h> true (1) & false (0) Banderas (Flags) if (activo) vs if (activo == true)

💡 Guía de navegación: Usá la barra espaciadora o las flechas del teclado (→ / ←) para avanzar diapositiva por diapositiva.

01 Objetivos de Aprendizaje

De la comparación a la variable

En las dos unidades anteriores aprendimos que las comparaciones como edad >= 18 producen una respuesta de verdad.

En esta clase aprenderemos a **guardar esas respuestas lógicas en variables dedicadas** (llamadas booleanos o banderas) para usarlas como interruptores que controlan el flujo de nuestro programa de manera limpia y profesional.

Lo que vas a dominar hoy

  • Declarar e inicializar variables de tipo bool.

  • Almacenar el resultado de comparaciones complejas.
  • Escribir condiciones directas y limpias sin redundancias.
  • Implementar el patrón de **Banderas de Estado (Flags)**.

02 El Ejemplo Canónico con stdbool.h

Declaración moderna de una variable booleana:

booleano_basico.c C99 / C11
#include <stdio.h> #include <stdbool.h> int main(void) { bool aprobado = true; if (aprobado) { printf("¡Felicitaciones, aprobaste la materia!\n"); } else { printf("Debes rendir el examen recuperatorio.\n"); } return 0; }

03 ¿Por qué hace falta <stdbool.h>?

El Pasado: C89/C90

En los primeros 30 años de C no existía el tipo booleano oficial. Los programadores usaban números enteros normales (int):

  • El número 0 significaba FALSO.
  • Cualquier número **distinto de 0** (como 1, 42 o -5) significaba VERDADERO.

Aunque funcionaba, el código era poco legible y se prestaba a confusiones.

El Presente: C99 en adelante

Con la llegada del estándar internacional C99, se añadió la cabecera <stdbool.h>, que nos permite escribir:

bool (como tipo de dato oficial)
true (con valor interno 1)
false (con valor interno 0)

El código se volvió mucho más claro, profesional y fácil de leer.

04 Guardar una Comparación en un bool

Podés separar el cálculo lógico de la decisión:

separacion_logica.c Código Limpio
float notaFinal = 8.5f; int asistencia = 85; // Evaluamos la regla una sola vez y la guardamos con un nombre descriptivo: bool cumpleRequisitos = (notaFinal >= 6.0f && asistencia >= 75); // La condición del if queda hermosamente legible: if (cumpleRequisitos) { printf("Alumno promovido directamente.\n"); }

🎯 Ventaja enorme: Si la regla del colegio cambia a 80% de asistencia, solo modificás la línea donde calculás cumpleRequisitos, y todo el resto del programa sigue funcionando sin tocarlo.

05 El Vicio del Principiante: Comparar con true

⚠️ Redundante y poco profesional
if (aprobado == true) // ¡REDUNDANTE!
if (aprobado == false) // ¡POCO ELEGANTE!

Es como decir: "Si es verdad que es verdad que aprobaste". Como aprobado ya es un booleano por sí mismo, no hace falta compararlo contra true.

✅ La forma limpia y profesional
if (aprobado) // Directo y conciso
if (!aprobado) // Con operador NOT

Se lee con la fluidez de una oración en español: "Si está aprobado..." o "Si NO está aprobado...".

06 Banderas de Estado (Flags) en Videojuegos

Un uso real y cotidiano de los booleanos: controlar estados del juego:

estado_juego.c Game Logic
bool tieneLlaveDorada = false; bool puertaAbierta = false; // El jugador encuentra la llave en el calabozo: tieneLlaveDorada = true; // El jugador llega al portón del jefe final: if (tieneLlaveDorada) { puertaAbierta = true; printf("¡El portón se abre lentamente!\n"); }

07 Errores Frecuentes con Booleanos

❌ Olvidar el include

Escribir bool x = true; sin poner #include <stdbool.h> arriba del todo.
El compilador te arrojará: unknown type name 'bool'.

⚠️ Escribir con Mayúsculas

Escribir True, TRUE, False o FALSE.
En C los identificadores oficiales en minúscula son estrictamente true y false.

08 Resumen de la Unidad y Checklist

Síntesis Booleana

  • #include <stdbool.h>: Obligatorio en C moderno.
  • bool: Tipo de dato con 2 estados: true o false.
  • true: Internamente equivale a 1.
  • false: Internamente equivale a 0.
  • if (x): La forma más elegante y concisa de evaluar.
  • Banderas (Flags): Recuerdan estados del sistema.
