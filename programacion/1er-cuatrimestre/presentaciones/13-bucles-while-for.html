Bucles: while y for

El superpoder de la repetición: cómo iterar millones de veces sin cansancio, tablas de traza y comparación definitiva

Bucle while Bucle for Tablas de Iteración Bucles Infinitos

💡 Guía de navegación: Usá la barra espaciadora o las flechas del teclado (→ / ←) para avanzar diapositiva por diapositiva.

01 Objetivos de Aprendizaje

¿Por qué las computadoras aman repetir?

A los humanos nos aburre hacer la misma tarea 500 veces seguidas: nos cansamos, nos distraemos y cometemos errores.

Una computadora puede repetir una serie de instrucciones **un millón de veces en un pestañeo con 100% de precisión matemática**. A esa estructura de repetición la llamamos **bucle, ciclo o loop**.

Lo que vas a dominar en esta clase

  • Comprender los 3 pilares de todo bucle: **Inicialización, Condición y Actualización**.
  • Dominar el bucle while con seguimiento paso a paso.
  • Dominar el bucle for y su orden de ejecución interno.
  • Seguir tablas de traza iteración por iteración.
  • Saber exactamente **cuándo usar while y cuándo usar for**.
  • Prevenir y abortar **bucles infinitos**.

02 La Santísima Trinidad de Todo Bucle

Todo ciclo de repetición en cualquier lenguaje del mundo necesita estos 3 componentes para no fallar:

1. Inicialización

Establecer el punto de partida de la variable de control antes de entrar al bucle.

int i = 1;

2. Condición

La pregunta que se evalúa **antes de cada vuelta**. Mientras sea verdadera, el bucle sigue girando.

i <= 5

3. Actualización (Paso)

Modificar la variable hacia el final para que en algún momento la condición se vuelva falsa y el ciclo termine.

i++;

⚠️ ¡Si falta la actualización: La variable nunca cambiará, la condición siempre será verdadera y el bucle girará infinitamente hasta congelar el programa!

03 Parte A: El Bucle while

En español, while significa "mientras". Funciona exactamente como un if que se repite:

bucle_while.c Ejemplo Obligatorio
int i = 1; // 1. Inicialización while (i <= 5) // 2. Condición de permanencia { printf("%d\n", i); // Cuerpo del bucle i++; // 3. Actualización indispensable }
Terminal de Salida
$ ./bucle_while 1 2 3 4 5

Vuelta 2 i = 2 2 <= 5 ➔ VERDADERO (1) Imprime 2 i pasa a valer 3

💡 Pregunta clave de examen: Al finalizar el bucle, ¿cuánto vale la variable i en memoria? ¡Vale 6! Es el valor 6 el que hizo fallar la condición y permitió salir.

05 El Peligro del Bucle Infinito

💥 El Bucle que Nunca Termina
int i = 1;
while (i <= 5)
{
    printf("%d\n", i);
    // ¡OLVIDASTE i++; !
}

Como i sigue valiendo 1 para siempre, la condición 1 <= 5 es eternamente verdadera. El programa imprimirá '1' miles de millones de veces hasta saturar la CPU.

🛡️ Cómo Abortar un Bucle Infinito

Si tu programa se queda "colgado" imprimiendo sin parar o sin responder en la terminal:

Presioná: Ctrl + C

Ctrl + C envía una señal de interrupción al sistema operativo para matar el proceso rebelde de inmediato.

06 Parte B: El Bucle for

Diseñado específicamente para repeticiones con **contador conocido**. Empaqueta los 3 pilares en una sola línea:

bucle_for.c Ejemplo Obligatorio
for (int i = 1; i <= 5; i++) { printf("%d\n", i); }

El Orden de Ejecución Exacto de un for

  1. Paso 1 (UNA SOLA VEZ): Se ejecuta la inicialización int i = 1.
  2. Paso 2: Se evalúa la condición i <= 5. Si es falsa, termina de inmediato.
  3. Paso 3: Si es verdadera, se ejecuta el cuerpo adentro de las llaves (el printf).
  4. Paso 4: Se ejecuta la actualización i++.
  5. Paso 5: Vuelve al Paso 2 para comprobar la condición nuevamente.

07 Parte C: Comparación Lado a Lado

Con bucle while

int i = 1; while (i <= 5) { printf("%d\n", i); i++; }

Los 3 pilares están separados en líneas distintas. Ideal cuando la repetición depende de un evento imprevisto.

Con bucle for

for (int i = 1; i <= 5; i++) { printf("%d\n", i); }

Todo compacto en la cabecera. Es casi imposible olvidar el i++ por accidente.

¿Cuándo conviene usar cada uno?

• Usá for cuando sabés de antemano cuántas vueltas querés dar (ej. contar del 1 al 10, repetir 100 veces).
• Usá while cuando la repetición depende de una condición externa o de lo que ingrese el usuario (ej. mientras no ingrese el número 0, mientras tenga vidas).

08 Galería de Bucles Prácticos

1. Mostrar solo Números Pares del 2 al 20

for (int i = 2; i <= 20; i += 2) { printf("%d ", i); }

Avanza de 2 en 2 con i += 2.

2. Sumar una Secuencia (Acumulador)

int suma = 0; for (int i = 1; i <= 10; i++) { suma += i; // Suma 1+2+3+...+10 } printf("Total: %d\n", suma); // Da 55

3. Bucle Centinela con while (Repetir hasta ingresar 0)

int numero = -1; while (numero != 0) { printf("Ingresa un número (0 para salir): "); scanf("%d", &numero); } printf("¡Programa finalizado con éxito!\n");

09 Errores Clásicos en Bucles

❌ El Punto y Coma Accidental
for (int i = 1; i <= 5; i++); // ¡PUNTO Y COMA TRÁGICO! { printf("%d\n", i); }

El ; hace que el bucle gire en el vacío 5 veces sin hacer nada, y luego ejecuta el bloque **una sola vez** mostrando 6.

⚠️ Errores de Límites (Off-by-one)

Confundir i < 5 con i <= 5.
• Con i < 5 se ejecuta 4 veces (1, 2, 3, 4).
• Con i <= 5 se ejecuta 5 veces (1, 2, 3, 4, 5).
¡Prestá siempre atención al signo igual en los límites!

10 Resumen de la Unidad y Checklist

Síntesis de Bucles

  • 3 Componentes: Inicialización, Condición y Actualización.
  • while: Excelente para repeticiones basadas en eventos o centinelas.
  • for: Excelente para iteraciones con contador numérico.
  • Evitar bucle infinito: Asegurar que la condición cambie hacia falso.
  • Ctrl + C: Freno de emergencia en terminal.
