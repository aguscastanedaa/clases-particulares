Operadores Lógicos

Combinando condiciones complejas: el poder de AND (&&), OR (||) y NOT (!) con tablas de verdad

&& (AND / Y) || (OR / O) ! (NOT / NO) Tablas de Verdad

💡 Guía de navegación: Usá la barra espaciadora o las flechas del teclado (→ / ←) para avanzar diapositiva por diapositiva.

01 Objetivos de Aprendizaje

¿Por qué necesitamos operadores lógicos?

En el mundo real casi ninguna decisión depende de una sola condición aislada. Decimos:

• "Para subir a la montaña rusa tenés que medir más de 1.40 m Y tener más de 12 años".
• "El descuento aplica si sos estudiante O jubilado".

Los operadores lógicos nos permiten unir múltiples comparaciones en una sola expresión coherente y precisa.

Lo que vas a dominar en esta clase

  • Comprender el operador AND && (ambas deben cumplirse).
  • Comprender el operador OR || (al menos una debe cumplirse).
  • Comprender el operador NOT ! (invierte el valor de verdad).
  • Construir e interpretar **tablas de verdad completas**.
  • Aprender qué es la **evaluación en cortocircuito**.
  • Evitar el error clásico de rangos: 10 < x < 20.

03 El Operador AND && (Y Lógico)

La Regla de Oro de &&

Una expresión con && es VERDADERA **únicamente si AMBAS partes son verdaderas**. Si tan solo una de ellas es falsa, toda la expresión colapsa y se vuelve FALSA.

Condición A Condición B Expresión: (A && B) Resultado
FALSO (0) FALSO (0) 0 && 0 FALSO (0)
VERDADERO (1) FALSO (0) 1 && 0 FALSO (0)
FALSO (0) VERDADERO (1) 0 && 1 FALSO (0)
VERDADERO (1) VERDADERO (1) 1 && 1 VERDADERO (1) ✓

04 El Operador OR || (O Lógico)

La Regla de Oro de ||

Una expresión con || (barra vertical doble) es VERDADERA **si AL MENOS UNA de las partes es verdadera**. Solo será falsa en el caso extremo donde ambas partes sean falsas.

Condición A Condición B Expresión: (A || B) Resultado
FALSO (0) FALSO (0) 0 || 0 FALSO (0)
VERDADERO (1) FALSO (0) 1 || 0 VERDADERO (1) ✓
FALSO (0) VERDADERO (1) 0 || 1 VERDADERO (1) ✓
VERDADERO (1) VERDADERO (1) 1 || 1 VERDADERO (1) ✓

05 El Operador NOT ! (Negación Lógica)

El Inversor de Verdad

El operador ! actúa sobre una sola condición a su derecha. Simplemente da vuelta su estado:

  • !true se convierte en false (0).
  • !false se convierte en true (1).

Ejemplo Práctico en Código

bool lloviendo = false; if (!lloviendo) { printf("Podemos salir al patio\n"); }

Se lee naturalmente: "Si NO está lloviendo, salimos al patio".

06 Evaluación en Cortocircuito (Short-Circuit)

Optimización Inteligente del Compilador C

C evalúa las expresiones lógicas de izquierda a derecha. Si el resultado final ya es **matemáticamente inevitable** con solo leer la primera condición, C **no pierde tiempo en evaluar la segunda**:

En el AND (&&)

Si la primera condición es FALSA, toda la expresión ya es falsa seguro. C no evalúa la segunda.

false && (x / 0 == 1) // ¡No crashea!

En el OR (||)

Si la primera condición es VERDADERA, toda la expresión ya es verdadera seguro. C no evalúa la segunda.

true || (cualquierCosa) // Salta directo

07 La Gran Trampa de Rangos: 10 < x < 20

❌ Lo que nunca funciona en C
if (10 < nota < 20) // ¡GRAVE ERROR!

¿Por qué falla?: C evalúa de izquierda a derecha: 10 < nota produce un 0 o un 1. Luego evalúa (0 o 1) < 20, ¡lo cual es SIEMPRE VERDADERO! No importa qué nota pongas, siempre dará verdadero.

✅ La forma correcta con &&
if (nota > 10 && nota < 20) // ¡IMPECABLE!

Comprueba explícitamente: ¿Es la nota mayor a 10? Y ADEMÁS, ¿es la nota menor a 20? Ambas condiciones deben cumplirse.

08 Desafío de Predicción: ¿Se ejecuta el bloque?

Dadas las variables int edad = 17; bool tieneBoleto = true; int categoria = 5;:

Caso 1:
(edad >= 18 && tieneBoleto)
Caso 2:
(categoria == 2 || categoria == 5)
Caso 3:
(!tieneBoleto || edad < 18)
Caso 4:
!(edad == 17)
👉 Clic acá para ver las soluciones paso a paso
  • Caso 1: 17 >= 18 (Falso) && true ➔ FALSO (0) (por ser AND, uno falso arruina todo).
  • Caso 2: 5 == 2 (Falso) || 5 == 5 (Verdadero) ➔ VERDADERO (1) (por ser OR, alcanza con uno verdadero).
  • Caso 3: !true (Falso) || 17 < 18 (Verdadero) ➔ VERDADERO (1).
  • Caso 4: !(17 == 17) ➔ !(Verdadero) ➔ FALSO (0).

09 Resumen de la Unidad y Checklist

Leyes Lógicas

  • && (AND): Exige que ambas sean 1.
  • || (OR): Exige que al menos una sea 1.
  • ! (NOT): Invierte el valor (1 pasa a 0, 0 a 1).
  • Cortocircuito: C no evalúa de más si el resultado es seguro.
  • Rangos: Siempre usar x >= min && x <= max.
