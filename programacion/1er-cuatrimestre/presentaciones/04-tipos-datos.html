Tipos de Datos en C

Enteros, decimales, caracteres y booleanos: cómo representar el mundo real en la memoria digital

int (Enteros) float (Decimales) char (Letras y Símbolos) bool (stdbool.h)

💡 Guía de navegación: Usá la barra espaciadora o las flechas del teclado (→ / ←) para avanzar diapositiva por diapositiva.

01 Objetivos de Aprendizaje

¿Por qué C exige tipos de datos?

En la memoria física de la computadora todo son unos y ceros (bits). Para la RAM, la secuencia 01000001 es idéntica si representa el número 65, la letra 'A' o una porción de color.

C es un lenguaje de tipado estático: el compilador necesita saber con precisión cuántos bytes de memoria reservar y cómo interpretar esos bits cuando el programa los use.

Lo que vas a dominar en esta clase

  • Comprender los 4 tipos elementales: int, float, char, bool.
  • Entender por qué en C se usa el punto decimal . y nunca la coma.
  • Aprender por qué los caracteres usan comillas simples ' '.
  • Conocer la naturaleza de la precisión finita de float.
  • Usar #include <stdbool.h> para manejar true y false.
  • Diferenciar asignaciones válidas de errores de compilación.

02 Los 4 Ejemplos Obligatorios

El póquer fundamental de datos en C moderno:

tipos_fundamentales.c C99 con stdbool.h
#include <stdbool.h> int edad = 16; float altura = 1.75f; char letra = 'A'; bool aprobado = true;

int

Enteros sin decimales (edad, año, vidas).

float

Reales con coma (altura, precio, peso).

char

Un solo símbolo entre ' ' ('A', '#', '9').

bool

Verdad lógica (true o false).

04 Profundizando en int (Enteros)

Propiedades de int

  • Almacena cantidades discretas que no tienen fracción ni decimales.
  • Puede ser positivo, negativo o cero:
    int temp = -10; int cero = 0; int nivel = 42;
  • Las operaciones entre dos int siempre dan un int exacto (se trunca la fracción sin redondear).

¿Qué pasa si le asignás decimales a un int?

Si escribís:

int precio = 9.99f;

⚠️ El compilador descarta completamente el .99 y guarda 9. ¡No redondea a 10, simplemente mutila los decimales (truncamiento)!

05 float: Decimales y Precisión Finita

Regla Sagrada: Punto, NO Coma

En español escribimos $1,75$, pero en el lenguaje C internacional se utiliza exclusivamente el punto decimal .:

float altura = 1.75f; // ¡CORRECTO!
float error = 1,75; // ¡ERROR FATAL DE SINTAXIS!

En C, la coma , es un operador de separación, no un signo numérico. El sufijo f le indica al compilador que es un float de precisión simple.

La Precisión Finita

La memoria de la computadora es finita (32 bits). Ciertas fracciones decimales simples como $0,1$ no tienen representación binaria finita exacta (son números periódicos en base 2).

Por eso, float tiene una precisión aproximada de 6 a 7 dígitos significativos. En la unidad de entrada y salida aprenderemos cuándo conviene usar float y cuándo double.

06 char: Caracteres y Comillas Simples

Un único símbolo entre ' '

El tipo char almacena un único carácter: una letra, un dígito o un signo especial.

char nota = 'A';
char digito = '7';
char simbolo = '#';

¡Atención!: '7' como carácter no es el número 7 para hacer cuentas, es el dibujo gráfico de la tecla 7.

La Gran Diferencia: ' ' vs " "

Comillas simples ' '

Para un solo char.

char c = 'A';
Comillas dobles " "

Para cadenas de texto (strings).

"Hola mundo"

⚠️ Escribir char letra = "A"; provocará error de compilación por incompatibilidad de tipos.

07 bool: Valores Lógicos con <stdbool.h>

Álgebra de Boole: Sí o No, Blanco o Negro

Nombrado en honor al matemático George Boole. Una variable booleana solo puede tener uno de dos estados posibles: true (verdadero) o false (falso).

ejemplo_booleano.c stdbool.h
#include <stdbool.h> bool aprobado = true; bool mayorDeEdad = false; bool tienePermiso = true;

¿Cómo lo entiende C por dentro?

En el estándar C moderno:

  • true se traduce internamente al número entero 1.
  • false se traduce al número entero 0.
  • Requiere siempre incluir #include <stdbool.h> al principio de tu archivo.

08 Galería: Correctos vs Incorrectos

❌ Asignaciones Inválidas

• int num = "10"; ➔ Intentar meter texto en un entero.
• float pi = 3,14f; ➔ Usar coma en lugar de punto.
• char vocal = 'aeiou'; ➔ Meter más de 1 letra en un char.
• char vocal = "a"; ➔ Usar comillas dobles para un char.
• bool flag = Verdadero; ➔ No existe en C, debe ser true.

✅ Asignaciones Válidas e Impecables

• int num = 10;
• float pi = 3.14f;
• char vocal = 'a';
• char digito = '9';
• bool flag = true; (con <stdbool.h>)

09 Desafío: Elegí el Tipo Adecuado

¿Qué tipo de dato de C usarías para modelar cada una de estas 4 situaciones reales?

1. La cantidad de goles en un partido de fútbol.
2. La temperatura corporal de un paciente (ej. 36.8 °C).
3. El tipo de sangre de una persona ('A', 'B', 'O').
4. Saber si la puerta del laboratorio está abierta o cerrada.
👉 Clic acá para ver la respuesta técnica justificada
  • 1. Goles: int ➔ No existen los medios goles, es un valor entero discreto (ej. int goles = 2;).
  • 2. Temperatura: float ➔ Requiere precisión decimal con punto (ej. float temp = 36.8f;).
  • 3. Tipo de sangre: char ➔ Es una única letra mayúscula (ej. char sangre = 'A';).
  • 4. Puerta abierta: bool ➔ Es un estado binario verdadero/falso (ej. bool puertaAbierta = true;).

10 Resumen de la Unidad y Checklist

El Catálogo de Tipos

  • int: Enteros sin decimales (4 bytes).
  • float: Decimales con punto . (4 bytes).
  • char: Un solo carácter entre comillas simples ' ' (1 byte).
  • bool: true o false con <stdbool.h> (1 byte).
