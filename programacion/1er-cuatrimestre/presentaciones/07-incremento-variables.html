Incremento de Variables

Hacer crecer tus datos: de x = x + 1 a los operadores abreviados += y el famoso ++

edad = edad + 1 edad += 1 edad++ Contadores & Acumuladores

💡 Guía de navegación: Usá la barra espaciadora o las flechas del teclado (→ / ←) para avanzar diapositiva por diapositiva.

01 Objetivos de Aprendizaje

¿Por qué este concepto es un antes y un después?

En álgebra tradicional de la escuela secundaria, la ecuación $x = x + 1$ es una contradicción imposible (¡un número no puede ser igual a sí mismo más uno!).

En programación, el signo = **no es una ecuación de igualdad, sino una orden de asignación**. Comprender cómo una variable se actualiza a partir de su propio valor anterior es la base indispensable para construir contadores y bucles.

Lo que vas a dominar en esta clase

  • Entender la mecánica paso a paso de edad = edad + 1.
  • Manejar los operadores de asignación compuesta: +=, -=, *=, /=.
  • Aprender el operador de incremento ++ y decremento --.
  • Demostrar la equivalencia de las tres formas clásicas.
  • Distinguir entre **contar de 1 en 1** y **acumular cantidades arbitrarias**.
  • Conocer (sin confusiones) la diferencia entre pre y post-incremento.

02 Las Tres Formas de Incrementar en 1

Estas tres instrucciones producen exactamente el mismo efecto final sobre la variable:

tres_caminos.c Equivalencia Total
// Forma 1: Explícita clásica edad = edad + 1; // Forma 2: Operador abreviado compuesto edad += 1; // Forma 3: Operador de incremento unitario edad++;

1. Explícita

Lee el valor actual, le suma 1 y guarda el resultado.

2. Abreviada

Suma directamente a la variable sin escribir su nombre dos veces.

3. Incremento ++

La sintaxis más rápida y popular en C para sumar una unidad.

03 La Mecánica de edad = edad + 1

¿Qué hace la CPU internamente? Siempre se resuelve primero la derecha:

1
Lectura: La CPU viaja a la caja edad en la RAM y lee su contenido actual (supongamos 16).
2
Cálculo en la ALU: La Unidad Aritmética calcula la suma: 16 + 1 = 17.
3
Escritura (Sobreescritura): El operador = toma el 17 y lo deposita en la caja edad. El 16 se borra y la caja ahora guarda 17.
Antes
edad
16
+ 1 ➔
Después
edad
17

04 Los Operadores Abreviados (Compuestos)

C ofrece atajos para combinar cualquier operador aritmético con la asignación:

Operador Sintaxis Abreviada Equivale exactamente a... Ejemplo de Uso Real
+= puntos += 50; puntos = puntos + 50; Sumar puntos a un marcador
-= vidas -= 1; vidas = vidas - 1; Restar vida al recibir daño
*= saldo *= 2; saldo = saldo * 2; Duplicar un valor
/= energia /= 2; energia = energia / 2; Reducir a la mitad
%= num %= 10; num = num % 10; Quedarse con el último dígito

05 El Operador ++ y --

Incremento: variable++

Suma exactamente 1 unidad a la variable y guarda el nuevo valor inmediatamente en la RAM.

int contador = 0; contador++; // Ahora vale 1 contador++; // Ahora vale 2

Decremento: variable--

Resta exactamente 1 unidad a la variable y la actualiza en memoria.

int vidas = 3; vidas--; // Ahora vale 2 vidas--; // Ahora vale 1

⚡ ¡C++ se llama así por este operador!: Bjarne Stroustrup nombró a su lenguaje C++ como un juego de palabras para indicar que era "el lenguaje C incrementado y evolucionado al siguiente nivel".

06 Tabla de Seguimiento: Contador vs Acumulador

Rastreemos la evolución de dos variables trabajando juntas:

int contador = 1; int suma = 0; suma += contador; // Paso 1 contador++; // Paso 2 suma += contador; // Paso 3 contador++; // Paso 4
Paso Instrucción Valor de contador Valor de suma Explicación
Inicio Declaración 1 0 Estado inicial
Paso 1 suma += contador; 1 1 Suma 0 + 1 = 1
Paso 2 contador++; 2 (subió) 1 El contador avanzó a 2
Paso 3 suma += contador; 2 3 (subió) Suma 1 + 2 = 3
Paso 4 contador++; 3 (subió) 3 El contador avanzó a 3

07 Complemento: i++ vs ++i

¿Qué diferencia hay entre poner el ++ adelante o atrás?

Post-incremento: i++

Usa primero el valor actual en la expresión en la que está metido, y LUEGO incrementa la variable en 1.

int i = 5; int a = i++; // 'a' recibe 5, y luego 'i' pasa a 6

Pre-incremento: ++i

Incrementa PRIMERO la variable en 1, y LUEGO entrega el nuevo valor a la expresión.

int i = 5; int a = ++i; // 'i' pasa a 6 primero, y 'a' recibe 6

💡 Consejo para principiantes: Cuando uses i++; en una línea sola independiente, i++ y ++i hacen exactamente lo mismo. Acostumbrate a escribirlo en su propia línea para mantener tu código claro y sin ambigüedades.

08 Errores Frecuentes al Incrementar

❌ El Error Fantasma: edad + 1;
int edad = 16;
edad + 1; // ¡NO HACE NADA!

¿Por qué? La computadora calcula 16 + 1 = 17, pero como no pusiste un = ni un ++, el 17 se evapora y edad sigue valiendo 16.

✅ Forma Correcta con Asignación
int edad = 16;
edad++; // O edad += 1; O edad = edad + 1;

Cualquiera de estas tres formas sí actualiza la memoria RAM de manera definitiva.

09 Resumen de la Unidad y Checklist

Resumen Práctico

  • x = x + 1: Lee x, suma 1 y guarda en x.
  • x += 5: Suma 5 a x de forma compacta.
  • x++: Suma 1 a x y modifica la variable en RAM.
  • x--: Resta 1 a x.
  • Contador: Crece de 1 en 1 (c++).
  • Acumulador: Suma valores variables (total += precio).
