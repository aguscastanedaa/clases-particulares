¿Qué es Programar?

El arte de transformar ideas y problemas cotidianos en instrucciones precisas para una computadora

Algoritmos Secuencia de Pasos Precisión y Lógica Primer Código C

01 Objetivos de Aprendizaje

¿Por qué aprender a programar hoy?

Una computadora es la máquina más poderosa que inventó la humanidad, pero por sí sola no tiene iniciativa ni inteligencia propia. Solo hace exactamente lo que un ser humano le indica.

Aprender a programar no es memorizar comandos raros: es entrenar tu cerebro para pensar de forma estructurada, descomponer problemas complejos y crear soluciones automáticas.

Lo que vas a dominar en esta clase

  • Comprender con exactitud qué significa programar.
  • Entender cómo la computadora ejecuta instrucciones a nivel físico.
  • Distinguir entre una instrucción aislada y una secuencia ordenada.
  • Reconocer por qué las instrucciones deben ser 100% precisas.
  • Identificar qué ocurre ante un error de sintaxis y ante un "bug" de lógica.
  • Leer y analizar tu primer fragmento de código real en C línea por línea.

02 ¿Qué significa realmente programar?

Desmitifiquemos la programación con palabras sencillas y cotidianas.

Definición Pedagógica

Programar es el proceso de diseñar, escribir y estructurar un conjunto de instrucciones detalladas y ordenadas (llamado algoritmo o programa) en un lenguaje que una computadora pueda interpretar y ejecutar para resolver un problema o realizar una tarea específica.

1. El Problema

Una necesidad real: calcular un promedio, controlar un semáforo, enviar un mensaje o mover un personaje de videojuego.

2. El Algoritmo

El plan mental paso a paso: definir qué pasos hacer primero, cuáles después y qué condiciones verificar.

3. El Código

Traducir ese plan a un lenguaje de programación formal (como C) para que el procesador lo ejecute a miles de millones de operaciones por segundo.

03 La analogía del robot y la receta

Analogía 1: La Receta de Cocina

Imaginá que estás cocinando una torta. Si la receta dice:

  1. 1. Mezclar harina y azúcar.
  2. 2. Agregar huevos y leche.
  3. 3. Hornear durante 40 minutos a 180°C.

Si horneás antes de mezclar los ingredientes, ¡el resultado es un desastre! En programación, el orden cronológico es inquebrantable.

Analogía 2: El Robot Hiper-Literal

Las personas deducimos intenciones por sentido común. Si a un amigo le decís "pasame la sal", él estira el brazo y te da el salero.

Un robot o una computadora no tiene sentido común. Si solo le decís "pasame la sal", no sabrá qué sal, cuánta fuerza usar, en qué dirección mover el brazo ni si debe soltarla. Necesita cada micro-paso detallado explícitamente.

04 ¿Cómo ejecuta instrucciones una computadora?

Un vistazo simplificado al interior del hardware que hace la magia:

1. Memoria RAM

Es la mesa de trabajo rápida. Aquí se cargan temporalmente las instrucciones de tu programa y los datos (variables) que están en uso en este instante. Al apagar la PC, se vacía.

2. CPU (Procesador)

Es el motor ejecutor. Funciona con un ciclo incansable:

Fetch (Buscar) → Decode (Entender) → Execute (Ejecutar)

3. Dispositivos E/S

Entrada: teclado, mouse (capturan datos del usuario).
Salida: monitor, terminal (muestran los resultados calculados).

⚡ Velocidad asombrosa: Un procesador actual ejecuta más de 3.000 millones de instrucciones por segundo (3 GHz). Por eso, si tus instrucciones son correctas, el resultado es instantáneo; pero si tu lógica está equivocada, cometerá millones de errores por segundo.

05 Instrucción individual vs Secuencia

Instrucción Individual

Es la unidad mínima de acción ejecutable. Una sola orden atómica que la computadora sabe llevar a cabo.

ejemplo_instruccion.c Instrucción
int numero = 5;

"Reservá una caja de memoria llamada numero y guardale el valor 5".

Secuencia de Instrucciones

Es una cadena ordenada de instrucciones que colaboran para lograr un objetivo mayor. La computadora las ejecuta estrictamente de arriba hacia abajo.

ejemplo_secuencia.c Secuencia
int numero = 5; int resultado = numero * 2;

La segunda línea depende del valor creado en la primera. Si invirtiéramos el orden, la computadora fallaría.

06 Análisis línea por línea: El doble de un número

Veamos el ejemplo canónico propuesto para calcular el doble de 5:

calculo_doble.c C99
// Línea 1: Creamos la primera variable int numero = 5; // Línea 2: Realizamos el cálculo y guardamos el resultado int resultado = numero * 2;
1
int numero = 5;
• int le avisa al compilador que la caja guardará un número entero.
• numero es el nombre identificador para encontrar esa caja en memoria.
• = (asignación) coloca el número 5 dentro de la caja.
• ; finaliza la instrucción obligatoriamente.
2
int resultado = numero * 2;
• Se reserva otra caja entera llamada resultado.
• La CPU busca qué hay dentro de numero (encuentra un 5).
• Multiplica 5 * 2 obteniendo 10.
• El valor 10 se almacena en la caja resultado.

07 ¿Cómo se ve en la Memoria RAM?

Visualicemos las "cajas con etiqueta" en la memoria de la computadora:

Dirección: 0x7ffd05

Punto clave de comprensión

Nota que la variable numero no se destruye ni se modifica al multiplicar. Sigue valiendo 5. La computadora simplemente leyó su contenido para calcular el 10 que depositó en la nueva variable resultado.

08 Problemas cotidianos traducidos a pasos

Problema 1: Sumar Dos Números

Calcular el total a pagar sumando un producto y su envío:

int precioProducto = 1200; int costoEnvio = 350; int totalAPagar = precioProducto + costoEnvio;

Resultado en memoria: totalAPagar = 1550.

Problema 2: Calcular una Edad Futura

Calcular cuántos años tendrá un alumno dentro de 5 años:

int edadActual = 16; int aniosAdelante = 5; int edadFutura = edadActual + aniosAdelante;

Resultado en memoria: edadFutura = 21.

09 ¿Qué ocurre cuando una instrucción es incorrecta?

Los programadores conviven a diario con errores. Hay dos grandes familias:

⚠️ 1. Error de Sintaxis (Gramática)

Escribiste mal una palabra del lenguaje o te olvidaste un símbolo obligatorio (como un punto y coma ;).

int x = 5 // ¡Falta el punto y coma!

Efecto: El programa no compila. La computadora avisa antes de ejecutarse y se niega a arrancar.

🐛 2. Error de Lógica ("Bug")

El código está perfectamente escrito según las reglas, pero el razonamiento matemático o lógico es erróneo.

// Querías el doble y pusiste suma:
int resultado = numero + 2;

Efecto: Compila y ejecuta, pero el resultado es incorrecto. ¡Son los más difíciles y divertidos de cazar!

10 Desafío de Predicción: Pensá como la CPU

Mirá el siguiente fragmento de código sin mirar la respuesta:

desafio_secuencia.c ¿Qué valor queda?
int puntos = 10; int bonus = 5; int total = puntos + bonus; puntos = 20;

🔮 Pregunta: Al terminar de ejecutarse la última línea, ¿cuánto vale la variable total? ¿15 o 25?

👉 Clic acá para ver la solución y la explicación

¡Respuesta correcta: 15!

¿Por qué? Porque cuando se ejecutó la línea int total = puntos + bonus;, la variable puntos valía 10 y bonus valía 5. La computadora calculó 10 + 5 = 15 y lo guardó en total. Cambiar puntos = 20 en la línea posterior no actualiza mágicamente las variables calculadas en el pasado, a menos que volvamos a indicarlo explícitamente. Las instrucciones se ejecutan paso a paso en el tiempo.

11 Resumen de la Unidad y Checklist

Conceptos Fundamentales

  • Programar: Comunicar un algoritmo a la máquina mediante código.
  • Computadora: Ejecutor hiper-rápido, pero 100% literal y sin iniciativa.
  • Orden secuencial: El procesador ejecuta de arriba a abajo.
  • Instrucción: Orden mínima que termina con punto y coma ;.
  • Memoria RAM: Cajas nombradas donde se guardan los datos.

Checklist de Autoevaluación

✓ ¿Puedo explicar con mis palabras qué es un algoritmo?
✓ ¿Entiendo por qué numero * 2 no altera el valor de numero?
✓ ¿Distingo entre un error de sintaxis y un error de lógica (bug)?
✓ ¿Comprendo por qué el orden de las instrucciones cambia el resultado?
