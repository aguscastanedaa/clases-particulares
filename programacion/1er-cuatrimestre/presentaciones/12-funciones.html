Funciones en C

Divide y vencerás: cómo crear bloques reutilizables de código con parámetros, retorno y ámbito local

Definición & Invocación Parámetros vs Argumentos return vs printf Funciones void & Scope

💡 Guía de navegación: Usá la barra espaciadora o las flechas del teclado (→ / ←) para avanzar diapositiva por diapositiva.

01 Objetivos de Aprendizaje

¿Por qué las funciones son el pilar del software?

Si escribiéramos todo nuestro código adentro de un solo bloque gigante de main(), un programa de 1.000 líneas se volvería un laberinto incomprensible e imposible de corregir.

Las **funciones** nos permiten empaquetar una tarea específica en una pequeña "caja negra" con nombre, resolverla una sola vez y usarla miles de veces (principio **DRY: Don't Repeat Yourself**).

Lo que vas a dominar en esta clase

  • Distinguir entre **definir** una función y **llamarla**.
  • Entender la anatomía: tipo de retorno, nombre y parámetros.
  • Diferenciar con precisión entre **parámetros** y **argumentos**.
  • Aclarar la gran confusión universal: return vs printf.
  • Comprender el uso de void para funciones sin retorno.
  • Aprender qué son los **prototipos** y el **ámbito (scope) local**.

02 El Ejemplo Canónico: La Función doble()

Veamos la función requerida en su forma más pura y clara:

funcion_doble.c Definición y Llamada
// 1. DEFINICIÓN de la función int doble(int numero) { return numero * 2; } // 2. LLAMADA a la función adentro de main: int main(void) { int resultado = doble(5); printf("El doble de 5 es %d\n", resultado); return 0; }

03 El Viaje del Dato Paso a Paso

¿Qué ocurre paso a paso cuando la CPU ejecuta int resultado = doble(5);?

1
Paso del Argumento: En main, se envía el valor 5 (el argumento) hacia la función doble.
2
Recepción en el Parámetro: La función doble despierta en memoria RAM y crea su variable local int numero, recibiendo el 5.
3
Cálculo y Retorno: Calcula 5 * 2 = 10. La instrucción return 10; finaliza la función de inmediato y "escupe" el número 10 hacia quien la llamó.
4
Almacenamiento: La expresión doble(5) es reemplazada por 10, y el operador = lo guarda en la variable resultado.

04 Anatomía Formal de una Función

int doble( int numero )

1. Tipo de Retorno (int)

Qué clase de dato le entregará la función al terminar a quien la llamó (int, float, char, bool o void si no entrega nada).

2. Nombre Identificador (doble)

El nombre con el que invocaremos a la función. Debe ser un verbo o acción clara (calcularArea, esPar).

3. Parámetros (int numero)

Los datos de entrada que la función necesita recibir para poder hacer su trabajo. Si no necesita nada, se escribe (void).

05 Parámetros vs Argumentos: La Distinción Exacta

PARÁMETRO (En la Definición)

Es la **variable receptora vacía** declarada entre los paréntesis de la función. Es como el molde o el casillero en el formulario.

int doble(int numero) // 'numero' es el parámetro
ARGUMENTO (En la Invocación / Llamada)

Es el **valor real y concreto** que le enviamos a la función cuando la ejecutamos en main().

int res = doble(5); // '5' es el argumento real

06 ¡ALERTA FUNDAMENTAL!: return vs printf

printf(): Es para los OJOS del HUMANO

printf dibuja letras con luz en la pantalla de la computadora. No le entrega ningún dato a la memoria de tu programa. No podés guardar la salida de un printf en una variable para hacer cálculos posteriores.

return: Es para la MEMORIA de la COMPUTADORA

return no muestra nada en pantalla. Devuelve un valor numérico o lógico a la memoria para que otra parte del código pueda sumarlo, guardarlo o usarlo en un if.

07 Funciones de Tipo void (Sin Retorno)

Cuando una función realiza una acción pero no necesita entregar ningún número de vuelta:

funcion_void.c tipo void
void mostrarCartelBienvenida(void) { printf("====================================\n"); printf(" BIENVENIDO AL SISTEMA ESCOLAR \n"); printf("====================================\n"); // No lleva 'return valor;' porque es de tipo void } int main(void) { mostrarCartelBienvenida(); // Se llama así de simple return 0; }

08 Galería de Funciones Prácticas Reales

1. Sumar dos números

int sumar(int a, int b) { return a + b; }

Llamada: int total = sumar(15, 20); // 35

2. Calcular el cuadrado

float cuadrado(float x) { return x * x; }

Llamada: float c = cuadrado(4.0f); // 16.0

3. Función Booleana: Determinar si un número es par

#include <stdbool.h> bool esPar(int numero) { return (numero % 2 == 0); }

¡Mirá qué belleza cómo se usa en un if!: if (esPar(edad)) { printf("Tu edad es par"); }

09 Ámbito de Variables (Scope) y Prototipos

El Ámbito Local (Scope)

Las variables declaradas adentro de una función son **locales y privadas**: nacen cuando la función empieza y mueren cuando termina con el return.

main() no puede ver ni modificar las variables internas de doble(), y viceversa. ¡Esto evita que distintas partes de un programa se arruinen variables entre sí por accidente!

Prototipos de Función

El compilador lee tu archivo de arriba hacia abajo. Si ponés la definición de tu función **debajo de main()**, tenés que avisarle arriba mediante un **prototipo** (la firma de la función terminada en ;):

int doble(int numero); // Prototipo

10 Resumen de la Unidad y Checklist

Síntesis Modular

  • Función: Bloque autónomo reutilizable con nombre.
  • Parámetro: Variable que recibe datos en la definición.
  • Argumento: Valor concreto enviado en la invocación.
  • return: Entrega el resultado a la memoria y finaliza la función.
  • void: Indica ausencia de retorno o de argumentos.
  • Scope: Las variables locales solo viven dentro de su función.
