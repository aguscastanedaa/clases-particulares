02 10. ¿Qué es un Vector Dinámico?

Definición del Apunte Teórico (pág. 36)

Un vector dinámico es un vector cuyo tamaño se decide mientras el programa está ejecutándose.

Recordemos el Vector Estático (Unidad 01)

Hasta ahora, cuando creábamos un vector normal en C, hacíamos algo así:

int numeros[5];

El tamaño (5) es fijo y está escrito en el código antes de que el programa arranque.

¿Qué problemas tenía ese tamaño fijo de 5?

  • ❌ Si el usuario quiere guardar 20 números: el vector de 5 posiciones no alcanza.
  • ⚠️ Si el usuario quiere guardar solo 2 números: nos sobran 3 posiciones que quedan ocupando memoria al divino botón.

✅ Con memoria dinámica podemos crear un vector del tamaño exacto que necesite el usuario.

Supongamos que queremos hacer un programa para guardar las notas de los alumnos de un curso. Pero cada curso tiene una cantidad distinta de estudiantes: un curso pequeño puede tener 5 alumnos, otro puede tener 30 y un curso universitario puede tener 200.

1

2

3
Creamos el vector a medida: Con malloc() reservamos en la memoria RAM exactamente cantidad casilleros para guardar esas notas. ¡Ni uno de más, ni uno de menos!

04 Cómo Crear un Vector Dinámico Paso a Paso

Mirá cómo se escriben en lenguaje C los dos pasos del Apunte Teórico (pág. 36):

Paso 1

Pedir la cantidad al usuario

int cantidad; printf("Cantidad de alumnos: "); scanf("%d", &cantidad);

Aquí la variable común cantidad recibe el número que escribe la persona en el teclado (por ejemplo, 4).

Paso 2

Reservar la memoria con malloc()

int *notas; notas = malloc(cantidad * sizeof(int));

En vez de poner un número fijo como 5 * sizeof(int), multiplicamos la variable cantidad * sizeof(int).

06 La Gran Revelación: ¿Cómo se Usa un Vector Dinámico?

¡Se usa EXACTAMENTE IGUAL que un vector normal! (Apunte, pág. 37)

Una vez que ya reservamos la memoria con notas = malloc(cantidad * sizeof(int));, nos olvidamos de los asteriscos y trabajamos con los corchetes notas[0], notas[1], notas[2] de toda la vida.

08 Cargar un Vector Dinámico con un Ciclo for

¿Cuál es el único cambio en el ciclo for? (Apunte, pág. 37)

En un vector estático de 5 elementos escribíamos i < 5. Ahora, como el tamaño lo eligió el usuario y está guardado en la variable cantidad, la condición del ciclo es i < cantidad:

cargar_vector_dinamico.c (pág. 37)
for(int i = 0; i < cantidad; i++) { printf("Ingrese una nota: "); scanf("%d", &notas[i]); }

Analicemos cada detalle

  • int i = 0: El primer casillero de cualquier vector en C siempre es el índice 0.
  • i < cantidad: Si cantidad es 4, el ciclo recorre los índices 0, 1, 2, 3 y frena antes del 4.
  • &notas[i]: En el scanf ponemos el símbolo & delante de notas[i] exactamente igual que en los vectores estáticos.

09 Mostrar un Vector Dinámico por Pantalla

Para imprimir todos los elementos guardados en el vector dinámico, usamos el mismo recorrido desde i = 0 hasta i < cantidad (Apunte Teórico, pág. 37):

mostrar_vector_dinamico.c (pág. 37)
for(int i = 0; i < cantidad; i++) { printf("%d\n", notas[i]); }

¿Cómo funciona vuelta por vuelta?

Vuelta Valor de i Qué muestra printf
1ª vuelta i = 0 Imprime notas[0]
2ª vuelta i = 1 Imprime notas[1]
... ... ...
Última i = cantidad - 1 Imprime la última nota

11 Las 4 Etapas de Todo Programa con Vector Dinámico

Si miramos con atención el programa completo del apunte, vemos que siempre respeta un orden lógico de 4 pasos:

1
Conocer la cantidad (scanf("%d", &cantidad);): Primero averiguamos cuántos elementos vamos a necesitar guardar.
2
Reservar la memoria (notas = malloc(cantidad * sizeof(int));): Creamos el vector en el Heap con ese tamaño exacto.
3
Usar el vector (notas[i]): Cargamos datos, los mostramos, buscamos o calculamos promedios usando ciclos for(int i = 0; i < cantidad; i++).
4
Liberar la memoria (free(notas);): Antes del return 0;, devolvemos la memoria al sistema operativo.

12 Comparación Rápida: Estático vs Dinámico (pág. 38)

Vector Estático

int numeros[10];

✅ Ventajas (según el Apunte):

  • Más simple.
  • Fácil de usar.
  • Automático (se crea y se destruye solo).

❌ Desventajas:

  • Tamaño fijo (no se puede cambiar ni elegir durante la ejecución).

Vector Dinámico

int *numeros; numeros = malloc(cantidad * sizeof(int));

✅ Ventajas (según el Apunte):

  • Tamaño elegido por el usuario.
  • Usa solamente la memoria necesaria.
  • Se puede redimensionar con realloc().

⚠️ Desventajas:

  • Requiere malloc() y requiere free().
  • Es un poco más complejo.

14 Caso Práctico 1: Suma y Promedio de Notas Dinámicas

Agreguemos al programa del apunte un acumulador suma para calcular el promedio del curso sin importar cuántos alumnos haya:

promedio_dinamico.c
#include <stdio.h> #include <stdlib.h> int main() { int cantidad; int *notas; int suma = 0; printf("Cantidad de alumnos: "); scanf("%d", &cantidad); notas = malloc(cantidad * sizeof(int)); for(int i = 0; i < cantidad; i++) { printf("Nota %d: ", i + 1); scanf("%d", &notas[i]); suma = suma + notas[i]; } float promedio = (float)suma / cantidad; printf("Promedio del curso: %.2f\n", promedio); free(notas); return 0; }
Consolastdin/stdout
Cantidad de alumnos: 4 Nota 1: 7 Nota 2: 9 Nota 3: 8 Nota 4: 10 Promedio del curso: 8.50

💡 Dividimos por cantidad porque esa variable guarda exactamente cuántas notas se cargaron.

15 Caso Práctico 2: Mayor y Menor en un Vector Dinámico

¿Recordás cómo buscábamos el mayor y el menor en la Unidad 02 inicializando con el primer elemento notas[0]? Mirá qué limpio queda en un vector dinámico:

mayor_menor_dinamico.c
// Una vez cargadas las 'cantidad' notas: int mayor = notas[0]; int menor = notas[0]; for(int i = 1; i < cantidad; i++) { if(notas[i] > mayor) { mayor = notas[i]; } if(notas[i] < menor) { menor = notas[i]; } } printf("Nota mas alta: %d\n", mayor); printf("Nota mas baja: %d\n", menor);

Por qué funciona para cualquier tamaño

  • Tomamos como referencia inicial la primera posición: mayor = notas[0]; y menor = notas[0];.
  • Recorremos desde i = 1 hasta i < cantidad comparando cada casillero.
  • Funciona igual si el usuario cargó 3 notas o si cargó 500 notas.

16 Caso Práctico 3: Buscar un Número en el Vector Dinámico

También podemos preguntarle al usuario qué número desea buscar dentro del vector dinámico y usar una variable bandera encontrado (como en la Unidad 02):

busqueda_dinamica.c
int buscado; int encontrado = 0; printf("Ingrese la nota que desea buscar: "); scanf("%d", &buscado); for(int i = 0; i < cantidad; i++) { if(notas[i] == buscado) { printf("Se encontro en la posicion %d\n", i); encontrado = 1; } } if(encontrado == 0) { printf("Esa nota no esta en el vector.\n"); }

Repaso de la lógica de búsqueda

• encontrado empieza en 0 (suponemos que todavía no apareció).

• Si en alguna vuelta se cumple notas[i] == buscado, informamos la posición i y cambiamos encontrado = 1.

• Al terminar el for, si encontrado sigue valiendo 0, avisamos que no estaba.

17 Caso Práctico 4: Ordenar un Vector Dinámico

¿Cómo ordenamos de menor a mayor un vector dinámico de tamaño cantidad? Usamos el mismo algoritmo de doble for y variable aux del Apunte Teórico (Unidad 03), cambiando el límite fijo por cantidad:

ordenar_vector_dinamico.c
int aux; // Doble ciclo for para ordenar de menor a mayor for(int i = 0; i < cantidad - 1; i++) { for(int j = 0; j < cantidad - 1; j++) { if(notas[j] > notas[j + 1]) { aux = notas[j]; notas[j] = notas[j + 1]; notas[j + 1] = aux; } } }

¿Por qué cantidad - 1?

Porque adentro del ciclo comparamos notas[j] con su vecino de la derecha notas[j + 1].

Al frenar en cantidad - 1, nos aseguramos de que j + 1 nunca se pase del último casillero válido del vector dinámico.

18 Programa Completo: Cargar y Ordenar Dinámicamente

carga_y_ordenamiento.c
#include <stdio.h> #include <stdlib.h> int main() { int cantidad, aux; printf("Cuantos numeros desea ordenar?: "); scanf("%d", &cantidad); int *v = malloc(cantidad * sizeof(int)); for(int i = 0; i < cantidad; i++) { printf("Numero %d: ", i + 1); scanf("%d", &v[i]); } for(int i = 0; i < cantidad - 1; i++) { for(int j = 0; j < cantidad - 1; j++) { if(v[j] > v[j + 1]) { aux = v[j]; v[j] = v[j + 1]; v[j + 1] = aux; } } } printf("Ordenados: "); for(int i = 0; i < cantidad; i++) printf("%d ", v[i]); free(v); return 0; }

19 Caso Práctico 5: Agregar Más Alumnos con realloc()

Supongamos que el profesor cargó las notas de cantidad alumnos, pero llegan nuevos alumnos tarde y quiere sumarlos al mismo vector dinámico:

agregar_alumnos_realloc.c
int nuevos; printf("Cuantos alumnos nuevos desea agregar?: "); scanf("%d", &nuevos); int total = cantidad + nuevos; // Agrandamos el vector dinámico para que entren todos notas = realloc(notas, total * sizeof(int)); // Cargamos únicamente los nuevos (desde i = cantidad hasta total - 1) for(int i = cantidad; i < total; i++) { printf("Nota del nuevo alumno %d: ", i + 1); scanf("%d", &notas[i]); }

📌 Mirá por qué el ciclo empieza en i = cantidad: si al principio había 3 alumnos (índices 0, 1, 2), el primer alumno nuevo debe guardarse en el índice 3 (que es justamente el valor de cantidad).

20 Vectores Dinámicos de Estructuras (struct)

Uniendo la Unidad 06 (Estructuras) con la Unidad 10 (Vectores Dinámicos)

En la Unidad 06 definimos la estructura struct Alumno del Apunte Teórico con tres datos: edad, promedio y division. ¿Cómo creamos un vector dinámico donde cada casillero sea un struct Alumno completo?

1. Definimos la estructura (Unidad 06)
struct Alumno { int edad; float promedio; char division; };
2. Reservamos con malloc()
struct Alumno *curso; curso = malloc(cantidad * sizeof(struct Alumno));

💡 Observá que dentro de sizeof(...) ponemos el tipo de dato de cada casillero: sizeof(struct Alumno). Así malloc() calcula automáticamente cuántos bytes ocupa un alumno completo y lo multiplica por cantidad.

22 Programa Completo: Vector Dinámico de struct Alumno

#include <stdio.h> #include <stdlib.h> struct Alumno { int edad; float promedio; char division; }; int main() { int cantidad; printf("Cantidad de alumnos: "); scanf("%d", &cantidad); struct Alumno *curso = malloc(cantidad * sizeof(struct Alumno)); for(int i = 0; i < cantidad; i++) { printf("\n--- Alumno %d ---\n", i + 1); printf("Edad: "); scanf("%d", &curso[i].edad); printf("Promedio: "); scanf("%f", &curso[i].promedio); printf("Division (letra): "); scanf(" %c", &curso[i].division); } printf("\nListado del curso:\n"); for(int i = 0; i < cantidad; i++) { printf("Alumno %d -> Edad: %d | Prom: %.2f | Div: %c\n", i + 1, curso[i].edad, curso[i].promedio, curso[i].division); } free(curso); return 0; }

23 Buscar el Mejor Promedio en struct Alumno *curso

¿Y si queremos saber cuál de los alumnos cargados en nuestro vector dinámico tiene el promedio más alto? Guardamos la posición del mejor en una variable pos_mejor:

mejor_promedio_struct.c
int pos_mejor = 0; for(int i = 1; i < cantidad; i++) { if(curso[i].promedio > curso[pos_mejor].promedio) { pos_mejor = i; } } printf("Mejor promedio: %.2f (Edad: %d, Div: %c)\n", curso[pos_mejor].promedio, curso[pos_mejor].edad, curso[pos_mejor].division);

¿Por qué guardamos el índice pos_mejor?

Si solo guardáramos el número del promedio máximo, no sabríamos a qué edad ni a qué división pertenece ese alumno.

En cambio, al guardar el índice pos_mejor = i;, al final tenemos acceso a todos los campos de ese alumno ganador: curso[pos_mejor].promedio, curso[pos_mejor].edad y curso[pos_mejor].division.

24 Ordenar struct Alumno *curso por Promedio

¿Y si queremos ordenar todo el vector dinámico de alumnos de menor a mayor promedio? La variable auxiliar aux debe ser de tipo struct Alumno para intercambiar la ficha entera:

ordenar_curso_struct.c
struct Alumno aux; for(int i = 0; i < cantidad - 1; i++) { for(int j = 0; j < cantidad - 1; j++) { if(curso[j].promedio > curso[j + 1].promedio) { aux = curso[j]; curso[j] = curso[j + 1]; curso[j + 1] = aux; } } }

¡Atención a esta diferencia clave!

  • En el if comparamos el campo: curso[j].promedio > curso[j + 1].promedio.
  • En el intercambio movemos toda la estructura: aux = curso[j]; (copia juntos la edad, el promedio y la división de ese alumno para que sus datos no se mezclen con los de otro).

25 Errores Frecuentes en Vectores Dinámicos (Parte 1)

❌ Error 1: Hacer malloc ANTES de leer cantidad
int cantidad; // ¡MAL! 'cantidad' todavía tiene basura int *notas = malloc(cantidad * sizeof(int)); scanf("%d", &cantidad);

Como cantidad no tenía valor cuando se llamó a malloc(), reservó cualquier cosa.

✅ Corrección: Primero scanf, después malloc
int cantidad; scanf("%d", &cantidad); // ¡BIEN! Ahora 'cantidad' ya tiene el número int *notas = malloc(cantidad * sizeof(int));

Siempre pedimos primero el tamaño al usuario y recién después reservamos.

26 Errores Frecuentes en Vectores Dinámicos (Parte 2)

❌ Error 2: Hacer free(notas) adentro del for
for(int i = 0; i < cantidad; i++) { printf("%d\n", notas[i]); free(notas); // ¡MAL! Destruye el vector en i=0 }

En la primera vuelta destruye todo el vector y en la segunda vuelta el programa falla.

✅ Corrección: Un solo free() afuera, al final
for(int i = 0; i < cantidad; i++) { printf("%d\n", notas[i]); } free(notas); // ¡BIEN! Al terminar de usarlo

free() se ejecuta una única vez cuando ya no vamos a usar más el vector.

27 Errores Frecuentes en Vectores Dinámicos (Parte 3)

❌ Error 3: Poner i <= cantidad en el for
// Si cantidad es 5, los índices son 0, 1, 2, 3, 4 for(int i = 0; i <= cantidad; i++) // ¡Pisa [5]! { scanf("%d", &notas[i]); }

El casillero notas[cantidad] no existe; está fuera de la memoria reservada.

✅ Corrección: Usar siempre i < cantidad
// Recorre exactamente de 0 a cantidad - 1 for(int i = 0; i < cantidad; i++) { scanf("%d", &notas[i]); }

Si reservamos cantidad elementos, los índices válidos van de 0 a cantidad - 1.

28 Desafío de Diagnóstico: ¿Qué Está Mal Aquí?

Un alumno escribió este programa para guardar temperaturas decimales (float) en un vector dinámico, pero cometió 2 errores importantes. ¿Podés descubrirlos antes de abrir la solución?

codigo_con_errores.c
int cantidad; float *temp; printf("Cuantas temperaturas?: "); scanf("%d", &cantidad); temp = malloc(cantidad); // <-- Mirar acá for(int i = 0; i < cantidad; i++) { scanf("%f", temp[i]); // <-- Y mirar acá }
🔍 Ver los 2 errores y cómo corregirlos
  1. Faltó * sizeof(float) en el malloc: Escribió malloc(cantidad), que reserva solo cantidad bytes en vez de cantidad * sizeof(float). Debe ser: temp = malloc(cantidad * sizeof(float));.
  2. Faltó el & en el scanf: Escribió scanf("%f", temp[i]); en lugar de scanf("%f", &temp[i]);.

29 Ejercicio Integrador 1: Contar Aprobados ($\ge 6$)

Enunciado

Pedir al usuario la cantidad de alumnos de un curso, crear un vector dinámico de enteros con malloc(), cargar todas las notas con un ciclo for y contar cuántos alumnos aprobaron (nota mayor o igual a 6). Mostrar el total de aprobados y liberar la memoria.

💻 Ver solución completa paso a paso
#include <stdio.h> #include <stdlib.h> int main() { int cantidad, aprobados = 0; int *notas; printf("Cantidad de alumnos: "); scanf("%d", &cantidad); notas = malloc(cantidad * sizeof(int)); for(int i = 0; i < cantidad; i++) { printf("Nota %d: ", i + 1); scanf("%d", &notas[i]); if(notas[i] >= 6) { aprobados++; } } printf("Cantidad de aprobados: %d de %d\n", aprobados, cantidad); free(notas); return 0; }

30 Ejercicio Integrador 2: Sueldos + Ampliación

Enunciado

Pedir la cantidad inicial de empleados de un comercio, reservar un vector dinámico de float con malloc() y cargar sus sueldos. Luego usar realloc() para agregar 1 empleado más al final, pedir su sueldo, mostrar todos los sueldos y liberar la memoria.

💻 Ver solución completa paso a paso
#include <stdio.h> #include <stdlib.h> int main() { int cantidad; printf("Cantidad de empleados: "); scanf("%d", &cantidad); float *sueldos = malloc(cantidad * sizeof(float)); for(int i = 0; i < cantidad; i++) { printf("Sueldo %d: ", i + 1); scanf("%f", &sueldos[i]); } // Agrandamos para 1 empleado más sueldos = realloc(sueldos, (cantidad + 1) * sizeof(float)); printf("Sueldo del nuevo empleado: "); scanf("%f", &sueldos[cantidad]); printf("\nLista completa de sueldos:\n"); for(int i = 0; i < cantidad + 1; i++) { printf("$%.2f\n", sueldos[i]); } free(sueldos); return 0; }

31 Ejercicio Integrador 3: Tipo Examen del Bimestre

Enunciado Integrador

Definir struct Producto con int codigo; y float precio;. Pedir al usuario cuántos productos quiere registrar, crear un vector dinámico con malloc(), cargar todos los productos y luego mostrar únicamente aquellos cuyo precio supere los $1000. Finalmente liberar la memoria.

💻 Ver solución completa tipo examen
#include <stdio.h> #include <stdlib.h> struct Producto { int codigo; float precio; }; int main() { int cantidad; printf("Cantidad de productos: "); scanf("%d", &cantidad); struct Producto *lista = malloc(cantidad * sizeof(struct Producto)); for(int i = 0; i < cantidad; i++) { printf("Codigo del producto %d: ", i + 1); scanf("%d", &lista[i].codigo); printf("Precio del producto %d: ", i + 1); scanf("%f", &lista[i].precio); } printf("\nProductos con precio mayor a $1000:\n"); for(int i = 0; i < cantidad; i++) { if(lista[i].precio > 1000) { printf("Codigo: %d | Precio: $%.2f\n", lista[i].codigo, lista[i].precio); } } free(lista); return 0; }
