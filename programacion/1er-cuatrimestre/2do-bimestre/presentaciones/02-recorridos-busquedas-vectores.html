01 Hoja de Ruta y Conexión con la Unidad 01

Lo que aprendimos en la Unidad 01

  • Un vector guarda muchos datos del mismo tipo bajo un único nombre.
  • Se declara indicando tipo nombre[tamaño];.
  • Las posiciones (índices) empiezan siempre en 0 y van hasta tamaño - 1.
  • Podemos acceder a una casilla puntual escribiendo vector[posicion].

02 3. ¿Qué Significa "Recorrer un Vector"?

Definición del Apunte

Recorrer un vector significa visitar cada una de sus posiciones, desde la primera (0) hasta la última (tamaño - 1), para leer, mostrar, modificar o procesar los valores almacenados.

Supongamos que tenemos este vector de 5 notas:

03 ¿Por Qué No Conviene Hacerlo "A Mano"?

Si quisiéramos mostrar todas las notas de int notas[5] = {8, 10, 7, 9, 6}; sin usar un ciclo, tendríamos que escribir una línea por cada casilla:

sin_ciclo.c Repetitivo
printf("%d\n", notas[0]); printf("%d\n", notas[1]); printf("%d\n", notas[2]); printf("%d\n", notas[3]); printf("%d\n", notas[4]);

🤔 Pregunta del Apunte:

¿Qué pasa si el vector tiene 100 elementos? ¿Escribirías 100 veces printf?
Claramente no. Por eso, en programación siempre usamos ciclos para recorrer vectores sin importar si tienen 5, 100 o 10.000 elementos.

05 La Herramienta Ideal: El Ciclo for

Para dar esos pasos automáticos del casillero 0 al último, usamos el ciclo for con esta estructura general universal:

Estructura general de recorrido Patrón Fundamental
for (int i = 0; i < tamaño; i++) { // trabajar con vector[i] }

¿Por qué siempre tiene esta forma?

Porque la variable i hace el papel de "dedo señalador" (el índice actual): empieza apuntando a la posición 0, avanza de uno en uno (i++) en cada vuelta, y se detiene justo antes de llegar a tamaño (es decir, en tamaño - 1).

06 Entendiendo Cada Parte del for

for (int i = 0; i < 5; i++) { printf("%d\n", notas[i]); }

1. int i = 0; (Inicio)

Creamos la variable i que representa la posición actual del vector. Empieza en 0 porque la primera casilla de todo vector en C es la posición 0.

2. i < 5; (Condición de permanencia)

El ciclo se repite mientras i sea menor que 5 (0, 1, 2, 3, 4). Cuando i llega a 5, la condición 5 < 5 da falso y el ciclo termina sin salirse del vector.

3. i++ (Avance al siguiente casillero)

Al terminar cada vuelta, suma 1 a i (es lo mismo que i = i + 1). Así pasamos del casillero 0 al 1, luego al 2, etc.

4. notas[i] (Acceso dinámico)

Adentro del ciclo no escribimos un número fijo como notas[0], sino notas[i]. En cada vuelta, i cambia y muestra la casilla correspondiente.

10 Recorrer para Cargar un Vector (con scanf)

También podemos usar el mismo ciclo for para pedirle al usuario que ingrese por teclado todos los valores del vector uno por uno:

cargar_vector_scanf.c Ejemplo del Apunte
#include <stdio.h> int main() { int edades[5]; for (int i = 0; i < 5; i++) { printf("Ingrese una edad: "); scanf("%d", &edades[i]); } return 0; }

🔑 Detalle clave: En scanf("%d", &edades[i]); nunca olvides el símbolo & delante de edades[i], y fijate que adentro de los corchetes va [i] para que cada lectura se guarde en un casillero distinto.

12 Recorrer para Modificar Valores del Vector

También podemos recorrer un vector para transformar sus valores. Por ejemplo, el apunte muestra cómo multiplicar todos los elementos por 2:

modificar_vector.c Ejemplo del Apunte
int numeros[5] = {1, 2, 3, 4, 5}; for (int i = 0; i < 5; i++) { numeros[i] = numeros[i] * 2; }

¿Cómo se lee numeros[i] = numeros[i] * 2;?

En C, primero se calcula lo que está a la derecha del signo = (toma el valor actual de numeros[i] y lo multiplica por 2), y ese resultado nuevo se guarda en la izquierda (sobreescribiendo la misma casilla numeros[i]).

14 Error Muy Común al Recorrer un Vector

El apunte advierte sobre un error que cometen muchísimos alumnos cuando piensan "como tiene 5 elementos, voy del 1 al 5":

❌ MAL: Empezar en 1 y usar <= 5
// ❌ ¡DOBLE ERROR! for (int i = 1; i <= 5; i++) { printf("%d\n", vector[i]); }
  • Problema 1: Como arranca en i = 1, se saltea e ignora a vector[0].
  • Problema 2: En la última vuelta i vale 5 e intenta acceder a vector[5], que NO existe.
✅ BIEN: Empezar en 0 y usar < 5
// ✅ SIEMPRE ASÍ: for (int i = 0; i < 5; i++) { printf("%d\n", vector[i]); }
  • Arranca en 0 (incluye a vector[0]).
  • Usa < 5 estricto, por lo que llega hasta 4 (vector[4]) y frena a tiempo.

15 Sumar Todos los Elementos (Variable Acumuladora)

Una operación muy frecuente al recorrer un vector es sumar todos sus valores (por ejemplo, para saber el total de gastos o el promedio de notas). Para eso usamos una variable acumuladora llamada suma:

sumar_elementos.c Acumulador
#include <stdio.h> int main() { int notas[5] = {8, 10, 7, 9, 6}; int suma = 0; // ¡Obligatorio empezar en 0 antes del for! for (int i = 0; i < 5; i++) { suma = suma + notas[i]; } printf("La suma total es: %d\n", suma); // Muestra 40 return 0; }

⚠️ ¿Por qué int suma = 0; va en cero y AFUERA del for? Si no la inicializás en 0, empezaría sumando sobre basura de memoria. Y si la pusieras adentro del for, se volvería a poner en 0 en cada vuelta.

¿Y cómo calculamos el promedio?

Una vez que terminó el ciclo for y ya tenemos la suma total (40), dividimos por la cantidad de elementos (5):

float promedio = (float)suma / 5; printf("Promedio: %.2f\n", promedio);

Usamos (float)suma para que la división conserve los decimales si la cuenta no da exacta.

17 Combinar Recorrido (for) + Decisión (if)

Muchísimas veces no queremos hacer lo mismo con todos los casilleros, sino revisar cuáles cumplen una condición. Para eso metemos un if adentro del ciclo for:

Estructura de filtro o conteo for + if
int contador = 0; for (int i = 0; i < 5; i++) { if (condicion sobre numeros[i]) { contador++; // Suma 1 solo cuando la casilla cumple la condición } }

Repaso rápido: ¿Cómo sabemos si un número es PAR en C?

Usamos el operador resto de la división %: un número es par cuando al dividirlo por 2 el resto da 0. Es decir: numeros[i] % 2 == 0.

18 Ejemplo del Apunte: Contar Cuántos Números son Pares

Analicemos el ejemplo del apunte sobre el vector {12, 7, 8, 15, 20}:

contar_pares.c Ejemplo del Apunte
#include <stdio.h> int main() { int numeros[5] = {12, 7, 8, 15, 20}; int contador = 0; for (int i = 0; i < 5; i++) { if (numeros[i] % 2 == 0) { contador++; } } printf("Cantidad de pares: %d\n", contador); return 0; }
Terminal Salida
$ ./contar_pares Cantidad de pares: 3

Los números pares encontrados son 12, 8 y 20, por lo que al final contador vale 3.

20 4. ¿Qué Significa "Buscar en un Vector"?

Definición del Apunte

Buscar en un vector significa recorrer sus elementos para encontrar uno (o varios) que cumplan una determinada condición.

Por ejemplo, en los problemas de programación nos pueden pedir buscar:

📉 El Menor o el Mayor

Encontrar cuál es el número más chico o el número más grande de todo el vector.

🥇 El Primero que Cumpla

Encontrar el primer número par o el primer negativo que aparezca en la fila.

🔎 Si Existe un Valor

Saber si un número determinado (por ejemplo el 25) está adentro del vector o cuántos son positivos.

22 El Patrón General de Búsqueda

Tal como sintetiza el apunte teórico, casi todos los ejercicios de búsqueda en vectores siguen este mismo molde:

Patrón General de Búsqueda Molde Maestro
for (int i = 0; i < tamaño; i++) { if (condicion) { // hacer algo (actualizar menor/mayor, contar, o cortar con break) } }

💡 Fórmula mental:
Recorrido (for) para visitar cada posición + Condición (if) para preguntar si el elemento actual numeros[i] es el que estamos buscando.

23 Buscar el Menor Elemento: Los 4 Pasos

¿Cómo hace la computadora para encontrar el número más chico de {12, 8, 25, 3, 17}? Sigue esta estrategia de 4 pasos del apunte:

1
Supongo al principio que el primer elemento es el menor:
Guardo el valor de la posición 0 en una variable: int menor = numeros[0];.
2
Recorro el resto del vector:
Uso un ciclo for que arranque desde i = 1 (porque el 0 ya lo guardé en menor).
3
Si encuentro un número más chico que el que tenía, lo actualizo:
Pregunto if (numeros[i] < menor). Si se cumple, hago menor = numeros[i];.
4
Al finalizar el ciclo, tengo el menor real:
Recién cuando termina el for, muestro la variable menor con printf.

24 Código Completo: Buscar el Menor del Vector

buscar_menor.c Ejemplo del Apunte
#include <stdio.h> int main() { int numeros[5] = {12, 8, 25, 3, 17}; int menor = numeros[0]; // Paso 1: empiezo con el primero for (int i = 1; i < 5; i++) { if (numeros[i] < menor) { menor = numeros[i]; // Paso 3: actualizo el menor } } printf("El menor es: %d\n", menor); return 0; }
Terminal Salida
$ ./buscar_menor El menor es: 3

Observá que el for empieza en i = 1 para no comparar inútilmente a numeros[0] consigo mismo.

26 ¡Peligro! ¿Por Qué NUNCA Hacer int menor = 0;?

Muchos estudiantes tienden por costumbre a poner todas las variables en 0 al principio. Mirá qué desastre ocurre si ponés int menor = 0; al buscar el menor de {12, 8, 25, 3, 17}:

❌ La Trampa: int menor = 0;
int numeros[5] = {12, 8, 25, 3, 17}; int menor = 0; // ❌ ¡ERROR LÓGICO! for (int i = 0; i < 5; i++) { if (numeros[i] < menor) { menor = numeros[i]; } }

Como todos los números del vector son positivos (mayores a 0), ninguno es menor que 0. ¡El programa terminará diciendo que el menor es 0, un número que ni siquiera estaba en el vector!

✅ La Regla Segura: int menor = numeros[0];
int numeros[5] = {12, 8, 25, 3, 17}; int menor = numeros[0]; // ✅ Toma el 12 real for (int i = 1; i < 5; i++) { if (numeros[i] < menor) { menor = numeros[i]; } }

Al empezar con numeros[0], garantizás que estás comparando contra un elemento que sí pertenece al vector. Funciona siempre (con positivos, negativos o ceros).

27 Buscar el Mayor Elemento (y su Posición)

Como indica el apunte, para buscar el mayor es exactamente la misma lógica, solo que cambiamos el signo menor < por el signo mayor >. Además, podemos guardar en qué posición estaba:

buscar_mayor.c Mayor y Posición
#include <stdio.h> int main() { int numeros[5] = {12, 8, 25, 3, 17}; int mayor = numeros[0]; int posMayor = 0; for (int i = 1; i < 5; i++) { if (numeros[i] > mayor) { mayor = numeros[i]; posMayor = i; // Guardamos en qué casilla estaba } } printf("El mayor es %d (posicion %d)\n", mayor, posMayor); return 0; }
Terminal Salida
$ ./buscar_mayor El mayor es 25 (posicion 2)

Cada vez que encontramos un nuevo campeón (numeros[i] > mayor), guardamos tanto el valor como su índice i.

28 Buscar el Primer Número Par (Uso de break)

¿Qué pasa si solo nos piden mostrar el primer número par que aparezca en el vector y no queremos que siga mostrando los demás? Veamos el ejemplo del apunte:

primer_par_break.c Ejemplo del Apunte
#include <stdio.h> int main() { int numeros[5] = {7, 11, 8, 15, 20}; for (int i = 0; i < 5; i++) { if (numeros[i] % 2 == 0) { printf("Primer par encontrado: %d\n", numeros[i]); break; // Corta el ciclo inmediatamente } } return 0; }
Terminal Salida
$ ./primer_par_break Primer par encontrado: 8

Aunque el 20 también es par, el programa solo muestra el 8 porque el break detuvo la búsqueda apenas halló el primero.

30 Buscar si Existe un Valor Específico (Bandera)

¿Y si buscamos un número puntual (por ejemplo el 25) y queremos informar al final si estaba o si NO estaba en el vector? Usamos una variable bandera (encontrado):

buscar_valor_especifico.c Bandera (Flag)
#include <stdio.h> int main() { int numeros[5] = {12, 8, 25, 3, 17}; int buscado = 25; int encontrado = 0; // 0 = Todavía NO lo encontré | 1 = ¡Sí lo encontré! for (int i = 0; i < 5; i++) { if (numeros[i] == buscado) { encontrado = 1; // Levanto la bandera printf("Encontrado en la posicion %d\n", i); break; } } if (encontrado == 0) { printf("El numero %d no esta en el vector.\n", buscado); } return 0; }

31 Error Clásico: Poner "No está" Adentro del for

Mirá qué pasa si en vez de usar una bandera afuera del ciclo ponés un else adentro del for buscando el 25 en {12, 8, 25, 3, 17}:

❌ MAL: Decir "No está" en cada casilla
for (int i = 0; i < 5; i++) { if (numeros[i] == 25) { printf("Encontrado!\n"); } else { // ❌ ¡Se apura a decir que no está! printf("No esta!\n"); } }

En la vuelta 0 mira el 12 y ya imprime "No está!" sin haber mirado el resto del vector. Imprime: No está, No está, Encontrado, No está, No está.

✅ BIEN: Preguntar recién al salir del for
int encontrado = 0; for (int i = 0; i < 5; i++) { if (numeros[i] == 25) { encontrado = 1; break; } } // Recién AFUERA del for sacamos la conclusión: if (encontrado == 0) { printf("No esta!\n"); }

Solo podemos asegurar que un número no existe después de haber revisado todas las casillas.

32 Relación con el Modelo de Examen (Nivel 4)

🎯 El Desafío de Examen del Apunte (Página 12)

En el examen suele aparecer este ejercicio integrador:
"Encontrar el menor número par del vector".

Para resolverlo tenemos que combinar las 3 herramientas que aprendimos hoy:

1. Recorrido con for

Para pasar por todos los elementos del vector de principio a fin.

2. Filtro de Paridad

Verificar primero si el número actual es par: if (numeros[i] % 2 == 0).

3. Búsqueda de Menor

Entre los que sí sean pares, quedarnos con el primer par que aparezca y luego actualizar si aparece un par más chico.

⚠️ ¡Atención! ¿Por qué acá NO podemos hacer simplemente menorPar = numeros[0]?
Porque ¿qué pasa si numeros[0] es un número impar chiquito como 1 o 3? ¡Estaríamos metiendo un impar en menorPar! Por eso usamos una bandera hayPar = 0 para capturar el primer par real que encontremos.

33 Solución Completa: El Menor Número Par

menor_numero_par_examen.c Modelo de Examen
#include <stdio.h> int main() { int numeros[5] = {3, 14, 7, 8, 20}; int menorPar; int hayPar = 0; // 0 = Aún no vi ningún par for (int i = 0; i < 5; i++) { if (numeros[i] % 2 == 0) { // Solo miro los pares if (hayPar == 0 || numeros[i] < menorPar) { menorPar = numeros[i]; hayPar = 1; } } } if (hayPar == 1) { printf("El menor par es: %d\n", menorPar); } else { printf("No habia numeros pares.\n"); } return 0; }
Terminal Salida
$ ./menor_par El menor par es: 8

• 3: impar (lo ignora).
• 14: 1° par (hayPar == 0) ➔ menorPar = 14, hayPar = 1.
• 7: impar (lo ignora).
• 8: par y 8 < 14 ➔ menorPar = 8.
• 20: par pero no es menor a 8.

Dado el vector int temperaturas[6] = {-3, 12, 0, 8, -1, 15};, escribí un ciclo for que cuente y muestre cuántas temperaturas son estrictamente mayores a 0.

int temperaturas[6] = {-3, 12, 0, 8, -1, 15}; int positivos = 0; for (int i = 0; i < 6; i++) { if (temperaturas[i] > 0) { positivos++; } } printf("Cantidad de positivos: %d\n", positivos); // Muestra 3 (12, 8 y 15)

Ejercicio 2: Encontrar el mayor número impar

Dado int v[5] = {20, 7, 15, 4, 9};, ¿cómo adaptarías el código de examen para encontrar el mayor número impar?

💻 Ver solución paso a paso
int v[5] = {20, 7, 15, 4, 9}; int mayorImpar, hayImpar = 0; for (int i = 0; i < 5; i++) { if (v[i] % 2 != 0) { // Condición de impar if (hayImpar == 0 || v[i] > mayorImpar) { mayorImpar = v[i]; hayImpar = 1; } } } printf("El mayor impar es: %d\n", mayorImpar); // Muestra 15
