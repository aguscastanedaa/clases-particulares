01 Objetivos y el Salto a Dos Dimensiones

De la línea recta (1D) al plano (2D)

En las primeras tres unidades trabajamos con vectores: una sola fila de casilleros uno al lado del otro donde nos alcanzaba con un único número de posición (índice) para encontrar cualquier dato.

Hoy damos un paso clave: ¿qué hacemos cuando nuestros datos tienen forma de tabla o cuadrícula con varios renglones y columnas? Para eso existen las matrices.

Lo que vas a dominar hoy

  • Comprender qué es una matriz y diferenciar filas (horizontales) de columnas (verticales).
  • Declarar e inicializar matrices calculando su cantidad total de posiciones.
  • Leer y modificar cualquier casillero usando sus dos coordenadas [fila][columna].
  • Recorrer, mostrar en forma de tabla y cargar matrices con dos ciclos for anidados.
  • Buscar el mayor/menor, sumar elementos y calcular totales por fila o por columna.

02 ¿Qué es una Matriz?

Definición del Apunte Teórico (Sección 6)

Una matriz es una estructura que permite almacenar muchos datos del mismo tipo organizados en filas y columnas. Podés imaginarla exactamente como una tabla de Excel o un cuadro de doble entrada.

↔️ Las Filas (Horizontales)

Son los renglones horizontales de la tabla (van de izquierda a derecha). Se numeran de arriba hacia abajo empezando siempre desde la Fila 0.

↕️ Las Columnas (Verticales)

Son las tiras verticales de la tabla (van de arriba hacia abajo). Se numeran de izquierda a derecha empezando siempre desde la Columna 0.

📌 Condición importante: Igual que en los vectores, todos los casilleros de una misma matriz deben ser del mismo tipo de dato (todos int, o todos float, o todos char).

04 ¿Cuándo Usamos una Matriz? (Ejemplos Reales)

Siempre que tengamos información cruzada entre dos categorías (por ejemplo, Alumnos × Materias o Filas × Butacas), una matriz es la estructura ideal:

📚 1. Boletín de Notas de un Curso

Si tenemos 4 alumnos y cada uno rinde 3 trimestres, en lugar de crear 4 vectores sueltos creamos una sola matriz notas[4][3]: cada fila es un alumno y cada columna es un trimestre.

🎮 2. Tableros de Juegos

Un tablero de Ta-Te-Tí es una matriz de 3x3; un tablero de Ajedrez o Damas es una matriz de 8x8; el mapa de la Batalla Naval es una cuadrícula de 10x10.

🎬 3. Reservas de Cine o Teatro

Las butacas de una sala están organizadas por fila y número de asiento. Podemos guardar un 0 si el asiento está libre y un 1 si ya está ocupado.

🗓️ 4. Horarios y Planillas de Ventas

El horario de la escuela (5 días de la semana × 6 módulos por día) o las ventas de 3 sucursales a lo largo de los 12 meses del año.

06 ¿Cómo se Declara una Matriz en C?

Sintaxis general obligatoria:

tipo nombre[FILAS][COLUMNAS];

1. tipo y nombre

Indica qué clase de datos guardará toda la tabla (int, float, char) y el nombre identificador que elegimos (ej. matriz, notas, tablero).

2. Primer Corchete: [FILAS]

El primer número entre corchetes indica SIEMPRE la cantidad de filas (renglones horizontales) que tendrá la matriz.

3. Segundo Corchete: [COLUMNAS]

El segundo número entre corchetes indica SIEMPRE la cantidad de columnas (verticales) que tendrá cada fila.

🧠 Regla para no olvidarte nunca el orden: Recordá la sigla "F-C" (como Fútbol Club): primero va la F de Fila y segundo va la C de Columna: matriz[Fila][Columna].

07 ¿Cuántos Elementos Entran en una Matriz?

Para saber cuántas casillas totales tiene una matriz, simplemente multiplicamos la cantidad de filas por la cantidad de columnas ($\text{Total} = \text{Filas} \times \text{Columnas}$). Veamos los dos ejemplos del apunte:

Ejemplo 1: Matriz Cuadrada 3x3

int matriz[3][3];
  • Cantidad de filas: 3
  • Cantidad de columnas: 3
  • Capacidad total: $3 \times 3 = \mathbf{9}$ números enteros.

Se llama matriz cuadrada porque tiene la misma cantidad de filas que de columnas.

Ejemplo 2: Matriz Rectangular 3x4

int matriz[3][4];
  • Cantidad de filas: 3
  • Cantidad de columnas: 4
  • Capacidad total: $3 \times 4 = \mathbf{12}$ posiciones en total.

Se llama matriz rectangular porque el número de filas es distinto al de columnas.

08 Índices en Base Cero: De 0 a N - 1

¡La misma regla fundamental de los vectores!

En lenguaje C, tanto las filas como las columnas empiezan a contarse desde 0 (nunca desde 1).

En int matriz[2][3];

  • Tiene 2 filas ➔ las filas válidas son la 0 y la 1.
    (¡La fila 2 NO existe!)
  • Tiene 3 columnas ➔ las columnas válidas son la 0, la 1 y la 2.
    (¡La columna 3 NO existe!)

Regla General para cualquier Matriz

Si declaramos tipo m[F][C];:

  • Primera casilla (arriba a la izquierda): m[0][0]
  • Filas válidas: desde 0 hasta F - 1
  • Columnas válidas: desde 0 hasta C - 1
  • Última casilla (abajo a la derecha): m[F - 1][C - 1]

10 Inicializar una Matriz al Crearla

Tal como muestra la página 17 del apunte, podemos crear una matriz ya cargada con valores iniciales usando llaves internas para cada fila separadas por una coma:

inicializar_matriz.c 2 Filas × 3 Columnas
int matriz[2][3] = { {1, 2, 3}, // Valores de la Fila 0 {4, 5, 6} // Valores de la Fila 1 };

¿Cómo se lee esta estructura de llaves?

  • La llave grande exterior { ... }; envuelve a toda la matriz y termina con punto y coma.
  • La primera llave interna {1, 2, 3} llena las 3 columnas de la Fila 0.
  • Después va una coma , para separar una fila de la siguiente.
  • La segunda llave interna {4, 5, 6} llena las 3 columnas de la Fila 1.

14 ¿Cómo Guarda C la Matriz en la Memoria RAM?

Un secreto del hardware: la memoria RAM es una tira recta

Aunque nosotros dibujamos la matriz como un cuadrado de filas y columnas, los chips de memoria RAM son una sola fila larga de casilleros. C guarda las matrices fila por fila, una detrás de la otra (técnica llamada Row-Major Order):

Así se ubican las 6 casillas de matriz[2][3] contiguas en la memoria RAM:

Fila 0 • [0][0]
1
Fila 0 • [0][1]
2
Fila 0 • [0][2]
3
Fila 1 • [1][0]
4
Fila 1 • [1][1]
5
Fila 1 • [1][2]
6

💡 ¿Por qué nos importa esto? Porque el orden natural y más veloz para recorrer una matriz en C es exactamente ese: terminar primero toda la Fila 0 de izquierda a derecha, y recién después bajar a la Fila 1.

15 Recorrer una Matriz: ¿Por Qué Dos Ciclos for?

Como explica la página 18 del apunte: "Para recorrer un vector alcanzaba con un solo for, pero una matriz tiene filas y columnas, por lo tanto necesitamos dos ciclos for anidados."

1. El Primer for (Externo) ➔ Recorre las FILAS

for(int fila = 0; fila < 2; fila++)

Elige en qué renglón horizontal estamos parados ahora. Primero se para en la fila = 0, espera a que se recorran todas sus columnas, y luego baja a la fila = 1.

2. El Segundo for (Interno) ➔ Recorre las COLUMNAS

for(int columna = 0; columna < 3; columna++)

Está adentro del primer for. Para la fila actual, camina de izquierda a derecha por todas sus columnas: columna = 0, luego columna = 1 y luego columna = 2.

📖 Analogía de lectura: Es exactamente igual a cómo leés un libro: tus ojos eligen el renglón 0 y leen palabra por palabra de izquierda a derecha (columnas); cuando terminás el renglón, bajás al renglón 1 y volvés a empezar desde la izquierda.

16 Código del Apunte para Mostrar una Matriz

Veamos el programa completo de las páginas 18 y 19 del apunte para mostrar nuestra matriz de 2 filas y 3 columnas en pantalla:

mostrar_matriz_apunte.c Recorrido 2D
#include <stdio.h> int main() { int matriz[2][3] = { {1, 2, 3}, {4, 5, 6} }; for(int fila = 0; fila < 2; fila++) { for(int columna = 0; columna < 3; columna++) { printf("%d ", matriz[fila][columna]); } printf("\n"); } return 0; }

¿Qué logra este código?

Imprime los 3 números de la Fila 0 separados por espacio, hace un salto de línea (\n) y abajo imprime los 3 números de la Fila 1.

17 El Rol Clave del printf("\n"); Entre las Llaves

Muchos alumnos preguntan qué pasa si nos olvidamos del printf("\n"); o si lo ponemos en el lugar equivocado. Compará los 3 casos:

✅ 1. Afuera del 2do for (Correcto)
for(int f = 0; f < 2; f++) { for(int c = 0; c < 3; c++) { printf("%d ", m[f][c]); } printf("\n"); }
1 2 3 4 5 6

Salta de renglón solo al terminar cada fila completa.

❌ 2. Si nos olvidamos el \n
for(int f = 0; f < 2; f++) { for(int c = 0; c < 3; c++) { printf("%d ", m[f][c]); } // Falta printf("\n"); }
1 2 3 4 5 6

Sale todo en una sola tira como si fuera un vector.

❌ 3. Si ponemos \n adentro
for(int f = 0; f < 2; f++) { for(int c = 0; c < 3; c++) { printf("%d\n", m[f][c]); } }
1 2 3...

Salta de renglón en cada número (sale una columna vertical).

19 Seguimiento: Vuelta 2 (fila = 1) y Traza Completa

Después del salto de línea, el primer for hace fila++ y pasa a valer fila = 1:

  • El ciclo interno de columna vuelve a empezar desde 0.
  • Con columna = 0: muestra matriz[1][0] ➔ 4
  • Con columna = 1: muestra matriz[1][1] ➔ 5
  • Con columna = 2: muestra matriz[1][2] ➔ 6
  • Termina el segundo for y hace el segundo printf("\n");.
  • Luego fila sube a 2, y como 2 < 2 es falso, termina todo.

20 Cargar una Matriz por Teclado con scanf

En la página 19 del apunte vemos cómo pedirle al usuario que ingrese por teclado todos los números de una matriz usando el mismo doble ciclo for:

cargar_matriz_apunte.c Lectura con scanf
#include <stdio.h> int main() { int matriz[2][3]; for(int fila = 0; fila < 2; fila++) { for(int columna = 0; columna < 3; columna++) { printf("Ingrese un numero: "); scanf("%d", &matriz[fila][columna]); } } return 0; }

⚠️ ¡No te olvides el símbolo ampersand (&)! En scanf("%d", &matriz[fila][columna]); el & adelante del nombre de la matriz es obligatorio para indicarle a C en qué casillero de la memoria guardar el número.

21 ¿En Qué Orden se Cargan los Datos con scanf?

Orden de llenado (Fila por Fila)

Como el primer for es de fila y el segundo de columna, los 6 números que escribe el usuario se guardan en este orden exacto:

  1. 1er número ingresado ➔ va a matriz[0][0]
  2. 2do número ingresado ➔ va a matriz[0][1]
  3. 3er número ingresado ➔ va a matriz[0][2] (fin Fila 0)
  4. 4to número ingresado ➔ va a matriz[1][0]
  5. 5to número ingresado ➔ va a matriz[1][1]
  6. 6to número ingresado ➔ va a matriz[1][2] (fin Fila 1)

✨ Mejora Pro: Avisarle al usuario qué casilla carga

Podemos mostrar los valores de fila y columna adentro del printf para que el usuario sepa qué coordenada está completando:

printf("Ingrese valor para [%d][%d]: ", fila, columna); scanf("%d", &matriz[fila][columna]);
Ingrese valor para [0][0]: 10 Ingrese valor para [0][1]: 25 Ingrese valor para [0][2]: 8...

22 Buscar el Mayor Elemento en una Matriz (Apunte pág. 20)

La idea es idéntica a cuando buscábamos el mayor en un vector: tomamos el primer elemento matriz[0][0] como referencia inicial y luego recorremos toda la matriz comparando cada casilla contra mayor:

buscar_mayor_matriz.c Algoritmo del Apunte (Pág. 20)
int mayor = matriz[0][0]; // Asumimos al principio que el primero es el mayor for(int fila = 0; fila < 2; fila++) { for(int columna = 0; columna < 3; columna++) { if(matriz[fila][columna] > mayor) { mayor = matriz[fila][columna]; // Actualizamos el récord } } } printf("El numero mayor de la matriz es: %d\n", mayor);

💡 ¿Y si quisiéramos buscar el MENOR de toda la matriz? Igual que en vectores: llamamos a la variable menor = matriz[0][0]; y cambiamos el signo > por < en el if: if(matriz[fila][columna] < menor).

23 Traza del Mayor y Cómo Guardar su Posición [fila][col]

Seguimiento sobre {{14, 92, 30}, {55, 99, 12}}

  • Inicio: mayor = matriz[0][0] ➔ arranca en 14.
  • [0][0] = 14: ¿14 > 14? No. Sigue 14.
  • [0][1] = 92: ¿92 > 14? SÍ ➔ mayor pasa a ser 92.
  • [0][2] = 30: ¿30 > 92? No. Sigue 92.
  • [1][0] = 55: ¿55 > 92? No. Sigue 92.
  • [1][1] = 99: ¿99 > 92? SÍ ➔ mayor pasa a ser 99.
  • [1][2] = 12: ¿12 > 99? No. Resultado final: 99.

¿En qué fila y columna estaba el mayor?

Si además nos piden informar en qué casillero apareció el máximo, guardamos fila y columna adentro del mismo if:

int mayor = matriz[0][0]; int filaMax = 0, colMax = 0; for(int fila = 0; fila < 2; fila++) { for(int col = 0; col < 3; col++) { if(matriz[fila][col] > mayor) { mayor = matriz[fila][col]; filaMax = fila; colMax = col; } } }

24 Ejemplo Nivel 2: Suma Total y Promedio de una Matriz

Para sumar todos los números de una matriz usamos una variable acumuladora int suma = 0; inicializada en cero antes del doble for:

suma_y_promedio_matriz.c Acumulador Global
#include <stdio.h> int main() { int matriz[2][3] = { {10, 20, 30}, {40, 50, 60} }; int suma = 0; float promedio; for(int fila = 0; fila < 2; fila++) { for(int columna = 0; columna < 3; columna++) { suma = suma + matriz[fila][columna]; } } promedio = (float)suma / 6; // 2 filas * 3 columnas = 6 elementos printf("Suma total: %d\n", suma); printf("Promedio: %.2f\n", promedio); return 0; }
Consolastdout
Suma total: 210 Promedio: 35.00

División del promedio

Recordá dividir por el total de casillas de la matriz ($\text{Filas} \times \text{Columnas} = 2 \times 3 = 6$), ¡no por la cantidad de filas sola!

25 Ejemplo Nivel 2B: Contar Elementos con Condición

¿Cómo contamos cuántos números mayores a 10 (o cuántos números pares) hay dentro de una matriz de 3x3? Agregamos un contador y un if adentro del segundo for:

contar_en_matriz.c Contador + if
#include <stdio.h> int main() { int matriz[3][3] = { {4, 15, 8}, {22, 7, 19}, {3, 12, 5} }; int contMayoresA10 = 0; int contPares = 0; for(int fila = 0; fila < 3; fila++) { for(int columna = 0; columna < 3; columna++) { if(matriz[fila][columna] > 10) { contMayoresA10++; } if(matriz[fila][columna] % 2 == 0) { contPares++; } } } printf("Mayores a 10: %d | Numeros pares: %d\n", contMayoresA10, contPares); return 0; }

26 Ejemplo Nivel 3: Sumar por Cada Fila Individual

Imaginá que cada fila es un alumno (3 alumnos) y cada columna es una nota (4 notas por alumno). Queremos mostrar el promedio de cada alumno por separado:

promedio_por_fila.c Nivel 3 • Subtotal por Fila
int notas[3][4] = { {8, 7, 9, 8}, // Alumno 0 {6, 5, 6, 7}, // Alumno 1 {10, 9, 10, 9} // Alumno 2 }; for(int fila = 0; fila < 3; fila++) { int sumaFila = 0; // ¡Se reinicia en 0 para cada alumno! for(int columna = 0; columna < 4; columna++) { sumaFila = sumaFila + notas[fila][columna]; } float prom = (float)sumaFila / 4; printf("Alumno %d -> Suma: %d | Promedio: %.2f\n", fila, sumaFila, prom); }
Consolastdout
Alumno 0 -> Suma: 32 | Promedio: 8.00 Alumno 1 -> Suma: 24 | Promedio: 6.00 Alumno 2 -> Suma: 38 | Promedio: 9.50

🔑 Ubicación de sumaFila = 0;: Va adentro del primer for y antes del segundo, para que al pasar al siguiente alumno la cuenta vuelva a empezar desde 0.

27 Ejemplo Nivel 4: Sumar por Cada Columna

¿Y si queremos saber cuánto se vendió en cada día (columna) sumando las 2 sucursales (filas)? Ponemos el for de columna afuera y el for de fila adentro, ¡pero al leer la matriz respetamos siempre ventas[fila][columna]!

suma_por_columna.c Nivel 4 • Subtotal por Columna
int ventas[2][3] = { {100, 200, 150}, // Sucursal 0 (Lunes, Martes, Miércoles) {300, 100, 250} // Sucursal 1 (Lunes, Martes, Miércoles) }; for(int columna = 0; columna < 3; columna++) { int sumaCol = 0; // Se reinicia en 0 para cada nueva columna for(int fila = 0; fila < 2; fila++) { sumaCol = sumaCol + ventas[fila][columna]; } printf("Total Columna %d: %d\n", columna, sumaCol); } // Imprime: Columna 0: 400 | Columna 1: 300 | Columna 2: 400

28 Nombres de Variables: fila / columna vs. i / j

Tanto en el apunte como en los exámenes vas a ver escritos los índices de dos maneras equivalentes. Ambas hacen exactamente lo mismo:

Estilo Descriptivo (Usado en el Apunte)

for(int fila = 0; fila < 2; fila++) { for(int columna = 0; columna < 3; columna++) { printf("%d ", matriz[fila][columna]); } printf("\n"); }

✓ Super claro para empezar porque el propio nombre te recuerda qué corchete es cuál.

Estilo Abreviado Clásico (i y j)

for(int i = 0; i < 2; i++) { for(int j = 0; j < 3; j++) { printf("%d ", matriz[i][j]); } printf("\n"); }

✓ Por convención universal, en matrices i representa la fila y j representa la columna.

29 Errores Frecuentes con Matrices (Parte 1)

❌ Error 1: Invertir los límites de Filas y Columnas
int matriz[2][3]; // 2 filas, 3 columnas for(int fila = 0; fila < 3; fila++) // ¡MAL! Puso 3 { for(int col = 0; col < 2; col++) // ¡MAL! Puso 2 matriz[fila][col] = 0; }

Qué pasa: En una matriz rectangular [2][3], si hacés fila < 3 intentás entrar a la matriz[2][...] que no existe (desborde de memoria). El tope de fila debe coincidir siempre con el primer corchete (2) y el de columna con el segundo (3).

❌ Error 2: Escribir coma [f, c] en vez de [f][c]
// Sintaxis inválida en lenguaje C: matriz[1, 2] = 50; // ¡ERROR! // Sintaxis correcta en lenguaje C: matriz[1][2] = 50; // ¡BIEN!

Qué pasa: En C cada dimensión lleva su propio par de corchetes separado. Nunca separes fila y columna con una coma adentro del mismo corchete.

30 Errores Frecuentes con Matrices (Parte 2)

❌ Error 3: Inicializar mayor = 0 en vez de matriz[0][0]
int mayor = 0; // Peligroso si hay negativos

Qué pasa: Si la matriz tiene todas temperaturas bajo cero (ej. -5, -12, -3), ningún elemento será mayor que 0 y tu programa dirá erróneamente que el mayor es 0. Si además buscás el menor y ponés menor = 0, ¡casi siempre dará 0! Siempre inicializá con matriz[0][0].

❌ Error 4: Olvidar reiniciar el acumulador por fila
int sumaFila = 0; // Afuera de ambos for for(int fila = 0; fila < 3; fila++) { for(int col = 0; col < 4; col++) sumaFila += notas[fila][col]; }

Qué pasa: Si no volvés a poner sumaFila = 0; al empezar cada nueva fila, las notas del Alumno 1 se suman encima de las del Alumno 0.

31 Ejercicio Práctico 1: Buscar el Menor en una Matriz

Enunciado

Dada una matriz de 3x3 ya inicializada con números enteros, escribí un programa en C que la muestre en formato tabla y luego busque e informe cuál es el número menor de toda la matriz y en qué fila y columna se encuentra.

👁️ Ver solución completa en C
#include <stdio.h> int main() { int matriz[3][3] = { {25, 18, 40}, {12, 7, 33}, {9, 50, 14} }; int menor = matriz[0][0]; int filaMenor = 0, colMenor = 0; for(int fila = 0; fila < 3; fila++) { for(int columna = 0; columna < 3; columna++) { printf("%d ", matriz[fila][columna]); if(matriz[fila][columna] < menor) { menor = matriz[fila][columna]; filaMenor = fila; colMenor = columna; } } printf("\n"); } printf("\nEl menor es %d (Fila %d, Columna %d)\n", menor, filaMenor, colMenor); return 0; }

32 Ejercicio Práctico 2: Control de Butacas de Cine

Enunciado

Una sala de cine pequeña tiene 2 filas de 4 asientos cada una (int cine[2][4]). Un 0 indica asiento libre y un 1 indica asiento ocupado. Escribí un programa que muestre el mapa de la sala y cuente cuántos asientos están libres y cuántos están ocupados.

👁️ Ver solución completa en C
#include <stdio.h> int main() { int cine[2][4] = { {1, 0, 1, 1}, {0, 0, 1, 0} }; int libres = 0, ocupados = 0; for(int fila = 0; fila < 2; fila++) { for(int columna = 0; columna < 4; columna++) { printf("%d ", cine[fila][columna]); if(cine[fila][columna] == 0) libres++; else ocupados++; } printf("\n"); } printf("Asientos libres: %d | Ocupados: %d\n", libres, ocupados); return 0; }

33 Ejercicio Práctico 3: Desafío Tipo Examen

Sin ejecutar el programa en la computadora, determiná: 1) ¿Cuántos elementos tiene la matriz? 2) ¿Cuál es el valor de m[1][2] antes del doble for? 3) ¿Qué muestra exactamente el printf final?

int m[2][3] = { {5, 10, 15}, {20, 25, 30} }; int acum = 0; m[0][1] = 50; for(int fila = 0; fila < 2; fila++) { for(int col = 0; col < 3; col++) { if(m[fila][col] >= 25) { acum = acum + m[fila][col]; } } } printf("Resultado: %d", acum);
👁️ Ver respuestas detalladas
  • 1) Total de elementos: $2 \text{ filas} \times 3 \text{ columnas} = \mathbf{6}$ elementos.
  • 2) Valor de m[1][2]: Fila 1 (segunda fila), Columna 2 (tercera columna) ➔ vale 30.
  • 3) Salida final: La línea m[0][1] = 50; cambia el 10 por un 50, quedando la matriz {{5, 50, 15}, {20, 25, 30}}. El if suma solo los mayores o iguales a 25: suma 50 + 25 + 30 = 105. Imprime: Resultado: 105.

34 Resumen Final y Checklist de la Unidad 04

Síntesis de Matrices

  • Declaración: tipo nombre[filas][columnas]; (capacidad total = $\text{filas} \times \text{columnas}$).
  • Coordenadas: Siempre en base cero (filas de 0 a F-1, columnas de 0 a C-1).
  • Doble ciclo for: El primero recorre las filas y el segundo recorre las columnas.
  • Formato tabla: Imprimir cada elemento con espacio adentro del 2do for y hacer printf("\n"); al cerrar el 2do for.
