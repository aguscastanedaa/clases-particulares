Reserva y Liberación: malloc() y free()

Cómo calcular el espacio exacto con sizeof(), pedir memoria a medida en el Heap con malloc() y devolverla responsablemente con free()

#include <stdlib.h> sizeof(tipo) malloc(cantidad * sizeof) free(vector)

💡 Objetivo central: Hoy pasamos de la teoría a la práctica real creando nuestros primeros vectores dinámicos cuyo tamaño elige el usuario mientras el programa se ejecuta.

01 Objetivos de Aprendizaje de la Unidad

Lo que vas a dominar hoy

  • Incluir la biblioteca obligatoria #include <stdlib.h>.
  • Calcular el tamaño en bytes de cualquier tipo usando sizeof().
  • Reservar bloques de memoria en el Heap con malloc().
  • Pedir al usuario cantidad por teclado y crear un vector exacto para esa cantidad.
  • Comprobar siempre si la reserva falló verificando if (vector == NULL).
  • Liberar la memoria al finalizar usando free(vector) y evitar los 4 errores clásicos.

Conexión con la Unidad 07

En la unidad anterior aprendimos que un puntero (int *vector;) es solo un "papelito" que guarda una dirección de memoria, y que la memoria dinámica vive en el Heap.

Hoy vamos a aprender las dos funciones que trabajan siempre en equipo: malloc() para reservar el espacio y free() para devolverlo.

02 La Biblioteca Obligatoria: #include <stdlib.h>

Requisito número 1 antes de usar memoria dinámica

Tal como indica el apunte en las páginas 29 y 30, para poder utilizar las funciones malloc() y free() es obligatorio incluir la biblioteca <stdlib.h> al comienzo de nuestro archivo:

encabezados.c Bibliotecas Estándar
#include <stdio.h> // Para printf() y scanf() #include <stdlib.h> // OBLIGATORIA para malloc(), free(), calloc() y realloc()

¿Qué significa stdlib.h?

Viene del inglés Standard Library (Biblioteca Estándar de C). Contiene las herramientas de control de memoria y utilidades generales del sistema.

¿Qué pasa si me olvido de incluirla?

El compilador mostrará una advertencia o error diciendo que no conoce a malloc ni a free (implicit declaration of function).

03 Antes de Pedir Memoria: ¿Cuánto Ocupa cada Dato?

Cuando llamamos a malloc() para pedir espacio en el Heap, malloc() no entiende de "enteros" o "notas": solo entiende de cantidad total de bytes.

¿Tengo que saber de memoria cuántos bytes mide cada tipo?

¡No! Como aclara el apunte en la página 29: "No hace falta saber exactamente cuántos bytes ocupa un entero en cada computadora".

En una PC moderna un int suele ocupar 4 bytes, pero en otros dispositivos puede variar. Por eso C nos da una herramienta automática que lo mide por nosotros: sizeof().

¿Qué hace sizeof()?

sizeof(tipo) le pregunta a la computadora cuántos bytes ocupa exactamente ese tipo de dato:

sizeof(int) // Devuelve 4 (bytes) sizeof(float) // Devuelve 4 (bytes) sizeof(char) // Devuelve 1 (byte)

04 El Operador sizeof() con Todos los Tipos

sizeof() funciona tanto con los tipos básicos de C (int, float, char, double) como con las estructuras struct que creamos en la Unidad 06:

Expresión en C Significado Valor típico en bytes
sizeof(char) Bytes que ocupa 1 carácter 1 byte
sizeof(int) Bytes que ocupa 1 número entero 4 bytes
sizeof(float) Bytes que ocupa 1 número con coma 4 bytes
sizeof(double) Bytes que ocupa 1 decimal de doble precisión 8 bytes
sizeof(struct Alumno) Bytes totales que suma toda la estructura Depende de sus campos (ej. 40 bytes)

06 La Función malloc() — ¿Qué Hace?

9.1 MALLOC() — Memory Allocation (Asignación de Memoria)

Su nombre viene del inglés Memory Allocation. Es la función que se encarga de reservar un bloque de memoria contigua en el Heap mientras el programa se está ejecutando.

1. ¿Qué recibe entre paréntesis?

La cantidad total de bytes que queremos reservar: por ejemplo, 5 * sizeof(int).

2. ¿Qué hace en la memoria RAM?

Va al Heap, busca un bloque libre de ese tamaño exacto y lo marca como reservado para nuestro programa.

3. ¿Qué nos devuelve?

Nos devuelve la dirección de memoria donde empieza ese bloque para que la guardemos en nuestro puntero.

07 Ejemplo Básico del Apunte: Reservar 5 Enteros

Veamos el primer ejemplo oficial de la página 29 del apunte para reservar memoria dinámica para 5 números enteros:

ejemplo_basico_malloc.c Apunte pág. 29
#include <stdlib.h> int *vector; vector = malloc(5 * sizeof(int));

💡 Nota útil: ¿Y si ves (int *)malloc(...) en algún libro o compilador?

En C estándar podés escribir directamente vector = malloc(5 * sizeof(int)); como en el apunte. Algunos programadores o compiladores agregan adelante el tipo entre paréntesis: vector = (int *)malloc(5 * sizeof(int));. Ambas formas hacen exactamente lo mismo: guardar la dirección en vector.

08 Desglose Paso a Paso de vector = malloc(5 * sizeof(int));

Entendamos qué ocurre exactamente en esa línea leyéndola de adentro hacia afuera:

vector = malloc(5 * sizeof(int));
1
sizeof(int) ➔ Averigua cuántos bytes ocupa un entero en la computadora (4 bytes).
2
5 * sizeof(int) ➔ Multiplica 5 por 4 bytes = 20 bytes totales necesarios para guardar 5 enteros.
3
malloc(20) ➔ Reserva un bloque continuo de 20 bytes en el Heap y devuelve su dirección de inicio (ej. 0x5000).
4
vector = ... ➔ Guarda esa dirección 0x5000 adentro de nuestro puntero vector. ¡Ahora tenemos un vector de 5 posiciones listo para usar!

10 Reservar Memoria según lo que Pida el Usuario

El verdadero poder de malloc() (Apunte pág. 30)

En lugar de poner un 5 fijo, primero le pedimos al usuario con scanf cuántos elementos necesita y guardamos ese número en la variable cantidad:

reserva_a_medida.c Apunte pág. 30
int cantidad; printf("Cantidad: "); scanf("%d", &cantidad); int *vector; vector = malloc(cantidad * sizeof(int));

✨ Resultado: Ahora el programa reserva memoria para la cantidad exacta que pidió el usuario. Si el usuario escribe 8, se reservan 8 lugares; si escribe 250, se reservan 250 lugares.

11 Simulación en Vivo: El Usuario Ingresa 8

Sigamos qué pasa en la computadora cuando ejecutamos el código anterior y el usuario escribe 8 en el teclado:

Paso Instrucción Ejecutada ¿Qué ocurre en la Memoria RAM?
1 int cantidad; Se crea la variable cantidad en el Stack.
2 scanf("%d", &cantidad); El usuario tipea 8. Ahora cantidad vale 8.
3 int *vector; Se crea el puntero vector en el Stack esperando una dirección.
4 malloc(cantidad * sizeof(int)) Calcula 8 * 4 = 32 bytes y reserva 8 casilleros enteros en el Heap (índices 0 al 7).

12 ¿Qué Pasa si No Hay Memoria Libre? (vector == NULL)

Comprobación de seguridad recomendada

En casi todos los ejercicios de clase habrá memoria de sobra. Pero si algún día un programa pide una cantidad gigantesca y la RAM no alcanza, malloc() falla y devuelve NULL.

validacion_null.c Buena Práctica
int *vector = malloc(cantidad * sizeof(int)); if (vector == NULL) { printf("Error: No se pudo reservar memoria.\n"); return 1; // Terminamos el programa de forma segura }

🛡️ ¿Por qué sirve este if? Porque si vector quedó en NULL y tratamos de guardar algo en vector[0], el programa se cierra abruptamente. Con el if mostramos un aviso claro.

13 ¿Qué Hay Adentro del Vector Recién Creado con malloc()?

¡Cuidado! malloc() reserva el espacio pero NO lo limpia

Igual que pasaba con las variables comunes sin inicializar, las casillas recién reservadas con malloc() contienen valores basura desconocidos hasta que les carguemos datos nosotros:

vector[0]
-84215
vector[1]
32767
vector[2]
0
vector[3]
194821

💡 Dato importante: Nunca imprimas ni sumes las casillas de un vector creado con malloc() antes de haberles asignado un valor (o cargado con scanf). En la Unidad 09 veremos que existe calloc() cuando necesitamos que arranquen todas en 0.

14 ¿Cómo Usamos el Vector Después de Hacer malloc()?

Una vez que ejecutaste vector = malloc(cantidad * sizeof(int));, podés usar vector con corchetes exactamente igual que cualquier vector de los que usamos todo el bimestre:

uso_con_corchetes.c Acceso con índices
int *vector = malloc(3 * sizeof(int)); // Guardamos valores en cada posicion usando corchetes: vector[0] = 10; vector[1] = 20; vector[2] = 30; // Los mostramos por pantalla: printf("Posicion 0: %d\n", vector[0]); printf("Posicion 1: %d\n", vector[1]); printf("Posicion 2: %d\n", vector[2]);

15 Recorrer el Vector Dinámico con el Ciclo for

Como la cantidad de elementos está guardada en la variable cantidad, nuestros ciclos for siempre van desde i = 0 hasta i < cantidad:

1. Cargar con scanf
for(int i = 0; i < cantidad; i++) { printf("Ingrese un numero: "); scanf("%d", &vector[i]); }
2. Mostrar con printf
for(int i = 0; i < cantidad; i++) { printf("%d ", vector[i]); }

👀 Fijate en el scanf: Se escribe &vector[i] igual que en los vectores estáticos, porque queremos la dirección del casillero número i.

16 9.2 free() — ¿Por Qué Tenemos que Liberar la Memoria?

El problema que resuelve free() (Apunte pág. 30)

Cuando usamos malloc(), el programa reserva memoria en el Heap, pero esa memoria NO se libera automáticamente. Si nosotros no la liberamos, esa memoria queda ocupada aunque ya no la estemos usando.

En Memoria Estática (Stack)

C limpia todo solo cuando termina la función. No teníamos que hacer nada especial.

En Memoria Dinámica (Heap)

Como nosotros pedimos la memoria manualmente con malloc(), nosotros debemos devolverla manualmente con free().

17 Analogía del Apunte: Alquilar una Cancha de Fútbol

En la página 30 del apunte tenemos una analogía genial para entender cómo trabajan juntos malloc() y free(). Imaginá que alquilás una cancha de fútbol para jugar con tus amigos:

Paso 1: malloc()

Reservar la cancha

Llamás al complejo y reservás la cancha para tu grupo. A partir de ese momento la cancha queda bloqueada para ustedes.

Paso 2: Uso del vector

Jugar el partido

Usás la cancha durante un rato para jugar (en el programa: cargás datos con scanf, calculás promedios y mostrás resultados).

Paso 3: free()

Devolver la cancha

Cuando terminás de jugar, avisás en recepción y devolvés la cancha para que quede libre y otros puedan usarla.

⚽ ¿Qué pasa si terminaste de jugar y NO devolvés la cancha? La cancha sigue ocupada innecesariamente, nadie más puede entrar a jugar y te siguen cobrando el alquiler. ¡Con la memoria RAM pasa exactamente lo mismo!

18 ¿Qué Ocurre si Nunca Llamamos a free()?

Fuga de Memoria (Memory Leak)

Cuando un programa pide memoria con malloc() y se olvida de liberarla con free(), se produce lo que en programación se conoce como una fuga de memoria (o Memory Leak).

En un programa cortito de práctica

Puede que no notes que la PC ande lenta porque el programa dura pocos segundos, pero igual es un error de programación que se descuenta en los exámenes.

En un juego, navegador o servidor

Si cada minuto el programa reserva memoria nueva y nunca hace free(), la memoria RAM se va llenando hasta que toda la computadora se congela.

19 Cómo se Escribe free() (Apunte págs. 30 y 31)

La función free() sirve para liberar la memoria que fue reservada con malloc(). Su sintaxis es súper sencilla: solo recibe entre paréntesis el nombre del puntero:

Sintaxis General
free(variable); // Por ejemplo: free(vector);
Ejemplo Mínimo (Apunte pág. 31)
#include <stdlib.h> int *vector; vector = malloc(5 * sizeof(int)); free(vector);

📌 Fijate qué simple: A free(vector); no hay que pasarle el tamaño ni sizeof. El sistema operativo ya recuerda cuántos bytes medía el bloque que empieza en esa dirección y los libera todos juntos.

20 La Regla Simple del Apunte (Pág. 31)

✨ "Siempre pensalos juntos"

Si usaste malloc() ➔ deberías usar free(), normalmente al final del programa cuando ya no necesites esos datos.
Cada malloc() debe tener un único free().

🟢 malloc() ➔ Reserva memoria

Se escribe al principio (después de saber cuántos elementos queremos) para pedir el bloque en el Heap.

🟠 free() ➔ Libera memoria

Se escribe al final (justo antes de return 0;) cuando ya terminamos de mostrar y procesar el vector.

21 Ejemplo Práctico Completo del Apunte (Pág. 31)

Este es el programa modelo de la página 31 del apunte que integra todo el ciclo completo: pedir la cantidad, reservar con malloc(), cargar con for, mostrar los números y liberar con free():

ejemplo_completo_apunte.c Apunte pág. 31
#include <stdio.h> #include <stdlib.h> int main() { int cantidad; printf("Cuantos numeros queres guardar?: "); scanf("%d", &cantidad); int *vector; vector = malloc(cantidad * sizeof(int)); for(int i = 0; i < cantidad; i++) { printf("Ingrese un numero: "); scanf("%d", &vector[i]); } printf("Numeros ingresados:\n"); for(int i = 0; i < cantidad; i++) { printf("%d ", vector[i]); } free(vector); return 0; }

22 Análisis del Ejemplo Completo — Parte 1: Reserva

int cantidad; printf("Cuantos numeros?: "); scanf("%d", &cantidad); int *vector; vector = malloc( cantidad * sizeof(int) );
1
Primero preguntamos cantidad: Jamás podemos hacer el malloc() antes del scanf("%d", &cantidad); porque todavía no sabríamos cuántos lugares pedir.
2
Creamos el puntero int *vector;: Preparamos la variable que recibirá la dirección del bloque.
3
Llamamos a malloc(): Multiplicamos cantidad * sizeof(int) para reservar en el Heap el tamaño exacto.

23 Análisis del Ejemplo Completo — Parte 2: Uso y Liberación

for(int i = 0; i < cantidad; i++) { scanf("%d", &vector[i]); } for(int i = 0; i < cantidad; i++) { printf("%d ", vector[i]); } free(vector); return 0;
4
Primer ciclo for (Carga): Va desde 0 hasta cantidad - 1 guardando cada número en vector[i].
5
Segundo ciclo for (Muestra): Recorre todas las posiciones mostrando los datos guardados.
6
Cierre limpio con free(vector);: Como ya mostramos los datos y el programa va a terminar, devolvemos la memoria al Heap.

24 Seguimiento del Ciclo de Vida en la Memoria RAM

Supongamos que el usuario ingresa cantidad = 3 y luego carga los números 15, 40 y 25:

Momento del Programa Stack (cantidad y vector) Heap (Bloque en 0x5000)
1. Tras scanf de cantidad cantidad = 3 | vector = ? Sin reservar todavía
2. Tras malloc(3 * sizeof(int)) cantidad = 3 | vector = 0x5000 [ ? , ? , ? ] (3 lugares con basura)
3. Tras el for de carga cantidad = 3 | vector = 0x5000 [ 15 , 40 , 25 ] (Datos cargados)
4. Tras ejecutar free(vector); cantidad = 3 | vector (liberado) Bloque devuelto al sistema operativo

25 Error Frecuente 1 (del Apunte): Olvidarse de free()

❌ Incorrecto: Sin free()
int *vector; vector = malloc(5 * sizeof(int)); vector[0] = 10; printf("%d\n", vector[0]); // ¡Termina sin liberar! return 0;
✅ Correcto: Con free() al final
int *vector; vector = malloc(5 * sizeof(int)); vector[0] = 10; printf("%d\n", vector[0]); free(vector); // ¡Devolvemos la cancha! return 0;

💡 Consejo práctico: Apenas escribas la línea de malloc(vector) en tu código, andá al final de main (arriba de return 0;) y escribí free(vector); para no olvidarte nunca.

26 Error Frecuente 2 (del Apunte): Liberar Dos Veces

Cada malloc() debe tener un ÚNICO free() (Apunte pág. 31)

Tal como advierte explícitamente el apunte en la página 31, nunca debés liberar la misma memoria dos veces (error conocido como Double Free):

❌ Error Grave: Doble free()
int *vector = malloc(5 * sizeof(int)); free(vector); // 1ra vez: libera bien free(vector); // 2da vez: ¡ERROR! Ya estaba libre
✅ Correcto: Un solo free()
int *vector = malloc(5 * sizeof(int)); free(vector); // Se libera una unica vez vector = NULL; // Opcional: dejamos en NULL

27 Error Frecuente 3: Poner free() Adentro del for

Un descuido muy común al cerrar las llaves { } del ciclo for es meter sin querer el free(vector); adentro del bucle:

❌ Mal: free() adentro del for
for(int i = 0; i < cantidad; i++) { printf("%d ", vector[i]); free(vector); // ¡Destruye el vector en i=0! }

En la primera vuelta (i = 0) libera todo el vector, y cuando quiere pasar a i = 1 el vector ya no existe.

✅ Bien: free() afuera y después del for
for(int i = 0; i < cantidad; i++) { printf("%d ", vector[i]); } // Recien cuando termino todo el for: free(vector);

Primero muestra todos los elementos de principio a fin y recién al salir del ciclo libera la memoria.

28 Error Frecuente 4: Usar el Vector Después de free()

Si ya devolviste la cancha, ¡no podés seguir jugando adentro!

Una vez que ejecutaste free(vector);, ese bloque del Heap ya no te pertenece. Intentar leer o escribir vector[0] después de haber hecho free() es un error grave:

❌ Incorrecto: Usar después de liberar
free(vector); // ¡PROHIBIDO! La memoria ya fue devuelta: vector[0] = 99; printf("%d", vector[0]);
✅ Correcto: free() es la última acción
vector[0] = 99; printf("%d", vector[0]); // Liberamos cuando ya no lo tocamos mas: free(vector); vector = NULL;

29 Ejemplo Nivel 1: Vector Dinámico de 3 Notas (float)

malloc() sirve para cualquier tipo de dato. Mirá cómo reservamos espacio para 3 números con coma (float):

nivel1_notas_float.c Nivel 1 • Tipo float
#include <stdio.h> #include <stdlib.h> int main() { float *notas; notas = malloc(3 * sizeof(float)); notas[0] = 8.5; notas[1] = 9.0; notas[2] = 7.5; printf("Notas: %.1f - %.1f - %.1f\n", notas[0], notas[1], notas[2]); free(notas); return 0; }

30 Ejemplo Nivel 2: Suma y Promedio con Memoria Dinámica

Combinemos la reserva dinámica según la cantidad que pide el usuario con un acumulador para calcular el promedio:

nivel2_promedio_dinamico.c Nivel 2 • Acumulador
#include <stdio.h> #include <stdlib.h> int main() { int cantidad, suma = 0; printf("Cuantas edades va a cargar?: "); scanf("%d", &cantidad); int *edades = malloc(cantidad * sizeof(int)); for(int i = 0; i < cantidad; i++) { printf("Edad %d: ", i + 1); scanf("%d", &edades[i]); suma = suma + edades[i]; } printf("Promedio de edades: %.2f\n", (float)suma / cantidad); free(edades); return 0; }

31 Ejemplo Nivel 3: Buscar el Mayor en un Vector Dinámico

nivel3_maximo_dinamico.c Nivel 3 • Búsqueda de Máximo
#include <stdio.h> #include <stdlib.h> int main() { int cantidad; printf("Cantidad de competidores: "); scanf("%d", &cantidad); int *puntajes = malloc(cantidad * sizeof(int)); for(int i = 0; i < cantidad; i++) { printf("Puntaje %d: ", i + 1); scanf("%d", &puntajes[i]); } int mayor = puntajes[0]; for(int i = 1; i < cantidad; i++) { if(puntajes[i] > mayor) { mayor = puntajes[i]; } } printf("El puntaje mas alto fue: %d\n", mayor); free(puntajes); return 0; }

32 Ejemplo Nivel 4: Vector Dinámico de struct

¡También podemos crear un vector dinámico de estructuras! Solo usamos sizeof(struct Producto) al llamar a malloc():

nivel4_struct_dinamico.c Nivel 4 • Struct + Heap
#include <stdio.h> #include <stdlib.h> struct Producto { int codigo; float precio; }; int main() { int cantidad; printf("Cuantos productos desea registrar?: "); scanf("%d", &cantidad); struct Producto *lista = malloc(cantidad * sizeof(struct Producto)); for(int i = 0; i < cantidad; i++) { printf("Codigo y precio del producto %d: ", i + 1); scanf("%d %f", &lista[i].codigo, &lista[i].precio); } free(lista); return 0; }

33 Ejercicio Práctico 1: Encontrá los 2 Errores

Observá con lupa el siguiente código. Tiene 2 errores importantes relacionados con lo que vimos hoy en el apunte. ¿Cuáles son?

ejercicio_1_errores.c Detectar Errores
#include <stdio.h> #include <stdlib.h> int main() { int cantidad; int *vector = malloc(cantidad * sizeof(int)); printf("Cantidad: "); scanf("%d", &cantidad); vector[0] = 50; free(vector); free(vector); return 0; }
🔍 Ver los 2 errores y su corrección
  1. Error 1 (Orden invertido): Llamó a malloc(cantidad * sizeof(int)) antes de pedirle cantidad al usuario con scanf. En ese momento cantidad tenía basura. El malloc siempre debe ir después del scanf.
  2. Error 2 (Doble free): Al final escribió free(vector); dos veces seguidas. Cada malloc() debe tener un único free().

34 Ejercicio Práctico 2: Completar el Programa

Consigna: Escribí un programa en C que le pregunte al usuario cuántos precios quiere cargar, reserve un vector dinámico de tipo float con malloc(), cargue los precios, muestre el total sumado y libere la memoria con free().

🔍 Ver código resuelto completo
#include <stdio.h> #include <stdlib.h> int main() { int cantidad; float total = 0; printf("Cuantos precios quiere cargar?: "); scanf("%d", &cantidad); float *precios = malloc(cantidad * sizeof(float)); for(int i = 0; i < cantidad; i++) { printf("Precio %d: ", i + 1); scanf("%f", &precios[i]); total = total + precios[i]; } printf("Total a pagar: $%.2f\n", total); free(precios); return 0; }
