Estructuras (struct) en C

Modelando objetos y entidades de la vida real: agrupación de campos de distintos tipos, el operador punto (.) y vectores de estructuras

struct Alumno Operador Punto (.) Molde vs Variable Vectores de Estructuras

💡 Guía de navegación: Usá la barra espaciadora o las flechas del teclado (→ / ←) para avanzar diapositiva por diapositiva. Vamos a construir cada concepto desde cero siguiendo el Apunte Teórico.

01 Objetivos de Aprendizaje y Hoja de Ruta

¿Por qué damos este salto hoy?

Hasta ahora guardábamos números sueltos en variables o listas de números iguales en vectores. Pero en el mundo real tratamos con personas, productos, alumnos, jugadores o autos, donde cada uno combina datos enteros, con coma y letras al mismo tiempo.

Hoy vas a aprender a crear tus propios tipos de datos compuestos en C usando estructuras (struct).

Lo que vas a dominar paso a paso

  • Entender por qué no alcanzan las variables sueltas ni los vectores comunes.
  • Declarar el molde de una estructura: struct Alumno { ... };.
  • Crear variables reales de tipo struct en memoria RAM.
  • Guardar, leer y mostrar sus campos usando el operador punto (.).
  • Dominar los vectores de estructuras (struct Alumno alumnos[30];), ¡el tema clave de examen!

02 Lo Que Ya Sabemos: Variables y Vectores

Hagamos un breve repaso de las dos herramientas que usamos hasta hoy para guardar datos en memoria:

Herramienta 1

Variables Simples

int edad = 16; float promedio = 8.5; char division = 'A';

Cada variable guarda un único valor. Son cajas sueltas e independientes en la memoria.

Herramienta 2

Vectores (Arrays)

int edades[3] = {16, 17, 15}; float notas[3] = {8.5, 9.0, 7.2};

Guardan muchos datos juntos, pero tienen una regla estricta: todos los elementos deben ser del mismo tipo de dato.

🤔 El límite: En un vector de int no podés meter un float ni un char. ¿Qué hacemos entonces cuando un objeto tiene datos de distintos tipos?

03 El Problema del Apunte: Representar un Alumno

Tal como plantea el Apunte Teórico (página 24), imaginá que queremos guardar en nuestro programa los datos de un Alumno de la escuela que tiene tres características de distinto tipo:

❌ ¿Qué pasa si usamos variables sueltas?

Si declaramos int edad; float promedio; char division; sueltas, para la computadora son tres variables que no tienen ninguna relación entre sí. Y si quisiéramos guardar 3 alumnos tendríamos que inventar edad1, edad2, edad3, promedio1, promedio2, promedio3, division1... ¡Un caos imposible de mantener!

04 La Idea Clave: Una «Ficha de Datos» Unificada

En la secretaría de una escuela, los datos de un alumno no están anotados en papelitos sueltos desparramados por el escritorio: están todos juntos dentro de una misma ficha o carnet de alumno.

Definición del Apunte Teórico (Sección 8, Pág. 25)

Una estructura (struct) es un tipo de dato que nos permite agrupar varias variables relacionadas entre sí (de igual o distinto tipo) bajo un mismo nombre. Cada una de las variables que están adentro de la estructura se llama campo o atributo.

05 ¿Cómo se Declara una Estructura en C?

Mirá la sintaxis exacta que enseña el Apunte Teórico en la página 25 para definir la estructura Alumno:

declaracion_struct.c Apunte Pág. 25
struct Alumno { int edad; float promedio; char division; };

¿Dónde se escribe esto?

Normalmente se escribe arriba de int main() (o al principio del programa) para que todo nuestro código conozca qué forma tiene un struct Alumno.

¡Mirá el final de la última línea!

A diferencia del if, del for o de main(), la llave de cierre de un struct SIEMPRE lleva un punto y coma obligatorio al final: };.

06 Desglose Línea por Línea de struct Alumno

Analicemos cada parte de la declaración para entender exactamente qué hace cada palabra:

1
struct: Es la palabra reservada de C que le avisa al compilador: «Voy a definir una nueva estructura de datos compuesta».
2
Alumno: Es el nombre que nosotros elegimos para este nuevo tipo de estructura (por costumbre se empieza con mayúscula: Alumno, Producto, Jugador).
3
int edad; float promedio; char division;: Son los campos o atributos internos de la estructura. Cada uno se declara con su propio tipo y nombre, terminado en ;.
4
};: La llave de cierre junto con el punto y coma final que indica que terminó la definición de la estructura.

07 ¡Aclaración Fundamental!: El Molde vs El Objeto Real

⚠️ Importante (Apunte Teórico, Pág. 25)

Escribir struct Alumno { int edad; float promedio; char division; }; todavía NO crea ningún alumno en la memoria RAM. Solamente define el «molde» o plano de cómo será un alumno.

1. Definir el Molde (Plano / Receta)

Es como dibujar el plano de una casa o escribir la receta de una torta en un cuaderno: explica qué ingredientes lleva (edad, promedio, division), pero todavía no hay ninguna torta sobre la mesa.

struct Alumno { int edad; float promedio; char division; }; // Solo crea el molde

2. Crear la Variable Real en main()

Para que realmente exista un alumno en la memoria RAM donde podamos guardar datos, tenemos que declarar una variable usando ese molde adentro de main():

int main() { // ¡Ahora sí nace alumno1 en RAM! struct Alumno alumno1; }

10 El Operador Punto (.): ¿Cómo Entramos a un Campo?

Como adentro de alumno1 hay tres datos distintos, para indicarle a C a cuál de los tres campos queremos entrar usamos un punto (.) entre el nombre de la variable y el nombre del campo:

operador_punto.c Apunte Pág. 26
struct Alumno alumno1; alumno1.edad = 16; alumno1.promedio = 8.5; alumno1.division = 'A';

¿Qué significa el punto? (Apunte, Pág. 26)

El punto conecta la estructura con su campo interno. Se lee en voz alta de derecha a izquierda:

  • alumno1.edad → «La edad de alumno1».
  • alumno1.promedio → «El promedio de alumno1».
  • alumno1.division → «La división de alumno1».

11 Mostrar los Campos por Pantalla con printf

Para mostrar los datos guardados en alumno1, usamos printf accediendo a cada campo con el punto y colocando la máscara que corresponde al tipo de ese campo:

mostrar_campos.c printf con .
// edad es int -> usamos %d printf("Edad: %d\n", alumno1.edad); // promedio es float -> usamos %.2f printf("Promedio: %.2f\n", alumno1.promedio); // division es char -> usamos %c printf("Division: %c\n", alumno1.division);
Salida por pantallastdout
Edad: 16 Promedio: 8.50 Division: A

💡 Recordá: alumno1.edad se comporta exactamente igual que cualquier variable int común; alumno1.promedio igual que un float; y alumno1.division igual que un char.

13 Cargar los Campos por Teclado con scanf

¿Y si queremos que el usuario escriba por teclado la edad, el promedio y la división del alumno? Usamos scanf poniendo el símbolo & adelante de alumno1.campo:

cargar_alumno_scanf.c Lectura por Teclado
struct Alumno alumno1; printf("Ingrese la edad: "); scanf("%d", &alumno1.edad); printf("Ingrese el promedio: "); scanf("%f", &alumno1.promedio); printf("Ingrese la division: "); scanf(" %c", &alumno1.division);

🔍 ¿Por qué hay un espacio en " %c"?

Cuando el usuario escribe el promedio (por ejemplo 8.5) y aprieta la tecla Enter, ese salto de línea queda flotando en el teclado.

Al poner un espacio antes de %c (es decir, " %c"), C ignora el Enter anterior y espera tranquilamente a que el usuario escriba la letra (ej. 'A').

14 Inicialización Directa con Llaves y Copia Completa

Además de asignar campo por campo con el punto, C nos permite dos atajos muy cómodos con estructuras:

Atajo 1

Inicializar con llaves { ... }

Podés darle los valores iniciales en el mismo orden en que declaraste los campos en el molde (edad, promedio, división):

// Orden: edad (16), promedio (8.5), division ('A') struct Alumno alumno1 = {16, 8.5, 'A'};
Atajo 2

Copiar toda la ficha con =

¡A diferencia de los vectores, dos variables del mismo tipo struct sí se pueden igualar directamente con =! Copia todos los campos de una sola vez:

struct Alumno alumno2; alumno2 = alumno1; // ¡Copia los 3 campos juntos!

17 Cómo Comparar Dos Estructuras (Nivel 2)

Si tenemos dos alumnos a1 y a2, no podemos escribir if (a1 > a2) porque la computadora no sabe si querés comparar por edad, por promedio o por división. Siempre comparamos el campo específico que nos interesa usando el punto:

comparar_dos_alumnos.c Comparación por Campo
struct Alumno a1 = {16, 8.5, 'A'}; struct Alumno a2 = {17, 9.2, 'B'}; // Comparamos el campo .promedio de cada alumno: if(a1.promedio > a2.promedio) { printf("El alumno 1 tiene mejor promedio (%.2f)\n", a1.promedio); } else if(a2.promedio > a1.promedio) { printf("El alumno 2 tiene mejor promedio (%.2f)\n", a2.promedio); } else { printf("Ambos tienen el mismo promedio.\n"); }

18 Vectores de Estructuras (¡Tema Clave de Examen!)

El Planteo del Apunte Teórico (Página 27)

Hasta ahora creamos alumno1, alumno2, alumno3. Pero ¿qué pasa si tenemos un curso entero de 30 alumnos? No vamos a declarar 30 variables sueltas. ¡La solución es combinar vectores con estructuras!

vector_de_estructuras.c Apunte Pág. 27
// Un vector común de 30 enteros: int numeros[30]; // Un vector de 30 estructuras Alumno: struct Alumno alumnos[30];

¿Qué significa struct Alumno alumnos[30];?

Crea un vector llamado alumnos con 30 posiciones (desde alumnos[0] hasta alumnos[29]), donde adentro de cada posición vive un struct Alumno completo con su propia edad, su propio promedio y su propia division.

20 Cómo Acceder a un Campo dentro del Vector

Para acceder a un dato específico seguimos dos pasos: primero elegimos qué alumno con los corchetes [i] y enseguida elegimos qué campo con el punto . (Apunte, pág. 27):

1
alumnos[0].edad = 16;
Se lee: «La edad del alumno en la posición 0 es 16».
2
alumnos[3].promedio = 9.5;
Se lee: «El promedio del alumno en la posición 3 es 9.5».
3
alumnos[i].division = 'B';
Se lee: «La división del alumno en la posición i es 'B'».

21 ¡Cuidado con el Orden!: alumnos[i].edad

Una duda muy común al empezar es dónde poner los corchetes [i]. Mirá la diferencia:

❌ Incorrecto: alumnos.edad[i]
// ¡ERROR DE COMPILACIÓN! alumnos.edad[i] = 16;

¿Por qué falla? Porque el que es un vector de 30 casilleros es alumnos, no edad. La variable edad es un simple número entero adentro de cada alumno.

✅ Correcto: alumnos[i].edad
// Primero el casillero [i], después el campo .edad alumnos[i].edad = 16;

Regla mental: Primero abrimos el casillero del vector (alumnos[i]) y, una vez adentro de ese alumno, tocamos su campo con el punto (.edad).

22 Cargar un Vector de Estructuras con for (Apunte Pág. 27)

Gracias a que tenemos un vector, podemos cargar los datos de todos los alumnos usando un único ciclo for tal como muestra el Apunte Teórico en la página 27:

cargar_vector_alumnos.c Código del Apunte (Pág. 27)
struct Alumno alumnos[3]; for(int i = 0; i < 3; i++) { printf("Edad: "); scanf("%d", &alumnos[i].edad); printf("Promedio: "); scanf("%f", &alumnos[i].promedio); printf("Division: "); scanf(" %c", &alumnos[i].division); }

¿Qué hace en cada vuelta del for?

  • Cuando i = 0: pide y guarda alumnos[0].edad, alumnos[0].promedio y alumnos[0].division.
  • Cuando i = 1: pide y guarda los 3 datos de alumnos[1].
  • Cuando i = 2: pide y guarda los 3 datos de alumnos[2].

💡 Si en vez de 3 alumnos fueran 30, solo cambiaríamos el 3 por 30 y el mismo bloque de código serviría para todo el curso.

24 Algoritmos Nivel 3: Filtrar y Contar en un Vector de struct

¿Cómo respondemos preguntas como «¿Cuántos alumnos son de la división 'A'?» o «¿Cuántos aprobaron con promedio mayor o igual a 6?»? Recorremos con un for y preguntamos con un if sobre el campo correspondiente:

contar_aprobados_y_division.c Filtro con if
int cantDivA = 0; int cantAprobados = 0; for(int i = 0; i < 3; i++) { // ¿El alumno i pertenece a la división 'A'? if(alumnos[i].division == 'A') { cantDivA++; } // ¿El alumno i tiene promedio mayor o igual a 6.0? if(alumnos[i].promedio >= 6.0) { cantAprobados++; } } printf("En la division A hay %d alumnos.\n", cantDivA); printf("Total de aprobados: %d\n", cantAprobados);

25 Algoritmos Nivel 3: Sumar un Campo de Todo el Vector

Si queremos conocer el promedio general de todo el curso, acumulamos el campo alumnos[i].promedio de cada estudiante en una variable sumaPromedios y al final dividimos por la cantidad de alumnos:

promedio_general_curso.c Acumulador sobre Campo
float sumaPromedios = 0; for(int i = 0; i < 3; i++) { sumaPromedios += alumnos[i].promedio; } float promedioCurso = sumaPromedios / 3; printf("Promedio general del curso: %.2f\n", promedioCurso);
Vuelta (i) Campo leído Valor sumado sumaPromedios
i = 0 alumnos[0].promedio 8.50 8.50
i = 1 alumnos[1].promedio 9.25 17.75
i = 2 alumnos[2].promedio 7.00 24.75

Al salir del for: 24.75 / 3 = 8.25

26 Algoritmo Clásico: Buscar el Alumno con Mayor Promedio

Cuando buscamos al mejor alumno, no queremos saber solamente cuál fue la nota más alta: también queremos saber qué edad tiene y de qué división es ese alumno. Por eso guardamos su posición posMejor:

buscar_mejor_alumno.c Búsqueda de Máximo en Structs
// Empezamos asumiendo que el mejor alumno está en la posición 0: int posMejor = 0; for(int i = 1; i < 3; i++) { // ¿El promedio del alumno i supera al del mejor hasta ahora? if(alumnos[i].promedio > alumnos[posMejor].promedio) { posMejor = i; // Guardamos el número de casillero ganador } } printf("Mejor promedio: %.2f (Edad: %d, Division: %c)\n", alumnos[posMejor].promedio, alumnos[posMejor].edad, alumnos[posMejor].division);

⭐ Truco de examen: Guardar el índice posMejor es mucho más poderoso que guardar solo float mayorPromedio, porque con alumnos[posMejor] podés mostrar todos los campos del alumno ganador.

27 Nivel 4: Buscar un Producto por su Código

Precio: $%.2f | Stock: %d\n", lista[i].precio, lista[i].stock); encontrado = 1; } } if(encontrado == 0) printf("No existe un producto con ese codigo.\n");

28 Nivel 4: Ordenar un Vector de Estructuras por Promedio

¿Qué pasa si queremos ordenar el vector de alumnos de mayor a menor promedio? Comparamos alumnos[j].promedio, ¡pero al intercambiar (swap) intercambiamos la estructura entera con una variable auxiliar struct Alumno aux!

ordenar_alumnos.c Burbujeo con struct
for(int i = 0; i < 3 - 1; i++) { for(int j = 0; j < 3 - 1 - i; j++) { // Comparamos por el campo .promedio: if(alumnos[j].promedio < alumnos[j + 1].promedio) { // ¡Intercambiamos la FICHA COMPLETA del alumno! struct Alumno aux = alumnos[j]; alumnos[j] = alumnos[j + 1]; alumnos[j + 1] = aux; } } }

💡 ¿Por qué intercambiamos toda la estructura y no solo el promedio? Porque si solo intercambiáramos el promedio, ¡le estaríamos poniendo la nota de un alumno a la edad y división de otro compañero! Al mover la ficha entera alumnos[j], todos sus datos viajan juntos.

29 Nota Complementaria: El Alias typedef struct

En el apunte usamos siempre struct Alumno. En algunos libros o códigos vas a ver la palabra typedef al definir una estructura. Mirá para qué sirve y cómo se equivalen:

Forma Estándar del Apunte

Con struct Alumno

struct Alumno { int edad; float promedio; char division; }; int main() { struct Alumno a1; struct Alumno curso[30]; }
Forma Alternativa con Alias

Con typedef struct

typedef struct { int edad; float promedio; char division; } Alumno; // Nombre del alias al final int main() { Alumno a1; // Sin repetir "struct" Alumno curso[30]; }

Ambas formas funcionan exactamente igual con el operador punto (a1.edad, curso[i].promedio). En nuestras evaluaciones podés usar la del apunte (struct Alumno) con total tranquilidad.

30 Errores Frecuentes que Debés Evitar (Apunte Pág. 28)

❌ Error 1 (Del Apunte Pág. 28): Usar el campo suelto sin indicar de qué variable es
struct Alumno alumno1; edad = 16; // ❌ ERROR: ¿La edad de quién?

✅ Correcto (Apunte): Siempre poné el nombre de la variable y el punto: alumno1.edad = 16;

❌ Error 2: Querer imprimir o leer toda la estructura junta en un solo printf
struct Alumno alumno1 = {16, 8.5, 'A'}; printf("%d", alumno1); // ❌ ERROR

✅ Correcto: printf y scanf trabajan campo por campo (alumno1.edad, alumno1.promedio, etc.).

⚠️ Error 3 (Olvidar el punto y coma final del molde): Al cerrar la llave de struct Alumno { ... }; nunca te olvides del punto y coma en };, porque sin él el compilador dará un error extraño en la línea siguiente.

31 Ejercicio Práctico 1: Estructura Producto y Valor de Stock

Consigna

Declarar una estructura llamada struct Producto con tres campos: int codigo, float precio e int stock. En main(), pedir al usuario que cargue los datos de un producto por teclado y luego mostrar cuánto dinero representa en total ese stock (calculando precio * stock).

🔍 Ver solución completa paso a paso
#include <stdio.h> struct Producto { int codigo; float precio; int stock; }; int main() { struct Producto p; printf("Codigo: "); scanf("%d", &p.codigo); printf("Precio: "); scanf("%f", &p.precio); printf("Stock: "); scanf("%d", &p.stock); float valorTotal = p.precio * p.stock; printf("El producto #%d tiene $%.2f en mercaderia.\n", p.codigo, valorTotal); return 0; }

34 Resumen de la Unidad y Checklist Final

Conceptos Clave del Apunte (Sección 8)

  • ¿Qué es un struct?: Un tipo de dato que agrupa varias variables relacionadas (campos) de igual o distinto tipo bajo un mismo nombre.
  • Molde vs Variable: struct Alumno { ... }; define el molde; struct Alumno alumno1; crea la variable en memoria.
  • Operador punto (.): alumno1.edad accede al campo edad de alumno1.
  • Vector de estructuras: struct Alumno alumnos[30]; permite manejar listas completas usando alumnos[i].campo.

Checklist de Autoevaluación

✓ Entiendo por qué nunca debo escribir edad = 16; suelto sino alumno1.edad = 16;.
✓ Sé cargar y mostrar un vector de estructuras con un ciclo for usando alumnos[i].campo.
✓ Puedo buscar máximos, contar y filtrar datos dentro de un vector de estructuras.
