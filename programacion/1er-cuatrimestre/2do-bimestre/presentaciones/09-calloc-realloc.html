01 Objetivos de la Clase

¿Dónde estamos parados?

En la Unidad 08 aprendimos a reservar memoria dinámica con malloc() y a devolverla al sistema operativo con free().

Sin embargo, en programas reales aparecen dos preguntas fundamentales que malloc() por sí solo no resuelve:

  • ¿Cómo reservamos memoria que ya venga limpia con ceros desde el primer instante?
  • ¿Qué hacemos si reservamos lugar para 5 datos y más adelante necesitamos espacio para 10?

Lo que vas a aprender desde cero hoy

  • Qué valores quedan adentro de la memoria cuando usamos malloc() (el problema de la basura).
  • Qué es calloc(), qué significa su nombre y cómo funcionan sus 2 parámetros.
  • Diferencia visual y práctica entre malloc() y calloc().
  • Qué es realloc() y cómo agrandar o achicar una reserva sin perder los datos ya guardados.
  • Qué ocurre en la memoria RAM tras bambalinas y el cuadro resumen de las 4 funciones de <stdlib.h>.

02 Parte 1: ¿Qué Hay Adentro de malloc()?

Recordemos cómo reserva memoria malloc() (Apunte Teórico, pág. 32)

Cuando reservamos memoria para 5 números enteros usando malloc(), el sistema operativo nos entrega un bloque libre en el Heap, pero NO limpia ni borra lo que había antes en esas celdas de RAM.

reserva_malloc.c Valores desconocidos
int *vector; vector = malloc(5 * sizeof(int)); // ¿Qué valores tienen inicialmente // vector[0], vector[1], ..., vector[4]?

Estado inicial con malloc()

La memoria se reserva, pero los valores iniciales son desconocidos ("basura"). Como muestra el apunte, podrían ser perfectamente:

[0]
154
[1]
-20
[2]
987
[3]
0
[4]

⚠️ Son restos de otros programas que usaron esa parte de la RAM antes.

03 ¿Por Qué Es un Problema la "Basura" en Memoria?

Si vamos a pisar cada casillero inmediatamente con un scanf() o una asignación directa (como vector[0] = 10;), la basura anterior no molesta porque se sobrescribe. ¿Pero qué pasa si queremos usar el vector como contador o acumulador?

❌ Peligro: Sumar sobre basura con malloc()
int *votos = malloc(5 * sizeof(int)); // Queremos sumar 1 voto al candidato 0: votos[0] = votos[0] + 1; // Si votos[0] tenía basura (154): // 154 + 1 = ¡155 votos con solo 1 votante!

Con malloc() tendríamos que acordarnos de hacer un ciclo for manual poniendo cada posición en 0 antes de empezar a contar.

✅ Solución directa: Que nazca en 0

Para ahorrarnos ese problema y tener la seguridad absoluta de que todas las posiciones arrancan limpias en 0, el lenguaje C nos ofrece una función hermana de malloc():

calloc()

Reserva memoria dinámica y además inicializa todos los valores en 0 automáticamente.

04 9.3 ¿Qué es calloc() y Qué Significa su Nombre?

Definición del Apunte Teórico (pág. 32)

La función calloc() también permite reservar memoria dinámica, igual que malloc(), y también pertenece a la biblioteca <stdlib.h>.

¿De dónde viene la palabra calloc?

Su nombre proviene del inglés:

Contiguous Allocation
(Asignación continua de memoria)

Sus 2 Tareas al Mismo Tiempo

1
Reserva memoria dinámica para una cantidad determinada de elementos contiguos en el Heap.
2
Inicializa todos los valores en 0 antes de devolvernos la dirección de memoria.

05 Sintaxis de calloc(): Sus 2 Parámetros

Forma general del Apunte Teórico (pág. 32)

calloc(cantidad_elementos, tamaño_de_cada_elemento);

⚠️ ¡Atención a la diferencia de escritura! Mientras que malloc() recibe 1 solo parámetro (con el signo * de multiplicación), calloc() recibe 2 parámetros separados por una coma (,):

Parámetro 1: cantidad_elementos

Indica cuántos casilleros o elementos queremos crear en nuestro vector dinámico.

Ejemplo: si queremos guardar 5 números enteros, el primer parámetro es 5.

Parámetro 2: tamaño_de_cada_elemento

Indica cuántos bytes ocupa cada elemento individual, usando siempre el operador sizeof().

Ejemplo: si cada elemento es un int, el segundo parámetro es sizeof(int).

06 Ejemplo Paso a Paso con calloc()

reserva_calloc.c (Apunte, pág. 32)
int *vector; vector = calloc(5, sizeof(int));
1
5 → le pedimos espacio para 5 elementos.
2
sizeof(int) → cada elemento tiene el tamaño de un int (4 bytes).
3
calloc() multiplica internamente $5 \times 4 = 20\text{ bytes}$, los reserva y rellena todo con 0.

¿Cómo queda el vector en la memoria?

Apenas termina de ejecutarse la línea vector = calloc(5, sizeof(int));, el vector comienza garantizado así:

vector[0]
0
vector[1]
0
vector[2]
0
vector[3]
0
vector[4]
0

✅ ¡No hay ningún valor basura! Todas las posiciones valen exactamente 0.

08 Ejemplo Completo del Apunte con calloc()

ejemplo_calloc_apunte.c (pág. 33)
#include <stdio.h> #include <stdlib.h> int main() { int *vector; vector = calloc(5, sizeof(int)); for(int i = 0; i < 5; i++) { printf("%d\n", vector[i]); } free(vector); return 0; }
Salida del programa stdout
0 0 0 0 0

Observá qué importante

En ningún momento hicimos vector[i] = 0; manualmente. Aun así, al imprimir las 5 posiciones con el for, todas muestran 0 porque calloc() ya las limpió al reservarlas. Y al final liberamos la memoria con free(vector);.

09 ¿Cuándo Conviene Usar malloc() y Cuándo calloc()?

Usá malloc() cuando...

  • Vas a cargar todos los valores inmediatamente (por ejemplo, pidiéndolos por teclado con scanf en un ciclo for).
  • No necesitás que las celdas empiecen en 0 porque las vas a pisar enseguida.
  • Buscás la máxima velocidad al reservar bloques muy grandes (no pierde tiempo rellenando ceros).
int *notas = malloc(5 * sizeof(int)); // Enseguida cargamos las 5 notas con scanf

Usá calloc() cuando...

  • Necesitás un vector de contadores o acumuladores (como contar votos, frecuencias o puntajes que se van sumando).
  • No vas a cargar todas las posiciones de inmediato y querés que las vacías valgan 0 por seguridad.
  • Querés evitar la basura en memoria sin tener que escribir un bucle for inicializador.
int *puntos = calloc(5, sizeof(int)); // Ya podemos hacer puntos[2] += 10; sin riesgo

10 Parte 2: ¿Y Si Nos Quedamos Cortos de Espacio?

El escenario del Apunte Teórico (pág. 34)

Supongamos que al principio del programa reservamos memoria dinámica para guardar 5 números enteros:

int *vector; vector = malloc(5 * sizeof(int));

El problema durante la ejecución

Ya guardamos datos en esos 5 lugares, pero mientras el programa sigue funcionando nos damos cuenta de que ahora necesitamos almacenar 10 enteros en total (5 más de los que teníamos).

¿Hay que empezar de cero? ¡No!

En memoria estática (int v[5];) sería imposible cambiar su tamaño. Pero en memoria dinámica podemos estirar o encoger nuestro bloque en cualquier momento usando realloc().

11 9.4 ¿Qué es realloc() y Qué Significa su Nombre?

Definición del Apunte Teórico (págs. 33 y 34)

La función realloc() permite cambiar el tamaño de un bloque de memoria dinámica que ya había sido reservado antes con malloc() o calloc().

¿De dónde viene la palabra realloc?

Su nombre proviene del inglés:

Reallocation
(Reasignación de memoria)

Dicho de manera sencilla

realloc() sirve para:

  • 📈 Agrandar un vector dinámico cuando necesitamos más casilleros.
  • 📉 Achicar un vector dinámico cuando nos sobran casilleros que ya no vamos a usar.

12 Sintaxis de realloc(): ¿Cómo se Escribe?

Forma general del Apunte Teórico (pág. 34)

variable = realloc(variable, nuevo_tamaño);
1
Primer parámetro (variable): Es el puntero del vector dinámico que ya teníamos reservado y cuyo tamaño queremos modificar (por ejemplo, vector).
2
Segundo parámetro (nuevo_tamaño): Es el nuevo tamaño TOTAL en bytes que queremos que tenga ahora todo el bloque (por ejemplo, 10 * sizeof(int)). ¡Ojo: se indica el total final, no cuánto le sumamos!
3
Asignación al puntero (variable = ...): Guardamos la dirección devuelta por realloc() nuevamente en nuestro puntero, porque el bloque redimensionado puede haberse mudado a una nueva dirección de la RAM.

13 Ejemplo del Apunte: Pasar de 5 a 10 Enteros

cambiar_tamano.c (Apunte, pág. 34)
int *vector; // 1. Reservamos lugar para 5 enteros vector = malloc(5 * sizeof(int)); // 2. Cambiamos el tamaño a 10 enteros vector = realloc(vector, 10 * sizeof(int)); // 3. Al terminar liberamos la memoria free(vector);

¿Qué pasó en cada paso?

  • Al principio: malloc(5 * sizeof(int)) reservó 20 bytes (espacio para 5 enteros: índices 0 al 4).
  • Al llamar a realloc: Le pasamos el puntero vector y el nuevo tamaño total 10 * sizeof(int) (40 bytes).
  • Resultado: Ahora el mismo vector tiene espacio para 10 enteros (índices 0 al 9).
  • Al final: Hacemos un único free(vector); para liberar todo el bloque de 10 enteros.

15 Ejemplo Completo del Apunte con realloc()

ejemplo_realloc_apunte.c (pág. 35)
#include <stdio.h> #include <stdlib.h> int main() { int *vector; vector = malloc(3 * sizeof(int)); vector[0] = 10; vector[1] = 20; vector[2] = 30; vector = realloc(vector, 6 * sizeof(int)); free(vector); return 0; }

Análisis línea por línea

  1. malloc(3 * sizeof(int)): Se reserva memoria para 3 enteros (posiciones [0], [1] y [2]).
  2. Se guardan 3 valores: 10 en [0], 20 en [1] y 30 en [2].
  3. realloc(vector, 6 * sizeof(int)): Se amplía la memoria para 6 enteros (ahora existen las posiciones [0] a [5]).
  4. free(vector): Se libera toda la memoria al terminar.

💡 Después del realloc a 6 enteros, ya podemos usar tranquilamente vector[3] = 40;, vector[4] = 50; y vector[5] = 60;.

16 Cargando e Imprimiendo las Nuevas Posiciones

Veamos qué pasa si al ejemplo anterior del apunte le completamos las 3 posiciones nuevas ([3], [4] y [5]) y mostramos los 6 elementos por pantalla:

17 Achicar Memoria con realloc() (Apunte, pág. 35)

También podemos reducir el tamaño de la memoria

Así como agrandamos un vector cuando nos falta espacio, si teníamos lugar para 10 elementos y descubrimos que solo necesitamos 5, podemos achicarlo para no desperdiciar memoria RAM:

achicar_realloc.c (Apunte, pág. 35)
vector = realloc(vector, 5 * sizeof(int));

¿Qué pasa con los primeros 5 elementos?

Los primeros 5 elementos (posiciones vector[0] a vector[4]) se conservan intactos con los valores que tenían guardados.

¿Qué pasa con los 5 lugares sobrantes?

Las posiciones [5] a [9] se devuelven al sistema operativo. ¡Ya no nos pertenecen! Intentar leer o escribir en vector[5] después de achicar a 5 elementos sería un acceso fuera de rango.

18 ¿Cómo Trabaja realloc() Internamente en la RAM?

¿Por qué siempre escribimos vector = realloc(vector, ...); guardando el resultado otra vez en el puntero? Porque cuando pedimos agrandar un bloque en el Heap, el sistema operativo puede encontrarse con 3 escenarios:

Escenario 1

Hay lugar pegado al lado

Si justo a la derecha de nuestro bloque hay celdas libres suficientes, el sistema simplemente estira el bloque en el mismo lugar.

📍 realloc() devuelve la misma dirección que ya tenía vector.

Escenario 2

Mudanza a otro sector

Si al lado está ocupado por otra variable, busca otro lugar del Heap donde entren todos juntos, copia solo los datos viejos, libera el bloque viejo y se muda.

🚚 realloc() devuelve una NUEVA dirección de memoria.

Escenario 3

No alcanza la memoria

Si pedimos un tamaño gigantesco y la memoria RAM está llena, la reasignación falla: no toca ni borra el bloque original.

⚠️ realloc() devuelve NULL para avisar que falló.

19 Visualizando la Mudanza Automática (Escenario 2)

Mirá por qué es obligatorio actualizar el puntero cuando realloc() necesita mudar el vector a otra zona libre del Heap:

Antes del realloc (en dirección 0x5000)

Tenemos 3 enteros en 0x5000, pero justo al lado (en 0x500C) hay otra variable ocupando lugar:

0x5000
v[0..2]
10|20|30
0x500C
Ocupado
Bloqueado

No entran 6 enteros seguidos empezando en 0x5000.

Después del realloc (mudado a 0x8200)

realloc() encuentra lugar libre en 0x8200, copia el 10, 20, 30, libera 0x5000 y nos devuelve 0x8200:

Nueva dirección: 0x8200
v[0..5] (6 enteros contiguos)
10 | 20 | 30 | ? | ? | ?

¡Ni siquiera tenemos que hacer un free del bloque viejo! realloc() lo libera solo.

20 Uso Seguro de realloc() con Puntero Auxiliar

¿Qué pasa si realloc() falla y devuelve NULL?

En programas pequeños hacemos directamente vector = realloc(vector, ...);. Pero si la memoria se agotara y realloc() devolviera NULL, al guardarlo directo en vector perderíamos la dirección de nuestros datos originales.

⚠️ Directo (Riesgo si falla la RAM)
vector = realloc(vector, 10 * sizeof(int)); // Si realloc falló y devolvió NULL, // 'vector' ahora vale NULL y perdimos // la dirección de los 5 datos viejos.
✅ Seguro con Puntero Auxiliar (Buena Práctica)
int *aux = realloc(vector, 10 * sizeof(int)); if(aux != NULL) { vector = aux; // Solo actualizamos si salió bien }

💡 Si aux no es NULL, significa que el cambio de tamaño tuvo éxito y actualizamos vector = aux;. Si dio NULL, vector conserva intacta su dirección original.

21 Resumen General de Memoria Dinámica (Apunte, pág. 36)

Con la clase de hoy completamos las 4 funciones fundamentales de la biblioteca <stdlib.h> para manejar memoria dinámica en C:

Función Para qué sirve (Apunte Teórico, pág. 36) Ejemplo de uso
malloc() Reserva memoria dinámica (sus valores iniciales son desconocidos / basura). v = malloc(5 * sizeof(int));
calloc() Reserva memoria dinámica e inicializa todos los elementos en 0. v = calloc(5, sizeof(int));
realloc() Cambia el tamaño (agranda o achica) de la memoria reservada sin perder los datos. v = realloc(v, 10 * sizeof(int));
free() Libera la memoria reservada y la devuelve al sistema operativo. free(v);

🔑 Regla de oro: Sin importar si reservaste con malloc(), con calloc() o si luego redimensionaste con realloc(), al final del programa siempre se libera con free().

25 Práctica Progresiva Nivel 4: Crecimiento a Pedido

Problema: Empezamos con un vector limpio de 3 enteros creado con calloc(). Luego le preguntamos al usuario cuántos casilleros extra quiere agregar y redimensionamos con realloc().

nivel4_crecimiento_usuario.c Nivel 4 • Integrando calloc, realloc y free
#include <stdio.h> #include <stdlib.h> int main() { int *vector = calloc(3, sizeof(int)); // Arranca con 3 ceros: 0, 0, 0 vector[0] = 100; vector[1] = 200; vector[2] = 300; int agregados; printf("Tiene 3 elementos. Cuantos mas quiere agregar?: "); scanf("%d", &agregados); int nuevo_total = 3 + agregados; vector = realloc(vector, nuevo_total * sizeof(int)); for(int i = 3; i < nuevo_total; i++) { printf("Ingrese valor para la posicion [%d]: ", i); scanf("%d", &vector[i]); } printf("Vector final (%d elementos): ", nuevo_total); for(int i = 0; i < nuevo_total; i++) printf("%d ", vector[i]); free(vector); return 0; }

26 Errores Frecuentes con calloc() y realloc() (Parte 1)

❌ Error 1: Multiplicar en calloc()
// ¡MAL! calloc lleva 2 parámetros con coma v = calloc(5 * sizeof(int));

No compila porque a calloc() le faltaría el segundo argumento.

✅ Corrección: Separar con coma ,
// ¡BIEN! Cantidad primero, tamaño después v = calloc(5, sizeof(int));

Recordá: malloc usa * (1 parámetro) y calloc usa , (2 parámetros).

❌ Error 2: Olvidar sizeof() en realloc()
// ¡MAL! Pide solo 10 bytes (no 10 ints) v = realloc(v, 10);
✅ Corrección: Multiplicar por sizeof(int)
// ¡BIEN! 10 enteros * 4 bytes = 40 bytes v = realloc(v, 10 * sizeof(int));

27 Errores Frecuentes con realloc() (Parte 2)

❌ Error 3: Pasar solo lo que se agrega
// Teníamos 5 y queremos 2 más (total 7): v = malloc(5 * sizeof(int)); v = realloc(v, 2 * sizeof(int)); // ¡Lo achicó a 2!

realloc() no suma 2 lugares: reemplaza el tamaño total por 2 lugares.

✅ Corrección: Pasar el tamaño TOTAL
// Si teníamos 5 y queremos 2 más, el total es 7: v = malloc(5 * sizeof(int)); v = realloc(v, 7 * sizeof(int)); // ¡Ahora tiene 7!

Siempre se pasa la cantidad total final de elementos.

⚠️ Error 4: Creer que realloc() inicializa en 0 los casilleros nuevos

Aunque el vector original haya sido creado con calloc(), cuando lo agrandamos con realloc() las nuevas posiciones agregadas al final NO vienen en 0 (contienen basura hasta que les asignemos un valor).

Escribir un programa en C que reserve memoria dinámica para 4 jugadores usando calloc() (para que todos arranquen con 0 puntos). Luego sumarle 50 puntos al jugador 0 y 30 puntos al jugador 3, mostrar los 4 puntajes y liberar la memoria.

💻 Ver código de solución completo
#include <stdio.h> #include <stdlib.h> int main() { int *puntos = calloc(4, sizeof(int)); puntos[0] = puntos[0] + 50; puntos[3] = puntos[3] + 30; for(int i = 0; i < 4; i++) { printf("Jugador %d: %d puntos\n", i, puntos[i]); } free(puntos); return 0; }

30 Ejercicio 2: De 3 a 5 Productos con realloc()

Enunciado

Reservar memoria con malloc() para guardar los precios (float) de 3 productos y cargarlos con scanf. Luego ampliar el vector a 5 productos usando realloc(), cargar los 2 precios nuevos, mostrar los 5 precios y liberar la memoria.

💻 Ver código de solución completo
#include <stdio.h> #include <stdlib.h> int main() { float *precios = malloc(3 * sizeof(float)); for(int i = 0; i < 3; i++) { printf("Precio %d: ", i + 1); scanf("%f", &precios[i]); } precios = realloc(precios, 5 * sizeof(float)); for(int i = 3; i < 5; i++) { printf("Nuevo precio %d: ", i + 1); scanf("%f", &precios[i]); } for(int i = 0; i < 5; i++) { printf("$%.2f\n", precios[i]); } free(precios); return 0; }

31 Ejercicio 3: Achicar un Vector Dinámico

Enunciado

Reservar memoria con malloc() para 6 enteros y guardar los valores 10, 20, 30, 40, 50, 60. Luego achicar el vector para quedarnos únicamente con los primeros 3 enteros usando realloc(), mostrar esos 3 valores y liberar la memoria.

💻 Ver código de solución completo
#include <stdio.h> #include <stdlib.h> int main() { int *v = malloc(6 * sizeof(int)); for(int i = 0; i < 6; i++) { v[i] = (i + 1) * 10; } // Achicamos la memoria a 3 enteros v = realloc(v, 3 * sizeof(int)); printf("Elementos que quedaron:\n"); for(int i = 0; i < 3; i++) { printf("%d\n", v[i]); } free(v); return 0; }
