01 Objetivos y Mapa de la Clase

¿Qué sabemos hasta ahora y qué sumamos hoy?

En las Unidades 01 y 02 aprendimos a declarar un vector, recorrerlo con un ciclo for y buscar datos adentro (como el mayor, el menor o contar cuántos cumplen una condición).

02 ¿Qué Significa Ordenar un Vector?

Definición del Apunte Teórico

Ordenar un vector significa reorganizar sus elementos adentro de las casillas siguiendo algún criterio definido, sin agregar ni borrar ningún número.

🏆 Rankings y Juegos

En un videojuego o torneo deportivo, los puntajes se cargan a medida que terminan los jugadores, pero la tabla de posiciones debe mostrarse ordenada del puntaje más alto al más bajo.

🛒 Tiendas Online

Cuando buscás zapatillas o celulares y elegís "Ordenar por menor precio", el programa toma el vector de precios y lo reacomoda de menor a mayor.

📋 Listados Escolares

Las notas de un curso, los números de legajo o los promedios finales se ordenan para detectar rápidamente quiénes obtuvieron las calificaciones más altas o más bajas.

🔑 Regla de oro del ordenamiento: El vector ordenado debe contener exactamente los mismos números que tenía el vector original, solo que ubicados en distintas posiciones.

04 La Idea General: Ordenar Cartas en la Mano

¿Cómo ordenamos los humanos cuando jugamos a las cartas?

Como explica el apunte: "Una forma muy simple de pensar el ordenamiento es imaginar que estamos ordenando cartas en la mano. Tomamos una carta, la comparamos con las demás y, si encontramos una que debería ir antes, las intercambiamos de lugar."

1
Miramos la primera posición (posición 0): Queremos que ahí quede la carta más chica de toda nuestra mano.
2
Comparamos con cada una de las cartas que están a su derecha: Miramos la segunda carta; si es menor que la que tenemos en la primera posición, las cambiamos de lugar entre sí. Seguimos comparando contra la tercera, la cuarta y la quinta carta.
3
La primera posición ya quedó lista: Cuando terminamos de comparar contra todas las de la derecha, estamos 100% seguros de que en la primera posición quedó la carta más chica de todas.
4
Avanzamos a la siguiente posición: Ahora nos paramos en la segunda posición (posición 1) y repetimos exactamente el mismo trabajo con las cartas que quedan a su derecha.

06 Primer Intento (INCORRECTO): Sin Variable Auxiliar

Alguien podría pensar en escribir estas dos líneas. Sigamos paso a paso qué hace realmente la computadora:

❌ Código Incorrecto
int a = 10; int b = 20; a = b; b = a;

Recordá que en una variable entra un solo valor a la vez. Al guardar un valor nuevo, el valor viejo se destruye para siempre.

Paso Instrucción Valor de a Valor de b ¿Qué ocurrió en la RAM?
Inicio int a=10, b=20; 10 20 Estado inicial correcto.
Línea 1 a = b; 20 20 Se copia el 20 de b adentro de a. ¡El 10 que tenía a se pisó y se perdió!
Línea 2 b = a; 20 20 Se copia el valor actual de a (que ahora es 20) en b. ¡Ambas quedan en 20!

💥 Conclusión del apunte: Cuando hicimos a = b;, el valor original de a (que era 10) fue sobrescrito por el 20. Para no perderlo, necesitamos guardarlo antes en otro lugar.

07 La Solución: Usar una Variable Auxiliar (aux)

🥤 La Analogía de los Dos Vasos

Imaginá que tenés el Vaso A lleno de agua y el Vaso B lleno de jugo de naranja. Querés que el jugo pase al Vaso A y el agua al Vaso B.

No podés volcar el Vaso B directamente sobre el Vaso A porque se mezclarían o se rebalsaría. Necesitás sí o sí un tercer vaso vacío temporal (aux):

  1. Volcás el agua del Vaso A en el Vaso Auxiliar (aux = a;).
  2. Volcás el jugo del Vaso B en el Vaso A (a = b;).
  3. Volcás el agua guardada en el Vaso Auxiliar hacia el Vaso B (b = aux;).
✅ Código Correcto del Apunte con aux
intercambio_aux.c Patrón de 3 Pasos
int a = 10; int b = 20; int aux; aux = a; // Paso 1: guardamos el 10 de 'a' en 'aux' a = b; // Paso 2: pasamos el 20 de 'b' hacia 'a' b = aux; // Paso 3: recuperamos el 10 desde 'aux' en 'b'

💡 Mirá la diagonal visual del código: aux = a; ➔ a = b; ➔ b = aux;. La variable que queda a la derecha arriba pasa a la izquierda en el renglón siguiente.

09 Intercambiando Dos Casillas de un Vector

Cada casilla de un vector (por ejemplo, numeros[i] y numeros[j]) funciona exactamente igual que una variable entera común. Por lo tanto, usamos las mismas 3 líneas con aux:

swap_en_vector.c Casillas i y j
// Intercambiar numeros[i] con numeros[j]: int aux; aux = numeros[i]; numeros[i] = numeros[j]; numeros[j] = aux;

Ejemplo con i = 0 y j = 1

Si numeros[0] vale 8 y numeros[1] vale 3:

  • aux = numeros[0]; ➔ aux guarda el 8.
  • numeros[0] = numeros[1]; ➔ numeros[0] recibe el 3.
  • numeros[1] = aux; ➔ numeros[1] recibe el 8.

10 ¿Por Qué Necesitamos Dos Ciclos for?

La gran duda cuando empezamos a ordenar

Hasta ahora, para mostrar un vector, sumar sus elementos o buscar el mayor nos alcanzaba con un solo ciclo for. ¿Por qué para ordenar necesitamos dos ciclos for?

Con un solo ciclo for...

Si solo recorremos el vector una vez comparando la posición 0 contra las demás (1, 2, 3, 4), logramos ubicar al número más chico (el 1) en la casilla [0].

Pero mirá cómo quedan las demás casillas después de acomodar solo la posición 0:

[0]
1
[1]
8
[2]
10
[3]
3
[4]
5

¡Las posiciones 1, 2, 3 y 4 siguen desordenadas!

Con dos ciclos for (uno adentro del otro)

Necesitamos repetir ese proceso para cada posición del vector:

  • El primer for (con i) elige qué casilla estamos acomodando ahora (primero la 0, después la 1, luego la 2...).
  • El segundo for (con j) recorre todas las casillas que están adelante de i para compararlas contra numeros[i].

✓ A poner un ciclo adentro de otro se lo llama ciclos anidados (for anidado).

11 ¿Cómo Funciona un for Anidado?

La Analogía de las Agujas del Reloj 🕒

Pensá en el ciclo externo (i) como la aguja de las horas y en el ciclo interno (j) como la aguja de los minutos: por cada 1 paso que avanza i, el ciclo interno j da todas sus vueltas completas desde el principio hasta el final.

mecanica_for_anidado.c i fija, j avanza
for(int i = 0; i < 5; i++) { for(int j = i + 1; j < 5; j++) { // Comparamos posición i con posición j } }

¿Qué parejas (i, j) se forman?

  • Cuando i = 0: j arranca en 0 + 1 = 1 y recorre j = 1, 2, 3, 4.
    Compara pos 0 contra 1, contra 2, contra 3 y contra 4.
  • Cuando i = 1: j arranca en 1 + 1 = 2 y recorre j = 2, 3, 4.
    Compara pos 1 contra 2, contra 3 y contra 4.
  • Cuando i = 2: j arranca en 2 + 1 = 3 y recorre j = 3, 4.
  • Cuando i = 3: j arranca en 3 + 1 = 4 y recorre j = 4.
  • Cuando i = 4: j arranca en 5; como 5 < 5 es falso, no entra.

12 ¿Por Qué j Empieza en i + 1?

Miremos gráficamente qué rol cumple cada índice durante el algoritmo del apunte:

📍 Índice i (Posición que estamos acomodando)

i se queda quieto señalando el casillero donde queremos dejar el menor valor disponible.

Todo lo que está a la izquierda de i ya fue ordenado en las vueltas anteriores y no debemos tocarlo más.

🔍 Índice j = i + 1 (Explorador hacia adelante)

No tiene sentido comparar una casilla consigo misma (numeros[i] con numeros[i]), ni tampoco volver hacia atrás.

Por eso j nace siempre en i + 1 (exactamente una posición a la derecha de i) y camina hasta el final del vector.

13 El Algoritmo del Apunte (De Menor a Mayor)

Este es el bloque exacto de código que presenta el Apunte Teórico (página 14) para ordenar un vector de 5 números de menor a mayor:

ordenamiento_apunte.c Algoritmo Central de Clase
int aux; for(int i = 0; i < 5; i++) { for(int j = i + 1; j < 5; j++) { if(numeros[j] < numeros[i]) { aux = numeros[i]; numeros[i] = numeros[j]; numeros[j] = aux; } } }

💡 Leelo en voz alta como una oración en español: "Para cada posición i del vector, recorro todas las posiciones siguientes j. Si encuentro en numeros[j] un número más chico que el que tengo en numeros[i], los intercambio de lugar usando aux."

14 Entendiendo el Algoritmo Parte por Parte

1. Primer for: for(int i = 0; i < 5; i++)

Representa la posición que estamos intentando acomodar. Empieza acomodando la casilla 0, luego la 1, luego la 2, y así sucesivamente.

2. Segundo for: for(int j = i + 1; j < 5; j++)

Recorre todas las posiciones que están después de i. Como empieza en i + 1, siempre mira hacia adelante buscando candidatos más chicos.

3. La Comparación: if(numeros[j] < numeros[i])

Pregunta: ¿el número que está más adelante (en j) es menor que el que está en la posición i? Si la respuesta es SÍ, significa que están desordenados y hay que intercambiarlos.

4. El Intercambio: aux = numeros[i]; ...

Cuando el if da verdadero, las tres líneas con aux intercambian los dos valores. Así, el número más pequeño pasa inmediatamente a ocupar la posición numeros[i].

21 Ordenar de Mayor a Menor (Descendente)

El truco del Apunte Teórico (página 15)

¿Qué cambia si el ejercicio nos pide ordenar de mayor a menor? ¡Casi nada! Solo tenemos que cambiar el signo < por el signo > dentro del if:

menor_a_mayor.c Ascendente (<)
for(int i = 0; i < 5; i++) { for(int j = i + 1; j < 5; j++) { if(numeros[j] < numeros[i]) { aux = numeros[i]; numeros[i] = numeros[j]; numeros[j] = aux; } } }
mayor_a_menor.c Descendente (>)
for(int i = 0; i < 5; i++) { for(int j = i + 1; j < 5; j++) { if(numeros[j] > numeros[i]) { aux = numeros[i]; numeros[i] = numeros[j]; numeros[j] = aux; } } }

🧠 ¿Por qué funciona cambiar < por >? Porque ahora preguntamos: "¿el elemento que está más adelante en numeros[j] es más grande que el que tengo en numeros[i]?". Si es más grande, lo traemos hacia adelante.

23 Variante Complementaria: Burbujeo de Adyacentes

¿Por qué vemos también esta variante?

En libros, videos o ejercicios de programación vas a encontrar muy seguido una variante hermana llamada Método de la Burbuja Clásico (Bubble Sort de vecinos). Es fundamental conocerla para no confundirte si la ves escrita.

¿En qué consiste el Burbujeo de Vecinos?

En lugar de dejar fija la casilla i y compararla contra todas las j lejanas, esta variante compara siempre dos casillas vecinas pegadas:

numeros[j]  contra  numeros[j + 1]

Si el vecino de la izquierda es mayor que el vecino de la derecha (numeros[j] > numeros[j + 1]), se intercambian. Así, el número más grande va "flotando" como una burbuja hacia el final del vector en cada pasada.

burbuja_vecinos.c Compara j con j + 1
int aux; for(int i = 0; i < 5 - 1; i++) { for(int j = 0; j < 5 - 1 - i; j++) { if(numeros[j] > numeros[j + 1]) { aux = numeros[j]; numeros[j] = numeros[j + 1]; numeros[j + 1] = aux; } } }

24 Comparativa: Método del Apunte vs. Burbuja Vecinos

Ambos métodos usan doble for + if + intercambio con aux y ambos dejan el vector exactamente con el mismo resultado final. Mirá sus diferencias:

Característica Método del Apunte (Fijando i) ⭐ Burbuja de Adyacentes (j y j+1)
¿Qué casillas compara el if? numeros[j] contra numeros[i] numeros[j] contra numeros[j + 1]
¿Dónde arranca j? En j = i + 1 (una adelante de i) En j = 0 (desde el principio)
¿Qué queda fijo tras la 1ra pasada? El menor queda fijo al principio (en [0]) El mayor queda fijo al final (en [N-1])
¿Cuál debés escribir en tus pruebas? ¡Este! Es el algoritmo oficial del apunte de clase. Reconocerlo si aparece en un ejercicio de lectura de código.

✅ Para tus exámenes y prácticas: Usá siempre el modelo del apunte (for i ➔ for j = i + 1 ➔ if(numeros[j] < numeros[i])), que es más corto, no tiene riesgo de salirse del vector con j + 1 y es el que espera tu profesor.

🔎 El "Esqueleto" Visual del Ordenamiento

Cada vez que leas un programa en un examen y veas esta escalera de 4 niveles, sabés sin dudar que está ordenando un vector:

for (...) // 1. Ciclo externo { for (...) // 2. Ciclo interno { if (...) // 3. Comparación { // 4. Intercambio con aux } } }

📝 ¿Por qué se toma siempre en el Examen?

Como explica el apunte, con un solo ejercicio de ordenamiento el profesor evalúa 4 temas fundamentales a la vez:

1
Saber recorrer vectores usando índices sin salirse de rango.
2
Saber utilizar ciclos for anidados (i y j).
3
Saber comparar elementos con if (< o >).
4
Saber intercambiar valores usando una variable auxiliar aux.

26 Ejemplo Práctico: Cargar con scanf y Ordenar

Combinemos las 3 etapas clásicas de un programa completo: 1) Cargar los 5 números por teclado, 2) Ordenarlos de menor a mayor y 3) Mostrarlos:

cargar_y_ordenar.c Nivel 1-2 • Ciclo Completo
#include <stdio.h> int main() { int numeros[5]; int aux; // ETAPA 1: Carga del vector por teclado for(int i = 0; i < 5; i++) { printf("Ingrese el numero de la posicion %d: ", i); scanf("%d", &numeros[i]); } // ETAPA 2: Ordenamiento de menor a mayor for(int i = 0; i < 5; i++) { for(int j = i + 1; j < 5; j++) { if(numeros[j] < numeros[i]) { aux = numeros[i]; numeros[i] = numeros[j]; numeros[j] = aux; } } } // ETAPA 3: Mostrar el resultado printf("\nNumeros ordenados de menor a mayor: "); for(int i = 0; i < 5; i++) { printf("%d ", numeros[i]); } return 0; }

27 Ejemplo Nivel 3: Podio de Puntajes (Top 3)

Una ventaja enorme de tener un vector ordenado es que los valores especiales quedan en posiciones fijas. Si ordenamos 6 puntajes de mayor a menor, el 1er puesto está en [0], el 2do en [1] y el 3ro en [2]:

podio_puntajes.c Nivel 3 • Top 3
#include <stdio.h> int main() { int pts[6] = {450, 890, 120, 950, 610, 780}; int aux; // Ordenamos de MAYOR a MENOR (>) for(int i = 0; i < 6; i++) { for(int j = i + 1; j < 6; j++) { if(pts[j] > pts[i]) { aux = pts[i]; pts[i] = pts[j]; pts[j] = aux; } } } printf("1er Puesto (Oro): %d pts\n", pts[0]); printf("2do Puesto (Plata): %d pts\n", pts[1]); printf("3er Puesto (Bronce): %d pts\n", pts[2]); printf("Puntaje mas bajo: %d pts\n", pts[5]); return 0; }
Consolastdout
1er Puesto (Oro): 950 pts 2do Puesto (Plata): 890 pts 3er Puesto (Bronce): 780 pts Puntaje mas bajo: 120 pts

💡 Atajo útil: Con el vector ordenado, el máximo y el mínimo están siempre en las puntas: [0] y [N-1].

28 Ejemplo Nivel 4: Ordenar con Datos Asociados

¿Qué pasa si tenemos un vector de notas[4] y otro vector paralelo con los números de legajo[4] de cada alumno? Si intercambiamos dos notas, también debemos intercambiar sus legajos adentro del mismo if para que no se mezclen de dueño:

vectores_paralelos.c Nivel 4 • Doble Swap Sincronizado
int legajos[4] = {101, 102, 103, 104}; int notas[4] = {7, 10, 4, 9}; int auxNota, auxLegajo; for(int i = 0; i < 4; i++) { for(int j = i + 1; j < 4; j++) { if(notas[j] > notas[i]) // El criterio lo manda el vector 'notas' { // 1. Intercambiamos las notas auxNota = notas[i]; notas[i] = notas[j]; notas[j] = auxNota; // 2. Intercambiamos TAMBIÉN los legajos en las mismas posiciones i y j auxLegajo = legajos[i]; legajos[i] = legajos[j]; legajos[j] = auxLegajo; } } } // Ahora en pos 0 queda: Legajo 102 con Nota 10.

29 Errores Frecuentes al Ordenar (Parte 1)

❌ Error 1: Hacer el swap sin variable aux
if(numeros[j] < numeros[i]) { numeros[i] = numeros[j]; numeros[j] = numeros[i]; // ¡MAL! }

Qué pasa: Perdés el número original que estaba en numeros[i] y el vector termina lleno de números repetidos. Siempre usá las 3 líneas con aux.

❌ Error 2: Empezar j = 0 en vez de j = i + 1
for(int i = 0; i < 5; i++) { for(int j = 0; j < 5; j++) // ¡Cuidado! { if(numeros[j] < numeros[i]) { ... } } }

Qué pasa: Si j empieza en 0, el ciclo interno vuelve a tocar las casillas anteriores a i que ya estaban acomodadas y las desordena al revés. j debe arrancar siempre en i + 1.

30 Errores Frecuentes al Ordenar (Parte 2)

❌ Error 3: Imprimir el vector ADENTRO del doble for
for(int i = 0; i < 5; i++) { for(int j = i + 1; j < 5; j++) { if(numeros[j] < numeros[i]) { ... } printf("%d ", numeros[i]); // ¡MAL UBICADO! } }

Qué pasa: Se imprimen números a medio ordenar decenas de veces. El for que muestra el vector va después de cerrar las llaves del ordenamiento.

✅ Regla Mnemotécnica para < y >

Si estás usando el algoritmo del apunte con if(numeros[j] OP numeros[i]):

  • Querés de menor a mayor ➔ preguntás si numeros[j] es menor: numeros[j] < numeros[i].
  • Querés de mayor a menor ➔ preguntás si numeros[j] es mayor: numeros[j] > numeros[i].

¡El símbolo que ponés cuando numeros[j] va a la izquierda coincide con la primera palabra del criterio!

31 Ejercicio Práctico 1: Ordenar Precios

Enunciado

Dado el vector int precios[5] = {1500, 800, 2300, 450, 1200};, escribí un programa en C que lo ordene de menor a mayor, muestre el listado completo ordenado y luego informe por separado cuál es el precio más barato y cuál es el más caro usando las posiciones del vector.

👁️ Ver solución paso a paso en C
#include <stdio.h> int main() { int precios[5] = {1500, 800, 2300, 450, 1200}; int aux; for(int i = 0; i < 5; i++) { for(int j = i + 1; j < 5; j++) { if(precios[j] < precios[i]) { aux = precios[i]; precios[i] = precios[j]; precios[j] = aux; } } } printf("Precios de menor a mayor: "); for(int i = 0; i < 5; i++) { printf("$%d ", precios[i]); } printf("\nMas barato: $%d | Mas caro: $%d\n", precios[0], precios[4]); return 0; }

32 Ejercicio Práctico 2: Lectura de Código (Tipo Examen)

Analizá el siguiente código y respondé antes de abrir la solución: 1) ¿Qué hace este programa? 2) ¿En qué orden queda el vector? 3) ¿Cómo queda el vector al terminar la primera vuelta externa (i = 0)?

int v[4] = {12, 25, 7, 30}; int aux; for(int i = 0; i < 4; i++) { for(int j = i + 1; j < 4; j++) { if(v[j] > v[i]) { aux = v[i]; v[i] = v[j]; v[j] = aux; } } }
👁️ Ver respuestas y traza paso a paso
  • 1) ¿Qué hace?: Ordena el vector v de 4 elementos.
  • 2) ¿En qué criterio?: Como la condición es if(v[j] > v[i]), ordena de mayor a menor (descendente). Al terminar todo el programa queda: {30, 25, 12, 7}.
  • 3) Traza de i = 0: Arranca con [12, 25, 7, 30].
    • Con j = 1: ¿25 > 12? Sí ➔ intercambia pos 0 y pos 1 ➔ [25, 12, 7, 30].
    • Con j = 2: ¿7 > 25? No ➔ queda [25, 12, 7, 30].
    • Con j = 3: ¿30 > 25? Sí ➔ intercambia pos 0 y pos 3 ➔ [30, 12, 7, 25].

33 Resumen Final y Checklist de la Unidad 03

Síntesis de Conceptos Clave

  • Ordenar: Reorganizar las casillas de menor a mayor o de mayor a menor sin perder ningún elemento.
  • Variable aux: Indispensable para intercambiar dos variables (aux = a; a = b; b = aux;).
  • Doble ciclo for: El externo (i) fija la casilla que estamos acomodando; el interno (j = i + 1) recorre todas las siguientes.
  • Criterio: if(numeros[j] < numeros[i]) ordena de menor a mayor; con > ordena de mayor a menor.

Checklist antes de pasar a Matrices

✓ ¿Puedo explicar con mis palabras por qué falla a = b; b = a;?
✓ ¿Sé escribir de memoria las 3 líneas del intercambio con aux?
✓ ¿Entiendo por qué el segundo ciclo empieza en j = i + 1?
✓ ¿Sé cambiar el signo del if para ordenar ascendente o descendente?
