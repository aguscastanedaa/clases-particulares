02 El Problema: ¿Qué Pasa Si Repetimos a Mano?

Imaginá que nos piden un programa que muestre en pantalla los números del 1 al 5, uno debajo del otro. Sin conocer bucles, tendríamos que escribir esto:

sin_bucles.c Código repetitivo
#include <stdio.h> int main() { printf("1\n"); printf("2\n"); printf("3\n"); printf("4\n"); printf("5\n"); return 0; }

🤔 Pensá un segundo:

¿Qué pasaría si el profesor te pide mostrar los números del 1 al 1000? ¿Escribirías 1000 líneas de printf? ¡Imposible! Necesitamos una instrucción que le diga a la computadora: "repetí esta acción mientras se cumpla esta condición".

03 ¿Qué es un Bucle (Ciclo) y Cómo Pensarlo?

Concepto Fundamental

Un bucle (también llamado ciclo o loop) es una estructura de control que permite repetir un bloque de instrucciones varias veces de forma automática. Cada vuelta completa del bucle se llama iteración.

🏃 Analogía: Pista de Atletismo

Imaginá que el profesor de educación física te dice: "Empezá en la vuelta 1. Mientras vayas por la vuelta 5 o menos, corré una vuelta a la pista y sumá 1 a tu contador de vueltas". Cuando tu contador llega a 6, dejás de correr.

¿Qué significa "Iteración"?

En el apunte vas a leer la palabra iteración (y el verbo iterar). Significa simplemente "una vuelta del ciclo":
• 1ra iteración = 1ra vuelta.
• 5 iteraciones = 5 vueltas en total.

04 Los 3 Ingredientes de Todo Ciclo

Para que cualquier bucle funcione bien (empiece, trabaje y sepa cuándo frenar), siempre necesita estos 3 ingredientes:

1. Inicio (Inicialización)

Crear la variable contadora (suele llamarse i por iterador) y darle su valor inicial.

int i = 1;

2. Condición de Continuidad

La pregunta que se hace antes de cada vuelta. Si da True, entra al ciclo; si da False, termina.

i <= 5

3. Avance (Incremento)

Aumentar la variable en cada vuelta para acercarnos al final y que el ciclo no sea eterno.

i++;

05 13.1. Bucle while (Definición del Apunte)

Definición del Apunte

Repite instrucciones mientras una condición sea verdadera.

La palabra while en inglés significa literalmente "mientras". Su estructura es muy parecida a la de un if, con la diferencia de que cuando termina de ejecutar la última llave }, vuelve arriba a preguntar la condición otra vez:

Sintaxis del bucle while Estructura
while(condicion) { instrucciones; }

06 El Ejemplo del Apunte: Contar del 1 al 5 con while

Veamos el ejemplo exacto de la página 10 del apunte:

Ejemplo 13.1 del Apunte Página 10
int i = 1; while(i <= 5) { printf("%d\n", i); i++; }

Explicación Textual del Apunte

"i empieza con valor = 1, mientras que i sea menor o igual a 5, vamos a printear el valor de i. Y además incrementamos i en 1, ¿qué quiere decir eso? En cada iteración que hace el while, a la variable i se le va a sumar un 1."

07 Desglose Pieza por Pieza del Ejemplo while

1. int i = 1;

Se ejecuta antes de llegar al bucle. Crea la cajita i y guarda el número 1 como punto de partida.

2. while(i <= 5)

Es el "guardia de entrada". Antes de cada vuelta pregunta: "¿El valor actual de i es menor o igual a 5?".

3. printf("%d\n", i);

Muestra en pantalla el valor que tiene i en esa vuelta y baja un renglón gracias al salto de línea \n.

4. i++;

Le suma 1 a i (equivale a i = i + 1;). Luego llega a la llave } y salta otra vez arriba al while(i <= 5).

08 Cómo Ocurre la 1ra Iteración (Paso a Paso del Apunte)

Leamos cómo describe el apunte lo que ocurre en la primera vuelta del bucle:

1
Estado inicial (1ra iteración): La variable entra con i = 1.
2
Pregunta del while: "¿i es menor o igual que 5?" (1 <= 5). ¡Sí! Es menor (Verdadero), entonces entra al bloque { }.
3
Acción en pantalla: Printea el valor de i ➔ muestra 1 en la consola.
4
Incremento: Se incrementa i + 1 ➔ 1 + 1 = 2. Ahora i vale 2 y vuelve a subir al while para la 2da vuelta.

10 ¿Por Qué Frena Exactamente Cuando i Llega a 6?

Explicación Textual del Apunte (Página 10)

"Entonces repite este proceso hasta que la condición del while (i menor o igual a 5) deje de cumplirse, o sea se repetirá hasta que i sea = 6, ya que cuando i vale 1, 2, 3, 4, 5 la condición de que sea menor O igual a 5 es VERDADERA."

¿Cuándo es VERDADERA (i <= 5)?

• Con 1, 2, 3, 4 es menor a 5 ➔ Verdadera.
• Con 5 es igual a 5 ➔ Verdadera (entra e imprime el 5, y luego hace 5 + 1 = 6).

¿Cuándo se vuelve FALSA?

Recién cuando i toma el valor 6. Como 6 no es ni menor ni igual a 5, la condición da Falso y el programa salta debajo de la llave de cierre }.

11 ¿Qué Pasa Si Olvidamos Escribir i++?

Imaginá que borramos u olvidamos la línea i++; adentro del while:

💥 Bucle Infinito (Se tilda el programa)
int i = 1; while(i <= 5) { printf("%d\n", i); // ¡Falta i++;! }

i empieza en 1 y nunca cambia. En cada vuelta pregunta 1 <= 5 (siempre verdadero) e imprime 1 infinitas veces sin terminar jamás.

🛟 Cómo Detenerlo y Cómo Prevenirlo

• Para prevenirlo: Revisá siempre que adentro de las llaves { } del while haya una instrucción que modifique la variable de la condición.

• Freno de emergencia: Si ejecutaste un programa con bucle infinito en la consola, presioná Ctrl + C en el teclado para detenerlo.

12 Ejemplo Nivel 1: Programa Completo con while

nivel1_while.c Nivel 1 — Completo
#include <stdio.h> int main() { int i = 1; while(i <= 5) { printf("%d\n", i); i++; } printf("Afuera del while, i vale: %d\n", i); return 0; }
Salida en Consola
$ ./nivel1_while 1 2 3 4 5 Afuera del while, i vale: 6

¡Mirá la última línea de la consola! Comprueba en vivo lo que explica el apunte: adentro del ciclo se imprimen del 1 al 5, y el ciclo termina cuando i llega a 6.

13 Variantes con while: De 2 en 2 y Cuenta Regresiva

Cambiando los 3 ingredientes (inicio, condición y avance), podemos generar cualquier secuencia:

Saltar de 2 en 2 (i += 2)

int i = 2; while(i <= 10) { printf("%d ", i); i += 2; // Suma de a 2 }

Muestra: 2 4 6 8 10 (frena cuando i llega a 12).

Cuenta Regresiva del 5 al 1 (i--)

int i = 5; while(i >= 1) { printf("%d ", i); i--; // Resta 1 en cada vuelta }

Muestra: 5 4 3 2 1 (frena cuando i baja a 0).

14 El Gran Fuerte del while: Cuando No Sabemos Cuántas Vueltas Son

Muchas veces no sabemos de antemano cuántas veces se repetirá el ciclo porque depende de lo que ingrese el usuario con scanf. Por ejemplo, pedir una clave o repetir mientras no ingrese 0:

while_interactivo.c Repetición por condición
#include <stdio.h> int main() { int numero = 1; // Valor inicial distinto de 0 para entrar while(numero != 0) { printf("Ingrese un numero (0 para terminar): "); scanf("%d", &numero); } printf("Fin del programa.\n"); return 0; }

15 13.2. Bucle for (Definición del Apunte)

Definición del Apunte (Página 10)

Permite repetir una cantidad conocida de veces.

¿Por qué se inventó el for?

En el while teníamos los 3 ingredientes desparramados en distintas líneas (int i = 1; arriba, i <= 5 en el medio e i++; al final), con el riesgo de olvidar el i++.

Todo reunido en un solo renglón

El bucle for agrupa el inicio, la condición y el incremento adentro del mismo paréntesis, separados por punto y coma (;). ¡De un solo vistazo sabés cuántas veces va a iterar!

16 El Ejemplo del Apunte: Contar del 1 al 5 con for

Veamos el ejemplo exacto de las páginas 10 y 11 del apunte:

Ejemplo 13.2 del Apunte Páginas 10 y 11
for(int i = 1; i <= 5; i++) { printf("%d\n", i); }

Explicación Textual del Apunte

"Acá el bucle se va a repetir con la cantidad de iteraciones que nosotros le digamos, en este caso itera 5 veces:
i = 1, i = 2, i = 3, i = 4, i = 5 (última)."

17 Anatomía del for: Las 3 Partes del Paréntesis

for ( int i = 1 ; i <= 5 ; i++ )

1. int i = 1

Inicialización: En qué valor arranca la variable contadora i. Se ejecuta una única vez al principio de todo.

2. i <= 5

Condición: Hasta dónde sigue iterando. Se evalúa antes de cada vuelta. Mientras sea verdadera, entra a las llaves { }.

3. i++

Incremento / Paso: Cómo avanza i al terminar cada vuelta (acá suma 1 por vuelta).

18 Los 4 Pasos de Ejecución Interna de un for

¡Atención! Muchos creen que el i++ se ejecuta antes del printf porque está escrito arriba. No es así. Mirá el orden real en que la computadora ejecuta un for:

1
Paso 1 — Inicialización (int i = 1): Se hace una sola vez al llegar al for.
2
Paso 2 — Condición (i <= 5): Pregunta si se cumple. Si da Falso, el for termina inmediatamente. Si da Verdadero, pasa al Paso 3.
3
Paso 3 — Cuerpo del bucle ({ printf("%d\n", i); }): Ejecuta todas las instrucciones adentro de las llaves.
4
Paso 4 — Incremento (i++) y repetir: Recién al chocar con la llave de cierre }, aumenta i en 1 y vuelve al Paso 2 a evaluar la condición.

19 Traza Completa de for(int i = 1; i <= 5; i++)

Iteración (Vuelta) Valor de i Paso 2: ¿i <= 5? Paso 3: Cuerpo printf Paso 4: i++ al cerrar }

2da i = 2 2 <= 5 (Verdadero) Muestra 2 i sube a 3
3ra i = 3 3 <= 5 (Verdadero) Muestra 3 i sube a 4
4ta i = 4 4 <= 5 (Verdadero) Muestra 4 i sube a 5
5ta (última) i = 5 5 <= 5 (Verdadero) Muestra 5 i sube a 6
Chequeo final i = 6 6 <= 5 (Falso) No se ejecuta Termina el for

20 Comparación Lado a Lado: while vs for

Mirando los dos ejemplos del apunte uno al lado del otro, vemos que hacen exactamente el mismo trabajo y producen la misma salida (1, 2, 3, 4, 5):

13.1. Con Bucle while

int i = 1; while(i <= 5) { printf("%d\n", i); i++; }

Inicio afuera, condición en el paréntesis e incremento adentro al final.

13.2. Con Bucle for

for(int i = 1; i <= 5; i++) { printf("%d\n", i); }

Inicio, condición e incremento compactados en el encabezado del for.

21 ¿Cuándo Conviene Elegir for y Cuándo while?

✅ Elegí for cuando...

Conocés la cantidad exacta de iteraciones antes de empezar el ciclo (tal como define el apunte).

  • Mostrar los números del 1 al 100.
  • Pedir exactamente 5 notas por teclado.
  • Calcular la tabla de multiplicar del 1 al 10.
  • Recorrer las casillas de un vector (2do Bimestre).

✅ Elegí while cuando...

No sabés cuántas vueltas dará porque depende de una condición que cambia durante el programa.

  • Pedir números al usuario mientras no ingrese 0.
  • Pedir una contraseña mientras sea incorrecta.
  • Seguir jugando mientras el jugador tenga vidas mayores a 0.

22 Contadores y Acumuladores Adentro de un Bucle

Al combinar la Sección 7 (Incremento de variables: += y ++) con los bucles de la Sección 13, nacen dos herramientas fundamentales de la programación:

🔢 Contador (suma una cantidad fija, +1)

Sirve para contar cuántas veces ocurre algo (ej: cuántos números pares aparecieron).

int cantidad = 0; // Empieza en 0 // Adentro del bucle: cantidad++; // Sube de 1 en 1

🧺 Acumulador (suma valores variables)

Sirve para ir sumando un total (ej: la suma de todos los números o el total de una compra).

int suma = 0; // Empieza en 0 // Adentro del bucle: suma += i; // Equivale a: suma = suma + i;

24 Pedir Varios Números con scanf Adentro de un for

Si necesitamos pedirle 5 números al usuario para sumarlos, no hace falta declarar 5 variables distintas (n1, n2, n3, n4, n5). Ponemos un único scanf adentro de un for que dé 5 vueltas:

scanf_en_for.c Patrón clásico
#include <stdio.h> int main() { int valor; int suma = 0; for(int i = 1; i <= 5; i++) { printf("Ingrese el numero %d: ", i); scanf("%d", &valor); suma += valor; } printf("Suma de los 5 ingresados: %d\n", suma); return 0; }

25 Ejemplo Nivel 3: Filtrar con if Adentro de un for

Combinemos bucles (Sección 13) + divisibilidad por 2 (Sección 6) + condicionales (Sección 9): recorremos del 1 al 6, mostramos cuáles son pares y los contamos:

nivel3_contar_pares.c Nivel 3 — Intermedio
#include <stdio.h> int main() { int pares = 0; for(int i = 1; i <= 6; i++) { if(i % 2 == 0) { printf("%d es par\n", i); pares++; } } printf("Total de pares: %d\n", pares); return 0; }

26 Integración: Llamar a doble(i) Adentro de un for

¡Unamos los dos grandes temas de cierre del 1er Bimestre! Podemos llamar a la función int doble(int numero) de la Sección 12 en cada vuelta del bucle for de la Sección 13:

funciones_y_bucles.c Secciones 12 + 13
#include <stdio.h> int doble(int numero) { return numero * 2; } int main() { for(int i = 1; i <= 5; i++) { int resultado = doble(i); printf("El doble de %d es %d\n", i, resultado); } return 0; }
Salida en Consola

En cada vuelta, i cambia de valor (1, 2, 3, 4, 5) y se envía como argumento a doble(i).

27 Puente Hacia el 2do Bimestre: Contar desde 0

En la próxima unidad (2do Bimestre: Vectores) vas a descubrir que en C las posiciones de un vector se numeran empezando desde 0 (0, 1, 2, 3, 4). Por eso, este patrón de for será tu mejor amigo:

Del 1 al 5 (i = 1; i <= 5)

for(int i = 1; i <= 5; i++) { printf("%d ", i); }

Itera 5 veces con valores: 1, 2, 3, 4, 5 (frena en 6).

Del 0 al 4 (i = 0; i < 5)

for(int i = 0; i < 5; i++) { printf("%d ", i); }

¡También itera 5 veces! Con valores: 0, 1, 2, 3, 4 (frena en 5 porque usa < 5).

28 Ejemplo Nivel 4: Cómo Pensar y Construir la Solución

Problema Integrador

Un profesor quiere ingresar las notas de 4 alumnos (entre 1 y 10). Al finalizar la carga, el programa debe informar:
1) Cuántos alumnos aprobaron (nota mayor o igual a 6).
2) El promedio general de las 4 notas.

1
¿Qué ciclo elegimos? Como sabemos de antemano que son exactamente 4 alumnos, usamos un for(int i = 1; i <= 4; i++).
2
¿Qué variables necesitamos antes del ciclo? Un contador int aprobados = 0; y un acumulador int sumaNotas = 0;.
3
¿Qué hacemos en cada vuelta? Leemos la nota con scanf, la sumamos a sumaNotas += nota;, y si nota >= 6 incrementamos aprobados++;.

29 Ejemplo Nivel 4: Código Completo y Traza

nivel4_curso.c Nivel 4
#include <stdio.h> int main() { int nota; int aprobados = 0; int sumaNotas = 0; for(int i = 1; i <= 4; i++) { printf("Nota del alumno %d: ", i); scanf("%d", &nota); sumaNotas += nota; if(nota >= 6) { aprobados++; } } float promedio = sumaNotas / 4.0; printf("Aprobados: %d\n", aprobados); printf("Promedio: %.2f\n", promedio); return 0; }

30 Error Frecuente #1: El Punto y Coma al Final de while o for

Uno de los errores más difíciles de detectar a simple vista es poner un punto y coma (;) justo después de cerrar el paréntesis de for(...) o while(...):

❌ MAL: Punto y coma después del paréntesis
for(int i = 1; i <= 5; i++); // <-- ¡ERROR!
{
    printf("%d\n", i);
}

Ese ; le dice a C que el bucle tiene un cuerpo vacío. En un for gira en vacío hasta 6; y en un while(i <= 5); ¡congela el programa en un bucle infinito silencioso porque nunca llega al i++ de adentro!

✅ BIEN: Sin punto y coma antes de abrir {
for(int i = 1; i <= 5; i++) { printf("%d\n", i); }

Los puntos y coma van adentro del paréntesis del for separando sus 3 partes, jamás al final de la línea donde empieza el bloque {.

31 Error Frecuente #2: Poner int suma = 0; Adentro del Ciclo

❌ MAL: Reiniciar en 0 en cada vuelta
for(int i = 1; i <= 5; i++) { int suma = 0; // ¡Borra lo acumulado! suma += i; }

Si declarás e inicializás suma = 0 adentro de las llaves del bucle, en cada vuelta vuelve a cero y pierde todo lo que venía sumando. Además, no existirá afuera del ciclo.

✅ BIEN: Inicializar ANTES de entrar al ciclo
int suma = 0; // 1 sola vez ANTES del for for(int i = 1; i <= 5; i++) { suma += i; }

Todo contador o acumulador se pone en 0 arriba del bucle, se actualiza adentro y se muestra con printf abajo al terminar.

32 Buenas Prácticas al Programar con Bucles

1. Usá Siempre Llaves { } e Indentación

Dejá siempre una sangría (espacios a la izquierda) para las instrucciones que están adentro del while o del for. Así ves de inmediato qué se repite y qué está afuera.

2. Verificá la Primera y la Última Vuelta

Revisá siempre el valor inicial (i = 1 vs i = 0) y el operador de la condición (< vs <=) para asegurarte de que no falte ni sobre ninguna iteración.

3. No Modifiques i por Duplicado en un for

Si ya pusiste i++ en el paréntesis del for(int i = 1; i <= 5; i++), no vuelvas a escribir i++; adentro de las llaves { }.

4. Mostrá los Totales Afuera del Ciclo

Si solo te piden el resultado final de una suma o conteo, colocá el printf después de la llave de cierre } para que se imprima una sola vez al terminar.

33 Ejercicios de Aplicación (Parte 1)

Ejercicio 1: Del 1 al 10 con while y con for

Adaptá los ejemplos del apunte para mostrar por pantalla los números del 1 al 10 usando primero un bucle while y luego un bucle for. ¿Con qué valor de i frena cada ciclo?

💻 Ver solución paso a paso
#include <stdio.h> int main() { // Con while (frena cuando i llega a 11) int i = 1; while(i <= 10) { printf("%d\n", i); i++; } // Con for (itera 10 veces: i = 1 hasta i = 10) for(int j = 1; j <= 10; j++) { printf("%d\n", j); } return 0; }

Ejercicio 2: Tabla de Multiplicar del 7

Usando un bucle for que vaya desde i = 1 hasta i <= 10, mostrá los resultados de multiplicar 7 * i en cada vuelta.

💻 Ver solución paso a paso
#include <stdio.h> int main() { for(int i = 1; i <= 10; i++) { int resultado = 7 * i; printf("7 x %d = %d\n", i, resultado); } return 0; }

34 Ejercicio de Aplicación 3 (Integrador Final del 1er Bimestre)

Ejercicio 3: Función + Bucle for + Condicional

1) Creá una función int doble(int numero) igual a la del apunte.
2) En main(), usá un bucle for que pida 5 números enteros por teclado con scanf.
3) Por cada número ingresado, llamá a doble(numero) y, si el doble obtenido es mayor a 20, sumá 1 a un contador. Al final mostrá cuántos superaron 20.

💻 Ver solución completa
#include <stdio.h> int doble(int numero) { return numero * 2; } int main() { int n; int mayoresA20 = 0; for(int i = 1; i <= 5; i++) { printf("Ingrese numero %d: ", i); scanf("%d", &n); int resultado = doble(n); if(resultado > 20) { mayoresA20++; } } printf("Cantidad cuyo doble supera 20: %d\n", mayoresA20); return 0; }
