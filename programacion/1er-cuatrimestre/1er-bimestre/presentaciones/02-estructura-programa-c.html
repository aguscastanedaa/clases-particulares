Estructura Básica de un Programa en C

Anatomía completa del esqueleto de todo programa en C: bibliotecas, la puerta principal main() y return 0;

1. #include y Bibliotecas 2. stdio.h y stdbool.h 3. int main() (Puerta Principal) 4. Llaves { } y Punto y Coma ; 5. printf() y return 0;

02 El Problema: ¿Por Qué No Basta con Instrucciones Sueltas?

Si abrimos un archivo en blanco y escribimos únicamente printf("Hola mundo"); suelto sin nada alrededor, el compilador de C nos rechazará el archivo. ¿Por qué?

❌ Instrucción suelta sin estructura
// Archivo incompleto: printf("Hola mundo");

La computadora no sabe de dónde salió la función printf, dónde empieza el programa ni dónde termina.

Las 3 cosas que necesita saber la PC

1
¿Qué herramientas va a usar? (Bibliotecas con #include).
2
¿Por dónde debe empezar a ejecutar? (Puerta de entrada int main()).
3
¿Cuándo terminó todo bien? (Aviso de cierre return 0;).

03 La Estructura Básica de un Programa en C (Apunte)

Miremos el programa modelo exacto que presenta la Sección 2 de nuestro apunte teórico:

hola_mundo.c (Sección 2 del Apunte) Esqueleto Base
#include <stdio.h> int main() { printf("Hola mundo"); return 0; }
Salida por Pantalla
Hola mundo

🔍 Observá: Aunque parezcan varias líneas para mostrar un solo mensaje, estas 8 líneas forman la plantilla universal que vamos a usar en absolutamente todos los programas de la materia.

04 Funcionamiento Interno: Del Archivo .c a la Pantalla

¿Qué ocurre internamente desde que escribimos este código hasta que vemos Hola mundo en el monitor?

1. Código Fuente (.c)

Escribimos nuestro programa en un archivo de texto terminado en .c (por ejemplo, programa.c).

2. Compilación

El compilador revisa que no falte ningún ; ni ninguna llave } y traduce todo a lenguaje máquina.

3. Ejecución

El sistema operativo abre la puerta int main(), ejecuta las instrucciones de adentro y muestra el resultado.

💡 Por eso es tan importante conocer cada pieza: Si te falta una sola parte del esqueleto, el paso 2 (Compilación) te avisará con un error antes de poder ejecutar.

05 Las 4 Zonas del Esqueleto de un Programa en C

zonas_del_programa.c 4 Zonas
// ZONA 1: Bibliotecas #include <stdio.h> // ZONA 2: Puerta de entrada int main() { // ZONA 3: Instrucciones del programa printf("Hola mundo"); // ZONA 4: Cierre exitoso return 0; }
1
Zona 1 (#include): Incorpora las bibliotecas de funciones que vamos a necesitar.
2
Zona 2 (int main()): Marca el punto de entrada donde arranca el programa.
3
Zona 3 (Entre { y }): Tus instrucciones paso a paso (variables, cuentas, printf).
4
Zona 4 (return 0;): Indica que el programa finalizó correctamente.

06 Pieza 1: ¿Qué es #include y Qué es una Biblioteca?

Leamos la definición exacta de nuestro apunte teórico en la Página 2:

📘 Definición del Apunte

¿Qué es #include?
Permite incorporar bibliotecas al programa.
Las bibliotecas contienen funciones que ya fueron creadas por otros programadores.

🧰 Analogía de la Caja de Herramientas

Imaginá que vas a armar un mueble. En vez de fabricar vos mismo un destornillador desde cero fundiendo metal, traés una caja de herramientas ya fabricada. Eso hace #include: trae herramientas listas para usar.

🔍 Desglose de #include <stdio.h>

  • #include: Orden de "incluir / incorporar" antes de compilar.
  • < >: Signos menor y mayor que encierran el nombre de la biblioteca estándar.
  • .h: Extensión de archivo de cabecera (header).

07 Primera Biblioteca del Apunte: <stdio.h>

La biblioteca que vas a escribir en la primera línea de prácticamente todos tus programas es <stdio.h>:

Biblioteca de Entrada y Salida Del Apunte
#include <stdio.h>

¿Qué permite utilizar según el apunte?

  • printf() → Para mostrar mensajes y resultados por pantalla (salida / output).
  • scanf() → Para ingresar datos desde el teclado (entrada / input, que veremos en la Unidad 05).

¿De dónde sale el nombre stdio.h?

No es una palabra al azar, es una abreviatura en inglés:

• std = Standard (Estándar)
• i = Input (Entrada)
• o = Output (Salida)
• .h = Header (Cabecera)

08 Segunda Biblioteca del Apunte: <stdbool.h>

El apunte también nos presenta una segunda biblioteca fundamental cuando trabajamos con valores de verdadero o falso:

Biblioteca de Valores Booleanos (Lógicos) Del Apunte
#include <stdbool.h>

¿Qué permite utilizar según el apunte?

  • bool → El tipo de dato para variables lógicas.
  • true → El valor lógico verdadero.
  • false → El valor lógico falso.

¿Podemos poner varios #include juntos?

¡Sí! Cuando un programa necesita ambas cajas de herramientas, se colocan una debajo de la otra arriba de todo:

#include <stdio.h> #include <stdbool.h>

09 Pieza 2: ¿Qué es int main()? (La Puerta Principal)

Debajo de los #include siempre aparece int main(). Veamos cómo lo explica el apunte:

📘 Definición del Apunte

¿Qué es main()?
La función main es el punto de entrada del programa.
Cuando ejecutamos un programa, la primera función que se ejecuta es: int main().

🚪 Analogía del Apunte: La Puerta Principal

"Podemos pensarla como: La puerta principal del programa. Todo comienza ahí."

int

Indica que al terminar, main devolverá un número entero (el 0 del return 0;).

main

Palabra en inglés que significa "principal". Debe ir siempre en minúsculas.

()

Los paréntesis identifican a main como una función.

10 Pieza 3: Las Llaves { } (El Cuerpo del Programa)

Inmediatamente después de int main() se abre una llave { y al final del programa se cierra con }:

bloque_main.c Inicio y Fin
int main() { // <-- Llave de APERTURA (empieza el bloque) printf("Hola mundo"); return 0; } // <-- Llave de CIERRE (termina el bloque)

🏠 Analogía de las Paredes

Si int main() es la puerta principal de la casa, las llaves { y } son las paredes que encierran la habitación principal.

Regla inquebrantable: Toda llave que se abre { tiene que tener obligatoriamente su llave pareja que la cierra }.

11 Pieza 4: printf("Hola mundo");

Adentro de las llaves de main() encontramos nuestra primera orden visible en pantalla:

Mostrar texto en pantalla Salida (Output)
printf("Hola mundo");
1
printf: Es la función (traída desde <stdio.h>) que imprime información por pantalla.
2
( ... ) Paréntesis: Adentro de los paréntesis le entregamos a printf qué queremos mostrar.
3
"Hola mundo" Comillas dobles: Todo texto o frase literal en C debe ir encerrado entre comillas dobles " ".
4
; Punto y coma: Indica el final de la orden.

12 El Punto y Coma ;: ¿Cuándo Va y Cuándo NO Va?

Una duda muy común al empezar es: "¿Por qué algunas líneas llevan punto y coma ; al final y otras no?"

✅ SÍ llevan punto y coma ;

Todas las instrucciones o acciones que ejecuta el programa adentro de las llaves:

int numero = 5; printf("Hola mundo"); return 0;

🚫 NO llevan punto y coma ;

Las directivas #include, el encabezado int main() y las llaves { }:

#include <stdio.h> // SIN ; int main() // SIN ; { // SIN ; } // SIN ;

💡 Regla práctica: Si es una orden suelta adentro del bloque (declarar una variable, hacer una cuenta, llamar a printf o return 0), termina con ;. Si abre un bloque con { o empieza con #, no lleva ;.

13 Pieza 5: ¿Qué Significa return 0;? (Apunte)

En la última línea antes de cerrar la llave } siempre escribimos return 0;. Veamos la explicación del apunte:

📘 Definición del Apunte

¿Qué significa return 0?
Indica que el programa terminó correctamente.
Por ahora podemos pensar: Todo programa en C termina con return 0;

¿A quién le devuelve ese 0?

Se lo devuelve al sistema operativo (Windows o Linux). Para el sistema operativo, recibir un 0 significa: "Misión cumplida, hubo 0 errores".

⚠️ ¿Qué pasa después de return 0;?

return 0; finaliza inmediatamente la función main(). Por eso siempre debe ser la última instrucción antes de la llave de cierre }.

14 Radiografía Completa Línea por Línea

Repasemos de punta a punta qué función cumple cada una de las líneas del programa básico:

Línea Código en C ¿Qué significa y para qué está?
1 #include <stdio.h> Incorpora la biblioteca que nos permite usar printf() y scanf().
2 int main() Puerta principal del programa: todo comienza a ejecutarse acá.
3 { Abre el bloque de instrucciones de main.
4 printf("Hola mundo"); Muestra el texto Hola mundo en la pantalla y termina con ;.
5 return 0; Indica que el programa terminó correctamente.
6 } Cierra el bloque de la función main.

15 Un Detalle Fundamental: El Salto de Línea \n

¿Qué pasa si ponemos dos printf seguidos sin nada especial adentro del texto? ¡Mirá la diferencia!

Sin \n (Sale todo pegado en un renglón)

printf("Hola"); printf("Mundo");
Salida en Pantalla
HolaMundo

Como la computadora no supone nada, printf no baja de renglón sola.

Con \n (Baja al renglón siguiente)

printf("Hola\n"); printf("Mundo\n");
Salida en Pantalla
Hola Mundo

El símbolo \n (barra invertida + n) significa nueva línea (como apretar Enter).

21 Ejemplo Nivel 4: Cómo Armar un Programa Completo desde Hoja en Blanco

Cuando estás frente a una hoja en blanco en un examen o trabajo práctico, ¿en qué orden conviene escribir el código para no olvidarte ninguna llave ni ningún punto y coma?

Paso 1: La Biblioteca

#include <stdio.h>

Empezá siempre trayendo <stdio.h> arriba de todo.

Paso 2: El Esqueleto Vacío

#include <stdio.h> int main() { return 0; }

Abrí y cerrá { } con return 0; adentro antes de programar nada más.

Paso 3: Rellenar el Interior

#include <stdio.h> int main() { // Tus instrucciones aca return 0; }

Escribí tus variables y printf arriba del return 0;.

23 Error Frecuente #1: Olvidar el Punto y Coma ;

Es el error número 1 de todo programador en C. Mirá qué ocurre si omitís el ; al final de printf:

❌ Incorrecto: Falta el ; después de printf
#include <stdio.h> int main() { printf("Hola mundo") return 0; // ... error: expected ';' before 'return' }

El compilador te dirá: error: expected ';' before 'return' porque recién se da cuenta de que faltaba el ; cuando choca con la palabra return de abajo.

✅ Correcto: Punto y coma al final de cada instrucción
#include <stdio.h> int main() { printf("Hola mundo"); return 0; }

Tanto printf("Hola mundo"); como return 0; llevan su punto y coma obligatorio.

24 Error Frecuente #2: Olvidar la Llave de Cierre }

Si abrís el cuerpo de main() con { pero te olvidás de cerrarlo al final del archivo con }:

❌ Incorrecto: Llave abierta sin su cierre
#include <stdio.h> int main() { printf("Hola mundo"); return 0; // ... Falta la llave } al final del archivo

El compilador llega al final del archivo esperando encontrar la pared de cierre y arroja: error: expected '}' at end of input.

✅ Correcto: Toda llave { que abre tiene su } que cierra
#include <stdio.h> int main() { printf("Hola mundo"); return 0; }

Tip: apenas escribas {, apretá Enter y escribí inmediatamente la } de cierre para no olvidarla nunca.

25 Error Frecuente #3: Escribir Main o Printf con Mayúscula

El lenguaje C es sensible a mayúsculas y minúsculas (en inglés, case-sensitive). Para C, la letra m y la letra M son dos símbolos totalmente distintos:

❌ Incorrecto: Palabras clave con mayúscula inicial
// Mal: Int, Main, Printf y Return no existen Int Main() { Printf("Hola mundo"); Return 0; // ... }

A veces el corrector del celular o de Word pone la primera letra en mayúscula automáticamente. ¡En C eso rompe el programa!

✅ Correcto: Palabras reservadas de C siempre en minúscula
int main() { printf("Hola mundo"); return 0; }

#include, int, main, printf, scanf, bool, true, false y return van siempre en minúscula.

26 Error Frecuente #4: Escribir Después de return 0;

¿Qué pasa si ponemos un printf debajo de return 0;?

❌ Incorrecto: Código inalcanzable debajo de return 0;
#include <stdio.h> int main() { return 0; printf("Hola mundo"); // ¡Nunca se ejecuta! }

Como return 0; significa "terminar el programa ahora mismo", la computadora se despide en la línea 5 y jamás llega a ejecutar el printf de la línea 6.

✅ Correcto: return 0; es el último paso antes de }
#include <stdio.h> int main() { printf("Hola mundo"); return 0; }

Primero ejecutamos todas nuestras instrucciones y recién al final cerramos con return 0;.

27 Error Frecuente #5: Usar printf sin #include <stdio.h>

¿Qué pasa si queremos usar printf() o bool sin haber puesto su #include correspondiente arriba de todo?

❌ Sin la biblioteca correspondiente
// Falta #include <stdbool.h> int main() { bool activo = true; return 0; // ... }

El compilador dirá unknown type name 'bool' porque nadie le incorporó la biblioteca donde existe bool.

Tabla Rápida de Bibliotecas del Apunte

Si en tu programa usás... Arriba de todo debés poner...
printf() o scanf() #include <stdio.h>
bool, true o false #include <stdbool.h>

32 Las 3 Preguntas del Apunte que Siempre Toman

1. ¿Qué es #include?

Permite incorporar bibliotecas al programa. Las bibliotecas contienen funciones que ya fueron creadas por otros programadores (ej: stdio.h y stdbool.h).

2. ¿Qué es main()?

Es el punto de entrada del programa. La primera función que se ejecuta al arrancar: la puerta principal donde todo comienza.

3. ¿Qué es return 0;?

Indica que el programa terminó correctamente. Todo programa en C termina con return 0; antes de cerrar }.
