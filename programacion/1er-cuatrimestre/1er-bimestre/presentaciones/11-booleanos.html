02 El Problema: ¿Cómo Recordamos una Respuesta Lógica?

Imaginá que en tres partes distintas de tu programa necesitás saber si un alumno aprobó (sacó 6 o más Y tuvo al menos 75% de asistencia). Si no guardamos esa respuesta en ningún lado, tenemos que repetir toda la fórmula una y otra vez:

⚠️ Repitiendo la condición en todos lados
if(nota >= 6 && asistencia >= 75) { printf("Felicitaciones\n"); } // Más abajo en el mismo programa: if(nota >= 6 && asistencia >= 75) { printf("Se emite certificado\n"); }

Si mañana cambia el reglamento a nota 7, tenés que buscar y corregir todas las líneas donde repetiste la condición.

✅ Guardando el resultado en una variable bool
bool aprobado = (nota >= 6 && asistencia >= 75); if(aprobado) { printf("Felicitaciones\n"); } if(aprobado) { printf("Se emite certificado\n"); }

Calculamos la respuesta una sola vez, la guardamos en la cajita aprobado y la consultamos cuantas veces queramos.

03 Definición del Apunte: ¿Qué son los Booleanos?

📖 Definición del Apunte (Secciones 4 y 11)

11. BOOLEANOS — Definición: Representan valores lógicos. Solo existen dos posibilidades:
1. True (Verdadero)   |   2. False (Falso)
Ejemplo del apunte: bool aprobado = true;

En palabras sencillas

Mientras que en una variable int pueden entrar millones de números distintos (-5, 0, 18, 4500), una variable bool es una cajita especial donde solo caben dos valores posibles: sí o no, verdadero o falso.

💡 Analogía cotidiana: La tecla de luz

Pensá en el interruptor de luz de tu habitación: no tiene posiciones intermedias. O está ENCENDIDO (true) o está APAGADO (false). Una moneda al caer también es booleana: cara o ceca.

04 ¿Por Qué se Llaman Booleanos y Qué Hace <stdbool.h>?

🎩 El origen del nombre

Se llaman booleanos en honor a George Boole (1815–1864), un matemático inglés que inventó el Álgebra de Boole: un sistema donde toda la lógica humana se reduce a dos valores: Verdadero (1) y Falso (0), la base de todas las computadoras modernas.

📚 La biblioteca <stdbool.h> (Sección 2)

Tal como vimos en la Sección 2 del apunte, para poder usar booleanos en C debemos incluir arriba del todo:
#include <stdbool.h>
Esta biblioteca de C99 incorpora las tres palabras clave:
• bool  • true  • false

05 Funcionamiento Interno: ¿Qué son true y false para C?

En el interior de la memoria de la computadora no existen las palabras en inglés true ni false; todo se guarda con números. ¿Cómo representa el lenguaje C la verdad internamente?

Palabra en C Significado Lógico Valor Interno en Memoria Regla general de C al evaluar una condición
false Falso (Apagado / No) 0 El número 0 es el único valor que C considera FALSO.
true Verdadero (Encendido / Sí) 1 El 1 (y cualquier número distinto de cero) se considera VERDADERO.

🔍 Dato curioso: Si a una variable de tipo bool le asignás cualquier número distinto de cero (por ejemplo, bool x = 25;), el tipo bool de C99 lo convierte automáticamente en un 1 (true). Y si le asignás 0, guarda 0 (false).

06 Representación en Memoria RAM de una Variable bool

Cuando declaramos dos variables booleanas, en la memoria RAM se reservan dos pequeñas cajitas (de 1 byte cada una) que guardan un 1 o un 0:

memoria_bool.c Declaración
bool aprobado = true; bool tieneDeuda = false;
Cajita en RAM (true)
aprobado bool
1
Cajita en RAM (false)
tieneDeuda bool
0

💡 Por qué usamos true y false en vez de 1 y 0: Aunque para la computadora true sea un 1, para los seres humanos leer aprobado = true; deja clarísimo que se trata de un estado lógico y no de una nota numérica igual a 1.

09 ¿Cómo se Muestra un Booleano con printf()?

En lenguaje C no existe un especificador especial (como %b) para imprimir las palabras "true" o "false" automáticamente. Tenemos dos formas de mostrarlo:

Opción 1: Imprimir su número interno con %d

bool aprobado = true; bool libre = false; printf("Aprobado: %d\n", aprobado); printf("Libre: %d\n", libre);
Aprobado: 1 Libre: 0

Opción 2: Mostrar un mensaje claro con if / else

if(aprobado) { printf("Estado: Verdadero (Si)\n"); } else { printf("Estado: Falso (No)\n"); }

Para el usuario final del programa es mucho más amigable leer "Si" o "Aprobado" que ver un 1.

10 Guardar el Resultado de una Comparación en un bool

No solo podemos escribir true o false a mano: también podemos hacer que C evalúe una comparación y guarde automáticamente el resultado adentro de una variable bool:

comparacion_en_bool.c Concepto Clave
int edad = 20; // 1ro: C evalúa la pregunta (edad >= 18) -> da true (1) // 2do: El signo = guarda ese true adentro de la variable esMayor bool esMayor = (edad >= 18);
1
No confundas los dos signos: El >= de la derecha es una comparación (hace la pregunta), mientras que el = de la izquierda es la asignación (guarda la respuesta en esMayor).
2
¿Por qué ponemos paréntesis en (edad >= 18)?: Aunque C resuelve primero el >= antes que el =, rodear la comparación con paréntesis hace que la línea sea comodísima de leer a simple vista.

11 Guardar Condiciones con &&, || y ! en un bool

Esta técnica brilla todavía más cuando la combinamos con los operadores lógicos de la Unidad 10. Podemos resumir una condición larga en un nombre corto y descriptivo:

condiciones_compuestas_bool.c Uniendo Unidad 10 + Unidad 11
#include <stdio.h> #include <stdbool.h> int main() { int edad = 22; int categoria = 7; bool esMayor = (edad >= 18); bool categoriaEspecial = (categoria == 2 || categoria == 7); bool recibeBeneficio = (esMayor && categoriaEspecial); if(recibeBeneficio) { printf("Beneficio otorgado\n"); } return 0; }

✨ Mirá qué limpio queda: En vez de un if gigante lleno de símbolos, dividimos el pensamiento en pequeños pasos con nombre propio (esMayor, categoriaEspecial y recibeBeneficio).

12 Uso Elegante en Condicionales: if(aprobado)

Cuando evaluamos una variable booleana en un if, ¿hace falta escribir == true? ¡No! Mirá la diferencia:

⚠️ Redundante (repetitivo)
bool aprobado = true; if(aprobado == true) { printf("Aprobo\n"); }

Funciona, pero es redundante: como aprobado ya vale true, hacer true == true vuelve a dar true. Es como preguntar "¿Es verdad que es verdad que aprobó?".

✅ Elegante y directo
bool aprobado = true; if(aprobado) { printf("Aprobo\n"); }

El if solo necesita que lo que esté adentro de sus paréntesis valga true (1) o false (0). Como aprobado ya es un booleano, lo colocamos directamente.

13 Preguntar si un Booleano es Falso: if(!aprobado)

¿Y si queremos entrar al if justamente cuando la variable booleana es falsa? Usamos el operador NOT (!) que aprendimos en la Unidad 10:

⚠️ Comparando contra false
bool aprobado = false; if(aprobado == false) { printf("Debe rendir recuperatorio\n"); }

Aunque compila y funciona, escribir == false es más largo y menos natural que usar el operador de negación.

✅ Forma profesional con !
bool aprobado = false; if(!aprobado) { printf("Debe rendir recuperatorio\n"); }

Si aprobado es false (0), entonces !aprobado se evalúa como !false → true (1) y entra al if. Se lee: "Si NO está aprobado...".

14 Cambiar o Invertir el Valor de un Booleano

Como cualquier variable en C, un bool puede cambiar de valor mientras corre el programa. Incluso podemos invertir su estado actual (como apretar un botón de encendido/apagado) haciendo luz = !luz;:

interruptor.c Toggle / Inversión
#include <stdio.h> #include <stdbool.h> int main() { bool luzEncendida = false; printf("Inicio: %d\n", luzEncendida); // Apretamos la tecla por 1ra vez: luzEncendida = !luzEncendida; printf("1er clic: %d\n", luzEncendida); // Apretamos la tecla por 2da vez: luzEncendida = !luzEncendida; printf("2do clic: %d\n", luzEncendida); return 0; }
Consola / Output
Inicio: 0 1er clic: 1 2do clic: 0

🔄 ¿Cómo funciona luzEncendida = !luzEncendida;?:
Primero toma el valor actual de la derecha, lo invierte con ! (de 0 pasa a 1, o de 1 pasa a 0) y lo guarda de nuevo en la variable.

15 Concepto Fundamental: Bandera Lógica (Flag)

🚩 ¿Qué es una Bandera (Flag) en Programación?

Llamamos bandera (o flag en inglés) a una variable booleana que usamos como señal o testigo para recordar si ocurrió o no un evento importante durante la ejecución del programa.

📫 Analogía 1: El buzón de cartas

Los buzones clásicos tienen una banderita roja al costado:
• A la mañana está baja (false).
• Cuando pasa el cartero y deja una carta, levanta la bandera (true).
• Más tarde vos mirás desde la ventana: si la bandera está levantada, sabés que llegó correo sin tener que ir a revisar adentro.

🎮 Analogía 2: La llave del videojuego

Al empezar el nivel, bool tieneLlave = false;.
Si en algún momento el jugador abre el cofre, el programa cambia tieneLlave = true;.
Media hora después, al tocar la puerta final, el juego solo pregunta if(tieneLlave).

16 El Ciclo de Vida de una Bandera en 3 Pasos

Siempre que uses una bandera lógica en un programa (hoy con condicionales y muy pronto en la Unidad 13 con bucles), vas a seguir estos tres pasos:

1
Paso 1 — Inicializar la bandera (estado por defecto):
Antes de empezar los chequeos, le damos su valor inicial conocido: por ejemplo, bool hayError = false; (suponemos que al principio está todo bien).
2
Paso 2 — Activar la bandera si ocurre el evento:
Si detectamos algún problema en un if, levantamos la bandera: hayError = true;.
3
Paso 3 — Consultar la bandera al final para decidir:
Al terminar las verificaciones preguntamos if(!hayError) para continuar solo si ningún control levantó la bandera.

17 ¿Cómo Pedimos un Dato Booleano con scanf()?

Como scanf no tiene un formato directo para leer la palabra "true", la forma más segura y sencilla es pedirle al usuario que ingrese un número entero (1 para Sí, 0 para No) en una variable int y guardarlo en nuestro bool:

lectura_booleano.c Patrón Seguro con scanf
#include <stdio.h> #include <stdbool.h> int main() { int respuesta; printf("¿Tiene carnet de socio? (1 = Si, 0 = No): "); scanf("%d", &respuesta); // Convertimos la respuesta numérica en una variable booleana: bool esSocio = (respuesta == 1); if(esSocio) { printf("Ingresa gratis a la pileta\n"); } else { printf("Debe abonar la entrada\n"); } return 0; }

20 Ejemplo Nivel 4: Razonamiento Paso a Paso con Bandera Testigo

El problema a resolver: Queremos validar una extracción de dinero en un cajero. El cliente ingresa cuánto quiere retirar, pero pueden ocurrir varios errores independientes (monto negativo/cero, monto que no es múltiplo de 1000, o saldo insuficiente). Queremos mostrar todos los errores que tenga y solo entregar los billetes si no hubo ningún error.

1
Creamos nuestra bandera testigo: Declaramos bool operacionValida = true; antes de empezar a revisar.
2
Hacemos cada chequeo por separado: Si falla el monto mínimo, avisamos y bajamos la bandera (operacionValida = false;). Si no es múltiplo de 1000, avisamos y bajamos la bandera. Si supera el saldo, avisamos y bajamos la bandera.
3
Decisión final con la bandera: Al final solo preguntamos if(operacionValida). Si sigue en true, descontamos el saldo.

21 Ejemplo Nivel 4: Código Completo con Bandera operacionValida

nivel4_bandera_cajero.c Nivel 4 • Bandera Testigo
#include <stdio.h> #include <stdbool.h> int main() { int saldo = 15000; int retiro = 4000; bool operacionValida = true; if(retiro <= 0) { printf("Error: monto debe ser positivo\n"); operacionValida = false; } if(retiro % 1000 != 0) { printf("Error: solo billetes de 1000\n"); operacionValida = false; } if(retiro > saldo) { printf("Error: saldo insuficiente\n"); operacionValida = false; } if(operacionValida) { saldo -= retiro; printf("Retiro exitoso. Saldo: %d\n", saldo); } return 0; }
Paso Condición evaluada operacionValida
Inicio retiro = 4000 true (1)
Chequeo 1 4000 <= 0 (Falso) sigue true (1)
Chequeo 2 4000 % 1000 != 0 (Falso) sigue true (1)
Chequeo 3 4000 > 15000 (Falso) sigue true (1)
Final if(operacionValida) Descuenta → 11000
Consola / Output
Retiro exitoso. Saldo: 11000

22 Error Frecuente #1: Olvidar #include <stdbool.h>

A diferencia de int, float o char (que vienen activados de fábrica), en C99 y C11 las palabras bool, true y false requieren incluir su biblioteca:

❌ Sin incluir <stdbool.h>
#include <stdio.h> int main() { bool aprobado = true; return 0; }

Error del compilador:
error: unknown type name 'bool'
error: 'true' undeclared

✅ Incluyendo <stdbool.h> arriba
#include <stdio.h> #include <stdbool.h> int main() { bool aprobado = true; return 0; }

Con #include <stdbool.h> en el encabezado, el compilador reconoce bool, true y false sin ningún problema.

23 Error Frecuente #2: Escribir True o False con Mayúscula en C

En los apuntes teóricos o en otros lenguajes (como Python) suele escribirse "True" y "False" con mayúscula inicial al explicar el concepto. Pero el compilador de C distingue mayúsculas de minúsculas (es case-sensitive):

❌ Con mayúscula o entre comillas
bool a = True; // Error: 'True' no existe bool b = FALSE; // Error: 'FALSE' no existe bool c = "true"; // Error: "true" es texto

En C, ni True ni False son palabras clave válidas, y poner comillas "true" lo convierte en un texto en vez de un valor lógico.

✅ Todo en minúsculas y sin comillas
bool a = true; bool b = false;

Exactamente como en el ejemplo de código del apunte (bool aprobado = true;): tanto bool como true y false van siempre en minúsculas.

24 Error Frecuente #3: Escribir if(aprobado = true) con un Solo =

Esta es una de las razones más fuertes por las cuales los programadores prefieren escribir if(aprobado) en lugar de comparar contra true:

❌ Un solo = adentro del if (¡Destruye el dato!)
bool aprobado = false; // Quiso comparar con == pero puso un solo = if(aprobado = true) { printf("Aprobaste!\n"); }

¿Qué pasa acá?: El signo = sobreescribe la variable aprobado guardándole true a la fuerza, y hace que el if dé siempre Verdadero aunque el alumno hubiera desaprobado.

✅ Sin comparación: imposible equivocarse
bool aprobado = false; // Directo, limpio y a prueba de errores de tipeo: if(aprobado) { printf("Aprobaste!\n"); }

Al acostumbrarte a escribir siempre if(aprobado) y if(!aprobado), eliminás para siempre el riesgo de poner un = por accidente.

25 Error Frecuente #4: Usar %s en printf o scanf Directo en un bool

❌ Intentar imprimir un bool como texto %s
bool activo = true; // ¡ERROR! %s espera texto, no un bool: printf("%s\n", activo);

Como activo vale internamente el número 1, usar %s hace que el programa intente leer la dirección de memoria 1 y se cuelgue inmediatamente.

✅ Usar %d o un condicional
bool activo = true; // Para ver 1 o 0 usamos %d: printf("Valor numerico: %d\n", activo);

Recordá siempre: internamente un bool es un entero pequeño (1 o 0), por eso en printf se muestra con %d.

26 Buenas Prácticas: ¿Cómo Bautizar una Variable Booleana?

Un buen nombre de variable booleana se reconoce porque suena como una pregunta que se responde por Sí o por No, o como un estado claro:

Prefijo / Estilo Mal nombre (confuso) ❌ Buen nombre booleano ✅ Cómo se lee en el if(...)
Adjetivo / Estado bool nota; bool aprobado; if(aprobado) → "Si está aprobado..."
Prefijo es... bool edad; bool esMayor; if(esMayor) → "Si es mayor..."
Prefijo tiene... bool entrada; bool tieneEntrada; if(tieneEntrada) → "Si tiene entrada..."
Prefijo puede... bool voto; bool puedeVotar; if(puedeVotar) → "Si puede votar..."

💡 Evitá nombres negativos como bool noAprobado;: Si la llamás en negativo y después la negás con if(!noAprobado), tenés una doble negación ("si no es no aprobado") que marea a cualquiera. Llamala siempre en positivo: aprobado.

27 Resumen Comparativo: ¿Cuándo Uso int y Cuándo Uso bool?

🔢 Usá int cuando...

  • Guardás una cantidad para contar o calcular: edad (16), puntos (150), stock (40), año (2024).
  • Guardás un código con más de 2 opciones: categoría (1 a 10), día de la semana (1 a 7).
  • Necesitás sumar, restar, multiplicar o sacar el resto con %.

✅ Usá bool cuando...

  • El dato tiene estrictamente dos posibilidades (Verdadero/Falso, Sí/No, Encendido/Apagado).
  • Querés guardar el resultado de una comparación como (edad >= 18).
  • Necesitás una bandera lógica (flag) para recordar si se cumplió una condición o si hubo un error.

31 Ejercicio 3: Alarma Domiciliaria con Banderas

📝 Enunciado

Una alarma domiciliaria suena si el sistema está activado Y además se detecta movimiento en la puerta O en la ventana.
Declarar tres variables booleanas (bool alarmaActivada = true;, bool sensorPuerta = false;, bool sensorVentana = true;), calcular en una cuarta variable bool debeSonar si corresponde disparar la sirena y mostrar el resultado con if(debeSonar).

💻 Ver código solución completo
#include <stdio.h> #include <stdbool.h> int main() { bool alarmaActivada = true; bool sensorPuerta = false; bool sensorVentana = true; bool debeSonar = (alarmaActivada && (sensorPuerta || sensorVentana)); if(debeSonar) { printf("ALERTA: Sirena encendida!\n"); } else { printf("Casa en orden y sin alertas\n"); } return 0; }

32 Ejercicio 4: Compra Online con Bandera de Envío Gratis

📝 Enunciado

En una tienda online, el envío cuesta $2500, pero es gratis si la compra supera los $20000 O si el comprador tiene membresía VIP (ingresa 1 para Sí, 0 para No).
Pedir el monto de la compra y si es VIP, calcular una variable bool envioGratis, sumar el costo de envío solo cuando !envioGratis y mostrar el total a pagar.

💻 Ver código solución completo
#include <stdio.h> #include <stdbool.h> int main() { int monto, respuestaVip; printf("Ingrese el monto de la compra: "); scanf("%d", &monto); printf("Es miembro VIP? (1 = Si, 0 = No): "); scanf("%d", &respuestaVip); bool esVip = (respuestaVip == 1); bool envioGratis = (monto > 20000 || esVip); if(!envioGratis) { monto += 2500; printf("Se sumaron $2500 de envio.\n"); } else { printf("Tenes envio gratis!\n"); } printf("Total final a pagar: $%d\n", monto); return 0; }

33 Resumen de la Unidad 11 y Checklist

Ideas Clave que te Llevás Hoy

  • ¿Qué es un booleano?: Un tipo de dato lógico con solo 2 posibilidades: true y false.
  • Biblioteca obligatoria: #include <stdbool.h>.
  • En memoria RAM: false vale 0 y true vale 1.
  • Guardar comparaciones: bool esMayor = (edad >= 18);.
  • Condicional elegante: Usar if(aprobado) y if(!aprobado).
  • Bandera (Flag): Variable bool que recuerda un estado o suceso.
