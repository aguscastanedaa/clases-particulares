02 El Problema: ¿Qué Pasa Cuando Repetimos Código?

Hasta ahora escribimos todas nuestras instrucciones adentro de main(). Pero imaginá que en tres partes distintas del programa necesitamos calcular el doble de distintos números:

sin_funciones.c Todo amontonado en main
#include <stdio.h> int main() { int r1 = 5 * 2; int r2 = 12 * 2; int r3 = 30 * 2; printf("Resultados: %d, %d, %d\n", r1, r2, r3); return 0; }

¿Por qué esto se vuelve un problema en programas reales?

Si una tarea lleva 15 líneas de código y la necesitamos 10 veces, tendríamos que copiar y pegar 150 líneas adentro de main(). Si luego descubrimos un error en la fórmula, ¡habría que corregirlo en los 10 lugares! Las funciones resuelven esto: escribimos la receta una sola vez y la usamos cuantas veces queramos.

03 12. ¿Qué es una Función? (Definición del Apunte)

Definición del Apunte

Una función es un bloque de código que realiza una tarea específica.

En palabras simples

Una función es como una mini-máquina con nombre propio dentro de nuestro programa. Le damos un nombre claro (por ejemplo, doble, sumar o esMayor) y la entrenamos para hacer un único trabajo bien definido.

¡Ya venimos usando funciones!

En la Unidad 02 aprendimos que #include <stdio.h> nos trae funciones ya creadas por otros programadores, como printf() y scanf(), y que main() es la función principal. ¡Hoy vamos a crear nuestras propias funciones!

04 Ejemplo Cotidiano del Apunte: La Licuadora

Para entender cómo funciona una función por dentro, el apunte nos propone una analogía perfecta: pensá en una licuadora.

1. Ingredientes ➔ Parámetros

Es lo que metemos adentro de la licuadora para que trabaje (por ejemplo: banana y leche). En programación, son los datos de entrada que recibe la función entre paréntesis.

2. Proceso ➔ Código

Es el trabajo que hacen las cuchillas girando para transformar los ingredientes. En programación, son las instrucciones entre llaves { } que procesan o calculan.

3. Resultado ➔ return

Es el vaso de licuado listo que nos entrega al terminar. En programación, es el valor final que la función devuelve usando la palabra clave return.

🍌 Ingredientes (parámetros) ➔ ⚙️ Licuadora (código) ➔ 🥤 Licuado listo (return)

05 Modelo Mental: main() y sus Ayudantes

Recordemos de la Unidad 02 que todo programa en C comienza ejecutándose en int main() (la puerta principal). ¿Cómo se relaciona main() con las funciones que creamos?

1
main() es el Director de Orquesta: El programa arranca siempre en la primera línea de main(). Las demás funciones están "dormidas" esperando que alguien las llame.
2
El Llamado (Invocación): Cuando main() necesita hacer un cálculo específico, llama a una función ayudante por su nombre y le pasa los ingredientes (datos).
3
Pausa y Ejecución: main() se queda en pausa un instante mientras la función ayudante despierta, ejecuta su código interno y llega a su return.
4
Regreso con el Resultado: La función le entrega el resultado a main(), se apaga, y main() continúa ejecutando normalmente desde donde se había quedado.

06 Sintaxis General de una Función en C

Tal como muestra el apunte en la Sección 12, la estructura general para escribir (definir) una función en C es:

Plantilla de Sintaxis del Apunte Sección 12
tipo_retorno nombre(parametros) { codigo; }

La Cabecera (Firma)

La primera línea tipo_retorno nombre(parametros) presenta a la función: dice qué tipo de dato devuelve, cómo se llama y qué datos necesita recibir para trabajar. ¡Nunca lleva punto y coma al final de esta línea cuando abrimos llaves!

El Cuerpo de la Función

Todo lo que está encerrado entre la llave de apertura { y la llave de cierre } es el proceso: las instrucciones que se ejecutarán cada vez que llamemos a la función.

07 ¿Qué Significa tipo_retorno?

Explicación Textual del Apunte

"Tipo de retorno es el TIPO DE DATO que la función va a devolver (retornar), si quiero que devuelva un ENTERO, sería int."

Si la función devuelve... El tipo_retorno es... Ejemplo de cabecera Ejemplo de return

Un número con decimales float float mitad(float x) return 2.5;

08 El Ejemplo Central del Apunte: doble

En la página 1 de nuestro apunte vimos que la computadora no sabe qué significa "el doble de un número" a menos que le digamos que multiplique por 2. En la Sección 12, el apunte convierte esa idea en nuestra primera función:

Ejemplo del Apunte — Definición de la función doble Página 9
int doble(int numero) { return numero * 2; }

¿Cómo se lee esto en español?

"Creamos una función llamada doble que recibe como ingrediente un número entero llamado numero, lo multiplica por 2, y retorna ese resultado como un número entero (int)."

09 Partes de una Función (Desglose del Apunte)

Analicemos las 4 piezas exactas que señala el apunte sobre la función doble:

int doble( int numero ) { return numero * 2; }

1. Tipo de retorno: int

Indica que el resultado final que entregará la función al terminar será un número entero.

2. Nombre: doble

Es la etiqueta o identificador con el que vamos a llamar a esta función cuando la necesitemos.

3. Parámetro: numero (de tipo int)

Es la "cajita" receptora donde se guardará el número de entrada que le enviemos al llamarla.

4. Retorno: return numero * 2;

Calcula el doble del valor recibido en numero y lo devuelve como respuesta final.

10 Cómo Llamar a una Función (Página 9 y 10)

Escribir la función doble es como fabricar la licuadora: todavía está apagada. Para usarla adentro de main(), tenemos que llamarla (o invocarla):

Llamar una función (Apunte) Resultado: 10
int resultado = doble(5);

Explicación Textual del Apunte

"GUARDO en una variable de tipo int llamada resultado, al resultado que devuelve la función doble cuando le ingresa el valor 5. Esto sería hacer 5 * 2 ➔ 10."

Lado derecho del = (Primero)

Se ejecuta doble(5). El número 5 viaja a la función, se multiplica por 2 y la función retorna 10.

Lado izquierdo del = (Después)

Ese valor 10 retornado se guarda dentro de la cajita int resultado.

11 El Viaje del Dato Paso a Paso en Memoria RAM

Sigamos con lupa los 4 momentos exactos de int resultado = doble(5);:

1
Envío de entrada: En main() escribimos doble(5). El valor 5 sale de main() hacia la puerta de entrada de la función doble.
2
Copia en el parámetro: La función doble(int numero) crea su propia cajita temporal numero y guarda adentro el 5 (es decir, hace internamente numero = 5).
3
Proceso y return: Evalúa numero * 2 ➔ 5 * 2 ➔ 10. La orden return 10; envía el número 10 de vuelta hacia main().
4
Reemplazo y asignación: En main(), el llamado doble(5) se transforma en 10, quedando int resultado = 10;. ¡La cajita resultado ahora vale 10!

12 Ejemplo Nivel 1: Programa Completo con doble()

Unamos la definición de doble y su llamada dentro de un programa completo en C listo para compilar y ejecutar:

nivel1_doble.c Nivel 1 — Introductorio
#include <stdio.h> // 1. Definimos la función ANTES de main() int doble(int numero) { return numero * 2; } int main() { // 2. Llamamos a la función y guardamos lo que retorna int resultado = doble(5); // 3. Mostramos el valor guardado en resultado printf("Resultado: %d\n", resultado); return 0; }

13 El Poder de Reutilizar la Misma Función

Una vez definida doble(), podemos llamarla todas las veces que queramos, pasándole números fijos o incluso el contenido de otras variables:

#include <stdio.h> int doble(int numero) { return numero * 2; } int main() { int a = doble(5); int b = doble(12); int x = 7; int c = doble(x); printf("a=%d, b=%d, c=%d\n", a, b, c); return 0; }
Llamada en main() Valor que recibe numero Cálculo en doble Valor retornado Variable en main
doble(5) numero = 5 5 * 2 10 a = 10
doble(12) numero = 12 12 * 2 24 b = 24
doble(x) (con x = 7) numero = 7 7 * 2 14 c = 14

14 Parámetros vs Argumentos: ¿Cuál es la Diferencia?

En programación vas a escuchar ambos términos todo el tiempo. Aunque trabajan juntos, nombran dos momentos distintos:

📥 PARÁMETRO (En la Definición)

Es la variable declarada entre los paréntesis cuando escribimos la receta de la función. Es el "molde vacío" que espera recibir un dato.

// 'numero' es el PARÁMETRO int doble(int numero) { return numero * 2; }
🚀 ARGUMENTO (En la Llamada)

Es el valor concreto (por ejemplo 5) que le enviamos entre paréntesis cuando llamamos a la función para usarla.

// '5' es el ARGUMENTO int resultado = doble(5);

15 Funciones con Varios Parámetros: sumar(int a, int b)

¿Qué pasa si nuestra "licuadora" necesita dos o más ingredientes? Separamos cada parámetro con una coma (,), indicando siempre el tipo de dato de cada uno:

Función con 2 parámetros enteros Separados por coma
int sumar(int a, int b) { return a + b; }

Regla de Oro de los Parámetros

En la cabecera de la función, cada parámetro debe llevar su propio tipo de dato: se escribe (int a, int b). Escribir (int a, b) es un error de compilación en C.

Correspondencia por Orden

Al llamar sumar(4, 9), el primer argumento (4) se copia en el primer parámetro (a), y el segundo argumento (9) se copia en el segundo parámetro (b).

16 Ejemplo Nivel 2: sumar() con Datos del Usuario

nivel2_suma.c Nivel 2
#include <stdio.h> int sumar(int a, int b) { int r = a + b; return r; } int main() { int n1, n2, total; printf("Ingrese dos enteros: "); scanf("%d %d", &n1, &n2); total = sumar(n1, n2); printf("La suma es: %d\n", total); return 0; }
Interacción en Terminal
$ ./nivel2_suma Ingrese dos enteros: 15 25 La suma es: 40
Paso Dónde Estado de Variables
1. scanf main n1 = 15, n2 = 25
2. Llamada sumar a = 15, b = 25
3. Cálculo sumar r = 40 ➔ return 40
4. Regreso main total = 40

17 Funciones que Retornan float y bool

Las funciones no solo devuelven int. Podemos combinar lo aprendido en las Unidades 04 (Tipos de datos) y 11 (Booleanos):

1. Promedio con decimales (float)

float promedio(float x, float y) { return (x + y) / 2.0; }

Llamada: float prom = promedio(7.0, 8.0); ➔ guarda 7.5.

2. Función lógica (bool)

#include <stdbool.h> bool esPar(int numero) { return (numero % 2 == 0); }

Llamada: bool par = esPar(14); ➔ guarda true (porque 14 % 2 == 0).

💡 Truco profesional: Una función que devuelve bool se puede usar directamente adentro de la condición de un if: if (esPar(numero)) { printf("Es par"); }.

18 Funciones void: Cuando No Hay Valor de Retorno

En inglés, void significa "vacío" o "nada". Si queremos que una función realice una tarea (por ejemplo, mostrar un cartel o imprimir un reporte por pantalla) pero no necesitamos que devuelva ningún dato, ponemos void como tipo de retorno:

funciones_void.c Sin return de valor
#include <stdio.h> void mostrarBienvenida() { printf("=== SISTEMA DE ALUMNOS ===\n"); } void mostrarEdad(int edad) { printf("Edad registrada: %d anios\n", edad); } int main() { mostrarBienvenida(); mostrarEdad(16); return 0; }

Observá cómo se llaman en main(): van sueltas en su propia línea (mostrarEdad(16);), sin int resultado = ... adelante, porque no devuelven ningún valor para guardar.

19 Diferencia Crucial: return vs printf

Una de las dudas más frecuentes al empezar a programar es confundir return con printf(). ¡Hacen cosas totalmente distintas!

🔙 return (Para la MEMORIA)
  • Le entrega el resultado a quien llamó a la función (por ejemplo, a main).
  • NO muestra nada en la pantalla negra de la consola.
  • El valor devuelto se puede guardar en una variable o seguir usando en cuentas: int r = doble(5) + 1;.
🖥️ printf (Para la PANTALLA)
  • Dibuja texto o números en el monitor para que los ojos del humano los lean.
  • NO le devuelve el resultado numérico a la variable de main.
  • Una vez impreso en pantalla, el programa no puede "agarrar" ese texto para multiplicarlo o sumarlo.

20 ¿Por Qué return Permite Seguir Calculando?

Mirá por qué en el apunte la función doble usa return numero * 2; y no printf:

encadenar_calculos.c Ventaja de return
#include <stdio.h> int doble(int numero) { return numero * 2; } int main() { int resultado = doble(5); // Guarda 10 int masDiez = resultado + 10; // Usa ese 10: 10 + 10 = 20 int cuadruple = doble(doble(3)); // doble(3) da 6 -> doble(6) da 12 printf("resultado = %d\n", resultado); printf("masDiez = %d\n", masDiez); printf("cuadruple = %d\n", cuadruple); return 0; }

✅ Como doble() retorna el número, en main() podemos guardarlo, sumarle 10, compararlo en un if o incluso metérselo adentro de otro doble().

21 ¿Qué Ocurre en el Instante en que se Ejecuta return?

Regla de Ejecución

La instrucción return cumple dos tareas al mismo tiempo: 1) entrega el valor de respuesta y 2) finaliza la función inmediatamente. Cualquier línea escrita debajo de un return que ya se ejecutó jamás llegará a correrse.

Código Inalcanzable (Código Muerto)

int doble(int numero) { return numero * 2; // ¡Esta línea NUNCA se ejecuta! printf("Calculado\n"); }

Múltiples return en un if / else

int mayor(int a, int b) { if (a >= b) { return a; // Sale por acá } else { return b; // O sale por acá } }

22 Ámbito (Scope) Local: Las Cajitas son Privadas

En la Unidad 03 vimos que cada variable es una "cajita" en memoria. Cuando trabajamos con funciones, cada función tiene su propia habitación privada de cajitas:

Habitación de main()

  • Las variables creadas dentro de main() (como resultado) solo existen dentro de main().
  • La función doble() no puede tocar ni ver directamente la cajita resultado de main().

Habitación de doble()

  • El parámetro numero y cualquier variable declarada dentro de doble() son variables locales.
  • Nacen cuando llamamos a doble() y se destruyen automáticamente apenas ejecuta su return.

🛡️ ¿Por qué esto es buenísimo? Porque podemos usar el nombre numero o resultado en 5 funciones distintas sin que se mezclen ni se pisen los valores entre sí.

23 Paso por Valor: Se Envía una Copia del Dato

Cuando llamamos a una función pasándole una variable de main(), C envía una fotocopia del valor, no la cajita original. Mirá qué pasa si modificamos el parámetro adentro de la función:

#include <stdio.h> int doble(int numero) { numero = numero * 2; return numero; } int main() { int original = 5; int res = doble(original); printf("original = %d\n", original); printf("res = %d\n", res); return 0; }
Momento original (en main) numero (en doble)
Antes de llamar 5 No existe
Al entrar a doble 5 5 (copia)
numero = numero * 2 5 (intacto) 10
Después del return 5 (y res = 10) Destruida

En main(), original sigue valiendo 5 porque doble() trabajó sobre su propia copia local numero.

24 ¿Dónde Escribimos las Funciones en el Archivo .c?

El compilador de C lee nuestro código de arriba hacia abajo. Por eso existen dos formas válidas de organizar un programa con funciones:

Opción A (Recomendada): Arriba de main()

#include <stdio.h> int doble(int numero) { return numero * 2; } int main() { int resultado = doble(5); printf("%d\n", resultado); return 0; }

Cuando el compilador llega a main(), ya conoce a doble().

Opción B: Con Prototipo arriba y código abajo

#include <stdio.h> int doble(int numero); // Prototipo (aviso) int main() { int resultado = doble(5); printf("%d\n", resultado); return 0; } int doble(int numero) { return numero * 2; }

El prototipo (terminado en ;) avisa que la función está definida más abajo.

25 Ejemplo Nivel 3: Funciones + Divisibilidad e if/else

En la Sección 6 del apunte vimos que si numero % divisor == 0, entonces numero es divisible por divisor. Llevemos esa regla y los condicionales de la Sección 9 adentro de funciones:

nivel3_divisible_y_mayor.c Nivel 3 — Intermedio
#include <stdio.h> #include <stdbool.h> bool esDivisible(int numero, int divisor) { if (numero % divisor == 0) { return true; } else { return false; } } int calcularMayor(int a, int b) { if (a > b) { return a; } else { return b; } } int main() { int mayor = calcularMayor(14, 20); printf("El mayor entre 14 y 20 es: %d\n", mayor); if (esDivisible(14, 7)) { printf("14 es divisible por 7\n"); } return 0; }

27 Ejemplo Nivel 4: Cómo Pensar un Problema con Funciones

Enunciado del Problema

Un cine cobra $4000 la entrada general, pero si la persona es menor de 18 años o tiene 65 años o más, recibe un descuento de $1500. Además, queremos comprar varias entradas del mismo tipo y saber el total a pagar. ¿Cómo lo dividimos en funciones?

1
Función 1 — bool tieneDescuento(int edad): Recibe la edad y usa el operador lógico OR (||) de la Sección 10: retorna true si edad < 18 || edad >= 65.
2
Función 2 — int calcularPrecioEntrada(int edad): Llama a tieneDescuento(edad); si es verdadero retorna 4000 - 1500 (2500), si no retorna 4000.
3
Función 3 — int calcularTotal(int precioUnitario, int cantidad): Multiplica el precio de cada entrada por la cantidad de entradas y retorna el total.

28 Ejemplo Nivel 4: Código Completo e Integrador

nivel4_cine.c Nivel 4 — Modular
#include <stdio.h> #include <stdbool.h> bool tieneDescuento(int edad) { return (edad < 18 || edad >= 65); } int calcularPrecioEntrada(int edad) { if (tieneDescuento(edad)) { return 4000 - 1500; } else { return 4000; } } int calcularTotal(int precio, int cantidad) { return precio * cantidad; } int main() { int edad = 16; int cant = 3; int unitario = calcularPrecioEntrada(edad); int total = calcularTotal(unitario, cant); printf("Precio unitario: $%d\n", unitario); printf("Total por %d entradas: $%d\n", cant, total); return 0; }
Salida en Consola
$ ./nivel4_cine Precio unitario: $2500 Total por 3 entradas: $7500

¿Viste cómo una función puede llamar a otra?

main() llamó a calcularPrecioEntrada(16), y esta a su vez llamó a tieneDescuento(16). Cada función es cortita, fácil de leer y hace una única responsabilidad.

29 Error Frecuente #1: Definir una Función Adentro de main()

En lenguaje C estándar, no existen funciones adentro de otras funciones. Todas las funciones son "hermanas" al mismo nivel:

❌ MAL: Función metida adentro de main
int main() { // ERROR: ¡No se puede definir acá adentro! // int doble(int numero) { ... } return 0; }

Adentro de main() solo se llaman las funciones, nunca se definen.

✅ BIEN: Definida afuera y llamada adentro
int doble(int numero) { return numero * 2; } int main() { int resultado = doble(5); return 0; }

doble() se define arriba de main(), y adentro de main() la llamamos.

30 Error Frecuente #2: Ignorar el Retorno o Poner Tipos al Llamar

❌ MAL: Llamar sin guardar y poner int al argumento
int main()
{
    // Error A: tirar el retorno a la basura
    doble(5);

    // Error B: poner el tipo 'int' al llamar
    int r = doble(int 5);
    return 0;
}

Si escribís doble(5); suelto, la función calcula el 10 pero como nadie lo recibe, ¡se pierde en el aire! Y al llamar nunca se escribe la palabra int adentro del paréntesis.

✅ BIEN: Guardar el retorno y pasar solo el valor
int doble(int numero) { return numero * 2; } int main() { int resultado = doble(5); printf("%d\n", resultado); return 0; }

El tipo int del parámetro va solo en la definición (arriba). En la llamada (abajo) pasamos directamente 5 y guardamos el retorno en resultado.

31 Error Frecuente #3: Prometer un Tipo y Olvidar el return

❌ MAL: Declarar int pero no retornar nada
int doble(int numero)
{
    int r = numero * 2;
    // ¡Olvidó escribir return r;!
}

Si la función promete devolver un int en su cabecera pero termina sin ejecutar return, la variable resultado en main() recibirá basura de memoria impredecible.

✅ BIEN: Toda función con tipo debe retornar ese tipo
int doble(int numero) { int r = numero * 2; return r; }

O en una sola línea directa como en el apunte: return numero * 2;.

32 Buenas Prácticas al Crear Funciones

1. Nombres con Verbos Claros

Como las funciones realizan acciones o cálculos, llamalas con nombres descriptivos: doble, sumar, calcularPromedio, esMayorDeEdad. Evitá nombres vagos como f1() o cosa().

2. Una Función = Una Sola Tarea

Respetá la definición del apunte: "realiza una tarea específica". Es mejor tener una función que calcule y otra que muestre, en vez de una función gigante que mezcle todo.

3. Preferí return para los Cálculos

Hacé que las funciones matemáticas (como doble o sumar) devuelvan el resultado con return, y dejá que main() decida cuándo mostrarlo con printf().

4. Usá Variables Locales y Parámetros

Pasá siempre los datos que la función necesita como parámetros entre paréntesis. Así la función es 100% independiente y fácil de probar.

34 Ejercicio de Aplicación 3 (Integrador con bool e if)

Ejercicio 3: ¿Promociona la Materia?

Para promocionar una materia, un estudiante debe tener ambos parciales con nota mayor o igual a 7 (recordá el operador && de la Sección 10).
1) Escribí una función bool promociona(int nota1, int nota2) que retorne true si cumple la condición, o false en caso contrario.
2) En main(), probala con las notas 8 y 9 mostrando "Promocionado" o "Debe rendir final".

💻 Ver solución completa
#include <stdio.h> #include <stdbool.h> bool promociona(int nota1, int nota2) { if (nota1 >= 7 && nota2 >= 7) { return true; } else { return false; } } int main() { bool estado = promociona(8, 9); if (estado == true) { printf("Promocionado\n"); } else { printf("Debe rendir final\n"); } return 0; }

35 Resumen de la Unidad 12 y Checklist

Conceptos Clave del Apunte

  • Función: Bloque de código que realiza una tarea específica.
  • Licuadora: Ingredientes ➔ parámetros; Proceso ➔ código; Resultado ➔ return.
  • Sintaxis: tipo_retorno nombre(parametros) { codigo; }.
  • Ejemplo del apunte: int doble(int numero) { return numero * 2; }.
  • Llamada: int resultado = doble(5); guarda 10 en resultado.
