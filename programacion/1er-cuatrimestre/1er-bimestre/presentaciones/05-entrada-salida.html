Entrada y Salida de Datos en C

Cómo hacer que el usuario interactúe con nuestro programa usando printf() y scanf()

02 El Problema: Programas "Sordos" con Valores Fijos

Hasta ahora, para guardar una edad en una variable la escribíamos fija adentro del código fuente:

edad_fija.c Sin interacción
#include <stdio.h> int main() { int edad = 16; // ¡Siempre vale 16! printf("Edad guardada: %d\n", edad); return 0; }

🤔 ¿Cuál es el problema? Si viene otra persona que tiene 18 años, este programa sigue diciendo 16. Un usuario común de un cajero automático o de un juego no puede abrir el código en C para cambiar un número: el programa tiene que preguntárselo por pantalla y leer lo que escriba en el teclado.

03 Definición: Entrada y Salida de Datos

📖 Definición del Apunte (Sección 5)

"Permiten que el usuario interactúe con el programa."

📤 Salida de datos (Output) → printf()

Es la información que viaja desde el programa hacia afuera (a la pantalla / monitor) para que el usuario la lea.

Analogía: Es cuando el programa "habla" y te muestra un mensaje o un resultado.

📥 Entrada de datos (Input) → scanf()

Es la información que viaja desde el usuario (el teclado) hacia adentro del programa para guardarse en una variable.

Analogía: Es cuando el programa "se queda en silencio escuchando" lo que tipeás.

📌 Recuerda de la Unidad 02: tanto printf() como scanf() viven adentro de la biblioteca #include <stdio.h> (Standard Input / Output).

04 1. printf(): Mostrar Información por Pantalla

📖 Apunte: "printf() → Muestra información por pantalla. (output)"

hola_mundo.c Del Apunte
#include <stdio.h> int main() { printf("Hola mundo"); return 0; }
Salida en Consola stdout
$ ./hola_mundo Hola mundo

Desglose pieza por pieza de printf("Hola mundo");

  • printf: Nombre de la función (significa print formatted, imprimir con formato).
  • ( ... ): Paréntesis donde entregamos lo que queremos mostrar.
  • "Hola mundo": Texto literal encerrado siempre entre comillas dobles " ".
  • ;: Punto y coma obligatorio al final de la orden.

05 El Salto de Línea \n: ¿Por qué se Pegan los Textos?

printf() NO baja de renglón automáticamente al terminar de escribir. Si ponés dos printf seguidos sin indicarle que baje de línea, ¡salen pegados en el mismo renglón!

❌ Sin \n (Sale todo pegado)
printf("Hola"); printf("Mundo");
$ ./programa HolaMundo
✅ Con \n (Cada uno en su renglón)
printf("Hola\n"); printf("Mundo\n");
$ ./programa Hola Mundo

💡 ¿Qué es \n? Viene de newline (nueva línea). Aunque se escribe con dos teclas (barra invertida \ + letra n adentro de las comillas), C lo interpreta como presionar Enter en la pantalla.

06 ¿Cómo Mostrar el Valor de una Variable con printf()?

Si escribimos printf("edad"); entre comillas, C imprime literalmente las 4 letras de la palabra edad, ¡no el número 16 que tiene adentro! Para mostrar el contenido de una caja necesitamos un especificador de formato (comodín con %):

mostrar_edad.c Con comodín %d
int edad = 16; printf("Tengo %d anios\n", edad);

¿Cómo funciona el reemplazo?

  1. Adentro de las comillas dejamos el "hueco" %d donde queremos que aparezca el número entero.
  2. Después de cerrar las comillas ponemos una coma ,.
  3. Escribimos el nombre de la variable (edad) cuyo valor rellenará ese hueco.

07 Los Especificadores del Apunte: %d, %f y %c

📖 Apunte (Sección 5): Cada tipo de dato tiene su propio símbolo con porcentaje (%):
%d → int  |  %f → float  |  %c → char

Especificador Tipo de Dato ¿Por qué lleva esa letra? Ejemplo en printf() Salida en Pantalla
%d int Decimal integer (entero en base 10) printf("Edad: %d", 16); Edad: 16
%f float Floating point (punto flotante) printf("Altura: %f", 1.75); Altura: 1.750000
%.2f float Float redondeado visualmente a 2 decimales printf("Altura: %.2f", 1.75); Altura: 1.75
%c char Character (un solo carácter) printf("Letra: %c", 'A'); Letra: A

08 Controlando los Decimales en Pantalla: %f vs %.2f

Por defecto, cuando usás %f a secas en printf, C muestra siempre 6 dígitos después del punto rellenando con ceros (ej. 1.750000). Para que la salida sea prolija, podemos indicar cuántos decimales mostrar:

precision_float.c Formato de Salida
float altura = 1.75; printf("Con %%f : %f\n", altura); printf("Con %%.2f : %.2f\n", altura); printf("Con %%.1f : %.1f\n", altura);
Salida en Consola stdout
$ ./precision_float Con %f : 1.750000 Con %.2f : 1.75 Con %.1f : 1.8

📌 Regla clave: Escribir %.2f en printf solo cambia cómo se dibuja el número en la pantalla; la variable altura en la memoria RAM sigue conservando su valor original intacto.

09 Mostrar Varias Variables en un Mismo printf()

Podemos colocar varios comodines (%d, %.2f, %c) adentro del mismo texto. C los irá completando en estricto orden de izquierda a derecha con las variables que listemos después de las comillas:

multiples_variables.c Orden 1 a 1
int edad = 16; float altura = 1.75; char letra = 'A'; // 1° hueco (%d) 2° hueco (%.2f) 3° hueco (%c) 1° 2° 3° printf("Edad: %d | Altura: %.2f | Curso: %c\n", edad, altura, letra);
Salida en Consola stdout
$ ./multiples_variables Edad: 16 | Altura: 1.75 | Curso: A

⚠️ Si ponés 3 símbolos % adentro del texto, tenés que pasar exactamente 3 variables separadas por comas, y cada una debe coincidir con el tipo de su comodín.

10 2. scanf(): Ingresar Información por Teclado

📖 Apunte (Sección 5): "scanf() → Permite ingresar información. (input)
scanf("%d", &edad);"

lectura_basica.c Del Apunte
int edad; scanf("%d", &edad);

¿Qué pasa cuando el programa llega a scanf?

  1. El programa se detiene (se congela esperando) y el cursor parpadea en la consola.
  2. El usuario escribe un número en el teclado (por ejemplo 16) y presiona la tecla Enter.
  3. scanf toma ese 16, lo guarda dentro de la caja edad y el programa sigue con la línea siguiente.

11 Desglose Pieza por Pieza de scanf("%d", &edad);

Miremos con lupa cada parte de la instrucción del apunte:

scanf ( "%d" , &edad ) ; // 1 2 3 4 5 6
  1. scanf: Función de lectura (scan formatted, escanear con formato).
  2. "%d": Como dice el apunte: "Le indica a scanf que recibirá un entero".
  3. ,: Coma que separa el formato del destino.
  1. & (Ampersand): Operador de dirección de memoria (indica dónde está ubicada la caja).
  2. edad: Nombre de la variable donde se guardará el dato leído.
  3. ;: Cierre de la instrucción.

12 ¿Qué Significa el Símbolo & (Ampersand)?

📖 Explicación del Apunte (Sección 5)

"¿Qué significa el &?
Indica qué variable usaremos (y dónde se almacena esa variable).
Por ahora podemos pensar: Siempre que usemos scanf con variables numéricas debemos colocar &."

🏠 La analogía del repartidor de correo

Imaginá que scanf es un repartidor que tiene en la mano el paquete que el usuario escribió en el teclado y tiene que meterlo adentro de tu casa (la variable edad):

  • edad (sin &): Es solo una foto de lo que hay adentro de la casa. Sirve para printf (mirar), pero no para entregar un paquete.
  • &edad (con &): Es la dirección exacta en la memoria RAM donde vive la caja edad para que scanf pueda abrirla y guardar el dato.
Dirección: &edad (0x7ffe04)
edad int
16

scanf("%d", &edad) viaja hasta &edad y deposita el 16 adentro de la caja.

13 El Dúo Inseparable: Siempre un printf antes del scanf

Si tu programa empieza directamente con scanf("%d", &edad); sin mostrar ningún cartel antes, la pantalla quedará totalmente negra y el usuario pensará que el programa se trabó.

❌ Mal hábito: scanf a ciegas
int edad; scanf("%d", &edad);

La consola queda muda esperando un dato. El usuario no sabe si debe ingresar su edad, su DNI o su altura.

✅ Buen hábito: Pedir con printf y leer con scanf
int edad; printf("Ingrese su edad: "); scanf("%d", &edad);

Primero el programa pregunta amablemente en pantalla y deja el cursor al lado esperando la respuesta.

14 Cómo Leer cada Tipo de Dato con scanf()

Usamos los mismos 3 especificadores del apunte (%d, %f, %c) acompañados siempre por el operador &:

Tipo de Variable Declaración Instrucción de Lectura ¿Qué escribe el usuario en el teclado?
Entero (int) int edad; scanf("%d", &edad); Un entero, ej: 16 + Enter
Decimal (float) float altura; scanf("%f", &altura); Un decimal con punto, ej: 1.75 + Enter
Carácter (char) char letra; scanf(" %c", &letra); Una sola tecla (sin comillas), ej: A + Enter

👀 ¿Viste ese espacio en blanco adelante de " %c" en la última fila? ¡No es un error de tipeo! En la siguiente diapositiva vamos a descubrir por qué ese pequeño espacio nos salva de uno de los dolores de cabeza más famosos de C.

15 El Secreto de " %c": El Problema del Enter Pendiente

Cuando el usuario ingresa su edad (por ejemplo escribe 16 y aprieta Enter), por el cable del teclado viajan 3 cosas al buffer (sala de espera): el '1', el '6' y el salto de línea '\n' de la tecla Enter.

❌ Con "%c" pegado (Se saltea la lectura)
scanf("%d", &edad); // Quedó el '\n' del Enter flotando... scanf("%c", &letra); // ¡Se traga el Enter!

scanf("%d", ...) consume el 16 pero deja el '\n' del Enter en la fila. Como '\n' es un carácter, ¡el scanf("%c", ...) siguiente lo lee al instante sin dejarte escribir la letra!

✅ Con " %c" (Un espacio antes del %)
scanf("%d", &edad); // El espacio en " %c" limpia el Enter previo: scanf(" %c", &letra); // ✅ Espera tu letra

Poner un espacio en blanco antes de %c (es decir, " %c") le ordena a scanf ignorar cualquier Enter o espacio viejo y esperar hasta que presiones una letra real.

16 Cara a Cara: printf() vs scanf()

Compará lado a lado cómo se escriben ambas funciones para no confundirlas jamás en un examen:

Característica printf() — Salida (Output) scanf() — Entrada (Input)
¿Qué hace? Muestra mensajes y valores en la pantalla Lee lo que el usuario escribe en el teclado
¿Lleva el símbolo &? NO (solo lee el valor: edad) SÍ, OBLIGATORIO (necesita la dirección: &edad)
¿Lleva texto decorativo o \n? SÍ (ej: "Su edad es: %d\n") NO (solo el comodín limpio: "%d")
¿Cómo se usa con float? Acepta %f o recortado %.2f Usa únicamente "%f" (nunca %.2f)

23 Error Frecuente #1: Olvidar el & en scanf()

Es el error más peligroso de esta unidad porque muchas veces el código compila igual, pero cuando el usuario ingresa el número y aprieta Enter, el programa explota y se cierra de golpe (Segmentation Fault / Crash):

❌ Peligro mortal: Sin & en scanf
int edad; scanf("%d", edad); // ❌ ¡Falta el &!

¿Por qué explota? Sin el &, scanf no recibe la dirección de la caja edad, sino el valor basura que había adentro, e intenta escribir en un lugar prohibido de la memoria RAM.

✅ Correcto: Siempre con & en variables simples
int edad; scanf("%d", &edad); // ✅ Dirección válida

Recordá la regla del apunte: siempre que usemos scanf con variables numéricas o caracteres debemos colocar &.

24 Error Frecuente #2: Poner & por Error Adentro de printf()

A veces, por acostumbrarse a poner & en scanf, los principiantes también lo ponen en printf. Mirá lo que pasa en la pantalla cuando hacés eso:

❌ Incorrecto: Poner & en printf
int edad = 16; printf("Edad: %d\n", &edad); // ❌ ¡Sobra el &!
Edad: 6422296

En lugar de mostrar 16, ¡muestra un número rarísimo (como 6422296) que es el número de celda de la memoria RAM donde vive la caja!

✅ Correcto: printf va SIN &
int edad = 16; printf("Edad: %d\n", edad); // ✅ Sin &
Edad: 16

A printf solo le interesa el valor guardado adentro de la variable, por eso va el nombre limpio sin &.

25 Error Frecuente #3: Usar el Especificador Equivocado

¿Qué pasa si tenés una variable float pero en el printf o en el scanf ponés %d en lugar de %f?

❌ Incorrecto: %d para un float
float altura = 1.75; printf("Altura: %d\n", altura); // ❌ %d es para int

Resultado: Imprime 0 o un número gigante sin sentido, porque los bits de un float están codificados de forma distinta a los de un int.

✅ Correcto: Cada tipo con su pareja
float altura = 1.75; printf("Altura: %.2f\n", altura); // ✅ %f / %.2f

Verificá siempre la pareja: int ↔ %d, float ↔ %f, char ↔ %c.

26 Error Frecuente #4: Poner Texto, \n o %.2f en scanf()

Adentro de las comillas de scanf() solo debe ir el especificador ("%d", "%f" o " %c"). Nunca pongas mensajes ni saltos de línea ahí adentro:

❌ Incorrecto: Ensuciar el scanf
// ❌ No poner mensajes adentro de scanf: scanf("Edad: %d", &edad); // ❌ No poner \n ni %.2f en scanf: scanf("%.2f\n", &altura);

Si ponés "Edad: %d" en scanf, el usuario estaría obligado a tipear literalmente las letras Edad: antes del número, o la lectura fallará.

✅ Correcto: scanf limpio y puro
// El mensaje va en printf, y el scanf va limpio: printf("Edad: "); scanf("%d", &edad); printf("Altura: "); scanf("%f", &altura);

27 Buenas Prácticas de Entrada y Salida

✅ Mensajes claros para el usuario

  • Indicá qué formato esperás: En lugar de decir solo "Altura: ", escribí "Ingrese su altura en metros (ej 1.75): " para que el usuario no ingrese centímetros ni use coma.
  • Terminá las salidas con \n: Todo printf que muestre un resultado final debe cerrar con \n para que la consola quede ordenada.
  • Usá " %c" por norma: Acostumbrate a poner siempre el espacio delante de %c en scanf(" %c", &variable);.

📐 El molde estándar de lectura

// 1. Declarar la caja int cantidad; // 2. Mostrar mensaje orientador printf("Ingrese la cantidad de unidades: "); // 3. Leer con scanf y & scanf("%d", &cantidad);

31 Qué Pasa en la Computadora de Punta a Punta

Repasemos el circuito completo que recorre un dato desde tu dedo en el teclado hasta el monitor:

1
Reserva en RAM: int edad; crea la cajita en una dirección de memoria (ej. &edad).
2
Pedido en Pantalla (Output): printf("Ingrese edad: "); envía el mensaje hacia el monitor.
3
Lectura de Teclado (Input): scanf("%d", &edad); recibe las teclas, las convierte en un entero y las guarda en la dirección &edad.
4
Respuesta Final (Output): printf("Edad: %d\n", edad); lee el contenido de la cajita y lo muestra en pantalla.

32 Síntesis Visual de la Sección 5 del Apunte

printf() — Mostrar (Output)

Muestra texto o el valor de variables por pantalla. No lleva &.

printf("Hola mundo\n"); printf("Edad: %d\n", edad);

scanf() — Ingresar (Input)

Lee un dato del teclado y lo guarda en la variable. Siempre lleva &.

scanf("%d", &edad); scanf("%f", &altura);

Los 3 Especificadores

  • %d → int (números enteros)
  • %f → float (números con decimales)
  • %c → char (un único carácter)

El Símbolo &

Indica qué variable usaremos y dónde se almacena esa variable en memoria para que scanf pueda depositar el dato ahí adentro.

Ideas Clave que te Llevás Hoy

  • Interacción: printf() saca datos a la pantalla (output) y scanf() entra datos desde el teclado (input).
  • Especificadores: %d para int, %f (o %.2f en salida) para float, y %c para char.
  • El operador &: Va siempre delante de la variable en scanf("%d", &edad); y nunca en printf.
  • Lectura segura de char: Usar un espacio en scanf(" %c", &letra); evita leer el Enter anterior.
