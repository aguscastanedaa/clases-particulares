Condicionales en C: if y else

Cómo enseñarle a un programa a tomar decisiones y elegir distintos caminos según se cumpla o no una condición

02 El Problema: Hasta Hoy Nuestros Programas Eran un Tren sin Desvíos

Todos los programas que escribimos de la Unidad 01 a la 08 tenían ejecución secuencial: empezaban en la primera línea de main() y ejecutaban absolutamente todos los renglones hasta llegar a return 0;.

🚂 Sin condicionales (Un solo camino fijo)
printf("Es mayor\n"); printf("Es menor\n"); // ¡Imprime LOS DOS mensajes siempre!

Sin una estructura de decisión, no podemos elegir mostrar un mensaje y ocultar el otro.

🔀 Con condicionales (Bifurcación inteligente)

Llegamos a una encrucijada en el camino: miramos el dato (por ejemplo, edad) y elegimos un camino u otro, salteando las instrucciones que no correspondan.

03 Definición y Analogía Cotidiana del Apunte

📖 Definición del Apunte (Sección 9 - Página 6)

"Condicionales — Definición: Permiten tomar decisiones."

🌧️ Si llueve (Condición Verdadera)

Si llueve:
    llevo paraguas.

Mirás por la ventana. Como la condición "llueve" se cumple, realizás la acción de agarrar el paraguas.

☀️ Si no llueve (Condición Falsa)

Si no llueve:
    no llevo paraguas.

Mirás por la ventana. Como la condición "llueve" NO se cumple, tomás la decisión alternativa.

💡 La idea central: En nuestra vida diaria tomamos decisiones todo el tiempo usando la palabra "Si...". En lenguaje C, la palabra "Si" se escribe en inglés: if.

04 Sintaxis de if en el Apunte y Desglose Pieza por Pieza

sintaxis_apunte.c Sección 9 del Apunte
if(condicion) { instrucciones; }
1
if: Palabra clave de C (en minúsculas) que significa "Si se cumple que...".
2
(condicion): Entre paréntesis obligatorios va la pregunta (por ejemplo, una comparación edad >= 18).
3
{ instrucciones; }: Las llaves { } encierran la "zona protegida" que solo se ejecuta si la condición dio Verdadero.

⚠️ Observá bien el renglón de if(condicion): ¡NO lleva punto y coma (;) al final del paréntesis! La sentencia recién empieza ahí y continúa adentro de las llaves { }.

05 Ejemplo del Apunte: Condicional if Simple

Veamos el primer ejemplo en código de la Sección 9 (página 7 del apunte) con su explicación exacta:

if_simple_apunte.c Página 7 del Apunte
if(edad >= 18) { printf("Es mayor"); }

📖 Explicación del Apunte

"El if evalúa si el valor que almacena la variable edad es mayor o igual a 18, esta condición devuelve:"

  • True en caso de cumplirse → imprime “Es mayor”
  • False en caso de que no se cumpla → no hace nada (en este caso)

06 Cómo Funciona el if Simple en Ambos Casos

Comparemos qué hace la CPU con if(edad >= 18) { printf("Es mayor"); } según el valor de edad:

Caso A: edad = 20 (Da True / 1)

1
Evalúa 20 >= 18 ➔ Da True (1).
2
La puerta de las llaves { } se abre: entra y ejecuta printf("Es mayor");.
3
Sale por la llave de cierre } y sigue con el resto del programa.

Caso B: edad = 15 (Da False / 0)

1
Evalúa 15 >= 18 ➔ Da False (0).
2
La puerta de las llaves { } queda cerrada: saltea todo el bloque sin ejecutarlo.
3
Salta directamente debajo de la llave } (no imprime nada).

07 Diagrama de Flujo Visual del if Simple

En los diagramas de flujo, toda pregunta de un if se dibuja adentro de un rombo de decisión:

08 Ejemplo Nivel 1: Programa Completo con if Simple

nivel1_if_simple.c Nivel 1 • if Simple
#include <stdio.h> int main() { int edad; printf("Ingrese su edad: "); scanf("%d", &edad); if(edad >= 18) { printf("Es mayor\n"); } printf("Fin del trámite.\n"); return 0; }
Corrida 1 (Ingresa 21 → True)
Ingrese su edad: 21 Es mayor Fin del trámite.
Corrida 2 (Ingresa 14 → False)
Ingrese su edad: 14 Fin del trámite.

📌 Notá la diferencia: La línea printf("Fin del trámite.\n"); está afuera de las llaves del if, por eso se ejecuta siempre en ambas corridas.

09 La Estructura if / else del Apunte

¿Qué pasa si cuando la condición da False no queremos quedarnos callados, sino ejecutar un plan alternativo? ¡Ahí entra el else (que significa "si no")!

if_else_apunte.c Página 7 del Apunte
if(edad >= 18) { printf("Mayor"); } else { printf("Menor"); }

📖 Explicación exacta del Apunte

"Acá entra en juego el “else”, esto se lee:
Si (condición), muestro “mayor”, si no (o sea, si no se cumple) muestro “menor”."

  • True en caso de cumplirse → imprime “Es mayor” / “Mayor”
  • False en caso de que no se cumpla → imprime “Menor”

10 Lectura Coloquial del Apunte: Cómo Pensar el if / else

📖 Frase textual del Apunte (Sección 9 - Página 7)

"Entonces: si pasa esto, hace esto. Si no paso eso, hace esto.
Así se “leería” coloquialmente."

Traducción palabra por palabra

  • "Si pasa esto" ➔ if(edad >= 18)
  • "hace esto" ➔ { printf("Mayor"); }
  • "Si no pasó eso" ➔ else
  • "hace esto otro" ➔ { printf("Menor"); }

Detalle sintáctico clave del else

Observá que else NO lleva paréntesis con condición al lado. ¿Por qué? Porque else significa automáticamente "en cualquier otro caso donde el if de arriba haya dado False".

11 Diagrama de Flujo Visual de if / else

Con if / else hay dos caminos mutuamente excluyentes: siempre se ejecuta uno y solo uno de los dos bloques:

12 Ejemplo Nivel 2: Traza Completa con 16, 18 y 20

nivel2_mayor_menor.c Nivel 2 • if / else
#include <stdio.h> int main() { int edad; printf("Edad: "); scanf("%d", &edad); if(edad >= 18) { printf("Mayor\n"); } else { printf("Menor\n"); } return 0; }
Entrada edad >= 18 Rama elegida Imprime
16 False (0) Entra al else Menor
18 True (1) Entra al if Mayor
20 True (1) Entra al if Mayor

🔑 Ley de exclusión mutua: Es imposible que para una misma ejecución imprima Mayor y Menor a la vez. Si entra al if, ignora el else; si entra al else, fue porque ignoró el if.

13 Varias Instrucciones Adentro de { } (Modificando Variables)

Adentro de las llaves { } de un if o de un else no solo podemos poner un printf(): podemos poner todas las líneas que queramos, incluyendo cuentas e incrementos de la Unidad 07:

bloque_completo.c Cálculos por Rama
int precio = 1000; int edad = 15; if(edad >= 18) { printf("Entrada adulto\n"); precio += 200; // Recargo de $200 } else { printf("Entrada menor con descuento\n"); precio -= 300; // Descuento de $300 }

📦 El rol de las llaves { }: Agrupan varias instrucciones para que funcionen como un solo paquete indivisible. Si la condición es falsa, se saltea el paquete entero.

14 Ejemplo Nivel 3: Decidir si un Número es Par o Impar

Unamos la fórmula de divisibilidad de la Sección 6 del apunte (numero % 2 == 0) con la estructura if / else de la Sección 9:

nivel3_par_impar.c Nivel 3 • Módulo + if/else
#include <stdio.h> int main() { int numero; printf("Ingrese un numero: "); scanf("%d", &numero); if(numero % 2 == 0) { printf("El %d es PAR\n", numero); } else { printf("El %d es IMPAR\n", numero); } return 0; }
Corrida con 20 (del apunte)
Ingrese un numero: 20 El 20 es PAR
Corrida con 7 (del apunte)
Ingrese un numero: 7 El 7 es IMPAR

15 ¿Y si Hay 3 o Más Caminos Posibles? La Cascada else if

Con if / else elegimos entre 2 caminos (ej: Mayor o Menor). Pero en muchos problemas hay 3 o más posibilidades:

Camino 1: Positivo

Si num > 0, el número es positivo.

Camino 2: Negativo

Si no, preguntamos si num < 0 (negativo).

Camino 3: Cero

Si no fue ni mayor ni menor que 0, por descarte es 0.

🪜 Cómo se escribe en C: Usamos else if (segunda_condicion), que se lee literalmente: "Si no se cumplió lo de arriba, entonces preguntá si se cumple esta otra condición...".

16 Sintaxis y Funcionamiento de if / else if / else

cascada_signo.c 3 Caminos Excluyentes
if(num > 0) { printf("Positivo\n"); } else if(num < 0) { printf("Negativo\n"); } else { printf("Es Cero\n"); }
1
Evalúa de arriba hacia abajo. Si num > 0 da True, imprime "Positivo" y saltea todo el resto de la escalera.
2
Solo si el primero dio False, baja a evaluar else if(num < 0).
3
Si todas las preguntas anteriores dieron False, ejecuta el else final por descarte.

17 Cascada else if Aplicada a Notas Escolares

calificaciones.c Escalera de Rangos
if(nota >= 7) { printf("Promocionado\n"); } else if(nota >= 4) { printf("Aprobado\n"); } else { printf("Desaprobado\n"); }
nota 1° nota >= 7 2° nota >= 4 Salida
9 True (entra) No se evalúa Promocionado
6 False True (entra) Aprobado
2 False False (al else) Desaprobado

💡 ¿Por qué cuando nota es 9 no entra también a nota >= 4? Porque al usar else if, apenas entra en la primera rama verdadera salta al final de toda la estructura.

18 Diferencia Crucial: Varios if Sueltos vs else if

Mirá qué ocurre si para int nota = 9; olvidamos escribir la palabra else antes del segundo if:

❌ Con dos if independientes (Entra a los dos)
int nota = 9; if(nota >= 7) { printf("Promociona "); } if(nota >= 4) { printf("Aprueba"); } // ¡Imprime "Promociona Aprueba" porque 9 >= 4 tambien es True!

Como el segundo if no tiene else adelante, se evalúa siempre aunque el primero ya haya entrado.

✅ Con else if conectados (Entra a uno solo)
int nota = 9; if(nota >= 7) { printf("Promociona"); } else if(nota >= 4) { printf("Aprueba"); } // Imprime solo "Promociona" y saltea el else if

El else if solo se pregunta si el if anterior dio False.

19 Condicionales Anidados: Una Decisión Adentro de Otra

A veces queremos hacer una segunda pregunta únicamente si la primera pregunta ya dio Verdadero. A eso lo llamamos anidar condicionales (meter un if adentro de las llaves de otro if):

if_anidado.c if dentro de if
if(edad >= 18) { printf("Es mayor de edad.\n"); if(tieneEntrada == 1) { printf("Puede ingresar al recital.\n"); } else { printf("Le falta comprar la entrada.\n"); } } else { printf("No puede pasar: es menor.\n"); }

¿Cómo se razona un if anidado?

  • 1° Filtro (Puerta exterior): Pregunta edad >= 18. Si tiene 15 años, va directo al else de abajo y ni siquiera le pregunta por la entrada.
  • 2° Filtro (Puerta interior): Si tiene 18 o más, entra al primer bloque y recién ahí evalúa if(tieneEntrada == 1).

20 Integrando Unidad 07 + Unidad 09: Contar Solo si Cumple

En la Unidad 07 aprendimos qué es un contador (cont++;). Cuando lo metemos adentro de un if, obtenemos un contador condicional: ¡solo suma 1 cuando se cumple la condición!

contar_aprobados.c if + Contador ++
int aprobados = 0; int nota1 = 8; int nota2 = 4; if(nota1 >= 6) { aprobados++; // Como 8 >= 6 es True, sube a 1 } if(nota2 >= 6) { aprobados++; // Como 4 >= 6 es False, NO suma }

¿Por qué acá usamos dos if separados?

Porque queremos revisar las dos notas de forma independiente: primero evaluamos si aprobó el examen 1, y después evaluamos si aprobó el examen 2. Al final, aprobados vale 1.

21 Ejemplo Nivel 4: Pensar y Construir una Cajera con Descuento

📋 Enunciado del Problema

Una tienda pide ingresar el monto de una compra. Si el monto es mayor o igual a $10000, se le aplica un descuento de $1500 (usando -=) y se informa que tuvo descuento. Si no llega a $10000, no tiene descuento y se le suman $500 de envío (usando +=). Al final, mostrar el total definitivo a pagar.

1
Identificar la condición: "Mayor o igual a 10000" se escribe monto >= 10000 (incluye el caso borde 10000).
2
Diseñar las 2 ramas: En la rama if restamos con monto -= 1500;. En la rama else sumamos con monto += 500;.

22 Código Completo y Ejecución del Ejemplo Nivel 4

nivel4_tienda.c Nivel 4 • Integrador
#include <stdio.h> int main() { int monto; printf("Ingrese monto de compra: "); scanf("%d", &monto); if(monto >= 10000) { printf("Descuento de $1500 aplicado.\n"); monto -= 1500; } else { printf("Se suma envio de $500.\n"); monto += 500; } printf("Total final a pagar: $%d\n", monto); return 0; }
Corrida 1 (Compra de $12000 → if)
Ingrese monto de compra: 12000 Descuento de $1500 aplicado. Total final a pagar: $10500
Corrida 2 (Compra de $6000 → else)
Ingrese monto de compra: 6000 Se suma envio de $500. Total final a pagar: $6500

23 Patrón Clásico de Examen: Mayor entre Dos Números

Uno de los problemas más tomados en el 1er Bimestre es pedir dos números enteros a y b y decidir cuál es mayor o si son iguales:

mayor_de_dos.c Patrón Fundamental
#include <stdio.h> int main() { int a, b; printf("Ingrese dos numeros: "); scanf("%d %d", &a, &b); if(a > b) { printf("El mayor es %d\n", a); } else if(b > a) { printf("El mayor es %d\n", b); } else { printf("Ambos numeros son iguales (%d)\n", a); } return 0; }

24 Aplicación Protectora: Evitar Dividir por Cero

En matemática y en programación no se puede dividir por 0 (si hacés a / 0 el programa explota). Con un if / else podemos proteger la cuenta:

division_segura.c Validación con != 0
int dividendo = 20; int divisor = 0; if(divisor != 0) { printf("Resultado: %d\n", dividendo / divisor); } else { printf("Error: no se puede dividir por 0.\n"); }

¿Por qué funciona como escudo?

Antes de hacer dividendo / divisor, el if pregunta divisor != 0. Si el usuario ingresó un 0, la condición da False, saltea la división peligrosa y muestra un mensaje amigable en el else.

25 Error Clásico #1: Poner Punto y Coma ; Después de if(...)

Este es el error más famoso al empezar a programar en C. Mirá qué pasa si ponés un ; al final del renglón del if:

❌ El Punto y Coma Asesino: if(edad >= 18);
int edad = 12; if(edad >= 18); // ❌ ¡Este ; termina el if aca mismo! { printf("Es mayor"); // ¡Se imprime aunque tenga 12! }

Por qué falla: Para C, ese ; significa "fin del if (sin hacer nada)". Entonces las llaves de abajo quedan desconectadas del if y se ejecutan siempre.

✅ Sin punto y coma después de la condición
int edad = 12; if(edad >= 18) // ✅ Sin punto y coma { printf("Es mayor"); // Solo se ejecuta si da True }

Regla de oro: Ni if(...), ni else if(...), ni else llevan jamás punto y coma antes de abrir la llave {.

26 Error Clásico #2: Usar un Solo Igual = Adentro del if

❌ Trampa Mortal: if(edad = 18)
int edad = 10; if(edad = 18) // ❌ ¡Guarda 18 en edad y da SIEMPRE True! { printf("Tiene 18"); // ¡Entra siempre aunque tenia 10! }

Por qué entra siempre: En C, cualquier número distinto de 0 se considera Verdadero. Al hacer edad = 18, le asigna 18 y como 18 no es cero, el if lo toma como True siempre.

✅ Comparar con Doble Igual: if(edad == 18)
int edad = 10; if(edad == 18) // ✅ Pregunta si son iguales { printf("Tiene 18"); // Da False (no entra) }

Adentro de los paréntesis del if verificá siempre haber escrito == cuando quieras preguntar igualdad.

27 Errores Clásicos #3 y #4: Condición en else y Olvidar { }

❌ Error #3: Ponerle condición al else
if(edad >= 18) { printf("Mayor"); } else(edad < 18) { // ❌ ¡Error! else NO lleva condicion printf("Menor"); }

Corrección: else va solo: else { ... }. Si necesitás evaluar otra condición, escribí else if(edad < 18).

❌ Error #4: No poner llaves { } con 2 líneas
if(edad >= 18) printf("Es mayor\n"); printf("Puede votar\n"); // ❌ ¡Quedo afuera del if!

Corrección: Sin llaves { }, solo el primer renglón pertenece al if. Poné siempre las llaves { } como enseña el apunte.

28 Buenas Prácticas al Escribir Condicionales

Estilo limpio y profesional

  • Usá llaves { } siempre: incluso si adentro del if hay una sola línea printf("Es mayor");. Te evita errores cuando después agregás más líneas.
  • Indentá (dejá sangría con Tab): todo lo que está adentro de { } se escribe corrido 4 espacios a la derecha para ver de un vistazo qué pertenece al if y qué pertenece al else.

Verificación antes de compilar

  • Cada llave que abre { debe tener su llave que cierra }: contalas siempre en pareja.
  • Probá tu programa con al menos 3 valores: uno que entre al if (ej: 20), uno que entre al else (ej: 15) y el caso borde exacto (ej: 18).

31 Ejercicios de Aplicación (Parte 1: Seguimiento y Diagnóstico)

Ejercicio 1: ¿Qué imprime este código?

Si tenemos int puntos = 5;, luego hacemos puntos += 10; y a continuación:
if(puntos >= 15) { printf("Ganaste"); } else { printf("Perdiste"); }
¿Qué palabra sale por pantalla y por qué?

👁️ Ver respuesta explicada

1. Primero puntos += 10; suma 5 + 10 = 15.
2. El if evalúa 15 >= 15. Como >= incluye la igualdad, devuelve True (1).
3. Entra al bloque del if, imprime Ganaste y saltea el else.

Ejercicio 2: Descubrir los 2 errores ocultos

Encontrá los 2 errores en esta línea: if(clave = 1234); { printf("Acceso concedido"); }

👁️ Ver los 2 errores y la solución

• Error 1: Escribió clave = 1234 (asignación con un solo igual) en vez de clave == 1234.
• Error 2: Puso un punto y coma ; después del paréntesis del if.
• Correcto: if(clave == 1234) { printf("Acceso concedido"); }

32 Ejercicios de Aplicación (Parte 2: Escribir Código en C)

Ejercicio 3: Control de Temperatura con if / else

Escribir un programa completo en C que pida ingresar la temperatura actual (entero) con scanf. Si la temperatura es mayor o igual a 25, debe imprimir "Hace calor"; en caso contrario (else), debe imprimir "Está fresco".

💻 Ver código solución completo en C
#include <stdio.h> int main() { int temp; printf("Ingrese la temperatura: "); scanf("%d", &temp); if(temp >= 25) { printf("Hace calor\n"); } else { printf("Esta fresco\n"); } return 0; }
