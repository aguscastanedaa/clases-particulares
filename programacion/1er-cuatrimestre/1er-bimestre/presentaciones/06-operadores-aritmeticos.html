04 Suma (+), Resta (-) y Multiplicación (*)

📖 Apunte: + → Suma (3 + 5 = 8)  |  - → Resta (3 - 5 = -2)  |  * → Multiplicación (3 * 5 = 15)

operaciones_basicas.c Ejemplos del Apunte
int a = 3; int b = 5; int suma = a + b; // Guarda 8 int resta = a - b; // Guarda -2 int producto = a * b; // Guarda 15

⚠️ ¿Por qué se usa * para multiplicar?

En matemática escribimos $3 \times 5$ o $3 \cdot 5$, pero en programación:

  • Si escribís 3 x 5, C cree que x es el nombre de una variable.
  • Si escribís 3.5 con punto, C sabe que es el número decimal tres coma cinco.
  • Por eso el símbolo universal de multiplicación en C es el asterisco *.

05 El Gran Secreto: La División Entera (/)

📖 Apunte: "/ → División entera (7 / 2 = 3), es decir descarta el resto"

Cuando en C dividís un número entero (int) por otro número entero (int), el resultado es obligatoriamente otro número entero:

division_entera.c int / int
int resultado = 7 / 2; // En matemática: 7 dividido 2 es 3.5 // En C (entre enteros): da 3 (descarta el .5)

🍕 Analogía de las pizzas enteras

Imaginá que tenés 7 cajas cerradas y las querés repartir entre 2 personas sin abrir ni romper ninguna caja: cada persona recibe 3 cajas enteras (cociente entero), y queda 1 caja sin repartir.

06 División Entera (7 / 2) vs División Decimal (7.0 / 2.0)

¿Y qué hacemos cuando sí queremos que $7 \div 2$ nos dé 3.5 con decimales? Para que el operador / calcule los decimales, al menos uno de los dos números debe ser de tipo float (tener punto decimal):

🔢 División Entera (ambos son int)
int cociente = 7 / 2; printf("%d\n", cociente); // Muestra: 3

Tanto 7 como 2 son enteros sin punto. C hace división entera y descarta la parte fraccionaria.

🎯 División con Decimales (usando float)
float exacto = 7.0 / 2.0; printf("%.1f\n", exacto); // Muestra: 3.5

Al escribir 7.0 / 2.0 (o dividir variables float), C activa la división con punto flotante y conserva el .5.

07 El Operador Módulo (%): Lo que Sobra de la División

📖 Apunte (Sección 6): "% → Módulo (Resto de la división, lo que sobra) (7 % 2 = 1)"

¡Ojo con el símbolo! En programación el signo % entre dos números NO calcula porcentajes: calcula el resto de la división entera (como cuando hacías divisiones a mano en la escuela primaria):

División a mano de $7 \div 2$

Buscamos qué número multiplicado por $2$ se acerca a $7$ sin pasarse:

$$7 = 2 \times \underbrace{3}_{\text{Cociente } (7 / 2)} + \underbrace{1}_{\text{Resto } (7 \% 2)}$$

cociente_y_resto.c / vs %
int cociente = 7 / 2; // Vale 3 int resto = 7 % 2; // Vale 1 (lo que sobra)

10 Divisibilidad: ¿Cuándo un Número es Divisible por Otro?

📖 Regla de Divisibilidad del Apunte (Sección 6)

"Si: numero % divisor == 0 entonces el número es divisible."

Veamos los 3 ejemplos textuales del apunte:

✅ Cuando el resto da 0 (SÍ son divisibles)
  • 14 % 7 = 0 → (no hay resto en esta división). Por lo tanto, $14$ es divisible por $7$.
  • 20 % 2 = 0 → (no hay resto en esta división). Por lo tanto, $20$ es divisible por $2$.
❌ Cuando el resto NO es 0 (NO son divisibles)
  • 15 % 7 = 1 → (NO son divisibles, porque hay resto). Al dividir $15$ por $7$ sobra $1$.

💡 Recordá de la Unidad 03: el doble igual == pregunta "¿es igual a?". Así que numero % divisor == 0 pregunta: "¿el resto de dividir numero por divisor es igual a cero?".

11 Aplicación Clásica #1: Números Pares e Impares con % 2

En matemática, un número es par cuando es divisible por $2$ (como $4, 10, 20$). Gracias al operador módulo %, en programación es facilísimo detectar si cualquier número entero es par o impar:

🟢 Número PAR → numero % 2 == 0

Al dividir un número par por $2$, no sobra nada (el resto es 0):

20 % 2 // Da 0 -> 20 es PAR 8 % 2 // Da 0 -> 8 es PAR

🟠 Número IMPAR → numero % 2 == 1

Al dividir un número impar positivo por $2$, siempre sobra 1:

7 % 2 // Da 1 -> 7 es IMPAR 15 % 2 // Da 1 -> 15 es IMPAR

12 Aplicación Clásica #2: Desarmar Dígitos con % 10 y / 10

Otra propiedad mágica de la aritmética entera en base 10 es lo que ocurre cuando dividimos o aplicamos módulo por 10 a cualquier número entero (por ejemplo 148):

numero % 10 → Extrae el último dígito

Como $148 = 10 \times 14 + 8$, el resto de dividir por $10$ es siempre la última cifra de la derecha:

int ultimoDigito = 148 % 10; // Vale 8

numero / 10 → Quita el último dígito

La división entera por $10$ descarta la última cifra y nos deja el resto del número:

int sinUltimo = 148 / 10; // Vale 14

💡 Truco profesional: Este par de operaciones (% 10 y / 10) te servirá durante toda la carrera para separar las cifras de un DNI, una fecha o un código numérico.

13 Jerarquía de Operadores: ¿Qué Cuenta se Hace Primero?

Si en una misma línea combinás varias operaciones, como int x = 3 + 5 * 2;, ¿el resultado es 16 o 13? C respeta estrictamente la separación en términos de la matemática:

Prioridad Operadores Regla de Evaluación
1° (Máxima) ( ) Paréntesis Lo que está entre paréntesis se resuelve siempre primero de todo.
2° (Media) *   /   % Multiplicación, división y módulo tienen la misma prioridad (se evalúan de izquierda a derecha).
3° (Baja) +   - Suma y resta se resuelven al final.
int sinParentesis = 3 + 5 * 2; // Primero hace 5 * 2 (10) y luego suma 3 -> Da 13 int conParentesis = (3 + 5) * 2; // Primero hace (3 + 5) (8) y luego * 2 -> Da 16

14 El Caso Clásico del Promedio: Por Qué Faltan Paréntesis

Imaginá que un alumno sacó un 8 y un 10, y queremos calcular su promedio (que sabemos que tiene que dar 9.0). Mirá qué pasa si olvidamos los paréntesis:

❌ Sin paréntesis: ¡Da 13.0 en vez de 9.0!
float nota1 = 8.0; float nota2 = 10.0; float prom = nota1 + nota2 / 2.0; // Da 13.0 😱

Como la división / tiene más prioridad que la suma +, C divide solo nota2 / 2.0 ($10 / 2 = 5$) y se lo suma a $8$, dando $8 + 5 = 13.0$.

✅ Con paréntesis: Da 9.0 exacto
float nota1 = 8.0; float nota2 = 10.0; float prom = (nota1 + nota2) / 2.0; // Da 9.0 ✅

Los paréntesis obligan a sumar primero (8.0 + 10.0 = 18.0) y recién después dividir ese total por 2.0.

20 Ejemplo Nivel 4: ¿Cómo Pensar un Problema con / y %?

📋 Enunciado Clásico de Examen

Una película dura en total 135 minutos. Escribí un programa que pida la duración total en minutos y calcule a cuántas horas completas y cuántos minutos sueltos equivale (por ejemplo: 135 minutos = 2 horas y 15 minutos).

¿Cómo descubrimos qué operador usar para cada dato?

1. Calcular las horas completas

Sabemos que $1\text{ hora} = 60\text{ minutos}$. Para saber cuántos bloques enteros de $60$ entran en $135$, usamos la división entera:
horas = minutosTotales / 60;
($135 / 60 = \mathbf{2}$ horas completas).

2. Calcular los minutos que sobran

Los minutos que no llegaron a completar otra hora son exactamente el resto de dividir por 60:
minutosRestantes = minutosTotales % 60;
($135 \% 60 = \mathbf{15}$ minutos sobrantes, porque $60 \times 2 = 120$ y al $135$ sobran $15$).

22 Error Frecuente #1: La Trampa de float x = 7 / 2;

Muchos estudiantes piensan: "Como guardé el resultado en una variable float, entonces 7 / 2 me va a dar 3.5". ¡Mirá por qué eso es falso en C!

❌ Trampa clásica: Da 3.00 (pierde el .5)
float mitad = 7 / 2; printf("%.2f\n", mitad); // Imprime: 3.00

¿Por qué pasa? Primero C resuelve la derecha del = sin mirar la izquierda. Como 7 y 2 son enteros, calcula 7 / 2 = 3, y recién después guarda ese 3 como 3.00 en mitad.

✅ Solución: Poner .0 en al menos un número
float mitad = 7.0 / 2; printf("%.2f\n", mitad); // Imprime: 3.50

Al escribir 7.0 / 2 (o 7 / 2.0), la cuenta ya se realiza en modo decimal antes de guardarse en la caja.

23 Error Frecuente #2: Querer Usar Módulo (%) con float

El operador módulo % ("lo que sobra de la división entera") solo existe para números enteros (int). No se puede usar con variables ni números float:

❌ Error de compilación: % con decimales
float a = 7.5; float b = 2.0; float r = a % b; // ❌ Error: invalid operands to %

El compilador rechaza el programa porque en una división con decimales no existe el concepto de "resto entero".

✅ Correcto: Ambos operandos de % deben ser int
int a = 7; int b = 2; int r = a % b; // ✅ Válido: guarda 1

Siempre que necesites usar % (para divisibilidad, paridad o restos), declarálos como int.

24 Error Frecuente #3: La Prohibición de Dividir por Cero (/ 0 o % 0)

Tanto en matemática como en computación, no se puede dividir por cero. Mirá lo que ocurre si el divisor vale 0:

💥 Crash instantáneo: Dividir o hacer módulo por 0
int a = 15 / 0; // 💥 El programa colapsa int b = 15 % 0; // 💥 El programa colapsa

Como % también hace una división interna para hallar el resto, hacer numero % 0 produce exactamente el mismo fallo grave que numero / 0.

✅ Pero 0 arriba (en el numerador) SÍ es válido
int a = 0 / 7; // ✅ Da 0 int b = 0 % 7; // ✅ Da 0

Si tengo 0 caramelos para repartir entre 7 amigos, cada uno recibe 0 y sobran 0. Lo único prohibido es que el número de la derecha sea cero.

25 Error Frecuente #4: Omitir el Símbolo * al Multiplicar

En el pizarrón de matemática solemos escribir $2a$ o $2(x + y)$ sin poner ningún signo en el medio. En C, la multiplicación implícita no existe:

❌ Incorrecto: Pegar números y variables
int base = 10; int altura = 5; // ❌ Error de sintaxis: falta el * int perimetro = 2(base + altura); int doble = 2base;
✅ Correcto: Escribir siempre el asterisco *
int base = 10; int altura = 5; // ✅ El * es obligatorio en toda multiplicación: int perimetro = 2 * (base + altura); int doble = 2 * base;

26 Caso Especial de Examen: ¿Cuánto da 3 % 10?

¿Qué pasa cuando el número de la izquierda es más chico que el divisor de la derecha, por ejemplo 3 / 10 y 3 % 10?

Pensalo con caramelos

Si tenés solo 3 caramelos y querés darle la misma cantidad entera a 10 amigos:

• ¿Cuántos caramelos enteros recibe cada amigo? 0 (no alcanza ni para darle 1 a cada uno). Por eso 3 / 10 = 0.
• ¿Y cuántos caramelos te quedan sin repartir en la mano? ¡Los mismos 3! Por eso 3 % 10 = 3.

menor_que_divisor.c Regla General
int cociente = 3 / 10; // Da 0 int resto = 3 % 10; // Da 3 // Siempre que a < b (positivos): // a / b da 0 // a % b da el mismo 'a'

27 Buenas Prácticas al Escribir Fórmulas en C

✅ Claridad y seguridad en tus cálculos

  • Usá paréntesis ante la duda: Aunque conozcas la jerarquía de operadores, escribir (a * b) + (c * d) hace que tu código sea mucho más fácil de leer sin equivocaciones.
  • Guardá resultados intermedios en variables con buen nombre: En vez de una cuenta gigante en una sola línea, separala en pasos claros (subtotal, descuento, total).
  • Dejá espacios alrededor de los operadores: Escribí a + b * c en vez de a+b*c.

31 El Dúo Dinámico de C: / (Cociente) y % (Resto)

Siempre que tengas un problema de repartir, agrupar o convertir unidades enteras, pensá en esta pareja:

Problema Práctico Con División Entera (/) obtenés... Con Módulo (%) obtenés...
Repartir 15 entre 7 15 / 7 = 2 (cuánto recibe cada uno) 15 % 7 = 1 (cuánto sobra sin repartir)
Pasar 135 min a horas 135 / 60 = 2 (las horas completas) 135 % 60 = 15 (los minutos sobrantes)
Agrupar 29 en docenas 29 / 12 = 2 (las docenas completas) 29 % 12 = 5 (las unidades sueltas)
Analizar el número 148 148 / 10 = 14 (el número sin la última cifra) 148 % 10 = 8 (la última cifra sola)

32 Síntesis Visual de la Sección 6 del Apunte

Operaciones Directas

  • + → Suma: 3 + 5 = 8
  • - → Resta: 3 - 5 = -2
  • * → Multiplicación: 3 * 5 = 15

División Entera y Módulo

  • / → División entera: 7 / 2 = 3 (descarta el resto).
  • % → Módulo (resto): 7 % 2 = 1 y 15 % 7 = 1.

Criterio de Divisibilidad del Apunte

Si numero % divisor == 0, entonces el número es divisible:
• 14 % 7 = 0 (divisible, no hay resto)  |  20 % 2 = 0 (divisible, es par)  |  15 % 7 = 1 (NO es divisible, porque sobra 1).

Ideas Clave que te Llevás Hoy

  • División entre enteros: int / int trunca los decimales (7 / 2 da 3). Para conservar decimales usá 7.0 / 2.0.
  • Operador Módulo %: Calcula lo que sobra en una división entera (solo válido entre int).
  • Divisibilidad: Un número es divisible por otro si y solo si el resto % da exactamente 0.
  • Precedencia: *, / y % se resuelven antes que + y -, salvo que uses paréntesis ( ).
